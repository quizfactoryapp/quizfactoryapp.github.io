問1（衛生管理）

理容所・美容所で使用したはさみを次の客に用いる前に行う消毒として、血液が付着していない場合の扱いで最も適切なものはどれか。

  1. 流水で洗うだけでよい
  2. 乾いた布で拭けば消毒は不要である
  3. 洗浄後、適切な消毒薬や紫外線などで消毒する
  4. 刃先だけを水に浸して保管する
正解と解説を見る

正解：洗浄後、適切な消毒薬や紫外線などで消毒する

血液付着の有無にかかわらず、客ごとに洗浄し、器具に適した方法で消毒してから使用する。

問2（美容理論）

ブラントカットで一直線のカットラインを正確に出すため、最も適切なシザーズの操作はどれか。

  1. 刃を大きく開閉しながらスライドする
  2. パネルを安定させ、刃を毛流れに対して直角に入れる
  3. 毛束を強くねじってから刃先で削る
  4. 根元付近からセニングで量を減らす
正解と解説を見る

正解：パネルを安定させ、刃を毛流れに対して直角に入れる

ブラントカットは切り口をそろえる技法で、パネルの安定と直角のカットが基本である。

問3（香粧品・皮膚科学）

毛髪の主成分であるケラチンについて、最も適切な記述はどれか。

  1. 糖質を主体とし、水に容易に溶ける
  2. 無機塩類のみで構成される線維である
  3. 脂質を主体とし、アルカリで硬化する
  4. 硫黄を含むアミノ酸をもつたんぱく質である
正解と解説を見る

正解：硫黄を含むアミノ酸をもつたんぱく質である

毛髪は硫黄を含むシスチンなどをもつ硬ケラチンが主成分で、強度に関係する。

問4（関係法規）

美容師法における「美容師」として正しいものはどれか。業として美容を行う者に必要な資格の考え方から選べ。

  1. 美容師試験を受けた者をすべていう
  2. 無料で美容行為を行う者は含まれない
  3. 美容所を所有する者だけをいう
  4. 厚生労働大臣の免許を受け、美容を業とする者をいう
正解と解説を見る

正解：厚生労働大臣の免許を受け、美容を業とする者をいう

美容師は厚生労働大臣の免許を受け、美容を業とする者である。有料・無料だけでは判断しない。

問5（衛生管理）

消毒用エタノールを用いる際の説明として、最も適切なものはどれか。

  1. 汚れが付いたまま使用すると効果が増す
  2. 一般に約70〜80％の濃度で消毒効果が高い
  3. 芽胞を完全に死滅させる代表的な方法である
  4. 濃度が高いほど消毒効果は常に強くなる
正解と解説を見る

正解：一般に約70〜80％の濃度で消毒効果が高い

エタノールは適正濃度で効果が高く、汚れや水分を除いてから用いることが重要である。

問6（美容理論）

レイヤーカットで上部の髪を短くし、下部に長さを残す目的として最も適切なものはどれか。

  1. 薬液の酸化を完全に止める
  2. 毛先に段差と動きをつくり、軽さを出す
  3. 頭皮の汚れを取り除きやすくする
  4. すべての毛先を同一線上にそろえる
正解と解説を見る

正解：毛先に段差と動きをつくり、軽さを出す

レイヤーは上部を短くして段をつくるため、軽さや動き、シルエット調整に用いられる。
