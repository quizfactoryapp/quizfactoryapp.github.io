問1（放射線基礎）

電離作用に関する説明として最も適切なものを選べ。X線が物質を通過したときに起こる、原子・分子と電子の関係変化を問う。

  1. 原子核どうしが融合して別の元素へ変化する現象
  2. 放射線の進行方向だけが曲がり、物質状態は変化しない現象
  3. 励起だけが起こり、電荷をもつ粒子は一切生じない現象
  4. 原子・分子から電子が離脱し、正負のイオン対が生成される現象
正解と解説を見る

正解：原子・分子から電子が離脱し、正負のイオン対が生成される現象

電離作用は、放射線が軌道電子へ十分なエネルギーを与え、電子を離脱させてイオン対を作る現象であり、放射線防護の基礎概念である。

問2（エックス線測定）

GM式サーベイメータでエックス線作業場の定期測定を始める前の点検として、最も適切な組合せはどれか。

  1. 高線量率場所で最大レンジ固定のまま直ちに測定する。
  2. 電池確認は不要で、ゼロ調整だけ実施する。
  3. 背景線量率は常に0として記録のみ行う。
  4. 電池確認・ゼロ点確認・既知線源で応答確認を行う。
正解と解説を見る

正解：電池確認・ゼロ点確認・既知線源で応答確認を行う。

測定前は電池、ゼロ点、既知線源での応答確認が基本である。機器異常や感度低下を事前に把握し、誤測定を防げる。

問3（関係法令）

電離則における管理区域の定義として正しいものはどれか。外部放射線と空気中放射性物質による実効線量の合計基準で選べ。

  1. 合計が3月間につき1.3mSvを超えるおそれのある区域
  2. 合計が1年間につき5mSvを超えるおそれのある区域
  3. 合計が1週間につき1mSvを超えるおそれのある区域
  4. 合計が1日につき0.1mSvを超えるおそれのある区域
正解と解説を見る

正解：合計が3月間につき1.3mSvを超えるおそれのある区域

管理区域は、外部放射線と空気中放射性物質による実効線量の合計が3月間1.3mSvを超えるおそれで判定するのが電離則の原則。

問4（放射線基礎）

同じ吸収線量でも生物影響が大きくなりやすい放射線の特徴として正しいものを選べ。線エネルギー付与（LET）の考え方に基づいて判断せよ。

  1. LETが低いほど、常に生物影響は大きくなる
  2. LETが高いほど電離が密に生じ、一般に生物影響は大きい
  3. 放射線の種類が違ってもLETは常に同一である
  4. LETと生物影響の大きさに関連はない
正解と解説を見る

正解：LETが高いほど電離が密に生じ、一般に生物影響は大きい

LETが高い放射線は飛跡周辺に密な電離を起こし、細胞損傷が集中しやすい。そのため同じ吸収線量でも影響が増す傾向がある。

問5（エックス線測定）

GM計数管サーベイメータで高線量率の漏えい線を測定したところ、表示値が頭打ちになり実際より低く出た。主因はどれか。

  1. 不感時間の影響で計数損失が増えるため。
  2. 幾何学効率が上がり過ぎているため。
  3. 窓材の吸収が完全にゼロになるため。
  4. 空気密度変化で電離箱換算が過大になるため。
正解と解説を見る

正解：不感時間の影響で計数損失が増えるため。

GM管は1パルス後の不感時間中に入射した事象を数えられない。高線量率では計数損失が増え、指示値が過小になりやすい。

問6（関係法令）

管理区域への立入りに関する電離則の規定として正しいものはどれか。事業者が講ずべき措置の内容に着目して選べ。

  1. 立入制限は深夜作業時のみ適用される
  2. 事業者は必要のある者以外を管理区域に立ち入らせてはならない
  3. 管理区域では誰でも短時間なら自由に立ち入れる
  4. 管理区域への立入りは作業主任者の口頭許可のみで足りる
正解と解説を見る

正解：事業者は必要のある者以外を管理区域に立ち入らせてはならない

電離則では、管理区域への立入りは必要な者に限定する義務が事業者に課される。時間帯や口頭許可のみで解除できる規定はない。
