司法書士 予想問題の例

問1（不動産登記法）

所有権保存登記の申請適格者に関する次の記述のうち、最も適切なものはどれか。

  1. 抵当権者は、債権保全のため単独で債務者名義の所有権保存登記を申請できる。
  2. 表題部所有者の相続人は、相続を証する情報を提供して自己名義で所有権保存登記を申請できる。
  3. 表題部所有者から売買により所有権を取得した者は、常に自己名義で直接所有権保存登記を申請できる。
  4. 建物の賃借人は、占有を証する情報を提供すれば所有権保存登記を申請できる。
正解と解説を見る

正解：表題部所有者の相続人は、相続を証する情報を提供して自己名義で所有権保存登記を申請できる。

表題部所有者の相続人その他の一般承継人は、承継を証する情報を添付して保存登記を申請できる。

問2（商業登記法）

発起設立による株式会社の設立登記を申請する場合、添付書面として原則必要となるものはどれか。

  1. 合併契約書
  2. 株主総会議事録
  3. 定款
  4. 代表取締役の辞任届
正解と解説を見る

正解：定款

株式会社の設立登記では、会社の根本規則である定款を添付するのが原則である。

問3（民法）

AからBへ甲土地が売却され、その後Aが同一土地をCにも売却した。B・Cの優劣に関する次の記述のうち、正しいものはどれか。

  1. BとCは対抗関係に立ち、原則として先に所有権移転登記を備えた者が優先する。
  2. Cが悪意であれば、登記を備えてもBに対して所有権を対抗できない。
  3. Bが引渡しを受けていれば、登記なくしてCに所有権を対抗できる。
  4. 先に売買契約を締結したBが、登記の有無にかかわらず常にCに優先する。
正解と解説を見る

正解：BとCは対抗関係に立ち、原則として先に所有権移転登記を備えた者が優先する。

不動産の二重譲渡では譲受人相互は対抗関係に立ち、民法177条により先に登記を備えた者が優先する。

問4（訴訟・供託・書士法）

民事訴訟における管轄の合意に関する次の記述のうち、民事訴訟法上正しいものはどれか。

  1. 管轄の合意は、すべての審級についてすることができる。
  2. 管轄の合意は、一定の法律関係に基づく訴えについてしなければならない。
  3. 管轄の合意は、口頭で明確にされていれば足りる。
  4. 専属管轄に反する管轄の合意も、当事者間では常に有効である。
正解と解説を見る

正解：管轄の合意は、一定の法律関係に基づく訴えについてしなければならない。

管轄の合意は第一審に限られ、一定の法律関係に基づく訴えについて書面等でする必要があります。

問5（不動産登記法）

抵当権設定登記の共同申請において、登記義務者に当たる者として正しいものはどれか。

  1. 登記識別情報を通知する登記官
  2. 抵当権の設定を受ける債権者
  3. 抵当権の目的不動産の所有者
  4. 被担保債権の保証人
正解と解説を見る

正解：抵当権の目的不動産の所有者

抵当権設定登記では、権利を失う側である目的不動産の所有者が登記義務者となる。

問6（商業登記法）

募集設立による株式会社の設立登記において、創立総会で選任された取締役の就任承諾を証する書面の添付に関する記述として正しいものはどれか。

  1. 代表取締役についてのみ添付すれば足りる
  2. 常に添付を要しない
  3. 定款に氏名が記載されていれば不要である
  4. 原則として添付を要する
正解と解説を見る

正解：原則として添付を要する

設立時役員の就任承諾は登記事項の真実性を担保するため、原則添付を要する。
