日本語検定 予想問題の例

問1（漢字・語彙）

次の文の（　）に入る漢字として最も適切なものを選びなさい。新しい制度の導入には、関係者の十分な（　）議が必要である。

  1. 競
  2. 共
  3. 供
  4. 協
正解と解説を見る

正解：協

「協議」は話し合って相談すること。「競技」「共議」「供議」はこの文脈では適切ではありません。

問2（文法）

次の文の（　）に入る助詞として最も適切なものを選びなさい。彼は約束の時間（　）三十分も遅れて会場に到着した。

  1. で
  2. に
  3. から
  4. を
正解と解説を見る

正解：から

基準となる時点との差を表す場合は「時間から遅れる」とし、「から」が適切です。

問3（言葉の意味）

次の文の「おもむろに」と最も近い意味で使われている語を選びなさい。彼は資料を読み終えると、おもむろに立ち上がって発言した。

  1. ゆっくりと
  2. 突然に
  3. こっそりと
  4. 急いで
正解と解説を見る

正解：ゆっくりと

「おもむろに」は「落ち着いて、ゆっくりと」の意味です。「急に」という意味ではありません。

問4（読解・表記）

次の文章の要旨として最も適切なものを選びなさい。新しい道具は便利だが、使い方を考えずに頼りすぎると、自分で判断する力が弱まる。

  1. 自分で判断する力は道具で高められる。
  2. 新しい道具は使わないほうがよい。
  3. 便利な道具ほど操作が難しい。
  4. 道具の便利さと付き合い方を考える必要がある。
正解と解説を見る

正解：道具の便利さと付き合い方を考える必要がある。

便利さを否定せず、頼りすぎる危うさを述べているため、付き合い方を考える内容が要旨です。

問5（漢字・語彙）

次の熟語の構成として最も近いものを選びなさい。「読書」は二字の関係から見ると、どの構成に当たりますか。

  1. 下の字が上の字の目的語になるもの
  2. 似た意味の漢字を重ねたもの
  3. 上の字が下の字を修飾するもの
  4. 反対の意味の漢字を重ねたもの
正解と解説を見る

正解：下の字が上の字の目的語になるもの

「読書」は「書を読む」という関係で、下の字「書」が上の字「読」の目的語になります。

問6（文法）

次の文の敬語表現として最も適切なものを選びなさい。部長が会議資料を読むことを、社外の相手に伝える文です。

  1. 部長が資料を読まれさせます。
  2. 部長が資料を拝読します。
  3. 部長が資料をお読みになります。
  4. 部長が資料を読んでいただきます。
正解と解説を見る

正解：部長が資料をお読みになります。

部長の動作を高める尊敬語なので、「お読みになります」が適切です。「拝読」は謙譲語です。
