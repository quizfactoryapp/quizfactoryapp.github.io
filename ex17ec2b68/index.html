問1（栄養と健康）

五大栄養素のうち、体内で主にエネルギー源となり、1gあたり約9kcalを産生するものとして正しいものはどれか。

  1. ビタミン
  2. たんぱく質
  3. 炭水化物
  4. 脂質
正解と解説を見る

正解：脂質

脂質は1gあたり約9kcalを産生し、炭水化物やたんぱく質の約4kcalより高い。

問2（食品学）

食品添加物に関する説明として、最も適切なものはどれか。食品の製造、加工、保存などの目的で使われ、使用できるものは法令で定められている。

  1. 食品添加物は家庭で使う調味料をすべて含む名称である
  2. 天然由来であれば食品添加物として表示する必要はない
  3. 食品添加物は賞味期限を延ばす目的にだけ使用される
  4. 食品添加物は安全性評価や規格基準に基づき使用が認められる
正解と解説を見る

正解：食品添加物は安全性評価や規格基準に基づき使用が認められる

食品添加物は用途や成分規格、使用基準などに基づき管理され、天然由来でも表示対象になり得ます。

問3（食文化）

正月の行事食である「おせち料理」において、黒豆に込められた主な願いとして最も適切なものはどれか。

  1. 腰が曲がるまで長生きすること
  2. 豊かな知識を身につけること
  3. まめに働き、健康に暮らすこと
  4. 子孫が多く繁栄すること
正解と解説を見る

正解：まめに働き、健康に暮らすこと

黒豆の「まめ」は勤勉や健康を意味し、まめに働き元気に暮らす願いが込められる。

問4（食マーケット）

外食産業におけるフランチャイズチェーン方式の特徴として、最も適切なものはどれか。

  1. 本部は商品開発や広告活動に関与しない
  2. 仕入先を店舗ごとに完全自由化することが義務づけられる
  3. 加盟店が本部の商標や運営ノウハウを利用し、対価を支払う
  4. 全店舗を本部が直営し、加盟店は存在しない
正解と解説を見る

正解：加盟店が本部の商標や運営ノウハウを利用し、対価を支払う

フランチャイズは本部が商標やノウハウを提供し、加盟店はロイヤルティなどを支払って営業します。

問5（栄養と健康）

たんぱく質を構成するアミノ酸のうち、体内で十分に合成できず食事から摂取する必要があるものを何というか。

  1. 非必須アミノ酸
  2. 必須アミノ酸
  3. 分岐鎖脂肪酸
  4. 水溶性アミノ酸
正解と解説を見る

正解：必須アミノ酸

必須アミノ酸は体内合成が不十分なため、食品中のたんぱく質から摂取する必要がある。

問6（食品学）

加工食品の原材料表示に関する次の記述のうち、最も適切なものはどれか。原材料名欄では、原材料と添加物を区分して表示することが基本である。

  1. 原材料は製造時の重量割合の高い順に表示されるのが原則である
  2. 添加物は量が少なければ必ず省略できる
  3. 複合原材料は常にすべて一括名だけで表示する
  4. 原材料名は五十音順に表示することが原則である
正解と解説を見る

正解：原材料は製造時の重量割合の高い順に表示されるのが原則である

一般用加工食品では、原材料は重量割合の高い順が基本で、添加物とは区分して表示されます。
