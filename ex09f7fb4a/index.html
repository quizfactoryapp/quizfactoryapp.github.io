整理収納アドバイザー1級一次試験 予想問題の例

問1（整理理論）

整理の基本ステップにおいて、最初に行う作業として最も適切なものはどれか。収納用品を買う前に必要な行動を問う。

  1. 使いやすい収納場所を先に決める
  2. よく使うモノだけを棚に戻す
  3. すべてのモノを出して全体量を把握する
  4. 同じ種類の収納ケースをそろえる
正解と解説を見る

正解：すべてのモノを出して全体量を把握する

整理は現状把握から始まる。全体量を見える化し、要不要の判断へ進むことが基本である。

問2（収納計画）

キッチンで毎朝使う弁当箱と水筒を収納する場所を決める際、動線分析の観点から最も適切な考え方はどれか。

  1. 季節用品と同じ箱に入れ、まとめて保管する
  2. 見た目を優先し、来客から見えない最上段にまとめる
  3. 洗浄後の乾燥場所、詰める作業台、持ち出す出口までの流れに近づける
  4. 使用者に関係なく、同じ素材の容器だけで分類する
正解と解説を見る

正解：洗浄後の乾燥場所、詰める作業台、持ち出す出口までの流れに近づける

動線分析では、使う前後の行動と移動距離を確認し、作業の流れに沿った配置を優先する。

問3（アドバイザー実務）

初回ヒアリングで、顧客が「とにかく全部きれいにしたい」と話した。最初に行う対応として最も適切なものはどれか。

  1. 不要品を一律で半分に減らす目標を示す
  2. 収納用品を多めに購入するよう提案する
  3. 困っている場面や理想の暮らしを具体的に確認する
  4. 作業日を決め、すぐに全室の片づけを始める
正解と解説を見る

正解：困っている場面や理想の暮らしを具体的に確認する

抽象的な要望は、生活上の困りごとや価値観を聞き取り、改善目標を具体化することが重要です。

問4（住生活管理）

家庭内在庫を適正量で管理するため、日用品の「ストック基準」を決める際に最も優先して確認すべきことはどれか。

  1. 見た目がそろう容器へすべて詰め替えること
  2. 同じ種類の商品をできるだけ多くそろえること
  3. 購入店のポイント還元率と特売日の頻度
  4. 家族の使用量、保管場所の容量、補充までの日数
正解と解説を見る

正解：家族の使用量、保管場所の容量、補充までの日数

適正在庫は、消費ペースと収納容量、買い足せるまでの期間から決めると欠品や過剰在庫を防げます。

問5（整理理論）

不必要品を判断する際、「高かったから捨てられない」という考えに最も適した整理上の対応はどれか。

  1. 購入価格ではなく現在の使用状況で判断する
  2. 同じ価格帯のモノをまとめて残す
  3. 高価なモノは必ず別室に保管する
  4. 価格順に並べてから収納場所を決める
正解と解説を見る

正解：購入価格ではなく現在の使用状況で判断する

整理では過去の価格より、現在と今後の暮らしに役立つかを基準に判断することが重要である。

問6（収納計画）

使用頻度分類で「毎日使うが、重くて落下すると危険な物」を収納する位置として最も適切なのはどれか。

  1. 腰から胸の高さの、出し入れしやすい安定した場所
  2. 踏み台が必要な吊り戸棚の最上段
  3. 使用場所から離れた納戸の上段
  4. 床下収納の奥
正解と解説を見る

正解：腰から胸の高さの、出し入れしやすい安定した場所

頻繁に使う重い物は、安全性と出し入れのしやすさを考え、腰から胸の高さに置くのが基本である。
