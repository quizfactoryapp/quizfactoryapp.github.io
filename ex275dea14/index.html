問1（普通計算）

商品の仕入額8,450円に送料3,276円を加え、値引き1,985円を差し引いた支払額はいくらですか。

  1. 9,741円
  2. 9,831円
  3. 10,741円
  4. 9,681円
正解と解説を見る

正解：9,741円

8,450に3,276を加えると11,726。そこから1,985を引くので9,741円です。

問2（ビジネス計算）

定価24,000円の商品を15％引きで販売した。値引き後の販売価格はいくらか。消費税は考えないものとする。

  1. 20,400円
  2. 19,800円
  3. 22,400円
  4. 21,600円
正解と解説を見る

正解：20,400円

15％引きは定価の85％で販売することなので、24,000×0.85＝20,400円となる。

問3（電卓操作）

5,800円、3,260円、4,740円を合計し、その合計から2,500円を差し引く。メモリーキーを使う場合の正しい操作はどれか。

  1. 5800 M+ 3260 M- 4740 M+ 2500 M+ MR
  2. 5800 M- 3260 M- 4740 M- 2500 M+ MR
  3. 5800 M+ 3260 M+ 4740 M- 2500 M- MR
  4. 5800 M+ 3260 M+ 4740 M+ 2500 M- MR
正解と解説を見る

正解：5800 M+ 3260 M+ 4740 M+ 2500 M- MR

加える金額はM+、差し引く金額はM-で記憶させ、最後にMRで記憶合計を呼び出します。

問4（応用計算）

商品を12,000円で販売したところ、原価は7,800円であった。売価に対する原価率は何％か。小数はないものとする。

  1. 60％
  2. 62.5％
  3. 70％
  4. 65％
正解と解説を見る

正解：65％

原価率は原価÷売価×100で求める。7,800÷12,000×100＝65％となる。

問5（普通計算）

見取算として、12,340円、8,765円、9,480円、6,215円、4,900円の合計金額を求めなさい。

  1. 41,170円
  2. 42,700円
  3. 41,700円
  4. 40,700円
正解と解説を見る

正解：41,700円

5つの金額を順に加えると、21,105、30,585、36,800、41,700円となります。

問6（ビジネス計算）

仕入原価3,600円の商品に、原価の25％の利益を見込んで定価をつけた。定価はいくらか。

  1. 4,200円
  2. 4,900円
  3. 4,800円
  4. 4,500円
正解と解説を見る

正解：4,500円

利益は3,600×0.25＝900円。原価に加えるので、3,600＋900＝4,500円となる。
