問1（基本操作）

Excelでセルの内容をコピーした後、元の書式も含めて貼り付けたい場合、どの操作を使うのが正しいですか？

  1. 貼り付けオプションから「元の書式を保持」を選択する
  2. 右クリックして「セルの挿入」を選択する
  3. 貼り付けオプションから「書式を結合して貼り付け」を選択する
  4. 貼り付けオプションから「値のみ」を選択する
正解と解説を見る

正解：貼り付けオプションから「元の書式を保持」を選択する

「元の書式を保持」でコピー元の内容と書式をそのまま貼り付けることができます。

問2（数式・関数）

セル範囲A1からA5の合計を求める数式として正しいものはどれですか？

  1. =ADD(A1:A5)
  2. =TOTAL(A1,A5)
  3. =SUM(A1:A5)
  4. =COUNT(A1:A5)
正解と解説を見る

正解：=SUM(A1:A5)

SUM関数は指定したセル範囲の数値の合計を計算します。

問3（データ管理）

Excelでデータを昇順または降順で並べ替える機能はどれですか？

  1. 条件付き書式
  2. 入力規則
  3. フィルター
  4. 並べ替え
正解と解説を見る

正解：並べ替え

並べ替えはデータを昇順や降順に並べ替え、特定の順序で表示できます。

問4（グラフ・分析）

Excelで棒グラフを作成する際、縦軸に表示されるデータはどの範囲を基に自動で設定されますか？

  1. 列幅の設定値
  2. 行見出しのセル範囲
  3. 選択したデータ系列のセル範囲
  4. グラフタイトルのセル範囲
正解と解説を見る

正解：選択したデータ系列のセル範囲

棒グラフの縦軸は選択したデータ系列の数値範囲を基に自動設定されます。

問5（基本操作）

セルのデータを削除せずに、セルの書式だけを初期状態に戻したい場合、どのメニューから操作しますか？

  1. ホームタブの「クリア」から「書式のクリア」を選ぶ
  2. フォントサイズを手動で小さく変更する
  3. セルを選択してDeleteキーを押す
  4. 右クリックメニューの「削除」を選ぶ
正解と解説を見る

正解：ホームタブの「クリア」から「書式のクリア」を選ぶ

「書式のクリア」を選ぶとセルの内容は残り、書式だけリセットされます。

問6（数式・関数）

セルB1の値が100以上の場合「合格」、そうでなければ「不合格」と表示する正しいIF関数はどれですか？

  1. =IF(B1<100, "合格", "不合格")
  2. =IF(B1>=100, "合格", "不合格")
  3. =IF(B1=100, "合格", "不合格")
  4. =IF(B1>100, "合格", "不合格")
正解と解説を見る

正解：=IF(B1>=100, "合格", "不合格")

IF関数で条件B1>=100を指定すると100以上の場合に「合格」を表示します。
