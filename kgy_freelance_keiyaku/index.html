フリーランス契約実務 練習問題の例

問1（業務委託契約の基礎）

民法上の請負契約について、業務委託契約の基礎知識として最も適切な説明はどれか。

  1. 労働者が使用者の指揮命令下で働くことを目的とする契約である。
  2. 請負人が仕事の完成を約し、注文者が報酬を支払う契約である。
  3. 成果の有無にかかわらず、時間の経過だけで報酬が当然発生する契約である。
  4. 受任者が法律行為を行うこと自体を目的とする契約である。
正解と解説を見る

正解：請負人が仕事の完成を約し、注文者が報酬を支払う契約である。

請負は仕事の完成を目的とする契約で、成果物や完成した仕事に着目して報酬が定められるのが基本です。

問2（契約書のチェック）

フリーランス契約で業務範囲を確認する際、契約書に明確に記載しておくべき事項として最も適切なものはどれか。

  1. 契約と無関係な第三者の取引条件
  2. 受注者の私生活上の予定すべて
  3. 発注者の社内人事評価の基準
  4. 作業内容、成果物、納期、対応範囲などの具体的条件
正解と解説を見る

正解：作業内容、成果物、納期、対応範囲などの具体的条件

業務範囲は作業内容、成果物、納期、対応範囲を明確にし、追加作業との区別を可能にすることが重要です。

問3（報酬と支払）

フリーランス契約で報酬額を定める際、後日の紛争を避けるため契約書に明記する事項として最も基本的なものはどれか。

  1. 報酬額、算定方法、支払時期などを具体的に記載する
  2. 報酬額は口頭で合意すれば契約書には不要である
  3. 報酬は成果物の評判だけで自動的に決まる
  4. 報酬額は発注者が納品後に自由に決められる
正解と解説を見る

正解：報酬額、算定方法、支払時期などを具体的に記載する

報酬額や算定方法、支払時期を明確にすることが契約実務の基本で、未払い防止にも役立つ。

問4（フリーランス新法・下請法）

フリーランス・事業者間取引適正化等法の基本的な目的として、制度上最も適切なものはどれか。

  1. 事業者間取引の適正化と、フリーランスが安定して働ける環境整備を図ること
  2. 発注事業者の利益を優先し、契約条件の自由な変更を認めること
  3. 個人事業主の所得税額を一律に軽減すること
  4. フリーランスをすべて労働者として扱い、労働契約に一本化すること
正解と解説を見る

正解：事業者間取引の適正化と、フリーランスが安定して働ける環境整備を図ること

同法は取引条件の明示や禁止行為などを通じ、取引適正化と就業環境整備を目的とする。

問5（業務委託契約の基礎）

民法上の委任契約について、制度上の基本的な位置づけとして最も適切なものはどれか。

  1. 必ず成果物の完成を目的とし、完成しなければ契約が成立しない。
  2. 法律行為をすることを相手方に委託し、相手方が承諾する契約である。
  3. 書面を作成しなければ、当事者の合意があっても成立しない。
  4. 雇用契約と同じく、常に発注者の指揮命令に従うことを内容とする。
正解と解説を見る

正解：法律行為をすることを相手方に委託し、相手方が承諾する契約である。

委任は法律行為の処理を委託する契約です。業務の遂行に着目し、請負のような完成義務とは区別されます。

問6（契約書のチェック）

契約書で業務範囲が曖昧な場合に生じやすい一般的なリスクとして、最も適切なものはどれか。

  1. 追加作業や責任範囲をめぐる認識違いが起こりやすい
  2. 報酬の支払いが法律上すべて不要になる
  3. 著作権が必ず発注者に帰属する
  4. 秘密保持義務が自動的に消滅する
正解と解説を見る

正解：追加作業や責任範囲をめぐる認識違いが起こりやすい

業務範囲が不明確だと、どこまでが契約内業務か判断しにくく、追加作業や責任範囲の紛争につながります。
