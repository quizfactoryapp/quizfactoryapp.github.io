消防設備士試験 予想問題の例

問1（消火設備類）

屋内消火栓設備において、消火栓ホースの標準的な長さはどれか。

  1. 20メートル
  2. 15メートル
  3. 10メートル
  4. 25メートル
正解と解説を見る

正解：15メートル

屋内消火栓設備のホース標準長さは15mであり、取り回しやすさを考慮して定められています。

問2（警報設備類）

自動火災報知設備における感知器の主な役割はどれか。

  1. 消火栓の水圧を監視する
  2. 非常口の案内を表示する
  3. 火災の煙や熱を感知して信号を送る
  4. 火災発生時に自動消火を行う
正解と解説を見る

正解：火災の煙や熱を感知して信号を送る

感知器は煙や熱を感知し、火災報知器に信号を送る機器です。

問3（避難設備類）

避難器具のうち、垂直の高さが5mを超える箇所に設置が義務付けられているものはどれか。

  1. 避難はしご
  2. 手すり
  3. 救助袋
  4. 緩降機
正解と解説を見る

正解：緩降機

垂直5mを超える避難経路には、緩降機の設置が法律で義務付けられています。

問4（消防関係法令）

消防法において、消防設備の点検を行う義務がある者は誰ですか？

  1. 消防設備の製造業者
  2. 消防署長
  3. 建物の管理権原を有する者
  4. 消防設備士
正解と解説を見る

正解：建物の管理権原を有する者

消防法では、建物の管理権原を有する者に消防設備の点検義務が課されています。

問5（消火設備類）

屋内消火栓設備の1号消火栓について、ノズル先端で確保すべき放水性能として正しいものはどれか。

  1. 放水圧力0.10MPa以上、放水量80L/min以上
  2. 放水圧力0.17MPa以上、放水量130L/min以上
  3. 放水圧力0.70MPa以上、放水量130L/min以上
  4. 放水圧力0.25MPa以上、放水量260L/min以上
正解と解説を見る

正解：放水圧力0.17MPa以上、放水量130L/min以上

1号消火栓は、同時使用時に各ノズル先端で0.17MPa以上・130L/min以上を確保する。

問6（警報設備類）

ガス漏れ火災警報設備で使用されるガス検知器の検知方式として一般的でないものはどれか。

  1. 半導体式
  2. 音響式
  3. 赤外線吸収式
  4. 触媒式
正解と解説を見る

正解：音響式

音響式はガス検知器の一般的な検知方式ではありません。
