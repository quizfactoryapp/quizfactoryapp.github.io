日本化粧品検定 予想問題の例

問1（皮膚科学）

角層バリア機能について正しいものはどれか。角層細胞と細胞間脂質が関わり、体内の水分保持と外部刺激からの防御に重要である。

  1. 角層細胞と細胞間脂質が水分蒸散を抑える
  2. 皮下脂肪が厚いほど角層バリアは直接強くなる
  3. 汗腺が多い部位では角層バリアは不要になる
  4. 角層は生きた細胞だけで構成され常に分裂する
正解と解説を見る

正解：角層細胞と細胞間脂質が水分蒸散を抑える

角層バリアは角層細胞とセラミドなどの細胞間脂質が支え、経皮水分蒸散を防ぎます。

問2（化粧品成分）

界面活性剤の基本的な性質に関する説明として、最も適切なものはどれか。水となじむ部分と油となじむ部分を併せ持つため、汚れを落とす働きがある。

  1. 紫外線を吸収して熱などのエネルギーに変える
  2. 水にも油にもまったくなじまないため、肌表面に膜を作る
  3. 水となじむ親水基と油となじむ親油基を持ち、乳化や洗浄に関わる
  4. メラニンの生成を抑えることを主目的に配合される
正解と解説を見る

正解：水となじむ親水基と油となじむ親油基を持ち、乳化や洗浄に関わる

界面活性剤は親水基と親油基を持ち、水と油をなじませる乳化や洗浄に利用されます。

問3（メイク・スキンケア）

クレンジング料を選ぶ際、濃いメイクやウォータープルーフのポイントメイクを落とす目的で最も適しているものはどれか。

  1. 専用のポイントメイクリムーバーを先に使う
  2. 乳液を厚く塗ってから洗顔料だけで落とす
  3. 化粧水を含ませたコットンで何度もこする
  4. 洗浄力の穏やかなミルクタイプを全顔に短時間なじませる
正解と解説を見る

正解：専用のポイントメイクリムーバーを先に使う

落ちにくい目元や口元のメイクは、専用リムーバーで先に浮かせると摩擦を減らしやすい。

問4（化粧品関連法規）

薬機法上の「化粧品」に関する説明として、最も適切なものはどれか。人体への作用が緩和で、清潔・美化などを目的とするものを選ぶ。

  1. 人の身体を清潔にし、美化し、魅力を増す等の目的で使用され、作用が緩和なもの
  2. 厚生労働大臣の承認があれば、医薬品と同じ効能を表示できるもの
  3. 疾病の診断、治療または予防を主目的とするもの
  4. 食品として摂取し、肌状態の改善を標ぼうするもの
正解と解説を見る

正解：人の身体を清潔にし、美化し、魅力を増す等の目的で使用され、作用が緩和なもの

化粧品は清潔、美化、魅力増進などを目的とし、人体への作用が緩和なものです。疾病の治療目的は医薬品の領域です。

問5（皮膚科学）

肌のターンオーバーに関する説明として最も適切なものはどれか。表皮の細胞が生まれ、角層となってはがれ落ちる過程を指す。

  1. 真皮のコラーゲンが皮脂に変わる周期である
  2. 表皮細胞が分化し角層として脱落する流れである
  3. 紫外線を浴びると必ず周期が一定に保たれる
  4. 汗が皮脂膜を作るまでの時間だけを意味する
正解と解説を見る

正解：表皮細胞が分化し角層として脱落する流れである

ターンオーバーは基底層で生まれた表皮細胞が分化し、角層となって自然にはがれる流れです。

問6（化粧品成分）

化粧水や美容液に配合される保湿成分のうち、角層の水分を抱え込み、しっとり感を与える代表的な多価アルコールはどれか。

  1. アルブチン
  2. パラベン
  3. グリセリン
  4. 酸化チタン
正解と解説を見る

正解：グリセリン

グリセリンは代表的な保湿成分で、水分を保持して肌の乾燥を防ぐ目的で広く使われます。
