銀行業務検定試験 財務3級 予想問題の例

問1（財務諸表）

貸借対照表において、流動資産に分類されるものとして最も適切なものはどれか。なお、通常1年以内に換金または費用化されるものを前提とする。

  1. 長期貸付金
  2. 建物
  3. 売掛金
  4. 投資有価証券
正解と解説を見る

正解：売掛金

売掛金は営業取引から生じ、通常1年以内に回収されるため流動資産に分類される。

問2（企業分析）

流動資産1,200万円、流動負債800万円の会社について、短期支払能力を見る流動比率として正しいものはどれか。

  1. 66.7％
  2. 100.0％
  3. 150.0％
  4. 200.0％
正解と解説を見る

正解：150.0％

流動比率は流動資産÷流動負債×100で求める。1,200÷800×100＝150％である。

問3（会計・税務基礎）

定額法による減価償却の説明として最も適切なものはどれか。残存価額を考慮せず、取得原価を耐用年数にわたり規則的に費用配分する場合を想定する。

  1. 期首帳簿価額に一定率を乗じて償却費を計算する方法である。
  2. 毎期同額の減価償却費を計上する方法である。
  3. 取得した年度に全額を費用処理する方法である。
  4. 使用量や生産高に応じて償却費を計算する方法である。
正解と解説を見る

正解：毎期同額の減価償却費を計上する方法である。

定額法は取得原価を耐用年数にわたり均等に配分するため、原則として毎期同額の償却費となる。

問4（財務諸表）

損益計算書で、売上総利益を求める計算式として正しいものはどれか。売上高と売上原価のみを用いて判断する。

  1. 経常利益－特別損失
  2. 営業利益＋営業外収益
  3. 売上高－売上原価
  4. 売上高－販売費及び一般管理費
正解と解説を見る

正解：売上高－売上原価

売上総利益は、売上高から売上原価を差し引いて計算する基本的な利益である。

問5（企業分析）

自己資本比率を高める効果が最も直接的に期待できる取引として、適切なものはどれか。

  1. 現金で仕入代金を支払う
  2. 利益を内部留保として蓄積する
  3. 借入金で機械を購入する
  4. 買掛金を手形に振り替える
正解と解説を見る

正解：利益を内部留保として蓄積する

自己資本比率は自己資本÷総資本で見る。利益の内部留保は自己資本を増やし、財務安定性を高める。

問6（会計・税務基礎）

建物附属設備を定率法で償却していた会社が、会計方針に基づき定額法へ変更した。この変更に関する説明として最も適切なものはどれか。

  1. 変更後は過年度の財務諸表を必ずすべて修正再表示する。
  2. 減価償却方法の変更は、常に誤謬の訂正として処理する。
  3. 償却方法は税務上の選択であり、会計処理には影響しない。
  4. 合理的な理由があれば会計方針の変更として扱われる。
正解と解説を見る

正解：合理的な理由があれば会計方針の変更として扱われる。

償却方法の変更は会計方針の変更に該当し、合理的な理由と適切な開示が求められる。
