二級建築士 予想問題の例

問1（建築計画）

共働き夫婦と子ども2人の戸建住宅で、炊事・洗濯・物干しを毎日効率よく行えるようにするための平面計画として、最も適切なのはどれか。

  1. 子ども室と浴室を隣接させ、キッチンは独立して配置する
  2. LDKを2階に置き、洗濯機は1階玄関脇に配置する
  3. 洗面脱衣室を寝室群の最奥に置き、廊下を長く確保する
  4. キッチンと洗面脱衣室・物干し場を近接させ、回遊できる動線とする
正解と解説を見る

正解：キッチンと洗面脱衣室・物干し場を近接させ、回遊できる動線とする

家事関連室を近接させて回遊動線にすると、移動距離と往復回数が減り、炊事・洗濯・干す作業を連続して行いやすくなる。

問2（建築法規）

同一敷地200㎡に、建築面積50㎡の主建築物と30㎡の附属建築物を建てる。この敷地の建ぺい率として正しいものはどれか。

  1. 40％
  2. 45％
  3. 35％
  4. 30％
正解と解説を見る

正解：40％

建ぺい率は同一敷地内の建築面積の合計を敷地面積で除して求める。50㎡＋30㎡＝80㎡なので、80÷200＝40％である。

問3（建築構造・施工）

鉄筋コンクリート造の梁に配置するあばら筋の主な役割として、せん断破壊に着目した場合に最も適切なものはどれか。

  1. 乾燥収縮を主として防止し、たわみをなくすこと
  2. コンクリート表面の仕上がりを平滑にすること
  3. 梁下端のかぶり厚さを大きく確保すること
  4. 斜めひび割れの進展を抑え、せん断耐力を高めること
正解と解説を見る

正解：斜めひび割れの進展を抑え、せん断耐力を高めること

あばら筋は梁に生じる斜めひび割れの進展を抑え、せん断耐力と靱性を確保し、地震時の急激な破壊も防ぎやすくする。

問4（建築計画）

高齢期まで住み続けることを想定した木造2階建て住宅の計画として、将来の身体機能低下に最も配慮したものはどれか。

  1. 寝室・浴室・便所をすべて2階にまとめ、1階はLDKのみにする
  2. 主寝室を2階南端に置き、階段を経由しないと便所へ行けない計画とする
  3. 収納を優先して1階の居室をなくし、来客用和室のみを設ける
  4. 主寝室と便所を1階に配置し、主要生活機能を1階で完結できるようにする
正解と解説を見る

正解：主寝室と便所を1階に配置し、主要生活機能を1階で完結できるようにする

加齢により階段昇降が負担になるため、寝室や便所など主要機能を1階にまとめると、将来の継続居住に有利である。

問5（建築法規）

敷地300㎡が、建ぺい率60％の区域180㎡と建ぺい率80％の区域120㎡にまたがる。この敷地の建ぺい率の限度として正しいものはどれか。

  1. 64％
  2. 72％
  3. 70％
  4. 68％
正解と解説を見る

正解：68％

区域が2以上にわたる場合は加重平均で求める。180×0.6＋120×0.8＝204、204÷300＝0.68より限度は68％となる。

問6（建築構造・施工）

鉄筋コンクリート造の柱に設ける帯筋の効果として、柱の地震時性能に関して最も適切なものはどれか。

  1. 柱の自重を軽くして地震力を小さくすること
  2. 柱の表面ひび割れだけを見えにくくすること
  3. コンクリートを拘束し、主筋の座屈を抑えること
  4. 型枠の取り外しを容易にすること
正解と解説を見る

正解：コンクリートを拘束し、主筋の座屈を抑えること

帯筋は柱コンクリートを横拘束し、圧縮部の崩れや主筋の座屈を抑えて、地震時にも粘り強く変形できる性能を高める。
