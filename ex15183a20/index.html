運行管理者試験（貨物） 予想問題の例

問1（貨物自動車運送事業法）

一般貨物自動車運送事業者が営業所ごとに選任する運行管理者について、法令上正しいものはどれか。

  1. 営業所の車両数にかかわらず、会社全体で1名選任すれば足りる。
  2. 補助者を置けば、運行管理者の選任は不要となる。
  3. 営業所ごとに、保有車両数に応じた数の運行管理者を選任しなければならない。
  4. 運転者全員を運行管理者として選任しなければならない。
正解と解説を見る

正解：営業所ごとに、保有車両数に応じた数の運行管理者を選任しなければならない。

運行管理者は営業所ごとに、配置する事業用自動車の数に応じて必要数を選任する。

問2（道路運送車両法）

事業用貨物自動車を運行の用に供する場合、自動車検査証について道路運送車両法上、正しいものはどれか。

  1. 有効な自動車検査証の交付を受け、車両に備え付けなければならない。
  2. 営業所に保管していれば車両に備え付けなくてもよい。
  3. 運行管理者が確認すれば有効期間満了後も運行できる。
  4. 定期点検記録簿があれば自動車検査証は不要である。
正解と解説を見る

正解：有効な自動車検査証の交付を受け、車両に備え付けなければならない。

検査対象自動車は、有効な自動車検査証の交付を受け、備え付けていなければ運行できません。

問3（道路交通法）

道路標識等により最高速度が指定されていない一般道路を貨物自動車で走行する場合、法定の最高速度として正しいものはどれか。

  1. 時速60キロメートルである。
  2. 車両総重量にかかわらず時速80キロメートルである。
  3. 時速50キロメートルである。
  4. 時速70キロメートルである。
正解と解説を見る

正解：時速60キロメートルである。

標識等による指定がない一般道路では、自動車の法定最高速度は原則として時速60キロメートルである。

問4（運転者指導監督）

貨物自動車運送事業者が、新たに常時選任する運転者を雇い入れた場合、初任診断の受診時期として正しいものはどれか。

  1. 雇入れ後1か月以内であれば、乗務開始後でもよい。
  2. 一般診断を受けていれば、初任診断は常に不要である。
  3. 初めて事業用トラックに乗務する前に受診させる。
  4. 重大事故を起こした後に限り受診させる。
正解と解説を見る

正解：初めて事業用トラックに乗務する前に受診させる。

初任診断は、新たに常時選任する運転者について、原則として初めて乗務する前に受診させる。

問5（貨物自動車運送事業法）

乗務前点呼で運行管理者が確認すべき事項として、法令上適切でないものはどれか。

  1. 疾病、疲労、睡眠不足その他の理由による安全運転への支障を確認する。
  2. 日常点検の実施又はその確認状況について報告を求める。
  3. 運賃の収受額を確認し、不足があれば乗務を禁止する。
  4. 酒気帯びの有無を目視等とアルコール検知器で確認する。
正解と解説を見る

正解：運賃の収受額を確認し、不足があれば乗務を禁止する。

乗務前点呼は安全運行のための確認と指示が中心であり、運賃収受額は確認事項ではない。

問6（道路運送車両法）

自動車検査証の有効期間が満了した事業用貨物自動車を引き続き使用するために必要な手続として正しいものはどれか。

  1. 自動車を提示し、継続検査を受けなければならない。
  2. 運行前点検記録を提出すれば使用できる。
  3. 臨時点検を実施すればそのまま使用できる。
  4. 整備管理者が口頭で承認すれば使用できる。
正解と解説を見る

正解：自動車を提示し、継続検査を受けなければならない。

有効期間満了後も使用する場合は、原則として自動車を提示して継続検査を受ける必要があります。
