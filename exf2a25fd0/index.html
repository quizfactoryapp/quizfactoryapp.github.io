2級建築施工管理技術検定 予想問題の例

問1（建築学等）

鉄筋コンクリート造の梁において、あばら筋を配置する主な目的として最も適当なものはどれか。

  1. 梁の自重を小さくし、曲げ応力度を低減するため
  2. 梁のせん断破壊を防止し、主筋の座屈を拘束するため
  3. コンクリートの乾燥収縮を完全に防止するため
  4. 梁端部のかぶり厚さを小さくするため
正解と解説を見る

正解：梁のせん断破壊を防止し、主筋の座屈を拘束するため

あばら筋は梁に生じるせん断力に抵抗し、主筋の拘束にも有効である。

問2（施工管理法）

ネットワーク工程表に関する記述として、最も適切なものはどれか。クリティカルパスの管理目的を踏まえて選べ。

  1. 工期に直接影響する作業経路を把握できる。
  2. 各作業の出来形数量だけを時系列に示す。
  3. 余裕時間が最も大きい作業の連なりを示す。
  4. 作業員の資格区分を一覧で示す。
正解と解説を見る

正解：工期に直接影響する作業経路を把握できる。

クリティカルパスは余裕時間がない経路で、遅延すると全体工期に影響するため重点管理する。

問3（建築施工）

鉄筋工事において、柱主筋のガス圧接継手を設ける位置として、一般に避けるべき箇所はどれか。

  1. 隣接する継手位置をずらした箇所
  2. 応力の小さい階高中央付近
  3. 施工性を確認できる作業床付近
  4. 梁との取り合い部で応力が大きい箇所
正解と解説を見る

正解：梁との取り合い部で応力が大きい箇所

鉄筋継手は応力の大きい梁端・柱梁接合部付近を避け、同一断面に集中させない。

問4（法規）

建築基準法における建築確認に関する記述として、最も適当なものはどれか。

  1. 確認申請は、施工者が必ず単独で行わなければならない。
  2. 確認済証の交付前でも、仮設でなければ基礎工事を開始できる。
  3. 用途変更では、どのような場合でも建築確認は不要である。
  4. 建築主は、工事着手前に確認済証の交付を受ける必要がある場合がある。
正解と解説を見る

正解：建築主は、工事着手前に確認済証の交付を受ける必要がある場合がある。

一定の建築物では、建築主が工事着手前に建築主事等の確認を受ける必要があります。

問5（建築学等）

木材の含水率に関する記述として、建築材料の性質上、最も適当なものはどれか。

  1. 含水率は木材の耐火性だけに影響し、強度には関係しない
  2. 繊維飽和点以下では、含水率の変化により強度や寸法が変化しやすい
  3. 気乾状態の木材は、含水率が常に0パーセントである
  4. 含水率が高いほど、一般に木材の収縮は終了している
正解と解説を見る

正解：繊維飽和点以下では、含水率の変化により強度や寸法が変化しやすい

繊維飽和点以下では水分変化に伴い収縮や膨張が生じ、強度にも影響する。

問6（施工管理法）

鉄筋コンクリート工事の品質管理において、コンクリート打込み前に確認すべき事項として最も適切なものはどれか。

  1. 型枠内の清掃状況、鉄筋のかぶり厚さ、配筋状態を確認する。
  2. 仕上げ塗装の色むらと光沢を確認する。
  3. 外構植栽の根鉢寸法と散水量を確認する。
  4. 建具の開閉力と気密材の劣化を確認する。
正解と解説を見る

正解：型枠内の清掃状況、鉄筋のかぶり厚さ、配筋状態を確認する。

打込み前は型枠・配筋・かぶり・清掃などを確認し、構造体の品質不良を防止する。
