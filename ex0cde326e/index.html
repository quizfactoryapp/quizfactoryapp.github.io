問1（旅行業法）

第2種旅行業を営もうとする者が受ける登録について、旅行業法上、登録行政庁として正しいものはどれか。

  1. 全国旅行業協会の会長
  2. 観光庁長官のみ
  3. 主たる営業所の所在地を管轄する都道府県知事
  4. 営業所ごとの市町村長
正解と解説を見る

正解：主たる営業所の所在地を管轄する都道府県知事

第2種、第3種、地域限定旅行業の登録は、主たる営業所所在地の都道府県知事が行う。

問2（旅行業約款）

募集型企画旅行契約における「募集型企画旅行」の定義として、標準旅行業約款上、最も適切なものはどれか。

  1. 運送機関が単独で企画し、旅行業者が販売のみを行う旅行
  2. 旅行業者が旅行者の募集のため、あらかじめ旅行計画を作成し実施する旅行
  3. 旅行者の依頼により旅行業者が個別に計画を作成し実施する旅行
  4. 旅行者が自ら旅行計画を作成し、旅行業者が予約だけを代行する旅行
正解と解説を見る

正解：旅行業者が旅行者の募集のため、あらかじめ旅行計画を作成し実施する旅行

募集型企画旅行は、旅行業者が募集のために事前に目的地・日程・代金等を定め実施する旅行です。

問3（国内運賃・料金）

JR旅客営業規則における旅客の年齢区分として、正しいものはどれか。なお、年齢は旅行開始時の満年齢で判断するものとする。

  1. 大人は12歳以上、小児は6歳以上12歳未満、幼児は1歳以上6歳未満である。
  2. 小児は3歳以上12歳未満、幼児は1歳以上3歳未満である。
  3. 小児は小学生に限られ、6歳でも未就学であれば幼児として扱う。
  4. 大人は13歳以上、小児は6歳以上13歳未満、乳児は2歳未満である。
正解と解説を見る

正解：大人は12歳以上、小児は6歳以上12歳未満、幼児は1歳以上6歳未満である。

JRの年齢区分は大人12歳以上、小児6歳以上12歳未満、幼児1歳以上6歳未満、乳児1歳未満である。

問4（国内観光資源）

次の温泉地と所在都道府県の組合せのうち、正しいものはどれか。

  1. 草津温泉－栃木県
  2. 道後温泉－愛媛県
  3. 別府温泉－鹿児島県
  4. 有馬温泉－和歌山県
正解と解説を見る

正解：道後温泉－愛媛県

道後温泉は愛媛県松山市にある古くから知られる温泉地で、日本三古湯の一つにも数えられる。

問5（旅行業法）

旅行業者代理業者の登録に関する次の記述のうち、旅行業法上正しいものはどれか。

  1. 所属旅行業者のために代理して契約を締結する事業である
  2. 第1種旅行業者に限り所属旅行業者となることができる
  3. 営業保証金を主たる営業所の最寄りの供託所に供託する
  4. 登録の有効期間は旅行業者と同じく5年である
正解と解説を見る

正解：所属旅行業者のために代理して契約を締結する事業である

旅行業者代理業者は、所属旅行業者を代理して旅行業務に関する契約締結等を行う者である。

問6（旅行業約款）

受注型企画旅行契約に関する記述として、標準旅行業約款上、正しいものはどれか。

  1. 旅行業者は旅行計画を作成せず、予約手続だけを引き受ける契約である
  2. 旅行者が運送・宿泊機関と直接契約し、旅行業者は一切関与しない旅行である
  3. 旅行業者は旅行者の募集のため、常にあらかじめ旅行代金を広告しなければならない
  4. 旅行業者が旅行者の依頼により旅行計画を作成し、これにより実施する旅行である
正解と解説を見る

正解：旅行業者が旅行者の依頼により旅行計画を作成し、これにより実施する旅行である

受注型企画旅行は、旅行者の依頼を受けて旅行業者が旅行計画を作成し実施する点が特徴です。
