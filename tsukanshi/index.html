通関士 過去問対策・予想問題（無料・全問解説付き）

通関士 合格ドリルは、通関士の出題分野に沿った過去問対策に使えるオリジナル予想問題160問を収録した学習ドリルです。すべての問題に解説が付いているので、間違えた問題もその場で理解できます。ページ上部のWeb版では20問を無料で体験でき、スマホアプリ版では全160問に取り組めます。

通関士 予想問題の例

問1（関税法）

輸入申告において、申告納税方式が適用される貨物について、輸入者が原則として申告すべき事項として最も適切なものはどれか。

  1. 貨物の品名、数量、価格等と関税の納付に関する事項
  2. 輸入後の販売予定先と販売利益のみ
  3. 船会社が発行した船荷証券番号のみ
  4. 輸出国の国内販売価格のみ
正解と解説を見る

正解：貨物の品名、数量、価格等と関税の納付に関する事項

輸入申告では品名、数量、価格等を申告し、申告納税方式の貨物は納税申告も必要です。

問2（関税定率法）

関税定率法上、輸入貨物の課税価格を原則として決定する場合、最も基本となる価格はどれか。

  1. 同種貨物の過去の輸入価格
  2. 税関長が任意に定める標準価格
  3. 現実支払価格に加算要素を加えた取引価格
  4. 輸入申告時の国内卸売価格
正解と解説を見る

正解：現実支払価格に加算要素を加えた取引価格

課税価格は原則として、輸入取引に係る現実支払価格に法定の加算要素を加えた取引価格による。

問3（通関実務）

輸入申告書を作成する際、インボイス価格に含まれていない買手負担の運賃・保険料がある場合、課税価格の取扱いとして正しいものはどれか。

  1. 輸入港到着までの運賃・保険料は常に課税価格から控除する
  2. 買手が負担しても売手に支払わない費用は一切算入しない
  3. 保険料のみ算入し、運賃は申告価格に含めない
  4. 輸入港到着までの運賃・保険料は原則として課税価格に算入する
正解と解説を見る

正解：輸入港到着までの運賃・保険料は原則として課税価格に算入する

課税価格は原則として輸入港到着までの運賃、保険料等を加算して算出するため、買手負担分も確認が必要である。

問4（関係法令）

輸出貿易管理令別表第1の1から15の項に該当する貨物を輸出する場合、原則として必要となる手続はどれか。

  1. 相手国政府の同意書があれば国内許可は不要。
  2. 財務大臣へ事後報告だけを行う。
  3. 経済産業大臣の輸出許可を受ける。
  4. 税関長の輸入許可を受ける。
正解と解説を見る

正解：経済産業大臣の輸出許可を受ける。

リスト規制該当貨物は、仕向地を問わず原則として経済産業大臣の輸出許可が必要である。

問5（関税法）

外国貨物を保税地域から国内に引き取る場合、関税法上、原則として必要となる手続として正しいものはどれか。

  1. 税関長に申告し、必要な検査を経て輸入の許可を受ける
  2. 輸入者が任意に帳簿へ記載すれば足りる
  3. 船長の承認を受ければ税関手続は不要となる
  4. 貨物到着後30日を経過すれば自動的に輸入許可となる
正解と解説を見る

正解：税関長に申告し、必要な検査を経て輸入の許可を受ける

外国貨物を輸入するには、税関長への申告、必要な検査、輸入許可が原則として必要です。

問6（関税定率法）

買手が輸入貨物の生産に無償で提供した金型の費用について、課税価格の計算上の取扱いとして正しいものはどれか。

  1. 売手の帳簿に記載がなければ無視する
  2. 輸入申告後にのみ加算できる
  3. 国内で使用されるため常に控除する
  4. 輸入貨物に関連する限度で加算する
正解と解説を見る

正解：輸入貨物に関連する限度で加算する

買手が無償又は低価で提供した生産用の金型等は、輸入貨物に関連する範囲で加算要素となる。

よくある質問

はい。このページのWeb版では20問を会員登録なしで無料で解けます。スマホアプリ版では全160問を収録しています。

iPhone・Android 向けのアプリがあります。オフラインでも学習できます。
