データベーススペシャリスト 予想問題の例

問1（データモデリング）

ER図における弱エンティティの特徴はどれか。

  1. 必ず複数の属性を持つエンティティを指す
  2. 主キーを単独で持つエンティティである
  3. 単数の属性で一意に識別可能なエンティティである
  4. 他のエンティティへの識別関係を持ち、主キーが部分的に依存する
正解と解説を見る

正解：他のエンティティへの識別関係を持ち、主キーが部分的に依存する

弱エンティティは単独では主キーを持たず、他のエンティティの主キーの一部を利用して識別されるエンティティである。

問2（DB管理）

トランザクションのACID特性のうち、一貫性を保証するのはどれか。

  1. トランザクション完了後もデータベースが整合性制約を満たすこと
  2. トランザクションによる更新が永続的に保存されること
  3. 同時実行されるトランザクションが互いに干渉しないこと
  4. トランザクション中の処理がすべて成功またはすべて失敗すること
正解と解説を見る

正解：トランザクション完了後もデータベースが整合性制約を満たすこと

ACID特性の一貫性は、トランザクション開始前後でデータベースが整合性制約を満たしていることを保証します。

問3（分散・NoSQL）

NoSQLのBASE特性とは何か

  1. BASEは分散トランザクションの同期制御方式の一つである
  2. BASEは強い整合性を保証する概念である
  3. BASEはトランザクションのACID特性の一部である
  4. BASEは基本的に可用性を重視し、最終的に整合性が保たれることを意味する
正解と解説を見る

正解：BASEは基本的に可用性を重視し、最終的に整合性が保たれることを意味する

BASEはACIDに対するNoSQLの特性で、可用性を重視しつつ、最終的に整合性をとる設計思想を表す。

問4（データモデリング）

正規化の第3正規形（3NF）の条件は何か。

  1. すべての非キー属性が他の非キー属性に関数従属していない
  2. すべての属性が主キーに対して多値従属している
  3. 部分関数従属だけを排除すればよい
  4. すべての非キー属性が主キーに対して完全関数従属している
正解と解説を見る

正解：すべての非キー属性が他の非キー属性に関数従属していない

第3正規形は、すべての非キー属性が主キーに対して推移的関数従属しないことを要求する。

問5（DB管理）

2フェーズロック方式の説明として正しいものはどれか。

  1. すべてのロックはトランザクション開始時に取得される
  2. ロックは読み込み時にのみ取得される
  3. ロックを解放してから別のロックを取得できる
  4. ロック取得と解放のフェーズがあり、取得フェーズが完了すると解放のみ行う
正解と解説を見る

正解：ロック取得と解放のフェーズがあり、取得フェーズが完了すると解放のみ行う

2PLは、ロック取得フェーズとロック解放フェーズの2段階で動作し、取得完了後はロックを解放のみ行うため、直列化可能性を保証します。

問6（分散・NoSQL）

CAP定理における3つの特性とは何か？

  1. 一貫性・性能・耐久性
  2. 一貫性・可用性・分断許容性
  3. 可用性・耐久性・スケーラビリティ
  4. 耐久性・分散性・スケーラビリティ
正解と解説を見る

正解：一貫性・可用性・分断許容性

CAP定理は分散システムで同時に満たせない3つの特性を示し、それぞれ一貫性、可用性、分断許容性を指します。
