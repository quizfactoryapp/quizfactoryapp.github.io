行政書士 予想問題の例

問1（憲法）

日本国憲法における「基本的人権」の保障は、どのような性質を持つとされているか？

  1. 国民の義務としてのみ規定されている
  2. 法律によって制限されることはない
  3. 国が必要と認めた場合にのみ保障される
  4. 永久に侵すことができない基本的権利である
正解と解説を見る

正解：永久に侵すことができない基本的権利である

日本国憲法は基本的人権を永久の権利として保障し、国家権力の侵害から守っているため、恒久性が認められている。

問2（行政法）

行政行為において、取消し可能な違法な行政処分を取り消すことができるのは誰か？

  1. 被処分者のみ
  2. 行政庁
  3. 国会
  4. 裁判所のみ
正解と解説を見る

正解：行政庁

行政庁は違法な行政処分を取り消す権限を持ち、裁判所は違法確認や無効確認などを行う。

問3（民法）

民法における意思表示の瑕疵の一つである「錯誤」とは何を指すか。

  1. 意思表示が善意で行われたこと
  2. 表示行為の相手方が誤解していること
  3. 意思表示が法律に反していること
  4. 当事者がその意思表示の内容について誤った認識をしていること
正解と解説を見る

正解：当事者がその意思表示の内容について誤った認識をしていること

錯誤とは、当事者が自己の意思表示の内容について誤った認識をしていることを指します。

問4（商法・一般知識）

株式会社の取締役会設置会社において、取締役の任期は最長何年とされていますか？

  1. 2年
  2. 4年
  3. 10年
  4. 1年
正解と解説を見る

正解：4年

取締役会設置会社の取締役の任期は最長4年とされているため、任期満了後の再任が必要です。

問5（憲法）

日本の国会はどのような構成であり、立法権をどのように担っているか？

  1. 天皇が直接議員を任命する
  2. 地方自治体の代表者だけで構成される
  3. 衆議院と参議院の二院制で立法権を行使する
  4. 単一院制で内閣の指名を受ける
正解と解説を見る

正解：衆議院と参議院の二院制で立法権を行使する

日本国憲法は二院制を採用し、衆議院と参議院が共同して立法権を行使する機関であると規定している。

問6（行政法）

行政手続法における「聴聞」の目的として最も適切なものはどれか？

  1. 処分の公示
  2. 当事者の意見聴取
  3. 証拠調査の代替
  4. 処分の事前通知
正解と解説を見る

正解：当事者の意見聴取

聴聞は当事者の意見を聞き、公正な意思決定を行うために実施される。
