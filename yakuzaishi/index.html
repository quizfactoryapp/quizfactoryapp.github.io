薬剤師 予想問題の例

問1（物理・化学・生物）

アスピリンの構造中で、体内のエステラーゼにより加水分解されやすく、サリチル酸生成に関与する官能基はどれか。

  1. カルボキシ基
  2. フェノール性ヒドロキシ基
  3. 芳香族炭化水素部位
  4. アセチルエステル結合
正解と解説を見る

正解：アセチルエステル結合

アスピリンはアセチルエステル結合が加水分解され、サリチル酸と酢酸を生じる。

問2（薬理）

β1受容体遮断薬の薬理作用として最も適切なのはどれか。心不全や狭心症での有用性に関連する作用を選べ。

  1. 瞳孔括約筋を収縮させる
  2. 胃酸分泌を強く抑制する
  3. 気管支平滑筋を弛緩させる
  4. 心拍数と心収縮力を低下させる
正解と解説を見る

正解：心拍数と心収縮力を低下させる

β1受容体遮断により心拍数と心収縮力が低下し、心筋酸素消費量が減少する。

問3（薬剤）

難溶性弱酸性薬物の経口吸収を改善する製剤設計として、溶出速度を高める目的で最も適切なのはどれか。

  1. 結晶性を高める
  2. 粒子径を大きくする
  3. 疎水性滑沢剤を過量添加する
  4. 微粉化して表面積を増やす
正解と解説を見る

正解：微粉化して表面積を増やす

微粉化は比表面積を増加させ、Noyes-Whitney式に従い溶出速度を高める。

問4（実務）

ワルファリン服用中の患者が、市販の鎮痛薬を希望している。服薬指導として最も適切なのはどれか。

  1. アスピリン含有薬は出血リスクが高まるため、自己判断で使用しないよう説明する
  2. イブプロフェンは抗凝固作用を弱めるため積極的に勧める
  3. 鎮痛薬はすべてワルファリンと相互作用しないと説明する
  4. 痛みがあればワルファリンを一時中止するよう説明する
正解と解説を見る

正解：アスピリン含有薬は出血リスクが高まるため、自己判断で使用しないよう説明する

ワルファリン服用中はNSAIDsやアスピリンで出血リスクが増すため、使用前の相談が重要である。

問5（法規・制度）

薬剤師が処方箋中の用法・用量に疑義を認めた場合の対応として、薬剤師法上もっとも適切なのはどれか。

  1. 薬局開設者の承認があれば調剤できる
  2. 患者の希望を優先してそのまま調剤する
  3. 疑義を確認せず、調剤録に理由を記載する
  4. 処方医等に確認し、疑義が解消してから調剤する
正解と解説を見る

正解：処方医等に確認し、疑義が解消してから調剤する

薬剤師法では処方箋に疑義があるとき、処方医等に確認して解消するまで調剤してはならない。

問6（物理・化学・生物）

弱酸性薬物HAのpKaが4.5である。pH7.5の水溶液中で主に存在する化学種として最も適切なのはどれか。

  1. HA型がほぼ100%
  2. H2A+型が主である
  3. HA型とA-型がほぼ等量
  4. A-型が主である
正解と解説を見る

正解：A-型が主である

pHがpKaより3高いので、Henderson-Hasselbalch式より解離型A-が優勢となる。

よくある質問

薬剤師の問題は無料で解けますか？

はい。このページのWeb版では25問を会員登録なしで無料で解けます。スマホアプリ版では全200問を収録しています。
