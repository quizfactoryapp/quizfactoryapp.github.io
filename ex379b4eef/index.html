問1（貨物自動車運送事業法）

一般貨物自動車運送事業者が、認可を受けた事業計画に定める営業所の位置を変更しようとする場合の手続として正しいものはどれか。

  1. 重要な事業計画の変更として、原則として国土交通大臣の認可を受ける。
  2. 変更後30日以内に社内で記録すれば足りる。
  3. 貨物の種類を変えない限り、届出も認可も不要である。
  4. 運行管理者が承認すれば行政手続は不要である。
正解と解説を見る

正解：重要な事業計画の変更として、原則として国土交通大臣の認可を受ける。

営業所の位置など重要な事業計画の変更は、原則として事前に認可を受ける必要がある。

問2（道路交通法）

高速自動車国道の本線車道を大型貨物自動車で通行する場合、標識等で別の最高速度が指定されていないときの法定最高速度として正しいものはどれか。

  1. 時速90キロメートル
  2. 時速80キロメートル
  3. 時速60キロメートル
  4. 時速100キロメートル
正解と解説を見る

正解：時速90キロメートル

大型貨物自動車等は、令和6年4月1日から高速自動車国道の法定最高速度が時速90キロメートルとされている。

問3（道路運送車両法）

事業用貨物自動車の日常点検について、道路運送車両法令上の取扱いとして正しいものはどれか。

  1. 定期点検を実施した日は省略できる。
  2. 運行後に異常があった場合だけ実施すればよい。
  3. 整備工場でなければ実施してはならない。
  4. 1日1回、その運行の開始前に実施しなければならない。
正解と解説を見る

正解：1日1回、その運行の開始前に実施しなければならない。

事業用自動車の日常点検は、1日1回、運行開始前に行うことが義務付けられている。

問4（運転者労務管理）

トラック運転者の改善基準告示における1か月の拘束時間について、原則として超えてはならない上限はどれか。

  1. 293時間
  2. 268時間
  3. 284時間
  4. 320時間
正解と解説を見る

正解：284時間

現行基準では、トラック運転者の1か月の拘束時間は原則284時間以内とされる。

問5（貨物自動車運送事業法）

一般貨物自動車運送事業の許可を受けた者が、事業用自動車の運行の安全確保のために選任しなければならない者はどれか。

  1. 運行管理者資格者証の交付を受けた者のうちから運行管理者を選任する。
  2. 全運転者の互選により代表運転者を選任する。
  3. 営業所長であれば資格の有無を問わず運行管理者にできる。
  4. 整備管理者だけで足り、運行管理者は任意である。
正解と解説を見る

正解：運行管理者資格者証の交付を受けた者のうちから運行管理者を選任する。

一般貨物自動車運送事業者は、資格者証を有する者から運行管理者を選任する義務がある。

問6（道路交通法）

高速自動車国道をけん引自動車で貨物トレーラをけん引して走行する場合、標識等による指定がないときの法定最高速度として正しいものはどれか。

  1. 時速80キロメートル
  2. 時速90キロメートル
  3. 時速100キロメートル
  4. 時速70キロメートル
正解と解説を見る

正解：時速80キロメートル

トレーラをけん引する自動車の高速自動車国道における法定最高速度は、引上げ後も時速80キロメートルである。
