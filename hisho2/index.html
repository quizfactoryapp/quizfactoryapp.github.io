秘書検定2級 予想問題の例

問1（必要とされる資質）

秘書の基本的な役割として最も適切なものはどれか。

  1. 社内の規則を独自に変更すること
  2. 上司の代わりに意思決定を行うこと
  3. 上司の業務を円滑に進めるための支援を行うこと
  4. 社外の取引先と直接交渉を行うこと
正解と解説を見る

正解：上司の業務を円滑に進めるための支援を行うこと

秘書の役割は上司の業務をスムーズに進める支援を行うことであり、意思決定は上司が行うものです。

問2（職務知識）

秘書がスケジュール管理を行う際、最も重要なことはどれか？

  1. 上司の希望を最優先にして予定を組む
  2. 重要度や緊急度を考慮して調整する
  3. 予定が重複しないように一つずつ順番に入れる
  4. 予定の詳細は全て上司に任せる
正解と解説を見る

正解：重要度や緊急度を考慮して調整する

スケジュール管理は重要度や緊急度を踏まえた調整が必要で、効率よく活動できるよう配慮することが大切です。

問3（一般知識）

企業が利益を出すために提供する財やサービスの価値を高める活動を何というか。

  1. マーケティング
  2. ファイナンス
  3. ロジスティクス
  4. マネジメント
正解と解説を見る

正解：マーケティング

マーケティングは顧客のニーズを把握し、価値ある商品やサービスを提供するための活動です。

問4（マナー・接遇）

電話応対において、お客様からの問い合わせにすぐに答えられない場合、最も適切な対応はどれか。

  1. わからないと言って電話を切る
  2. 担当者に取り次ぐ旨を伝えた後、折り返し連絡する
  3. 保留にして長時間待たせる
  4. 自分の判断で適当に答える
正解と解説を見る

正解：担当者に取り次ぐ旨を伝えた後、折り返し連絡する

電話で即答できない場合は、担当者に取り次ぐか折り返す旨を伝えて対応するのが適切です。

問5（必要とされる資質）

秘書に求められる能力のうち、最も重要でないものはどれか。

  1. 情報収集能力
  2. 時間管理能力
  3. コミュニケーション能力
  4. 高度なプログラミング能力
正解と解説を見る

正解：高度なプログラミング能力

秘書にはコミュニケーションや情報収集、時間管理能力が求められますが、プログラミング能力は必須ではありません。

問6（職務知識）

出張手配で、航空券の予約時に秘書が注意すべき点として最も適切なものはどれか？

  1. 便の遅延情報は考慮しない
  2. 乗り継ぎの回数が多い便を選ぶ
  3. 上司の都合の良い時間帯を優先して予約する
  4. 価格の安さだけを優先する
正解と解説を見る

正解：上司の都合の良い時間帯を優先して予約する

上司のスケジュールや体調を考慮し、利便性の高い時間帯を優先して航空券を予約することが求められます。
