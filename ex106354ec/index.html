秘書検定3級 予想問題の例

問1（必要とされる資質）

上司が不在のとき、取引先を名乗る相手から「進行中の契約内容を少しだけ教えてほしい」と電話があった。秘書として最も適切な対応はどれか。

  1. 急ぎと言われたので口頭で概要を伝える
  2. 相手が取引先なら要点だけ伝える
  3. 社内の担当者名だけなら教える
  4. 上司に確認後、折り返す旨を伝えて内容は答えない
正解と解説を見る

正解：上司に確認後、折り返す旨を伝えて内容は答えない

契約内容は機密情報に当たるため、相手が取引先でも独断で伝えてはならない。確認のうえ正式に対応する姿勢が必要である。

問2（職務知識）

上司が外出中に取引先の部長から電話があり、急ぎではないが本日中に折り返しがほしいと言われた。秘書として最も適切な対応はどれか。

  1. 上司に代わって自分の判断で返答する
  2. 要件・相手名・連絡先・折り返し希望時刻を確認し、上司に正確に伝える
  3. 上司の帰社予定だけを伝え、伝言は受けない
  4. 明日でよいか相手に一方的に変更を求める
正解と解説を見る

正解：要件・相手名・連絡先・折り返し希望時刻を確認し、上司に正確に伝える

上司不在時は、勝手な判断で返答せず、相手の要件や連絡先、希望事項を正確に確認して確実に上司へ伝えるのが基本である。

問3（マナー・技能）

社外から部長の田中を求める電話があり、本人は外出ではなく席を外している。取り次ぎの一次応対として最も適切な言い方はどれか。

  1. 部長の田中はただいま席を外しております
  2. 田中部長はおりません
  3. 田中はいません
  4. 田中様はご不在です
正解と解説を見る

正解：部長の田中はただいま席を外しております

社外への応対では、社内の人間に敬称を重ねず、状況は簡潔に伝える。『部長の田中は席を外しております』が自然である。

問4（必要とされる資質）

退社前、共有スペースの机に顧客名簿と会議資料が置かれたままになっているのを見つけた。秘書として最も望ましい行動はどれか。

  1. 適切に保管し、必要に応じて担当者や上司へ報告する
  2. 自分の担当ではないので触れない
  3. 顧客名簿だけを引き出しに入れて帰る
  4. 明日の朝に片づければよいのでそのままにする
正解と解説を見る

正解：適切に保管し、必要に応じて担当者や上司へ報告する

顧客名簿や会議資料は情報漏えいにつながるため、そのまま放置しない。適切に保管し、必要に応じて担当者や上司へ報告する。

問5（職務知識）

上司の代理として会議出席の可否を先方へ連絡することになった。まだ上司の最終判断を聞いていない場合、秘書の行動として最も適切なのはどれか。

  1. 判断が未確定であることを上司に確認し、確定後に連絡する
  2. 上司は出席すると見込んで先方へ伝える
  3. 先方に上司の私用予定まで説明して保留にする
  4. 返事を遅らせないため欠席として連絡する
正解と解説を見る

正解：判断が未確定であることを上司に確認し、確定後に連絡する

代理で連絡する場合でも、未確定事項を推測で伝えるのは不適切である。まず上司の意思を確認し、確定内容のみを簡潔に伝える。

問6（マナー・技能）

来客応対の報告で、上司に対して『お客様がその件は後で言うとのことでした』を敬語で言い換えるとき、『言う』の尊敬語として正しいものはどれか。

  1. 伺う
  2. 申す
  3. おっしゃる
  4. 申し上げる
正解と解説を見る

正解：おっしゃる

『言う』の尊敬語は『おっしゃる』である。『申す』『申し上げる』は自分側をへりくだる謙譲語なので使い分ける。
