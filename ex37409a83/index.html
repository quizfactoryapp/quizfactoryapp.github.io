医師国家試験 予想問題の例

問1（臨床医学総論）

68歳男性。突然の胸背部痛と左右上肢の血圧差を認める。意識清明で心電図にST上昇はない。初期に最も優先すべき検査はどれか。

  1. 運動負荷心電図
  2. 冠動脈カルシウムスコア
  3. 上部消化管内視鏡
  4. 胸腹部造影CT
正解と解説を見る

正解：胸腹部造影CT

突然の胸背部痛と血圧差は急性大動脈解離を疑う。循環が許せば造影CTで範囲と合併症を評価する。

問2（内科系疾患）

急性心筋梗塞で発症後90分以内の再灌流療法が最も強く推奨される心電図所見はどれか。

  1. 左室肥大所見のみ
  2. 洞性徐脈のみ
  3. ST上昇を伴う新規胸痛
  4. T波平低化のみ
正解と解説を見る

正解：ST上昇を伴う新規胸痛

ST上昇型心筋梗塞では責任冠動脈閉塞が疑われ、速やかなPCIによる再灌流が予後を改善する。

問3（外科系疾患）

交通外傷患者で気道は開通し呼吸数30/分、血圧70/40mmHg、骨盤部痛と不安定性を認める。初期対応で最も優先する処置はどれか。

  1. 尿道カテーテルを直ちに挿入する
  2. 腹部造影CTを先に撮影する
  3. 骨盤創外固定を待機的に予定する
  4. 骨盤をシーツまたはバインダーで固定する
正解と解説を見る

正解：骨盤をシーツまたはバインダーで固定する

不安定型骨盤骨折による出血性ショックでは、初期蘇生と同時に骨盤輪を閉鎖し出血を減らす。

問4（公衆衛生）

ある地域の1年間の新規胃癌患者数を、その期間の平均人口で割って求める疫学指標として正しいのはどれか。

  1. 罹患率
  2. 有病率
  3. 寄与危険割合
  4. 致命率
正解と解説を見る

正解：罹患率

罹患率は一定期間に新たに発生した患者数を対象人口で割る指標で、疾病発生頻度を示す。

問5（臨床医学総論）

24歳女性。発熱、咽頭痛、頸部リンパ節腫脹があり、ペニシリン投与後に全身の紅斑が出現した。最も疑う病原体はどれか。

  1. A群β溶連菌
  2. EBウイルス
  3. 単純ヘルペスウイルス
  4. 肺炎マイコプラズマ
正解と解説を見る

正解：EBウイルス

伝染性単核球症では咽頭炎、リンパ節腫脹を来し、アミノペニシリン投与後に発疹が出やすい。

問6（内科系疾患）

慢性心不全で生命予後改善効果が確立している薬剤として適切なのはどれか。

  1. ACE阻害薬
  2. ループ利尿薬単独
  3. ジギタリス単独
  4. 短時間作用型硝酸薬
正解と解説を見る

正解：ACE阻害薬

ACE阻害薬は心室リモデリングを抑制し、HFrEFの死亡率と入院を減らす基本治療である。
