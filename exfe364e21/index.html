知的財産管理技能検定 予想問題の例

問1（特許・実用新案）

特許法上の「発明」に該当するものとして、最も適切なものはどれか。単なる発見や人為的取り決めとの違いに注意する。

  1. じゃんけん大会の進行方法に関する取り決め
  2. 山中で未知の鉱物を発見したこと自体
  3. 商品の販売価格を決める新しい社内ルール
  4. 自然法則を利用した温度制御装置の技術的思想
正解と解説を見る

正解：自然法則を利用した温度制御装置の技術的思想

発明は自然法則を利用した技術的思想の創作で高度なものをいう。単なる発見や人為的ルールは該当しない。

問2（商標）

商標法3条1項3号にいう「商品の品質を普通に用いられる方法で表示する標章」に該当しやすいものはどれか。

  1. 菓子について「甘い」
  2. 時計について「青い星図形」
  3. 文房具について造語「ペルノア」
  4. 化粧品について「SAKURA WAVE」
正解と解説を見る

正解：菓子について「甘い」

商品の品質を直接表示する語は、自他商品識別力を欠き、原則として登録を受けられない。

問3（著作権）

著作権法上の「著作物」に該当するかを判断する際、最も基本となる要件として正しいものはどれか。

  1. 営利目的で制作され市場に流通していること
  2. 登録手続を経て公示されていること
  3. 思想又は感情を創作的に表現したものであること
  4. 社会的に高い評価を受けていること
正解と解説を見る

正解：思想又は感情を創作的に表現したものであること

著作物性は、思想又は感情の創作的表現であることが中心で、登録や評価は要件ではない。

問4（知財管理）

ライセンス契約で、特許権者が同一範囲について第三者にも実施許諾できる形態として最も適切なものはどれか。

  1. 質権設定契約
  2. 専用実施権
  3. 非独占的通常実施権
  4. 独占的通常実施権
正解と解説を見る

正解：非独占的通常実施権

非独占的通常実施権では、権利者は同じ範囲で複数の者に実施を許諾できる。

問5（特許・実用新案）

ビジネス方法に関する出願が特許法上の発明として扱われ得る場合について、最も適切な説明はどれか。

  1. 契約書の条項を工夫しただけでも、事業上有用なら発明となる
  2. ソフトウェアとハードウェア資源が協働して具体的処理を実現する場合がある
  3. 人の心理を利用するだけの販売手法は、常に発明として保護される
  4. 売上を増やす着想であれば、コンピュータ利用の有無にかかわらず発明となる
正解と解説を見る

正解：ソフトウェアとハードウェア資源が協働して具体的処理を実現する場合がある

ビジネス関連発明でも、情報処理装置等を用いた具体的な技術的処理として把握できる場合は発明該当性が問題となる。

問6（商標）

ありふれた氏である「田中」を、特段の図案化なく清酒に使用する商標として出願した場合の扱いとして最も適切なものはどれか。

  1. 不使用取消審判の対象にならない
  2. ありふれた氏を普通に表示するものとして識別力が否定され得る
  3. 必ず登録され、拒絶理由は生じない
  4. 商標権侵害の問題に限り判断される
正解と解説を見る

正解：ありふれた氏を普通に表示するものとして識別力が否定され得る

ありふれた氏を普通に表示する標章は、3条1項4号により識別力なしと判断され得る。
