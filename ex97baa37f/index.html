商業経済検定試験 予想問題の例

問1（ビジネス基礎）

家計・企業・政府の三つの経済主体に関する説明として、最も適切なものはどれか。

  1. 家計は消費や労働力の提供を行い、企業は財やサービスを生産する主体である。
  2. 政府は利潤の最大化を主な目的として、生産活動だけを行う主体である。
  3. 企業は消費だけを行い、家計は公共サービスを提供する主体である。
  4. 家計は財やサービスを生産し、企業は税金を徴収する主体である。
正解と解説を見る

正解：家計は消費や労働力の提供を行い、企業は財やサービスを生産する主体である。

家計は消費と労働力の提供、企業は生産、政府は公共サービスや再分配を担う。

問2（マーケティング）

市場を年齢、所得、ライフスタイルなどの基準で分け、それぞれに適した製品や販売方法を考える活動を何というか。

  1. 在庫管理
  2. 販売予測
  3. 大量生産
  4. 市場細分化
正解と解説を見る

正解：市場細分化

市場細分化は、顧客の特徴やニーズで市場を分け、標的市場を選ぶための基礎となる考え方である。

問3（経済活動と法）

契約自由の原則に関する説明として最も適切なものはどれか。ただし、強行法規や公序良俗による制限を考慮するものとする。

  1. 一度申し込みをすれば、相手の承諾がなくても契約は成立する
  2. 契約を結ぶ相手方は、行政機関が必ず指定する
  3. 契約は必ず書面で作成しなければ、どのような場合も成立しない
  4. 契約内容は当事者が自由に定められるが、法律上許されない内容は無効となることがある
正解と解説を見る

正解：契約内容は当事者が自由に定められるが、法律上許されない内容は無効となることがある

契約自由の原則は内容や相手方を自由に選べるが、強行法規や公序良俗には反せない。

問4（ビジネス経済）

ある商品の価格が上昇したところ、消費者が購入量を減らした。この関係を需要曲線で表すと、通常どのように説明できるか。

  1. 需要曲線上を左上方向へ移動する
  2. 供給曲線そのものが左へ移動する
  3. 需要曲線そのものが右へ移動する
  4. 需要曲線上を右下方向へ移動する
正解と解説を見る

正解：需要曲線上を左上方向へ移動する

価格上昇による需要量の減少は、需要の変化ではなく同じ需要曲線上の移動として表される。

問5（ビジネス基礎）

卸売業者が流通機構の中で果たす役割として、最も適切なものはどれか。

  1. 消費者に代わって所得税を納め、公共サービスを提供する。
  2. 企業の株主総会を運営し、会社の最高意思決定を行う。
  3. 製造業者から商品を仕入れ、小売業者などへ販売して流通を円滑にする。
  4. 商品の購入後に、消費者が家庭で行う使用方法を決定する。
正解と解説を見る

正解：製造業者から商品を仕入れ、小売業者などへ販売して流通を円滑にする。

卸売業者は生産者と小売業者を結び、仕入れ・保管・配送などを通じて流通を支える。

問6（マーケティング）

新商品の開発で、顧客が商品に求める機能、品質、デザイン、包装などを総合的に決める活動として最も適切なものはどれか。

  1. 商品計画
  2. 物流管理
  3. 価格維持政策
  4. 人的販売
正解と解説を見る

正解：商品計画

商品計画は、顧客ニーズに合う商品内容や品ぞろえ、包装、ブランドなどを計画する活動である。
