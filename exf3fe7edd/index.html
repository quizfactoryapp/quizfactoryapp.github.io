特定化学物質及び四アルキル鉛等作業主任者技能講習 予想問題の例

問1（特定化学物質の有害性）

発がん性物質を取り扱う作業で特に重視すべき考え方として、最も適切なものはどれか。ばく露量が少なくても長期的な健康障害につながるおそれがある。

  1. 皮膚に付着しなければ吸入ばく露は問題にならない
  2. ばく露をできるだけ低く管理し、長期影響を考慮する
  3. 臭気を感じなければ発がんリスクはないと判断する
  4. 短時間作業なら保護具や換気は不要である
正解と解説を見る

正解：ばく露をできるだけ低く管理し、長期影響を考慮する

発がん性物質は低濃度でも反復ばく露でリスクが高まるため、ばく露低減を徹底する。

問2（ばく露防止措置）

特定化学物質を反応槽へ投入する作業で、ばく露防止上もっとも優先して検討すべき設備上の措置はどれか。

  1. 作業時間を短くする手順書を作成する
  2. 発散源を密閉し、必要部を局所排気で捕捉する
  3. 休憩場所を発散源から離して設ける
  4. 作業者に防じんマスクだけを着用させる
正解と解説を見る

正解：発散源を密閉し、必要部を局所排気で捕捉する

ばく露防止は保護具より設備対策が優先され、密閉や局所排気で発散源を制御する。

問3（健康管理）

特定化学物質を取り扱う業務に常時従事する労働者へ行う健康診断として、法令上の基本的な実施時期の組合せはどれか。

  1. 雇入れの1年後と、その後3年以内ごと
  2. 作業主任者が異常を認めた月だけ
  3. 雇入れ又は配置替えの際と、その後6か月以内ごと
  4. 退職時のみ、本人が希望した場合
正解と解説を見る

正解：雇入れ又は配置替えの際と、その後6か月以内ごと

特定化学物質健康診断は、雇入れ・配置替え時と定期に実施するのが基本で、多くは6か月以内ごとである。

問4（特定化学物質障害予防規則）

特定化学物質作業主任者の職務として、作業方法を決定し労働者を指揮する目的として最も適切なものはどれか。

  1. 製品の品質検査を主任者が直接実施すること
  2. 作業時間を延長してばく露状況を確認すること
  3. 作業能率を上げるためだけに手順を簡略化すること
  4. 特定化学物質による労働者の汚染や吸入を防止すること
正解と解説を見る

正解：特定化学物質による労働者の汚染や吸入を防止すること

作業主任者は、汚染・吸入を防ぐため作業方法を決定し、労働者を指揮する職務を負う。

問5（特定化学物質の有害性）

ベンゼンなどの発がん性が問題となる物質について、健康影響の説明として最も適切なものはどれか。慢性影響を中心に判断する必要がある。

  1. 水に溶けにくい物質は吸入しても健康影響を生じない
  2. 長期ばく露により造血器への障害や白血病リスクが問題となる
  3. 皮膚刺激がなければ体内へ吸収されることはない
  4. 主な問題は一時的な眠気だけで、慢性障害はない
正解と解説を見る

正解：長期ばく露により造血器への障害や白血病リスクが問題となる

ベンゼンは造血器障害や白血病との関連が知られ、慢性的な吸入ばく露管理が重要である。

問6（ばく露防止措置）

局所排気装置のフードを設ける場合、捕捉効果を高めるための考え方として適切なものはどれか。

  1. 作業者の呼吸域を通過してから吸引させる
  2. フードは発散源からできるだけ離して広く吸引する
  3. 発散源に近づけ、気流が作業者側へ流れない配置にする
  4. 風量を下げて騒音を抑えることを最優先する
正解と解説を見る

正解：発散源に近づけ、気流が作業者側へ流れない配置にする

フードは発散源近くに置き、汚染気流を作業者の呼吸域へ流さない配置が重要である。
