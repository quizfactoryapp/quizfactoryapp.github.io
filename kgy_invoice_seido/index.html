インボイス制度 予想問題（無料・全問解説付き）

インボイス制度ドリルは、インボイス制度の出題分野に沿ったオリジナル予想問題120問を収録した学習ドリルです。すべての問題に解説が付いているので、間違えた問題もその場で理解できます。ページ上部のWeb版では20問を無料で体験でき、スマホアプリ版では全120問に取り組めます。

インボイス制度の出題分野

  • 制度の概要（30問）
  • 適格請求書の要件（30問）
  • 仕入税額控除（30問）
  • 登録と実務（30問）

インボイス制度 予想問題の例

問1（制度の概要）

インボイス制度において、買手が消費税の仕入税額控除を受けるために、原則として保存が求められる書類はどれですか。

  1. 契約書だけで、請求書や領収書は不要
  2. 適格請求書など、一定事項を記載した請求書等
  3. 支払先の名刺と振込明細のみ
  4. 税務署が個別に発行する控除証明書
正解と解説を見る

正解：適格請求書など、一定事項を記載した請求書等

インボイス制度では、仕入税額控除の要件として適格請求書等の保存が原則とされます。

問2（適格請求書の要件）

適格請求書の基本的な記載事項として、発行事業者に関して制度上必ず記載が求められるものはどれか。

  1. 発行事業者の取引銀行名および口座番号
  2. 発行事業者の氏名または名称および登録番号
  3. 発行事業者の資本金および従業員数
  4. 発行事業者の法人税申告書の受付番号
正解と解説を見る

正解：発行事業者の氏名または名称および登録番号

適格請求書には、発行事業者の氏名または名称と、適格請求書発行事業者の登録番号を記載します。

問3（仕入税額控除）

適格請求書等保存方式における仕入税額控除の基本的な要件として、買手側に求められる保存書類の組合せはどれか。

  1. 帳簿のみを保存すれば、すべての課税仕入れについて控除できる
  2. 領収書のみを保存すれば、帳簿の記載は不要である
  3. 一定事項を記載した帳簿および適格請求書等を保存する
  4. 契約書を保存すれば、請求書等の保存は一切不要である
正解と解説を見る

正解：一定事項を記載した帳簿および適格請求書等を保存する

原則として、帳簿と適格請求書等の保存が仕入税額控除の要件とされます。

問4（登録と実務）

適格請求書発行事業者の登録について、制度上の基本的な位置付けとして正しいものはどれですか。

  1. 登録を受けた事業者は、原則として消費税の課税事業者となる
  2. 登録は法人だけが対象で、個人事業者は対象外である
  3. 登録番号は任意で請求書に記載しなくても効力に影響しない
  4. 免税事業者のままでも登録を受ければ適格請求書を発行できる
正解と解説を見る

正解：登録を受けた事業者は、原則として消費税の課税事業者となる

適格請求書発行事業者は課税事業者として登録され、登録番号などを記載したインボイスを交付します。

問5（制度の概要）

適格請求書発行事業者として登録できる事業者について、制度上の一般的な説明として正しいものはどれですか。

  1. 法人だけが登録でき、個人事業者は登録できない
  2. すべての個人が事業の有無にかかわらず登録できる
  3. 免税事業者でなければ登録できない
  4. 消費税の課税事業者であることが基本となる
正解と解説を見る

正解：消費税の課税事業者であることが基本となる

適格請求書発行事業者の登録は、消費税の課税事業者であることを前提とする制度です。

問6（適格請求書の要件）

適格請求書における取引内容の記載について、軽減税率対象品目を含む場合の一般的な取扱いはどれか。

  1. 軽減税率対象品目はすべて標準税率として記載する
  2. 軽減税率対象品目は適格請求書に記載できない
  3. 軽減税率対象である旨の記載は不要で、品名だけで足りる
  4. 軽減税率対象品目である旨を取引内容に記載する
正解と解説を見る

正解：軽減税率対象品目である旨を取引内容に記載する

取引内容には、軽減税率の対象品目である場合、その旨が分かる記載を行うことが求められます。

よくある質問

インボイス制度の問題は無料で解けますか？

はい。このページのWeb版では20問を会員登録なしで無料で解けます。スマホアプリ版では全120問を収録しています。

収録されているのは本試験の過去問ですか？

実際の試験問題ではなく、インボイス制度の出題分野をもとに作成したオリジナルの予想問題です。

スマホアプリはありますか？

iPhone・Android 向けのアプリがあります。オフラインでも学習できます。
