日本語能力試験 予想問題の例

問1（言語知識（文字・語彙））

次の文の空欄に入る最も適切な言葉を選びなさい。彼は毎日朝早く起きて、＿＿＿＿を続けている。

  1. 運動
  2. 休憩
  3. 会議
  4. 勉強会
正解と解説を見る

正解：運動

文脈から「毎日朝早く起きて続けている」行動なので、「運動」が最も適切です。

問2（言語知識（文法）・読解）

次の文章の文法的誤りを含む文はどれですか？

  1. 昨日、友達と映画を見に行った。
  2. 私たちは図書館で本を読んでいます。
  3. 彼は来るかもしれません。
  4. 私わ新しいカメラを買った。
正解と解説を見る

正解：私わ新しいカメラを買った。

「私わ」は誤りで、正しくは「私は」です。助詞「は」の誤用です。

問3（聴解）

男の人と女の人が駅で話しています。 女の人：映画は何時からですか。 男の人：3時半からです。駅から映画館まで歩いて15分ぐらいかかります。 女の人：今、3時5分ですね。少し急ぎましょう。 男の人：そうですね。切符はもう買ってあります。 二人はこれから何をしますか。

  1. 駅で映画の切符を買います。
  2. 3時5分から映画を見ます。
  3. 映画館まで電車で行きます。
  4. 映画館まで急いで歩きます。
正解と解説を見る

正解：映画館まで急いで歩きます。

映画は3時半開始で、駅から映画館まで徒歩15分。今は3時5分で切符も購入済みなので、急いで映画館へ歩くのが正しいです。

問4（言語知識（文字・語彙））

「疲れる」の意味に最も近い言葉はどれですか。

  1. 笑う
  2. 増える
  3. 喜ぶ
  4. 疲労する
正解と解説を見る

正解：疲労する

「疲労する」は「疲れる」とほぼ同じ意味で、体や心が疲れることを指します。

問5（言語知識（文法）・読解）

次の文の空欄に入る最も適切な表現を選びなさい。 電車が遅れた＿＿＿＿、会議の開始時間には何とか間に合った。

  1. ことから
  2. かわりに
  3. せいで
  4. にもかかわらず
正解と解説を見る

正解：にもかかわらず

「遅れた」という不利な状況に反して間に合ったので、逆接を表す「にもかかわらず」が最も自然です。

問6（言語知識（文字・語彙））

「悲しい」の意味に最も近い言葉はどれですか。

  1. 嬉しい
  2. 楽しい
  3. 元気
  4. 切ない
正解と解説を見る

正解：切ない

「切ない」は「悲しい」と似た感情を表す言葉です。
