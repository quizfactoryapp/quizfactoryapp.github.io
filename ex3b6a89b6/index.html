生命保険一般課程試験 予想問題の例

問1（生命保険基礎）

定期保険の基本的な特徴として、最も適切なものはどれですか。死亡保障の期間と満期時の取扱いに着目してください。

  1. 一生涯の死亡保障があり、満期保険金も受け取れる
  2. 保険期間中に死亡しても保険金は支払われない
  3. 一定期間の死亡保障を目的とし、通常は満期保険金がない
  4. 入院日数に応じて給付金を支払う医療専用の保険である
正解と解説を見る

正解：一定期間の死亡保障を目的とし、通常は満期保険金がない

定期保険は保険期間を定めた死亡保障で、満期時に生存していても通常は満期保険金がありません。

問2（募集コンプライアンス）

生命保険募集人が保険募集を行う際、保険業法上もっとも適切な対応はどれか。

  1. 契約者の理解状況にかかわらず、パンフレットの交付だけで説明を終える。
  2. 申込後であれば、募集時の説明内容を記録する必要はない。
  3. 他社商品との比較では、自社に不利な情報は省略してよい。
  4. 重要事項を説明し、顧客の意向を把握・確認したうえで適切に募集する。
正解と解説を見る

正解：重要事項を説明し、顧客の意向を把握・確認したうえで適切に募集する。

保険募集では重要事項説明、意向把握・確認、適切な情報提供を行うことが求められます。

問3（契約保全）

契約者貸付制度について正しいものはどれですか。解約返戻金のある契約で、契約者が資金を必要とする場合を想定して選んでください。

  1. 保険金額の全額まで無利息で借りられる制度である
  2. 被保険者の健康状態にかかわらず、契約者が解約返戻金の一定範囲内で借りられる制度である
  3. 貸付を受けると、その時点で契約は必ず失効する
  4. 保険料の払込みが完了した契約では一切利用できない
正解と解説を見る

正解：被保険者の健康状態にかかわらず、契約者が解約返戻金の一定範囲内で借りられる制度である

契約者貸付は解約返戻金をもとにした制度で、通常は健康状態の審査を必要とせず、所定範囲内で利用できます。

問4（生命保険基礎）

終身保険について述べた次の記述のうち、最も適切なものはどれですか。保障期間と貯蓄性の性質を考えてください。

  1. 満期時だけ保険金が支払われ、死亡時は支払われない
  2. 保険期間は10年に限られ、更新できない
  3. 病気による入院だけを保障する医療保険である
  4. 死亡保障が一生涯続き、解約返戻金を備える場合が多い
正解と解説を見る

正解：死亡保障が一生涯続き、解約返戻金を備える場合が多い

終身保険は被保険者の死亡時まで保障が続く死亡保険で、長期契約のため解約返戻金を持つことが一般的です。

問5（募集コンプライアンス）

告知義務に関する説明として、もっとも適切なものはどれか。

  1. 告知は保険会社が尋ねた重要事項について、事実を正確に答える義務である。
  2. 過去の病歴は、現在完治していれば告知する必要が一切ない。
  3. 健康診断を受けていれば、申込書の告知欄は空欄でも差し支えない。
  4. 募集人に口頭で伝えれば、告知書に記入しなくても正式な告知となる。
正解と解説を見る

正解：告知は保険会社が尋ねた重要事項について、事実を正確に答える義務である。

告知は質問された事項に事実を正しく記入・回答する義務で、口頭のみでは不十分です。

問6（契約保全）

契約者貸付を受けたまま死亡保険金の支払事由が発生した場合、一般的な取扱いとして正しいものはどれですか。

  1. 貸付金は相続人が別途現金で返済するまで保険金は全額支払われない
  2. 貸付金と利息は死亡保険金から差し引かれる
  3. 貸付を受けた時点で死亡保障は自動的に半額となる
  4. 貸付金は保険会社が免除し、死亡保険金は全額支払われる
正解と解説を見る

正解：貸付金と利息は死亡保険金から差し引かれる

貸付金や利息が残っている場合、保険金や解約返戻金などの支払時に差し引かれるのが一般的です。
