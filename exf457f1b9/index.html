ビジネスマネジャー検定試験 予想問題の例

問1（マネジャーの役割）

組織目標を部門目標に落とし込む際、マネジャーが最も重視すべき対応として適切なものはどれか。

  1. 部門独自の判断で、全社目標とは別の優先順位を決める
  2. 上位方針との整合を確認し、具体的な成果指標と期限を設定する
  3. 達成困難な目標を掲げ、進捗確認は期末にまとめて行う
  4. 部下の負担を避けるため、目標はできるだけ抽象的に示す
正解と解説を見る

正解：上位方針との整合を確認し、具体的な成果指標と期限を設定する

部門目標は組織目標と整合し、測定可能な指標や期限を明確にすることで実行管理しやすくなる。

問2（人材マネジメント）

人事評価制度を運用する際、評価者によるばらつきを抑え、被評価者の納得感を高める施策として最も適切なものはどれか。

  1. 上司の主観を尊重し、基準の統一を避ける
  2. 評価者研修を行い、評価基準と面談方法を共有する
  3. 評価結果を本人に開示せず、処遇だけに反映する
  4. 評価項目を毎月大きく変更し、慣れを防ぐ
正解と解説を見る

正解：評価者研修を行い、評価基準と面談方法を共有する

評価者研修は基準理解をそろえ、評価誤差や説明不足を減らし、公平性と納得感を高める。

問3（業務管理）

PDCAサイクルにおける「Check」の段階で管理者が行うべき活動として、最も適切なものはどれか。

  1. 必要な人員を配置し、計画に沿って業務を実行する
  2. 改善案を現場へ展開し、標準手順として定着させる
  3. 年度方針を踏まえ、部門目標と実行計画を策定する
  4. 目標達成状況を指標で確認し、計画との差異を分析する
正解と解説を見る

正解：目標達成状況を指標で確認し、計画との差異を分析する

Checkは実行結果を測定し、計画との差異や原因を確認する段階である。

問4（経営基礎）

損益計算書において、売上高から売上原価を差し引いて算出され、商品の基本的な収益力を示す利益はどれか。

  1. 経常利益
  2. 当期純利益
  3. 売上総利益
  4. 営業利益
正解と解説を見る

正解：売上総利益

売上総利益は売上高から売上原価を差し引いた利益で、粗利益とも呼ばれます。

問5（マネジャーの役割）

権限委譲を行う目的として、最も適切なものはどれか。

  1. 業務を任せることで意思決定を早め、部下の成長機会をつくるため
  2. 部下の裁量をなくし、細かな指示で業務品質を均一化するため
  3. 重要業務を避け、定型業務だけを部下に集中させるため
  4. マネジャーが責任を完全に免れ、結果責任を部下へ移すため
正解と解説を見る

正解：業務を任せることで意思決定を早め、部下の成長機会をつくるため

権限委譲は裁量と責任範囲を与え、意思決定の迅速化と部下育成を同時に進める管理行動である。

問6（人材マネジメント）

目標管理制度において、期初に設定する目標として最も望ましいものはどれか。

  1. 抽象的で幅広く、達成判断を上司に委ねる目標
  2. 組織方針と連動し、達成水準や期限が明確な目標
  3. 本人の努力だけを示し、成果指標は定めない目標
  4. 前年と同じ内容をそのまま使う目標
正解と解説を見る

正解：組織方針と連動し、達成水準や期限が明確な目標

目標管理では組織方針との整合性、測定可能性、期限、達成水準の明確化が重要である。
