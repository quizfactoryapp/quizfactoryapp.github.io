問1（賃貸住宅管理業務）

賃貸住宅管理業者が、個人の賃貸人と管理受託契約を締結する場合の手続に関する次の記述のうち、最も適切なものはどれか。

  1. 管理受託契約締結時の書面は、契約締結前の重要事項説明書と同一の書面として交付すれば足りる。
  2. 管理受託契約を締結したときは、遅滞なく、契約内容など所定事項を記載した書面を相手方に交付する必要がある。
  3. 契約締結前に重要事項説明を行っていれば、契約締結時の書面交付は省略できる。
  4. 管理受託契約締結時の書面交付は、賃貸人から求められた場合に限り必要となる。
正解と解説を見る

正解：管理受託契約を締結したときは、遅滞なく、契約内容など所定事項を記載した書面を相手方に交付する必要がある。

締結前の重要事項説明と、締結時の書面交付は別の手続である。契約成立後は遅滞なく所定事項を記載した書面を交付する。

問2（賃貸借契約と法令）

借地借家法において、普通借家契約の期間満了後に更新がない場合、借主が引き続き居住することを何と呼ぶか？

  1. 法定更新
  2. 明渡し請求
  3. 契約解除
  4. 賃料減額請求
正解と解説を見る

正解：法定更新

契約期間満了後に借主が引き続き居住した場合、法律上は契約が自動更新されたものとみなされる「法定更新」と呼ばれます。

問3（建物・設備管理）

長期修繕計画における修繕積立金の設定で最も重要な目的はどれか。

  1. 建物の資産価値を最大化するため
  2. 入居者の快適性を向上させるため
  3. 消防設備の点検頻度を減らすため
  4. 修繕工事費用を計画的に準備するため
正解と解説を見る

正解：修繕工事費用を計画的に準備するため

長期修繕計画は、修繕工事の費用を計画的に積み立てて建物の適切な維持管理を行うことが目的です。

問4（賃貸住宅管理業務）

賃貸住宅管理業者の登録制度に関する次の記述のうち、正しいものはどれか。

  1. 管理戸数にかかわらず、賃貸住宅の管理業務を行う者はすべて国土交通大臣の登録を受けなければならない。
  2. 登録を受けた賃貸住宅管理業者は、業務管理者を営業所ごとに置く必要はない。
  3. 賃貸住宅管理業者の登録は、都道府県知事が行い、有効期間は3年である。
  4. 管理戸数が200戸以上で賃貸住宅管理業を営む者は、原則として国土交通大臣の登録を受けなければならない。
正解と解説を見る

正解：管理戸数が200戸以上で賃貸住宅管理業を営む者は、原則として国土交通大臣の登録を受けなければならない。

賃貸住宅管理業法では、管理戸数200戸以上の業者に国土交通大臣登録が義務付けられる。登録制や業務管理者の設置も重要事項である。

問5（賃貸借契約と法令）

賃貸住宅管理業者が宅地建物取引業者と異なり、行うことが禁止されている行為はどれか？

  1. 賃貸借契約の締結支援
  2. 賃貸住宅の管理受託
  3. 賃貸住宅の売買契約の締結代理
  4. 家賃の集金代行
正解と解説を見る

正解：賃貸住宅の売買契約の締結代理

賃貸住宅管理業者は売買契約の締結代理業務はできず、宅地建物取引業者のみ認められています。

問6（建物・設備管理）

建物の共用部における定期的な清掃管理で注意すべき事項はどれか。

  1. 居住者の私物を共用部に置くことを許可する
  2. 共用部の安全性と衛生面を維持する
  3. 共用部の照明は必要最低限に減らす
  4. 清掃は年に1回のみ行う
正解と解説を見る

正解：共用部の安全性と衛生面を維持する

共用部の清掃は安全性と衛生の確保が最重要であり、頻度や方法にも注意が必要です。
