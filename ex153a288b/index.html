不動産キャリアパーソン 予想問題の例

問1（不動産取引の基礎）

宅建業者が宅地建物の売買の媒介を依頼者から受けた場合、媒介契約書に必ず記載しなければならない事項として正しいものはどれか。

  1. 隣接地所有者の家族構成
  2. 依頼者の勤務先および年収
  3. 買主の住宅ローン審査結果
  4. 成約したときの報酬に関する事項
正解と解説を見る

正解：成約したときの報酬に関する事項

媒介契約書には物件表示、価額、媒介契約の種類、有効期間、報酬など法定事項を記載する必要がある。

問2（物件調査）

登記記録の表題部を確認する主な目的として、物件調査で最も適切なものはどれか。

  1. 固定資産税の納税者名を確認するため
  2. 都市計画道路の事業認可日を確認するため
  3. 所在、地番、地目、地積など物理的表示を確認するため
  4. 所有権移転の原因日付だけを確認するため
正解と解説を見る

正解：所在、地番、地目、地積など物理的表示を確認するため

表題部には土地や建物の所在・地番・地目・地積など、物件の表示に関する事項が記録される。

問3（取引実務）

中古マンションの価格査定で、取引事例比較法を用いる際に最も重視すべき取引事例の選び方はどれか。

  1. 近隣地域で時点、規模、品等が類似する成約事例を採用する
  2. 売主の希望価格が高い事例を優先して採用する
  3. 販売中の広告価格だけを成約価格として採用する
  4. 同一沿線であれば築年数や面積が大きく異なっても採用する
正解と解説を見る

正解：近隣地域で時点、規模、品等が類似する成約事例を採用する

取引事例比較法では、近隣性・時点・規模・品等の類似性が高い成約事例を補正して用いる。

問4（顧客対応と法令遵守）

媒介契約の相談時、顧客から取得した本人確認書類の写しを社内共有する場合の対応として最も適切なものはどれか。

  1. 営業効率を優先し、全社員が閲覧できる共有フォルダに保存する
  2. 顧客の同意があれば、目的外利用でも自由に転用できる
  3. 本人確認書類は個人情報に当たらないため特別な管理は不要である
  4. 利用目的と権限を限定し、必要な担当者だけが閲覧できるよう管理する
正解と解説を見る

正解：利用目的と権限を限定し、必要な担当者だけが閲覧できるよう管理する

本人確認書類は個人情報であり、利用目的とアクセス権限を限定して安全に管理する必要がある。

問5（不動産取引の基礎）

専任媒介契約を締結した宅建業者が、指定流通機構へ物件情報を登録しなければならない期限として正しいものはどれか。

  1. 契約締結日から14日以内
  2. 契約締結日から7日以内
  3. 契約締結日から30日以内
  4. 契約締結日から5日以内
正解と解説を見る

正解：契約締結日から7日以内

専任媒介契約では、休業日を除き契約締結日から7日以内に指定流通機構へ登録しなければならない。

問6（物件調査）

土地の登記記録で、抵当権など所有権以外の権利に関する事項が記録される欄はどれか。

  1. 共同担保目録だけ
  2. 権利部甲区
  3. 権利部乙区
  4. 表題部
正解と解説を見る

正解：権利部乙区

権利部乙区には抵当権、地上権、賃借権など、所有権以外の権利に関する事項が記録される。
