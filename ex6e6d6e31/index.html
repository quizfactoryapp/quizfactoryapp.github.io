問1（管工事一般）

受水槽方式の給水設備において、受水槽の有効容量を計画する際の考え方として、最も適切なものはどれか。

  1. 高置水槽がある場合、受水槽容量は任意に定めてよい。
  2. 時間変動と補給能力を考慮し、過大容量による滞留を避ける。
  3. 常に1日最大使用水量の全量以上とする。
  4. ポンプ能力に関係なく、槽を小さくするほど衛生上有利である。
正解と解説を見る

正解：時間変動と補給能力を考慮し、過大容量による滞留を避ける。

受水槽は断水時対応だけでなく水質保持も重要であり、使用変動と補給能力を踏まえ過大な滞留を避ける。

問2（施工管理法）

工程表の作成において、各作業の所要日数と作業間の先後関係を明確にし、全体工期に影響する経路を把握する手法として最も適当なものはどれか。

  1. チェックシート
  2. 出来高累計曲線
  3. バーチャート工程表
  4. ネットワーク工程表
正解と解説を見る

正解：ネットワーク工程表

ネットワーク工程表は作業の順序関係を表し、クリティカルパスを把握して工程遅延対策に活用できる。

問3（機器・材料）

遠心ポンプのキャビテーション防止策として、最も適切なものはどれか。

  1. 吸込管を細くして流速を高める
  2. ポンプの据付高さを低くし、有効吸込ヘッドを確保する
  3. 吸込側の弁を絞って流量を減らす
  4. 吐出管の口径を吸込管より小さくする
正解と解説を見る

正解：ポンプの据付高さを低くし、有効吸込ヘッドを確保する

キャビテーションは吸込圧力低下で生じるため、据付高さを下げてNPSHを確保することが有効です。

問4（法規）

建設業法における主任技術者の配置に関する記述として、最も適当なものはどれか。

  1. 主任技術者は、下請負人の労働者から必ず選任しなければならない。
  2. すべての建設工事で、営業所ごとに主任技術者を現場へ常駐させる。
  3. 建設業者は、請け負った建設工事を施工するとき、原則として工事現場に主任技術者を置く。
  4. 主任技術者は、発注者が直接選任し、請負業者へ通知する。
正解と解説を見る

正解：建設業者は、請け負った建設工事を施工するとき、原則として工事現場に主任技術者を置く。

建設業者は施工の技術管理を行わせるため、原則として工事現場に主任技術者を配置する必要がある。

問5（管工事一般）

給水管内でウォータハンマが発生しやすい条件として、最も適切なものはどれか。

  1. 配管内の水温が常に低く、圧力変動がない場合。
  2. 長い配管で流速が大きく、弁を急閉止する場合。
  3. 管径が大きく、流速が十分に低い場合。
  4. 流速が小さく、弁をゆっくり閉止する場合。
正解と解説を見る

正解：長い配管で流速が大きく、弁を急閉止する場合。

ウォータハンマは流体の運動量が急変して圧力波が生じる現象で、急閉止や高流速、長い配管で起こりやすい。

問6（施工管理法）

品質管理におけるヒストグラムの説明として最も適当なものはどれか。

  1. 二つの特性値の関係を点の分布で調べる図である
  2. 測定値を階級別に分け、ばらつきの状態を柱状に示す図である
  3. 不良原因を大きな要因から細分化して整理する図である
  4. 作業日程を横棒で示し、進捗を管理する図である
正解と解説を見る

正解：測定値を階級別に分け、ばらつきの状態を柱状に示す図である

ヒストグラムは測定値の分布やばらつき、規格値との関係を視覚的に確認する品質管理手法である。
