品質管理検定3級 予想問題の例

問1（QC七つ道具）

パレート図の主な目的として最も適切なものはどれか。

  1. 原因と結果の関係を視覚化する
  2. 製品の寸法を管理する
  3. データの時系列変動を監視する
  4. 問題の発生頻度を多い順に整理し重点改善点を特定する
正解と解説を見る

正解：問題の発生頻度を多い順に整理し重点改善点を特定する

パレート図は問題の頻度を多い順に並べ、重要な問題を特定するために使われます。

問2（工程管理）

工程能力指数（Cp）は何を表す指標でしょうか？

  1. 標準作業時間の短縮率
  2. 工程の平均値のずれ
  3. 工程のばらつきの大きさと許容範囲の関係
  4. 抜取検査の合格率
正解と解説を見る

正解：工程のばらつきの大きさと許容範囲の関係

Cpは工程のばらつきが許容範囲に対してどれだけ小さいかを示します。

問3（品質保証基礎）

品質方針を策定する目的として最も適切なものはどれか。

  1. 組織の品質目標の方向性を示すため
  2. 顧客との契約内容を交渉するため
  3. 製品デザインを決定するため
  4. 従業員の給与を決定するため
正解と解説を見る

正解：組織の品質目標の方向性を示すため

品質方針は組織の品質に関する方向性や目標を示し、全員の理解と共有を図るために策定されます。

問4（QC七つ道具）

特性要因図（フィッシュボーン図）で「設備」はどの分類に該当することが多いか。

  1. 設備（機械）
  2. 材料（モノ）
  3. 人（ヒト）
  4. 環境（場所）
正解と解説を見る

正解：設備（機械）

特性要因図では設備は機械や装置の要因として分類されます。

問5（工程管理）

抜取検査における「受入れ判定基準」として正しいものはどれか？

  1. ランダムに一定数を検査し合否を判定する
  2. 不良品が出たら全品検査を行う
  3. すべての製品を検査する
  4. 検査は製品完成後1週間以内に行う
正解と解説を見る

正解：ランダムに一定数を検査し合否を判定する

抜取検査はロットからランダムに抜き取り検査し合否を判断します。

問6（品質保証基礎）

新製品開発プロセスにおいて、品質を確保するために最も重要な初期段階はどれか。

  1. 試作品の評価
  2. 顧客要求の明確化
  3. 量産開始
  4. マーケティング調査
正解と解説を見る

正解：顧客要求の明確化

顧客要求の明確化は、新製品の品質目標設定や設計の基盤となるため重要です。
