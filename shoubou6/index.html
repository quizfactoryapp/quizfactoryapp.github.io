消防設備士乙種第6類 予想問題の例

問1（消防関係法令）

消防法第17条に基づく消防用設備等の設置・維持について、関係者に求められる基本的な義務として正しいものはどれか。

  1. 消防用設備等は設置後10年間は点検を省略できる
  2. 消防長の口頭指示がある場合だけ維持義務が生じる
  3. 小規模な防火対象物では消火器の維持管理義務は常に免除される
  4. 政令で定める技術上の基準に従い設置し、維持しなければならない
正解と解説を見る

正解：政令で定める技術上の基準に従い設置し、維持しなければならない

消防法第17条は、防火対象物の関係者に消防用設備等を基準どおり設置・維持する義務を課している。

問2（消火器構造）

粉末消火器の構造について、一般に粉末消火薬剤を放射するために必要な加圧用ガスとして最も適切なものはどれか。

  1. 空気中の水蒸気のみ
  2. 水素ガスまたは都市ガス
  3. 酸素ガスまたはアセチレンガス
  4. 窒素ガスまたは二酸化炭素ガス
正解と解説を見る

正解：窒素ガスまたは二酸化炭素ガス

粉末消火器では、薬剤を流動させ放射するため、窒素や二酸化炭素などの不燃性ガスを用いる。

問3（消火薬剤）

粉末ABC消火器に表示される適応火災として、一般に該当する組合せはどれか。消火薬剤の名称だけで判断しないこと。

  1. 普通火災、油火災、電気火災
  2. 普通火災、金属火災、ガス火災
  3. 普通火災、水素火災、電気火災
  4. 油火災、金属火災、電気火災
正解と解説を見る

正解：普通火災、油火災、電気火災

ABC粉末はA普通火災、B油火災、C電気火災に適応する代表的な消火薬剤である。

問4（整備・点検）

粉末消火器の外観点検で、ただちに整備または交換を検討すべき状態として最も適切なものはどれか。

  1. 設置場所の標識が見やすい位置にある。
  2. 安全栓に封印が取り付けられている。
  3. 本体容器の底部に著しい腐食や変形がある。
  4. 表示ラベルに製造年が印字されている。
正解と解説を見る

正解：本体容器の底部に著しい腐食や変形がある。

底部の著しい腐食や変形は破裂事故につながるおそれがあり、継続使用の可否を慎重に判断する。

問5（消防関係法令）

消防用設備等の点検結果報告について、特定防火対象物に該当する建物の報告周期として正しいものはどれか。

  1. 6か月に1回
  2. 2年に1回
  3. 3年に1回
  4. 1年に1回
正解と解説を見る

正解：1年に1回

特定防火対象物は、不特定多数の利用など火災時の危険性が高いため、点検結果を1年に1回報告する。

問6（消火器構造）

蓄圧式消火器の構造上の特徴として、加圧式消火器と比較した場合に最も適切な説明はどれか。

  1. 容器内に常時圧力がかかっている
  2. 安全栓を抜くと薬剤が必ず全量放射される
  3. 消火薬剤を入れず水だけを放射する
  4. 使用時に外部ポンプで圧力を加える
正解と解説を見る

正解：容器内に常時圧力がかかっている

蓄圧式は本体容器内に薬剤と加圧ガスを同封し、平常時から所定の圧力を保持している。
