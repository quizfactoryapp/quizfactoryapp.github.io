工事担任者試験 予想問題の例

問1（電気通信技術の基礎）

抵抗4Ωと6Ωを直列に接続し、両端に20Vを加えた。回路に流れる電流として最も適切なものはどれか。

  1. 1A
  2. 3A
  3. 5A
  4. 2A
正解と解説を見る

正解：2A

直列抵抗の合成抵抗は4+6=10Ωである。オームの法則より電流は20V÷10Ω=2Aとなる。

問2（端末設備の接続技術）

メタリック加入者線を宅内へ引き込む箇所に設置する保安器の主な役割として、最も適切なものはどれか。

  1. 光信号を電気信号へ変換して端末へ渡す
  2. 雷サージなどの異常電圧を接地側へ逃がす
  3. LANケーブルの伝送速度を自動的に上げる
  4. 通話信号をデジタル化してIPパケットへ変換する
正解と解説を見る

正解：雷サージなどの異常電圧を接地側へ逃がす

保安器は加入者線から侵入する雷サージ等を接地へ放流し、端末設備や人身を保護する装置である。

問3（電気通信法規）

電気通信事業法の定義に照らし、次のうち「電気通信役務」の説明として最も適切なものはどれか。

  1. 端末機器を製造し、販売店を通じて利用者へ譲渡すること
  2. 他人の通信を媒介し、又は電気通信設備を他人の通信の用に供すること
  3. 放送番組を編集し、不特定多数の受信者へ同時に送信すること
  4. 電気通信設備の保守用工具を貸与し、工事の便宜を図ること
正解と解説を見る

正解：他人の通信を媒介し、又は電気通信設備を他人の通信の用に供すること

電気通信役務は、通信の媒介又は設備を他人の通信の用に供する行為を指す定義である。

問4（電気通信技術の基礎）

コンデンサに正弦波交流電圧を加えたとき、電圧と電流の位相関係として正しいものはどれか。

  1. 電流と電圧の位相差は常に180度である
  2. 電流は電圧より90度遅れる
  3. 電圧と電流は同相である
  4. 電流は電圧より90度進む
正解と解説を見る

正解：電流は電圧より90度進む

コンデンサでは電荷の変化により電流が流れるため、正弦波交流では電流が電圧より90度進む。

問5（端末設備の接続技術）

1000BASE-TのLAN配線を施工する場合、カテゴリ5e以上のUTPケーブルで使用する対数として正しいものはどれか。

  1. 2対のみを使用する
  2. 4対すべてを使用する
  3. 3対のみを使用する
  4. 1対のみを使用する
正解と解説を見る

正解：4対すべてを使用する

1000BASE-Tは4対の平衡対を双方向に用いて伝送するため、8心すべての結線品質が重要となる。

問6（電気通信法規）

電気通信事業法が定める通信の秘密に関する記述として、電気通信事業者に求められる取扱いはどれか。

  1. 通信の秘密は努力義務であり、技術上困難な場合は保護しなくてよい
  2. 料金請求の都合があれば、通話内容を自由に確認して保存できる
  3. 利用者の同意がなくても、営業目的なら通信履歴を第三者へ提供できる
  4. 取扱中に係る通信の秘密を侵してはならず、保護義務を負う
正解と解説を見る

正解：取扱中に係る通信の秘密を侵してはならず、保護義務を負う

通信の秘密は電気通信事業法上の重要原則であり、取扱中の通信について侵害が禁じられる。
