終活ガイド検定 予想問題の例

問1（終活設計）

エンディングノートの説明として最も適切なものはどれか。法的効力と実務上の役割の違いを踏まえて選びなさい。

  1. 公証役場で作成しなければ無効となる死後事務の契約書
  2. 遺言書と同じ法的効力を持ち、財産分配を確定できる書面
  3. 本人の希望や連絡先などを整理し、家族や支援者の判断を助ける記録
  4. 医療同意権を第三者へ自動的に移すための公的証明書
正解と解説を見る

正解：本人の希望や連絡先などを整理し、家族や支援者の判断を助ける記録

エンディングノートは希望や情報の整理に役立つが、遺言のような法的拘束力はない。

問2（相続基礎）

被相続人に配偶者、長男、長女がいる場合、遺言がなければ法定相続人と法定相続分の組合せとして正しいものはどれか。

  1. 長男と長女だけが各2分の1を相続する
  2. 配偶者のみが全財産を相続する
  3. 配偶者が2分の1、長男と長女が各4分の1を相続する
  4. 配偶者、長男、長女が各3分の1を相続する
正解と解説を見る

正解：配偶者が2分の1、長男と長女が各4分の1を相続する

配偶者と子が相続人の場合、配偶者は2分の1、子全体で2分の1を等分します。

問3（葬送・供養）

家族葬について説明する際、終活ガイドとして最も適切なのはどれか。参列者を限定しやすい一方、後日弔問対応が増える場合がある。

  1. 法律上、一般葬より費用を安くする義務がある
  2. 親族だけで行うため宗教者を呼ぶことはできない
  3. 火葬許可証が不要になる簡略な葬儀形式である
  4. 参列範囲を絞れるが、周囲への事前・事後説明が重要である
正解と解説を見る

正解：参列範囲を絞れるが、周囲への事前・事後説明が重要である

家族葬は参列者を限定できるが、訃報範囲や後日の弔問対応を考えて説明することが大切です。

問4（医療・介護意思決定）

ACP（アドバンス・ケア・プランニング）の説明として最も適切なものはどれか。

  1. 相続財産の分け方を家族で決める会議
  2. 医師が単独で延命治療の有無を決める手続き
  3. 将来の医療やケアについて本人を中心に話し合いを重ねる過程
  4. 介護保険施設への入所を確定させる契約
正解と解説を見る

正解：将来の医療やケアについて本人を中心に話し合いを重ねる過程

ACPは本人の価値観や希望を確認し、家族や医療・介護職と継続的に共有する取り組みである。

問5（終活設計）

身元保証サービスを検討する際、契約前に特に確認すべき事項として最も適切なものはどれか。

  1. 契約内容、費用、預託金の管理方法、解約時の扱いが明示されているか
  2. 医師の判断に代わって事業者が治療方針を決定できるか
  3. 契約すれば親族への説明や同意が一切不要になるか
  4. 本人の財産を事業者が自由に運用できる条項があるか
正解と解説を見る

正解：契約内容、費用、預託金の管理方法、解約時の扱いが明示されているか

費用や預託金管理、提供範囲、解約条件はトラブル防止のため事前確認が重要である。

問6（相続基礎）

被相続人に配偶者はいるが子はなく、父母もすでに死亡し、兄と妹がいる場合の法定相続分として正しいものはどれか。

  1. 配偶者が2分の1、兄妹が各4分の1
  2. 配偶者が4分の3、兄妹が各8分の1
  3. 配偶者が3分の2、兄妹が各6分の1
  4. 配偶者、兄、妹が各3分の1
正解と解説を見る

正解：配偶者が4分の3、兄妹が各8分の1

配偶者と兄弟姉妹が相続人の場合、配偶者が4分の3、兄弟姉妹全体で4分の1です。
