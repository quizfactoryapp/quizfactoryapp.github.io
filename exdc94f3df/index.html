ビジネス実務マナー検定試験 予想問題の例

問1（職場常識）

上司から資料作成を急ぎで頼まれたが、別の締切作業を抱えている。この場合の最も適切な対応はどれか。

  1. 間に合わない可能性があっても、できるとだけ返事をする。
  2. 現在の作業状況と締切を伝え、優先順位を確認する。
  3. 急ぎと言われたので、他の作業を黙って中断する。
  4. 自分で優先順位を決め、頼まれた資料は後回しにする。
正解と解説を見る

正解：現在の作業状況と締切を伝え、優先順位を確認する。

複数の業務が重なる場合は、状況を正確に伝え、上司に優先順位を確認してから進めるのが基本である。

問2（対人技能）

取引先の課長が来社し、上司が会議中で応接できない。受付担当者として最も適切な最初の対応はどれか。

  1. 「約束の時間に来られても困ります」と事情を説明する
  2. 来訪への謝意を述べ、上司の状況を伝えたうえで、代理対応や待機の希望を確認する
  3. 「課長は会議中ですので、終わるまでそちらでお待ちください」と言う
  4. 「会議中です。用件をここで伺います」と受付で詳しく聞く
正解と解説を見る

正解：来訪への謝意を述べ、上司の状況を伝えたうえで、代理対応や待機の希望を確認する

来客にはまず謝意と配慮を示し、相手の意向を確認して代理対応などを調整するのが適切である。

問3（業務技能）

会議室を予約した後、出席者へ開催案内を送る際の対応として最も適切なものはどれか。

  1. 出欠確認は不要なので、案内後は当日まで待つ
  2. 日時と議題だけを送り、資料は当日に配布する
  3. 開始時刻、場所、目的、議題、事前準備事項を明記して送る
  4. 上司にだけ案内し、出席者へは口頭で伝える
正解と解説を見る

正解：開始時刻、場所、目的、議題、事前準備事項を明記して送る

会議案内は出席者が準備できるよう、目的や議題、場所、資料、出欠期限を具体的に示す。

問4（職場常識）

勤務中に私用のスマートフォン通知が続けて届いた。職場規律の観点から最も望ましい行動はどれか。

  1. 業務に支障が出ないよう通知を切り、休憩時間に確認する。
  2. 急ぎでなくても、短文ならすぐ返信してよい。
  3. 自席で通話し、用件が終わればすぐ業務に戻る。
  4. 周囲に聞こえないよう机の下で返信する。
正解と解説を見る

正解：業務に支障が出ないよう通知を切り、休憩時間に確認する。

勤務時間中は業務に集中することが職場規律であり、私用連絡は原則として休憩時間に行うのが適切である。

問5（対人技能）

社外の人に自社の部長である山田の不在を電話で伝えるとき、最も適切な表現はどれか。

  1. 「山田はただいま席を外しております」
  2. 「部長の山田さんは今いません」
  3. 「山田部長はただいま席を外していらっしゃいます」
  4. 「山田様はただいま席を外しております」
正解と解説を見る

正解：「山田はただいま席を外しております」

社外に対して自社の者には敬称や尊敬語を用いず、謙譲表現で「山田は」と伝える。

問6（業務技能）

会議で使用する配布資料を準備する際、部数の考え方として最も適切なものはどれか。

  1. 部数は当日の参加者に尋ねてから印刷する
  2. 経費節減のため、出席予定者数より少なめに用意する
  3. 出席予定者数に予備を加え、差し替えがないか事前確認する
  4. 資料は議長分だけ用意し、必要に応じて回覧する
正解と解説を見る

正解：出席予定者数に予備を加え、差し替えがないか事前確認する

当日の追加参加や汚損に備え、予定人数分に予備を加え、最新版か確認して準備する。
