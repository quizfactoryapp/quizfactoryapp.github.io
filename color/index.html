色彩検定3級 予想問題の例

問1（色彩理論）

次の色見本を見て、補色関係にある組み合わせを選べ。

  1. YとB
  2. RとB1
  3. RとY
  4. B1とB
正解と解説を見る

正解：RとB1

赤(R)とシアン(B1)は色相環上で180度離れた補色関係にあります。

問2（色彩心理）

次の配色のうち、類似色配色にあたる組み合わせを選べ。

  1. 緑と青
  2. 橙と赤橙
  3. 橙と緑
  4. 赤橙と青
正解と解説を見る

正解：橙と赤橙

橙と赤橙は色相環で隣接する類似色です。

問3（配色技法）

次の色見本から、ビビッドトーンの色を選べ。

  1. ダークイエロー
  2. ビビッドレッド
  3. ペールグレー
  4. ダークインディゴ
正解と解説を見る

正解：ビビッドレッド

ビビッドレッドは明度・彩度が高く鮮やかなビビッドトーンです。

問4（色彩理論）

次の色見本のうち、ビビッドトーン（鮮やかな色）はどれか。

  1. ビビッドR
  2. ペールR
  3. ダークR
  4. ライトR
正解と解説を見る

正解：ビビッドR

ビビッドトーンは彩度が高く鮮やかな色で、明度は中程度です。赤の中で最も鮮やかな色がビビッドRです。

問5（色彩心理）

次の色票のトーンの中で、最もビビッド（鮮やか）な色を選べ。

  1. ライトトマト
  2. ペールピンク
  3. ビビッドレッド
  4. ダークレッド
正解と解説を見る

正解：ビビッドレッド

ビビッドは彩度が高く鮮やかな色調で、ビビッドレッドがそれに該当します。

問6（配色技法）

配色技法の説明として、セパレーション配色に最も適しているものはどれか。

  1. 小面積に高彩度色を使い、全体に変化や強調を加える配色
  2. 対立しやすい色と色の間に、白・黒・灰色などを挟んで調和させる配色
  3. 色相環で隣り合う色を組み合わせ、自然なまとまりを出す配色
  4. 同じ色相で明度や彩度を変え、統一感を出す配色
正解と解説を見る

正解：対立しやすい色と色の間に、白・黒・灰色などを挟んで調和させる配色

セパレーション配色は、色同士の境界に無彩色などを入れて対比をやわらげ、見やすく整える技法である。
