問1（危険物法令）

第6類危険物を屋内で貯蔵する計画がある。消防法令上、第6類危険物の指定数量として正しいものはどれか。

  1. 50kg
  2. 1,000kg
  3. 300kg
  4. 100kg
正解と解説を見る

正解：300kg

第6類危険物は酸化性液体であり、指定数量は品名を通じて一律300kgとされる。

問2（基礎物理化学）

酸化還元反応に関する記述として正しいものはどれか。危険物の性質を考える際、電子の授受に着目して判断する。

  1. 酸化とは電子を受け取ることである
  2. 還元とは酸素と化合することである
  3. 還元剤は反応中に電子を受け取る物質である
  4. 酸化剤は相手を酸化し、自身は還元される
正解と解説を見る

正解：酸化剤は相手を酸化し、自身は還元される

酸化剤は相手から電子を奪って酸化させる物質で、自身は電子を受け取り還元される。

問3（第6類危険物）

第6類危険物に共通する性質として、最も適切なものはどれか。火災時の危険性を踏まえて選べ。

  1. 空気中で自然発火しやすい還元性液体である
  2. 酸化性が強く、可燃物の燃焼を促進する
  3. 可燃性蒸気を発生し、引火点が低い
  4. いずれも水より軽く、水面に浮いて燃焼する
正解と解説を見る

正解：酸化性が強く、可燃物の燃焼を促進する

第6類は酸化性液体であり、自ら燃えるよりも他物質の燃焼を激しくする性質が重要である。

問4（貯蔵・取扱い）

第6類危険物を貯蔵する容器として適切なものはどれか。性質に応じた耐食性を考えた場合の取扱いを選べ。

  1. 可燃性液体の空容器を洗浄せずに再利用する。
  2. 中身を確認しやすいよう、ふたのない開放容器に入れる。
  3. 任意の金属容器なら、酸化性液体にも常に使用できる。
  4. 内容物に侵されず、密栓できる適合容器を用いる。
正解と解説を見る

正解：内容物に侵されず、密栓できる適合容器を用いる。

第6類は腐食性・酸化性が強いものが多く、内容物に適した耐食性容器で密栓して保管する。

問5（危険物法令）

過酸化水素180kgと硝酸150kgを同一場所で貯蔵する場合、指定数量の倍数として正しいものはどれか。

  1. 1.1倍
  2. 0.6倍
  3. 3.0倍
  4. 1.8倍
正解と解説を見る

正解：1.1倍

第6類の指定数量は300kgなので、180/300＋150/300＝1.1倍となる。

問6（基礎物理化学）

燃焼が継続するために必要な三要素の組合せとして、最も適切なものはどれか。乙種危険物の火災理解に関わる。

  1. 可燃物、窒素、二酸化炭素
  2. 酸化剤、還元剤、消火剤
  3. 水、酸素供給源、冷却剤
  4. 可燃物、酸素供給源、点火源
正解と解説を見る

正解：可燃物、酸素供給源、点火源

燃焼には可燃物、酸素供給源、点火源が必要で、いずれかを除くと燃焼は停止する。
