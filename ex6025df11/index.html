医療事務技能審査試験 予想問題の例

問1（診療報酬請求）

初診料の算定に関する説明として最も適切なものはどれか。継続中の同一傷病で再び同じ医療機関を受診した場合を想定する。

  1. 月が変われば必ず初診料を算定する
  2. 同じ医師なら診療内容に関係なく初診料を算定する
  3. 処方のみでも毎回初診料を算定する
  4. 原則として再診料等を算定し、初診料は算定しない
正解と解説を見る

正解：原則として再診料等を算定し、初診料は算定しない

同一傷病で治療が継続している場合は、初診ではなく再診として扱うのが原則である。

問2（医療保険制度）

令和6年12月2日以降の医療機関受付で、マイナ保険証を保有していない患者が保険資格を示すために提示する書類として適切なものはどれか。

  1. 資格情報のお知らせ単独
  2. 住民票の写し
  3. 資格確認書
  4. 診察券のみ
正解と解説を見る

正解：資格確認書

マイナ保険証を持たない人には資格確認書が交付され、従来の保険証に代えて資格確認に用いる。

問3（医事業務）

カルテの保存管理について適切なのはどれか。診療録を院外へ持ち出す必要がある場合の基本的な対応として最も適切なものを選べ。

  1. 紛失防止のため、持出中は受付で患者氏名を掲示する
  2. 院内規程に従い、持出目的・日時・担当者を記録して管理する
  3. 患者の同意があれば保存場所や持出記録は不要である
  4. 担当者の判断で原本を持ち出し、後日返却すればよい
正解と解説を見る

正解：院内規程に従い、持出目的・日時・担当者を記録して管理する

診療録は個人情報を含む重要文書であり、院内規程に基づき所在と取扱者を記録して厳格に管理する。

問4（医療用語）

傷病名「急性気管支炎」の説明として最も適切なものはどれか。外来診療での病名理解として選びなさい。

  1. 関節軟骨の変性により疼痛が生じる疾患
  2. 胃粘膜に慢性的な炎症が生じる疾患
  3. 腎臓の糸球体に免疫反応が起こる疾患
  4. 気管支に急性の炎症が起こり咳や痰を伴う疾患
正解と解説を見る

正解：気管支に急性の炎症が起こり咳や痰を伴う疾患

急性気管支炎は気管支の急性炎症で、咳・痰・発熱などを伴うことが多い傷病名です。

問5（診療報酬請求）

レセプト作成時、保険者番号や記号・番号の確認を怠った場合に起こりやすい事務上の問題として最も適切なものはどれか。

  1. 診療録の保存期間が短縮される
  2. 審査支払機関から返戻となる可能性がある
  3. 診療報酬点数が自動的に増点される
  4. 患者負担割合が必ずゼロになる
正解と解説を見る

正解：審査支払機関から返戻となる可能性がある

資格情報の誤りは請求先の特定に関わるため、返戻や再請求の原因になりやすい。

問6（医療保険制度）

マイナ保険証を持つ患者が、機器不良などでオンライン資格確認できない場合の対応として正しいものはどれか。

  1. 診療を拒否する
  2. 全額自費扱いに固定する
  3. マイナンバーカードと資格情報のお知らせ等で確認する
  4. 公費負担番号を任意に入力する
正解と解説を見る

正解：マイナンバーカードと資格情報のお知らせ等で確認する

資格情報のお知らせは単独では使えず、マイナンバーカード等と組み合わせて資格確認を補助する。
