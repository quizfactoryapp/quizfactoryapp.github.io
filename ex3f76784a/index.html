二種外務員資格試験 予想問題の例

問1（金融商品取引法規）

適合性の原則において、金融商品取引業者が顧客に対して行うべき最も重要な対応はどれか？

  1. 高リスク商品の販売を優先する
  2. 顧客の同意なく商品の仕様を変更する
  3. 顧客の資産状況や投資目的に適した商品を提供する
  4. 顧客の投資経験を無視して商品を勧誘する
正解と解説を見る

正解：顧客の資産状況や投資目的に適した商品を提供する

適合性の原則は顧客の属性に合った商品提供を求めるものであり、無条件の販売は禁止されています。

問2（協会定款・諸規則）

外務員登録の申請に必要な書類として、正しいものはどれか。

  1. 健康診断書の提出
  2. 運転免許証のコピーのみ
  3. 税務申告書の写し
  4. 住民票と身分証明書の提出
正解と解説を見る

正解：住民票と身分証明書の提出

外務員登録には本人の身元確認のために住民票と身分証明書の提出が必要です。

問3（株式・債券商品）

上場株式の特徴として正しいものはどれか。株主は会社の一部所有者となり、配当を受ける権利がある。

  1. 株主は会社の債務を無制限に負う義務がある。
  2. 上場株式は必ず額面価格で取引される。
  3. 上場株式は満期になると元本が返される。
  4. 株主は会社の一部所有者であり、配当を受ける権利がある。
正解と解説を見る

正解：株主は会社の一部所有者であり、配当を受ける権利がある。

株主は会社の部分所有者であり、配当や議決権を持つが、負債は原則として負わない。

問4（投資信託・税制）

投資信託の目論見書に記載されている情報として正しいものはどれか。

  1. 証券会社の営業成績
  2. 投資家個人の税務状況
  3. ファンドの過去の基準価額の詳細な推移
  4. 運用方針やリスクに関する説明
正解と解説を見る

正解：運用方針やリスクに関する説明

目論見書にはファンドの運用方針やリスクなど重要事項が記載されているため、投資判断に役立つ。

問5（金融商品取引法規）

損失補填の禁止に関する法律上、金融商品取引業者が顧客の損失を補填した場合、どのような問題があるか？

  1. 不公正取引として法律違反になる
  2. 顧客が更なる損失を出しやすくなる
  3. 業者のリスクが減少する
  4. 顧客の信頼向上になる
正解と解説を見る

正解：不公正取引として法律違反になる

損失補填は禁止されており、違反すると不公正取引として処罰の対象になります。

問6（協会定款・諸規則）

顧客勧誘に関して、勧誘時に必ず提供しなければならない情報はどれか。

  1. 販売手数料の免除案内
  2. 金融商品の過去の価格推移のみ
  3. 他社商品の比較広告
  4. リスク説明書や重要事項の説明
正解と解説を見る

正解：リスク説明書や重要事項の説明

勧誘時には顧客に対してリスクや重要事項をしっかり説明する義務があります。
