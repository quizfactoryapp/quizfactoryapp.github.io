問1（統計的方法）

平均50、標準偏差10の正規分布に従う特性値について、値が70を超える確率を求めるときに用いる標準化変数zはいくつか。

  1. 2.5
  2. 1.0
  3. 2.0
  4. 1.5
正解と解説を見る

正解：2.0

標準化はz=(x-μ)/σで行う。x=70、μ=50、σ=10よりz=2.0となる。

問2（QC七つ道具）

パレート図を用いて不適合の重点対策を検討する際、横軸の項目の並べ方として最も適切なものはどれか。

  1. 累積比率の小さい順に左から並べる
  2. 工程の発生順に左から並べる
  3. 発生件数または損失金額の大きい順に左から並べる
  4. 項目名の五十音順に左から並べる
正解と解説を見る

正解：発生件数または損失金額の大きい順に左から並べる

パレート図は影響の大きい項目を左から順に並べ、重点管理すべき少数項目を把握する。

問3（工程管理）

工程能力指数Cpが1.33で、工程平均が規格中心からずれていない場合、この工程に対する評価として最も適切なものはどれか。

  1. 規格外品率は必ずゼロになるため、管理図は不要である
  2. ばらつきは規格幅に対して十分小さく、一般に工程能力はあると判断できる
  3. 平均が規格中心にあってもCpは1未満なので工程能力はない
  4. Cpは平均の偏りだけを表すため、ばらつきの評価には使えない
正解と解説を見る

正解：ばらつきは規格幅に対して十分小さく、一般に工程能力はあると判断できる

Cpは規格幅と工程ばらつきの比で、1.33程度以上なら一般に工程能力ありとみなす。

問4（品質経営）

方針管理における方針展開の説明として、最も適切なものはどれか。

  1. 経営方針を部門・階層ごとの目標と実施事項に具体化し、整合を取る活動
  2. 発生した不適合だけを対象に、原因調査と再発防止を行う活動
  3. 顧客の苦情件数を集計し、年度末に報告書へ記録するだけの活動
  4. 製品検査の判定基準を緩和し、出荷量を最大化する活動
正解と解説を見る

正解：経営方針を部門・階層ごとの目標と実施事項に具体化し、整合を取る活動

方針展開は、上位方針を各階層の目標・施策へ落とし込み、全体の方向を合わせる活動である。

問5（統計的方法）

母分散が既知で、母平均の両側95%信頼区間を作る。標本平均を中心に加減する量として最も適切なものはどれか。

  1. 標本平均×1.96/√n
  2. 1.96×母標準偏差/n
  3. 1.96×母標準偏差/√n
  4. 2.58×標本標準偏差/√n
正解と解説を見る

正解：1.96×母標準偏差/√n

母分散既知の母平均の95%信頼区間では、標準正規分布の1.96と標準誤差σ/√nを用いる。

問6（QC七つ道具）

特性要因図を作成する目的として最も適切なものはどれか。品質特性に影響する要因を体系的に整理したい。

  1. 二つの変量の相関係数を厳密に推定する
  2. 不適合項目を件数順に並べて累積比率を示す
  3. 特性に影響する要因を分類し、原因候補の抜けを防ぐ
  4. 時系列データから工程の安定状態を判定する
正解と解説を見る

正解：特性に影響する要因を分類し、原因候補の抜けを防ぐ

特性要因図は結果である特性と原因候補の関係を枝分かれで整理し、要因探索に用いる。
