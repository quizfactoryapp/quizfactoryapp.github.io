情報検定 情報活用試験 予想問題の例

問1（情報リテラシー）

検索エンジンで「再生可能エネルギー 政策 日本」と検索したが結果が多すぎる。必要な情報に絞り込む方法として最も適切なものはどれか。

  1. 関連しない語も追加して結果を増やす
  2. 検索語を1語だけに減らす
  3. 最初に表示された広告だけを確認する
  4. 「site:go.jp」や期間指定を使って条件を絞る
正解と解説を見る

正解：「site:go.jp」や期間指定を使って条件を絞る

公的機関や期間などの条件を指定すると、目的に合う信頼性の高い情報を効率よく探せる。

問2（データ活用）

表計算ソフトで、A1からA10までの数値の合計を求める式として最も適切なものはどれか。

  1. =MAX(A1:A10)
  2. =COUNT(A1:A10)
  3. =AVERAGE(A1:A10)
  4. =SUM(A1:A10)
正解と解説を見る

正解：=SUM(A1:A10)

SUM関数は指定したセル範囲内の数値を合計する。COUNTは個数、AVERAGEは平均を求める。

問3（ネットワーク利用）

Webサイトを閲覧しているとき、URLが「https://」で始まっている場合に最も適切な説明はどれか。

  1. 通信内容が暗号化され、改ざんや盗聴の危険を減らせる
  2. 表示される情報がすべて正確であることを保証している
  3. そのWebサイトを利用しても個人情報入力は不要である
  4. ウイルス感染を完全に防止できる状態を示している
正解と解説を見る

正解：通信内容が暗号化され、改ざんや盗聴の危険を減らせる

HTTPSは通信を暗号化する仕組みで、盗聴や改ざんのリスクを下げるが内容の正確性までは保証しない。

問4（問題解決）

フローチャートで、条件によって処理の流れを二つ以上に分けるときに用いる記号として最も適切なものはどれか。

  1. 円柱
  2. 平行四辺形
  3. 長方形
  4. ひし形
正解と解説を見る

正解：ひし形

ひし形は判断を表し、条件の真偽などにより処理の流れを分岐させるときに使う。

問5（情報リテラシー）

Webページの情報をレポートに利用する前に、情報の信頼性を確認する行動として最も適切なものはどれか。

  1. SNSで多く共有されていれば採用する
  2. デザインが見やすければ事実として扱う
  3. 作成者、公開日、根拠、他資料との一致を確認する
  4. 文字数が多いので正しいと判断する
正解と解説を見る

正解：作成者、公開日、根拠、他資料との一致を確認する

信頼性は見た目ではなく、発信者、時期、根拠、複数資料での確認によって判断する。

問6（データ活用）

商品の月別売上の増減を時間の流れに沿って比較したい。最も適したグラフの種類はどれか。

  1. 散布図
  2. 帯グラフ
  3. 折れ線グラフ
  4. 円グラフ
正解と解説を見る

正解：折れ線グラフ

折れ線グラフは時系列の変化を表すのに適しており、月ごとの増減を読み取りやすい。
