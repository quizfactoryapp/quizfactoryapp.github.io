問1（情報セキュリティ技術）

TLS 1.3で前方秘匿性を実現するために主に用いられる鍵交換方式として、最も適切なものはどれか。

  1. 一時的なDiffie-Hellman鍵交換を用いる方式
  2. サーバ証明書の公開鍵を通信鍵として使う方式
  3. RSA鍵配送でプリマスタシークレットを暗号化する方式
  4. 共有パスワードから固定鍵を直接生成する方式
正解と解説を見る

正解：一時的なDiffie-Hellman鍵交換を用いる方式

一時DH鍵交換ではセッションごとに鍵が生成され、長期秘密鍵漏えい後も過去通信を復号しにくい。

問2（ネットワークセキュリティ）

ステートフルインスペクション型ファイアウォールが、単純なパケットフィルタよりも適切に判断できる通信はどれか。

  1. 暗号化されたTLS本文に含まれるマルウェア名
  2. 送信元端末の利用者が正社員かどうか
  3. TCPの確立済みセッションに対する戻り通信かどうか
  4. 宛先Webサーバの脆弱性修正状況
正解と解説を見る

正解：TCPの確立済みセッションに対する戻り通信かどうか

ステートフル型はTCP状態やセッション情報を保持し、戻り通信などを文脈付きで判定できる。

問3（インシデント対応）

Webサーバのアクセスログで、同一IPから短時間に多数の404応答が発生し、その後管理画面へのPOSTが成功していた。最も疑うべき事象はどれか。

  1. TLS証明書の期限切れによる通信遮断
  2. ブルートフォース前のディレクトリ探索や脆弱性探索
  3. DNSキャッシュポイズニングによる名前解決の失敗
  4. バックアップ処理による静的ファイルの一時削除
正解と解説を見る

正解：ブルートフォース前のディレクトリ探索や脆弱性探索

多数の404は存在確認や探索の典型であり、その後のPOST成功は侵入試行の進展を示す。

問4（セキュリティ管理）

リスクアセスメントにおいて、リスク所有者がリスク対応を決定する前に最も優先して確認すべき事項はどれか。

  1. 脆弱性診断ツールの製品名と導入費用
  2. 過去に実施した教育研修の参加率
  3. リスク基準に照らしたリスクレベルと受容可否
  4. 監査人が推奨する監査手続の詳細
正解と解説を見る

正解：リスク基準に照らしたリスクレベルと受容可否

対応方針は、組織が定めたリスク基準と評価結果を比較し、受容可能かを判断して決定する。

問5（情報セキュリティ技術）

パスワード認証システムで、保存済みハッシュ値の総当たり解析を困難にする対策として最も適切なものはどれか。

  1. ハッシュ値をBase64で符号化して保存する
  2. パスワードを可逆暗号で暗号化して保存する
  3. 全利用者に同じソルトを付与してハッシュ化する
  4. 利用者ごとに異なるソルトと低速なKDFを用いる
正解と解説を見る

正解：利用者ごとに異なるソルトと低速なKDFを用いる

個別ソルトは事前計算攻撃を妨げ、低速KDFは総当たり試行のコストを高める。

問6（ネットワークセキュリティ）

DMZに公開Webサーバを置く構成で、内部DBサーバへのアクセス制御として最も適切な方針はどれか。

  1. WebサーバからDBサーバへの必要なポートだけを許可する
  2. インターネットからDBサーバへのTCP 3306を許可する
  3. DMZ内の全ホストから内部ネットワーク全体への通信を許可する
  4. Webサーバの管理用SSHを全インターネットに公開する
正解と解説を見る

正解：WebサーバからDBサーバへの必要なポートだけを許可する

DMZから内部への通信は最小権限とし、WebサーバからDBの必要ポートだけに限定する。
