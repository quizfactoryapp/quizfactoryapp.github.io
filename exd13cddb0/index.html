銀行業務検定試験 年金アドバイザー3級 予想問題の例

問1（国民年金）

国民年金の第1号被保険者に該当する者として、最も適切なものはどれか。なお、日本国内に住所があるものとする。

  1. 第2号被保険者に扶養される20歳以上60歳未満の配偶者
  2. 65歳以上の老齢基礎年金受給者全員
  3. 厚生年金保険に加入している会社員
  4. 20歳以上60歳未満の自営業者で厚生年金に加入していない者
正解と解説を見る

正解：20歳以上60歳未満の自営業者で厚生年金に加入していない者

第1号被保険者は、20歳以上60歳未満の自営業者、学生、無職等で第2号・第3号に該当しない者です。

問2（厚生年金保険）

厚生年金保険の定時決定では、原則として4月・5月・6月に受けた報酬を基に標準報酬月額を決める。この決定額の適用期間はどれか。

  1. 10月から翌年9月まで
  2. 1月から12月まで
  3. 7月から翌年6月まで
  4. 9月から翌年8月まで
正解と解説を見る

正解：9月から翌年8月まで

定時決定で見直された標準報酬月額は、原則としてその年9月から翌年8月まで適用される。

問3（年金額計算）

老齢基礎年金の受給資格期間を判定する際、保険料納付済期間、保険料免除期間および合算対象期間を合計して、原則として何年以上必要か。

  1. 5年以上
  2. 25年以上
  3. 20年以上
  4. 10年以上
正解と解説を見る

正解：10年以上

老齢基礎年金の受給資格期間は、納付済期間、免除期間、合算対象期間を合わせて原則10年以上で判定する。

問4（年金相談実務）

65歳から老齢基礎年金・老齢厚生年金を受けるための年金請求書について、実務上の説明として正しいものはどれか。

  1. 受給権が発生しても、原則として本人が年金請求書を提出して裁定を受ける。
  2. 年金請求書の提出は必ず65歳到達日の翌日以後でなければならない。
  3. 老齢年金の請求は市区町村役場だけで行い、年金事務所では扱わない。
  4. 年金請求書は提出しなくても、受給権発生後に自動的に支給が始まる。
正解と解説を見る

正解：受給権が発生しても、原則として本人が年金請求書を提出して裁定を受ける。

老齢年金は受給権発生だけでは支給開始されず、請求書を提出して裁定を受ける必要がある。

問5（社会保険周辺制度）

健康保険の任意継続被保険者制度について、退職後に加入できる期間と保険料負担の組合せとして正しいものはどれか。

  1. 最長2年間、保険料は全額本人が負担する
  2. 期間の上限はなく、保険料は退職前と同じ負担割合である
  3. 最長1年間、保険料は事業主と折半する
  4. 最長3年間、保険料は国が半額負担する
正解と解説を見る

正解：最長2年間、保険料は全額本人が負担する

任意継続は原則として最長2年間で、退職後は事業主負担がないため保険料は全額本人負担です。

問6（国民年金）

国民年金の第3号被保険者に関する説明として、正しいものはどれか。

  1. 本人が毎月、国民年金保険料を直接納付する必要がある
  2. 第2号被保険者に扶養される20歳以上60歳未満の配偶者が該当する
  3. 第1号被保険者に扶養される配偶者が該当する
  4. 年齢にかかわらず、厚生年金加入者の配偶者なら該当する
正解と解説を見る

正解：第2号被保険者に扶養される20歳以上60歳未満の配偶者が該当する

第3号被保険者は、第2号被保険者に扶養される20歳以上60歳未満の配偶者です。本人負担の直接納付はありません。
