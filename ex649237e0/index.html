1級管工事施工管理技術検定 予想問題の例

問1（高度設備工学）

冷温水配管の密閉回路に設ける膨張タンクの設置目的として、最も適切なものはどれか。

  1. 配管内の温度変化による水の体積変化を吸収するため
  2. ポンプの締切圧力を常時低下させるため
  3. 冷水の溶存酸素を積極的に増加させるため
  4. 各系統の流量を自動的に均等化するため
正解と解説を見る

正解：配管内の温度変化による水の体積変化を吸収するため

密閉回路では水温変化で体積が変わるため、膨張タンクで圧力上昇や負圧を抑制する。

問2（施工計画）

仮設配管を計画する際、既設設備を運転しながら改修工事を行う場合の留意事項として、最も適切なものはどれか。

  1. 切替時の停止時間、逆流防止、バイパス経路を事前に検討する。
  2. 仮設配管は本設配管より小口径とし、圧力損失を大きく見込む。
  3. 仮設配管は短期使用のため、支持間隔の検討を省略できる。
  4. 既設系統との接続位置は、現場作業時に任意に決定する。
正解と解説を見る

正解：切替時の停止時間、逆流防止、バイパス経路を事前に検討する。

運転継続工事では、停止時間の最小化と逆流・誤接続防止を含む切替手順の事前検討が重要である。

問3（監理技術）

発注者から直接請け負った管工事で、下請契約の請負代金総額が5,000万円以上となる場合、元請が配置すべき技術者として適切なものはどれか。

  1. 主任技術者を配置すれば足りる。
  2. 安全衛生責任者を主任技術者に代える。
  3. 現場代理人を監理技術者に代える。
  4. 監理技術者を配置する。
正解と解説を見る

正解：監理技術者を配置する。

管工事の元請で下請代金総額が5,000万円以上の場合は、主任技術者に代えて監理技術者を置く。

問4（施工経験記述）

工程短縮を目的に配管工事の施工手順を見直す場合、最も適切な検討内容はどれか。

  1. 後工程の検査項目を省略して作業時間を削減する。
  2. 材料搬入を最終日にまとめ、現場内の仮置きを減らす。
  3. 作業員を増員し、作業場所の制限を確認せず同時施工する。
  4. 関連工種との取合いを確認し、先行可能なプレハブ化範囲を拡大する。
正解と解説を見る

正解：関連工種との取合いを確認し、先行可能なプレハブ化範囲を拡大する。

工程短縮は品質や安全を損なわず、取合い確認と先行製作などで手待ちを減らすことが重要である。

問5（高度設備工学）

冷温水配管の二次側ポンプでインバータ制御を行う場合、差圧センサの設置位置として一般に望ましいものはどれか。

  1. 冷凍機入口の還り管だけに設置する
  2. 負荷末端に近い往還配管間に設置する
  3. 膨張タンク接続部の直近に設置する
  4. ポンプ吐出直後のみに設置する
正解と解説を見る

正解：負荷末端に近い往還配管間に設置する

末端差圧を検出すると、最不利系統の必要差圧を確保しつつ搬送動力を低減しやすい。

問6（施工計画）

大型空調機を地下機械室へ搬入する計画で、搬入口や通路寸法の確認と併せて最も優先して検討すべき事項はどれか。

  1. 取扱説明書の保管場所を施工図に記載すること。
  2. 搬入経路の床耐力、揚重方法、仮置きスペースの確保。
  3. 機器の銘板表示が完成後に見える位置か。
  4. 機器塗装色が建築仕上げと調和しているか。
正解と解説を見る

正解：搬入経路の床耐力、揚重方法、仮置きスペースの確保。

大型機器搬入では、寸法だけでなく床耐力、揚重荷重、仮置き場所を含めて安全性を確認する。
