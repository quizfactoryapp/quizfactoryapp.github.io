問1（精神医学）

統合失調症の陽性症状として最も適切なものはどれか。陰性症状や認知機能障害との違いに留意して選べ。

  1. 感情の平板化
  2. 意欲の低下
  3. 被害妄想
  4. 遂行機能の低下
正解と解説を見る

正解：被害妄想

被害妄想は現実検討の障害として出現する陽性症状である。感情平板化や意欲低下は陰性症状に分類される。

問2（精神保健福祉援助）

リカバリー志向の精神保健福祉援助に関する次の記述のうち、最も適切なものを一つ選びなさい。

  1. 本人の希望や強みを尊重し、主体的な生活の再構築を支える。
  2. 支援者が本人の生活目標を専門的に決定する。
  3. 再発予防のため、地域での役割取得は避ける。
  4. 症状の完全消失を支援の唯一の到達点とする。
正解と解説を見る

正解：本人の希望や強みを尊重し、主体的な生活の再構築を支える。

リカバリーは症状の有無だけでなく、本人の希望、強み、主体性を重視して生活を支える考え方である。

問3（精神保健福祉制度）

精神保健福祉法の目的に関する記述として、最も適切なものを一つ選びなさい。

  2. 精神障害者の雇用義務率を定め、企業に雇用計画の作成を義務づけることを主目的とする。
  3. 精神障害者の医療、保護、社会復帰、自立と社会参加の促進、国民の精神的健康の保持増進を図る。
  4. 生活保護の医療扶助を精神科医療に限定して給付するための手続を定める。
正解と解説を見る

正解：精神障害者の医療、保護、社会復帰、自立と社会参加の促進、国民の精神的健康の保持増進を図る。

精神保健福祉法は、精神障害者の医療・福祉と社会参加、国民の精神保健の向上を目的とする。

問4（地域生活支援）

就労継続支援A型の説明として、最も適切なものを一つ選びなさい。

  1. 対象者は精神障害者に限定される。
  2. 一般就労への移行支援だけを行い、生産活動は行わない。
  3. 利用期間は原則2年間に限定される。
  4. 利用者と事業所が雇用契約を結ぶことが原則である。
正解と解説を見る

正解：利用者と事業所が雇用契約を結ぶことが原則である。

A型は雇用契約に基づく就労機会の提供が原則で、賃金支払いが行われる。

問5（精神医学）

統合失調症の治療における第二世代抗精神病薬の説明として、最も適切なものはどれか。

  1. 陰性症状への効果はなく、陽性症状だけに用いる
  2. 代謝異常などの副作用に注意しながら使用する
  3. 依存性が強いため短期間のみ使用する
  4. すべての薬剤で錐体外路症状は全く起こらない
正解と解説を見る

正解：代謝異常などの副作用に注意しながら使用する

第二世代抗精神病薬は錐体外路症状が比較的少ない一方、体重増加や糖脂質代謝異常などの監視が重要である。

  3. 家族の意向を本人の意思より優先して支援計画を作る。
