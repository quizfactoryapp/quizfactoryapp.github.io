ニュース時事能力検定試験 予想問題の例

問1（政治）

日本国憲法が定める国会の地位について、最も適切なものはどれか。国会は何と位置づけられているか。

  1. 国権の最高機関で唯一の立法機関
  2. 内閣を補佐する行政機関
  3. 地方自治を監督する専門機関
  4. 司法権を統括する最高機関
正解と解説を見る

正解：国権の最高機関で唯一の立法機関

憲法41条は、国会を国権の最高機関であり、国の唯一の立法機関と定めている。

問2（経済）

日本銀行が政策金利を引き上げると、一般に家計や企業の借り入れにはどのような影響が出やすいか。

  1. 為替相場には必ず円安方向の影響だけが出る
  2. 預金金利だけが下がり、貸出金利は変わらない
  3. 借り入れコストが上がり、投資や消費が抑えられやすい
  4. 利払い負担が軽くなり、借り入れが急増しやすい
正解と解説を見る

正解：借り入れコストが上がり、投資や消費が抑えられやすい

利上げは貸出金利の上昇につながりやすく、資金需要を冷やして物価上昇を抑える効果がある。

問3（社会・環境）

厚生労働省の2024年人口動態統計で、日本の出生数と合計特殊出生率について正しい組み合わせはどれか。

  1. 出生数は前年より増え、合計特殊出生率は1.40を超えた
  2. 出生数は80万人台、合計特殊出生率は1.30台
  3. 出生数は100万人を回復し、合計特殊出生率は2.00に近づいた
  4. 出生数は70万人を下回り、合計特殊出生率は1.15
正解と解説を見る

正解：出生数は70万人を下回り、合計特殊出生率は1.15

2024年の出生数は68万6061人で初めて70万人を割り、合計特殊出生率は1.15だった。

問4（国際情勢）

国連安全保障理事会で、常任理事国5カ国に認められ、決議案の採択を阻むことがある権限は何か。

  1. 総会代行権
  2. 勧告停止権
  3. 拒否権
  4. 信任投票権
正解と解説を見る

正解：拒否権

安保理の常任理事国は米英仏中ロの5カ国で、実質事項の決議に拒否権を行使できる。

問5（政治）

衆議院と参議院で異なる議決をした法律案について、衆議院の優越が認められる場合の説明として正しいものはどれか。

  1. 衆議院で出席議員の過半数が再議決すれば成立する
  2. 参議院の議決が常に優先される
  3. 両院協議会を開けば自動的に成立する
  4. 衆議院で出席議員の3分の2以上が再議決すれば成立する
正解と解説を見る

正解：衆議院で出席議員の3分の2以上が再議決すれば成立する

法律案は参議院で否決などされた場合、衆議院が出席議員の3分の2以上で再議決すれば成立する。

問6（経済）

政府が景気後退時に公共事業を増やしたり減税したりする財政政策の主な目的として最も適切なものはどれか。

  1. 中央銀行の独立性を完全になくす
  2. 需要を増やし、雇用や生産の落ち込みを和らげる
  3. すべての国債を直ちに償還する
  4. 輸入品の価格を法律で一律に固定する
正解と解説を見る

正解：需要を増やし、雇用や生産の落ち込みを和らげる

不況時の拡張的財政政策は、政府支出や減税で総需要を支え、景気の下振れを緩和する。
