問1（建築物衛生行政）

建築物衛生法の目的として最も適切なものはどれか。多数の者が使用する建築物の維持管理について、環境衛生上必要な事項を定める趣旨を問う。

  1. 建築物における衛生的な環境を確保し、公衆衛生の向上及び増進に資すること
  2. 建築物の売買価格を公的に評価すること
  3. 建築物の耐震性能を統一的に向上させること
  4. 建築物の省エネルギー性能を格付けすること
正解と解説を見る

正解：建築物における衛生的な環境を確保し、公衆衛生の向上及び増進に資すること

建築物衛生法は、維持管理に関する環境衛生上の事項を定め、衛生的環境の確保と公衆衛生の向上を目的とする。

問2（空気環境管理）

空気調和設備の外気取入口の設置に関する記述として、最も適切なものはどれか。

  1. 外気量を安定させるため、地下駐車場内に設ける。
  2. 冬期の凍結防止のため、厨房排気口の近くに設ける。
  3. 雨水侵入を避けるため、床面に近い低位置に設ける。
  4. 排気口や汚染源から十分離し、清浄な外気を取り入れられる位置に設ける。
正解と解説を見る

正解：排気口や汚染源から十分離し、清浄な外気を取り入れられる位置に設ける。

外気取入口は排気や交通排ガスなどの影響を避け、清浄な外気を確保できる位置に設ける。

問3（給排水衛生）

飲料水の残留塩素管理に関する次の記述のうち、建築物内の給水栓での衛生管理として最も適切なものはどれか。

  1. 残留塩素は受水槽入口だけで測定すれば足りる。
  2. 遊離残留塩素は常に0であることが望ましい。
  3. 結合残留塩素は測定対象から除外してよい。
  4. 給水栓で遊離残留塩素0.1mg/L以上を確認する。
正解と解説を見る

正解：給水栓で遊離残留塩素0.1mg/L以上を確認する。

末端給水栓で消毒効果が保たれていることを確認するため、遊離残留塩素0.1mg/L以上が基本である。

問4（清掃・防除）

事務所ビルの廃棄物保管場所の管理として、衛生害虫や悪臭の発生を抑えるために最も適切なものはどれか。

  1. 床を常時湿らせ、粉じんの舞い上がりを防ぐ。
  2. 搬出直前まで分別せず、保管場所で一括して仕分ける。
  3. 容器はふた付きとし、清掃しやすく排水に配慮した場所で保管する。
  4. 換気を避け、外部から昆虫が入らないよう密閉する。
正解と解説を見る

正解：容器はふた付きとし、清掃しやすく排水に配慮した場所で保管する。

ふた付き容器、清掃性、排水、換気を確保することで、悪臭や害虫の発生を抑えられる。

問5（建築物衛生行政）

特定建築物に該当する規模要件として、学校教育法第1条に規定する学校以外の特定用途に供される部分の延べ面積は原則としてどれか。

  1. 2,000平方メートル以上
  2. 3,000平方メートル以上
  3. 5,000平方メートル以上
  4. 1,000平方メートル以上
正解と解説を見る

正解：3,000平方メートル以上

一般の特定用途では、特定用途に供される部分の延べ面積が3,000平方メートル以上であることが要件となる。

問6（空気環境管理）

建築物環境衛生管理基準における居室の二酸化炭素濃度の基準値として、正しいものはどれか。

  1. 1,000ppm以下
  2. 2,000ppm以下
  3. 500ppm以下
  4. 5,000ppm以下
正解と解説を見る

正解：1,000ppm以下

居室の二酸化炭素濃度は、換気状態の代表的指標として1,000ppm以下に維持する。
