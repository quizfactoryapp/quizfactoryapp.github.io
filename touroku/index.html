登録販売者 予想問題の例

問1（医薬品の基本知識）

医薬品の本質として正しいものはどれか。医薬品は何を目的として使用されるか？

  1. 栄養補助のための食品
  2. 化粧品や美容目的の物質
  3. 病気の予防や治療に用いる物質
  4. 精神的安定を目的としたサプリメント
正解と解説を見る

正解：病気の予防や治療に用いる物質

医薬品は病気の予防、診断、治療を目的として使用される物質です。

問2（人体の構造と働き）

消化器系で、食べ物の栄養分を吸収する主な場所はどこですか？

  1. 大腸
  2. 小腸
  3. 胃
  4. 食道
正解と解説を見る

正解：小腸

栄養の吸収は主に小腸で行われます。胃では主に消化が進みます。

問3（主な医薬品）

風邪薬に含まれる成分のうち、鼻づまりを改善する目的で配合されているのはどれか。

  1. ジフェンヒドラミン
  2. グアイフェネシン
  3. プソイドエフェドリン
  4. アセトアミノフェン
正解と解説を見る

正解：プソイドエフェドリン

プソイドエフェドリンは血管収縮作用があり、鼻粘膜の腫れを抑え鼻づまりを改善する成分です。

問4（薬事関連法規・制度）

医薬品医療機器等法において、一般用医薬品の販売に必要な資格はどれか。

  1. 薬剤師免許
  2. 登録販売者資格
  3. 看護師資格
  4. 管理栄養士資格
正解と解説を見る

正解：登録販売者資格

一般用医薬品販売には薬剤師か登録販売者の資格が必要であるが、登録販売者が特に重要である。

問5（医薬品の基本知識）

医薬品の副作用について正しい説明はどれか？

  1. 副作用は薬の効果を高める作用である
  2. 必ず全ての人に起こる症状である
  3. 薬の主作用以外に望ましくない反応が現れることがある
  4. 副作用が出た場合は必ず服用を続けるべきである
正解と解説を見る

正解：薬の主作用以外に望ましくない反応が現れることがある

副作用は薬の主作用以外に望ましくない反応が現れることを指します。

問6（人体の構造と働き）

呼吸器系において、気体交換が行われる場所はどこですか？

  1. 気管
  2. 鼻腔
  3. 肺胞
  4. 喉頭
正解と解説を見る

正解：肺胞

肺胞は酸素と二酸化炭素の交換が行われる肺の微細な構造です。
