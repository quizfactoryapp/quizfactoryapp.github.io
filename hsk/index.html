HSK漢語水平考試 予想問題の例

問1（听力）

【短対話理解】男：明日の会議は何時からですか。女：十時の予定でしたが、部長の都合で三十分遅くなりました。会議は何時からですか。

  1. 九時半
  2. 十時
  3. 十時半
  4. 十一時
正解と解説を見る

正解：十時半

女の人は十時の予定が三十分遅くなったと言っているので、会議は十時半からです。

問2（阅读）

語順整序：次の語句「我／昨天／在图书馆／复习／了／两个小时」を自然な中国語の文に並べたものはどれですか。

  1. 我复习了昨天在图书馆两个小时。
  2. 昨天我复习在图书馆了两个小时。
  3. 我在图书馆昨天两个小时复习了。
  4. 我昨天在图书馆复习了两个小时。
正解と解説を見る

正解：我昨天在图书馆复习了两个小时。

時間「昨天」は主語の後、場所「在图书馆」は動詞の前に置き、時量補語は動詞句の後に置きます。

問3（书写）

指定語句「因为……所以……」を使った文として、最も自然で正しいものを選びなさい。

  1. 因为今天下雨，所以我没去跑步。
  2. 所以今天下雨，因为我没去跑步。
  3. 今天因为下雨，所以我没去跑步吗。
  4. 因为今天下雨，我所以没去跑步。
正解と解説を見る

正解：因为今天下雨，所以我没去跑步。

「因为」は原因、「所以」は結果を導きます。語順も意味関係も自然なaが正答です。

問4（漢語語彙）

次の中国語文の空欄に入る最も自然な量詞を選びなさい。昨天我在书店买了一（　）汉语词典，打算每天查新词。

  1. 条
  2. 张
  3. 本
  4. 辆
正解と解説を見る

正解：本

「词典」は本の一種なので量詞は「本」を用います。「条」は細長い物、「张」は紙などに使います。

問5（听力）

【写真選択】音声：小王は公園のベンチに座り、新聞を読みながらコーヒーを飲んでいます。どの写真が内容に合いますか。

  1. 教室で宿題を書く学生
  2. 公園のベンチで新聞を読む人
  3. 駅で切符を買っている人
  4. 食堂で友達と話す人
正解と解説を見る

正解：公園のベンチで新聞を読む人

音声では公園のベンチ、新聞、コーヒーが示されており、選択肢bが最も合っています。

問6（阅读）

空所補充：这本书我已经看完了，内容很有意思，____ 有些地方不太容易懂。空所に入る最も適切な語はどれですか。

  1. 而且
  2. 如果
  3. 但是
  4. 所以
正解と解説を見る

正解：但是

前半は高評価、後半は理解しにくい部分があるという逆接なので、「但是」が最も自然です。
