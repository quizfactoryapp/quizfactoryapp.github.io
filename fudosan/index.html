不動産鑑定士 予想問題の例

問1（鑑定理論）

不動産鑑定評価基準における価格の三面性と鑑定評価方式の対応として、最も適切なものはどれか。

  1. 三方式はいずれも市場性のみに対応し、費用性や収益性は勘案しない。
  2. 費用性に収益還元法、市場性に原価法、収益性に取引事例比較法が対応する。
  3. 費用性に取引事例比較法、市場性に収益還元法、収益性に原価法が対応する。
  4. 費用性に原価法、市場性に取引事例比較法、収益性に収益還元法が対応する。
正解と解説を見る

正解：費用性に原価法、市場性に取引事例比較法、収益性に収益還元法が対応する。

原価法は費用性、取引事例比較法は市場性、収益還元法は収益性を基礎に価格を試算する。

問2（民法）

民法上、所有権に基づく妨害排除請求権に関する次の記述のうち、最も適切なものはどれか。

  1. 不法占有者に対しては、所有者であっても明渡しを請求できない。
  2. 妨害排除請求には、常に相手方の故意又は過失が必要である。
  3. 所有者は、所有権を妨害する者に対し、その妨害の排除を請求できる。
  4. 所有権に基づく請求権は、動産には認められない。
正解と解説を見る

正解：所有者は、所有権を妨害する者に対し、その妨害の排除を請求できる。

所有権は物を直接支配する権利であり、妨害があれば故意過失を問わず排除請求が可能である。

問3（経済学）

ある財の価格が上昇したとき、他の条件が一定なら通常その財の需要量は減少する。この関係を最も適切に説明するものはどれか。

  1. 限界効用逓減などにより需要曲線は右下がりになる
  2. 供給者数の増加により需要量が減少する
  3. 価格上昇は常に需要曲線そのものを左方へ移動させる
  4. 所得効果と代替効果により需要曲線は右上がりになる
正解と解説を見る

正解：限界効用逓減などにより需要曲線は右下がりになる

価格と需要量の逆方向の関係は需要法則であり、通常は右下がりの需要曲線として表される。

問4（会計学）

貸借対照表における固定資産の表示に関する次の記述のうち、企業会計原則上もっとも適切なものはどれか。

  1. 建設仮勘定は完成まで費用処理し、完成時に資産へ振り替える。
  2. 土地は使用により価値が減少するため、必ず定額法で償却する。
  3. 固定資産は原則として時価で評価し、評価差額を当期損益に計上する。
  4. 有形固定資産は取得原価から減価償却累計額を控除した額で表示される。
正解と解説を見る

正解：有形固定資産は取得原価から減価償却累計額を控除した額で表示される。

有形固定資産は取得原価主義に基づき、減価償却累計額を控除した帳簿価額で表示する。

問5（鑑定理論）

原価法において、積算価格を求める基本的な手順として最も適切なものはどれか。

  1. 純収益を還元利回りで還元し、将来の売却価格を加算する。
  2. 価格時点の再調達原価を求め、これに減価修正を行う。
  3. 多数の取引事例を選択し、事情補正と時点修正のみで価格を決定する。
  4. 公示価格を基準に、建物の賃料収入を控除して土地価格を求める。
正解と解説を見る

正解：価格時点の再調達原価を求め、これに減価修正を行う。

原価法は再調達原価から物理的、機能的、経済的減価を反映して積算価格を求める手法である。

問6（民法）

登記を備えていない不動産物権変動について、第三者との関係で正しい記述はどれか。

  1. 売買契約が有効に成立すれば、登記なくして常に第三者に対抗できる。
  2. 登記は当事者間の物権変動の効力発生要件である。
  3. 代金を全額支払えば、登記がなくても第三者に対抗できる。
  4. 不動産物権変動は、原則として登記をしなければ第三者に対抗できない。
正解と解説を見る

正解：不動産物権変動は、原則として登記をしなければ第三者に対抗できない。

不動産物権変動は当事者間では意思表示で効力を生じるが、第三者対抗には登記が必要である。
