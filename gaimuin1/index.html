証券外務員一種 予想問題の例

問1（金融商品取引）

株式の注文方法に関する説明として、もっとも適切なものはどれか。

  1. 成行注文は、約定価格があらかじめ確定している注文である。
  2. 指値注文は、買い注文では指定した価格以下、売り注文では指定した価格以上で約定する注文である。
  3. 成行注文は、売買価格を指定して発注する注文である。
  4. 指値注文は、必ず直ちに全数量が約定する注文である。
正解と解説を見る

正解：指値注文は、買い注文では指定した価格以下、売り注文では指定した価格以上で約定する注文である。

指値注文は価格条件を指定する注文で、買いは上限価格、売りは下限価格を示す。成行注文は価格を指定しない。

問2（法令・諸規則）

金融商品取引業者等が広告等を行う際の表示事項として、金融商品取引法上、原則として求められるものはどれか。

  1. 取引所の全上場銘柄の一覧
  2. 顧客の年収および投資経験の詳細
  3. 手数料等の概要および元本損失が生じるおそれ
  4. 担当外務員の個人資産の状況
正解と解説を見る

正解：手数料等の概要および元本損失が生じるおそれ

広告等では、手数料やリスクなど投資判断に重要な事項を明瞭かつ正確に表示する必要がある。

問3（市場と経済）

金融市場において、短期金融市場で主に取引される商品として最も適切なものはどれか。

  1. コールローン
  2. 普通社債
  3. 不動産投資信託
  4. 株式投資信託
正解と解説を見る

正解：コールローン

コールローンは金融機関相互で短期資金を融通する代表的な短期金融市場の商品である。

問4（税制・財務分析）

上場株式等の配当金について、申告分離課税を選択した場合の取扱いとして正しいものはどれか。

  1. 給与所得と損益通算できる
  2. 上場株式等の譲渡損失との損益通算ができる
  3. 税率は所得税のみ10％である
  4. 配当控除を受けることができる
正解と解説を見る

正解：上場株式等の譲渡損失との損益通算ができる

申告分離課税を選ぶと配当控除は不可だが、上場株式等の譲渡損失との損益通算が可能である。

問5（金融商品取引）

信用取引で委託保証金率が一定水準を下回った場合に、顧客へ追加差入れを求める保証金を何というか。

  1. 品貸料
  2. 日歩
  3. 追証
  4. 逆日歩
正解と解説を見る

正解：追証

委託保証金の維持率が低下した場合、顧客は不足分を追加で差し入れる必要があり、これを追証といいます。

問6（法令・諸規則）

金融商品取引法における適合性の原則に関する記述として、最も適切なものはどれか。

  1. 法人顧客には適合性の原則は一切適用されない
  2. 顧客が希望すれば、どのような商品でも必ず販売しなければならない
  3. 損失補てんを約束した場合に限り適合性を確認する
  4. 顧客の知識、経験、財産状況および契約締結目的に照らして勧誘する
正解と解説を見る

正解：顧客の知識、経験、財産状況および契約締結目的に照らして勧誘する

適合性の原則は、顧客属性や投資目的に照らして不適当な勧誘をしてはならないとする規制である。
