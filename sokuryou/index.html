測量士補 予想問題の例

問1（測量法規）

測量法において、基本測量を実施する主体として正しいものはどれか。

  1. 都道府県知事
  2. 国土地理院の長
  3. 登録測量業者
  4. 市町村長
正解と解説を見る

正解：国土地理院の長

基本測量は、すべての測量の基礎となる測量であり、国土地理院の長が実施する。

問2（基準点測量）

トータルステーションによる水平角観測で、望遠鏡の正反を1対として観測する主な目的として最も適切なものはどれか。

  1. 気温による距離補正を不要にするため
  2. 視準軸誤差など器械誤差の影響を軽減するため
  3. 器械高の読定誤差を完全に除去するため
  4. 標尺の沈下量を直接求めるため
正解と解説を見る

正解：視準軸誤差など器械誤差の影響を軽減するため

正反観測を平均すると、視準軸誤差や水平軸誤差などの系統的影響を小さくできる。

問3（地形測量）

平板測量でアリダードを用いて目標物を視準し、図紙上に方向線を引く作業として最も適切なものはどれか。

  1. 整準
  2. 方向観測
  3. 縮尺補正
  4. 定位
正解と解説を見る

正解：方向観測

アリダードで目標を視準し、図紙上にその方向を記入する作業は方向観測である。整準や定位とは目的が異なる。

問4（応用測量）

路線測量において、IPを設置して単曲線を計画する際、交角と曲線半径から直接求められる主な要素として最も適切なものはどれか。

  1. 筆界点番号と地番
  2. 接線長と曲線長
  3. 流量と水位差
  4. 横断勾配と計画高
正解と解説を見る

正解：接線長と曲線長

単曲線では交角と半径から接線長、曲線長、外割長などの曲線要素を計算する。

問5（測量法規）

公共測量を実施しようとする測量計画機関が、あらかじめ行うべき手続として正しいものはどれか。

  1. 国土地理院の長へ実施計画書を提出し、技術的助言を求める
  2. 測量士会へ成果を提出する
  3. 市町村議会の議決を得る
  4. 法務局へ測量標の設置許可を申請する
正解と解説を見る

正解：国土地理院の長へ実施計画書を提出し、技術的助言を求める

公共測量では、計画機関は実施前に国土地理院の長へ計画書を提出し、助言を求める。

問6（基準点測量）

トータルステーションで斜距離と鉛直角を観測して水平距離を求める場合、通常必要となる処理はどれか。

  1. 斜距離に方位角を加算して平均する
  2. 斜距離を標高差で割って縮尺係数を求める
  3. 斜距離から器械高だけを差し引く
  4. 斜距離を鉛直角により水平成分へ換算する
正解と解説を見る

正解：斜距離を鉛直角により水平成分へ換算する

水平距離は斜距離の水平成分であり、鉛直角または高度角を用いて換算する。
