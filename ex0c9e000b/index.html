一級小型船舶操縦士 予想問題の例

問1（航海）

海図上で自船位置を求めるため、同時に二つの灯台の方位を測った。交差角として最も精度が高くなりやすいものはどれか。

  1. 約170度
  2. 約30度
  3. 約90度
  4. 約5度
正解と解説を見る

正解：約90度

方位線の交差角は直角に近いほど位置誤差が小さく、浅すぎる交差は大きな誤差を生む。

問2（海上法規）

視界が良好な昼間、動力船同士が互いに横切る態勢で接近している。自船から見て相手船を右舷側に見る場合、原則として自船はどうするべきか。

  1. 相手船を避けるため早めに大きく動作する
  2. 直ちに左転し、相手船の船尾方へ向かう
  3. 針路速力を保ち、相手船に避航させる
  4. 速力を増して相手船の船首方を横切る
正解と解説を見る

正解：相手船を避けるため早めに大きく動作する

横切り船では、他船を右舷側に見る動力船が避航船となり、早期かつ明確な避航動作をとる。

問3（機関）

船外機の運転中、冷却水確認孔から水が出ていないことに気付いた。このまま航走を続けると最も起こりやすい不具合はどれか。

  1. 燃料タンク内の圧力が下がり、燃料が濃くなる
  2. プロペラのピッチが自動的に小さくなる
  3. 機関が過熱し、焼き付きなどの重大な故障につながる
  4. 点火プラグが冷えすぎて始動不能になる
正解と解説を見る

正解：機関が過熱し、焼き付きなどの重大な故障につながる

冷却水が出ない場合は冷却不良が疑われる。運転継続は過熱や焼き付きの原因となるため、速やかに停止して点検する。

問4（操船）

発航前点検で燃料系統を確認する際、最も適切な点検内容はどれか。

  1. 燃料タンクを満量にしていれば、配管や接続部の確認は省略できる。
  2. 燃料臭が少しあっても換気扇を回せば、点検せず出航してよい。
  3. 燃料の残量、燃料コックの開閉、配管や接続部からの漏れを確認する。
  4. 出航後にエンジンが始動すれば、燃料系統は正常と判断できる。
正解と解説を見る

正解：燃料の残量、燃料コックの開閉、配管や接続部からの漏れを確認する。

燃料不足や漏れは航行不能や火災の原因となるため、残量、コック、漏れを出航前に確認する。

問5（航海）

海図で水深の数字が示す基準面について、通常の日本の海図で正しい説明はどれか。

  1. 最高高潮面からの深さを示す
  2. 灯台基準面からの深さを示す
  3. 最低水面を基準にした深さを示す
  4. 平均海面からの高さを示す
正解と解説を見る

正解：最低水面を基準にした深さを示す

海図の水深は原則として最低水面を基準とするため、潮位を加減して実際の水深を見積もる。

問6（海上法規）

動力船同士がほぼ正反対の針路で接近し、衝突のおそれがある。海上衝突予防法上、両船が原則としてとるべき動作はどれか。

  1. 速力を増して短時間で航過する
  2. 互いに右転し、左舷対左舷で航過する
  3. 大きい船だけが避航し、小さい船は保持する
  4. 互いに左転し、右舷対右舷で航過する
正解と解説を見る

正解：互いに右転し、左舷対左舷で航過する

行会い船で衝突のおそれがあるときは、両船が各々右転して互いに左舷側を対して航過する。
