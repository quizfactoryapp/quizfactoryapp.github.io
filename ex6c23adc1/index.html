ｅｃｏ検定（環境社会検定試験） 予想問題の例

問1（持続可能な社会）

企業が温室効果ガス排出の実質ゼロを目指す際、一般に「カーボンニュートラル」の説明として最も適切なのはどれか。

  1. 排出量と吸収・除去量を差し引きして全体として均衡させる考え方
  2. 排出量を一切出さない状態のみを指し、吸収や除去は含まない
  3. 再生可能エネルギーを一度でも導入すれば達成したとみなす状態
  4. 国内での排出だけを対象にし、海外での排出は対象外とする考え方
正解と解説を見る

正解：排出量と吸収・除去量を差し引きして全体として均衡させる考え方

カーボンニュートラルは、排出を最大限削減したうえで、残余排出を吸収・除去で埋め合わせ、全体として実質ゼロを目指す考え方である。

問2（地球環境問題）

地球温暖化対策として国際的に重視される「カーボンプライシング」の説明として、最も適切なものはどれですか。企業や消費者の行動変容を促す考え方に着目して選びなさい。

  1. 森林保全のため木材製品の輸出を全面的に停止する制度
  2. 再生可能エネルギー設備の設置場所を国が無償提供する制度
  3. 家庭の電気料金を季節に関係なく一定額に固定する政策
  4. 温室効果ガス排出に価格を付け、排出削減を経済的に促す仕組み
正解と解説を見る

正解：温室効果ガス排出に価格を付け、排出削減を経済的に促す仕組み

カーボンプライシングは、炭素排出にコストを反映させることで、企業や消費者が省エネや低炭素な選択を進めやすくする政策手法です。

問3（企業・地域の環境経営）

ISO 14001に基づく環境マネジメントシステムの説明として最も適切なものはどれか。組織の環境影響を管理し、法令順守と継続的改善を進める観点から選べ。

  1. 認証取得後は環境目標の見直しを行わなくてよい。
  2. 環境側面を把握し、法令順守と継続的改善をPDCAで進める。
  3. 製品品質だけを対象にし、環境側面は扱わない。
  4. 事故が起きた時だけ一時的に運用する仕組みである。
正解と解説を見る

正解：環境側面を把握し、法令順守と継続的改善をPDCAで進める。

EMSは環境側面を把握し、目標設定・運用・監査・見直しを通じて法令順守と継続的改善を図る仕組みである。

問4（持続可能な社会）

SDGsの「誰一人取り残さない」という理念を最もよく反映した行政施策として、適切なのはどれか。

  1. 経済成長を優先し、教育や福祉の地域差は当面容認する
  2. 全国一律の施策のみを実施し、地域課題への調整を避ける
  3. 支援を受けやすい層だけに限定して短期成果を優先する
  4. 弱い立場にある人々へのアクセス改善を含め、包摂的に制度設計する
正解と解説を見る

正解：弱い立場にある人々へのアクセス改善を含め、包摂的に制度設計する

SDGsの中核には包摂性があり、社会的に不利な立場の人々も恩恵を受けられるよう、制度やサービスへのアクセスを確保することが重要である。

問5（地球環境問題）

パリ協定の特徴として最も適切なものはどれですか。京都議定書との違いも踏まえ、各国の参加のあり方と長期目標の考え方に注目して選びなさい。

  1. すべての締約国が削減目標を提出し、気温上昇抑制を目指す協定
  2. 先進国だけに削減義務を課し、途上国は対象外とした枠組み
  3. 化石燃料の国際取引を全面禁止することを主目的とした協定
  4. 森林伐採のみを対象にした地域限定の環境協定
正解と解説を見る

正解：すべての締約国が削減目標を提出し、気温上昇抑制を目指す協定

パリ協定では先進国と途上国の双方が自国目標を提出し、世界平均気温上昇を大きく下回る水準に抑えることを共通の方向として掲げています。

問6（企業・地域の環境経営）

工場で環境マネジメントシステムを構築する際、著しい環境側面の特定で優先的に確認すべき観点として最も適切なものはどれか。

  1. 影響の大きさ、発生頻度、法的要求、利害関係者の関心を踏まえる。
  2. 決算期に近い支出科目だけを優先して見る。
  3. 担当者の勤続年数だけを基準に判断する。
  4. 設備の色や制服デザインの統一状況だけを確認する。
正解と解説を見る

正解：影響の大きさ、発生頻度、法的要求、利害関係者の関心を踏まえる。

著しい環境側面は、環境影響の大きさや発生頻度、法的要求、地域住民や顧客などの関心を踏まえて評価する。
