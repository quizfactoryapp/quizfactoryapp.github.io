ビジネス文書実務検定試験 予想問題の例

問1（速度部門）

速度部門の日本語入力では、10分間で入力した文章のうち、成績として最も重視されるものはどれか。

  1. 誤りを除いた正確な入力字数
  2. 使用した漢字の種類の多さ
  3. 入力に使ったソフトの機能数
  4. 文字の見た目を整えた程度
正解と解説を見る

正解：誤りを除いた正確な入力字数

速度部門は、限られた時間内にどれだけ正確に入力できたかを正確字数で評価する。

問2（ビジネス文書書式）

社内の各部署へ会議日程を知らせる通知文を作成する場合、一般的な社内文書の書式として最も適切なものはどれか。

  1. 頭語と結語を必ず入れ、時候の挨拶を長く述べる。
  2. 本文の末尾に「敬具」を置き、記書きは使用しない。
  3. 宛名を省略し、差出人名だけを中央に配置する。
  4. 件名を明示し、用件を簡潔にまとめ、頭語・結語は省く。
正解と解説を見る

正解：件名を明示し、用件を簡潔にまとめ、頭語・結語は省く。

社内文書は迅速な伝達を目的とするため、件名を示して簡潔に書き、頭語・結語や時候の挨拶は通常省く。

問3（文書作成実技）

ビジネス文書で表を作成する際、項目名の行とデータ行を区別し、読み取りやすくするために最も適切な操作はどれか。

  1. 項目名の行に網かけや太字を設定する
  2. 項目名の行だけを削除する
  3. 表全体を本文の中央に重ねる
  4. すべての文字を白色にする
正解と解説を見る

正解：項目名の行に網かけや太字を設定する

項目名を太字や網かけで強調すると、表の構造が明確になり、内容を素早く確認できる。

問4（表記技能）

次のうち、社外向け案内文で、補助動詞としての「ください」を最も適切に表記しているものはどれか。

  1. 別紙資料をご確認下さいます様。
  2. 別紙資料を御確認くださいませ。
  3. 別紙資料をご確認ください。
  4. 別紙資料を御確認下さい。
正解と解説を見る

正解：別紙資料をご確認ください。

「確認する」に付く補助動詞は平仮名で「ください」と書くのが一般的で、過度な敬語も避ける。

問5（速度部門）

10分間入力の途中で変換ミスに気付いた場合の対応として、最も適切なものはどれか。

  1. 気付いても直さず最後まで入力する
  2. すべて平仮名にして入力を続ける
  3. 別の語に置き換えて意味を近づける
  4. 可能な範囲で正しい表記に直してから続ける
正解と解説を見る

正解：可能な範囲で正しい表記に直してから続ける

速度だけでなく正確さも評価されるため、変換ミスは放置せず、時間内で修正することが望ましい。

問6（ビジネス文書書式）

取引先へ新製品発表会の案内状を送る。社外文書として、宛名・発信者名・本文の扱いで最も適切なものはどれか。

  1. 宛名は省き、本文からすぐに用件を書き始める。
  2. 頭語だけを書き、結語は紙面節約のため省略する。
  3. 発信者名を左端に置き、宛名を右端に置く。
  4. 宛名を左側、発信者名を右側に置き、礼儀に沿って本文を書く。
正解と解説を見る

正解：宛名を左側、発信者名を右側に置き、礼儀に沿って本文を書く。

社外文書では、宛名を左側、発信者名を右側に配置し、頭語・結語や挨拶を含めて礼儀正しく整える。
