カラーコーディネーター検定試験 予想問題の例

問1（色彩の基礎）

色の三属性に関する説明として最も適切なものはどれか。色相・明度・彩度がそれぞれ何を表すかに注意して選びなさい。

  1. 色相は明るさ、明度は鮮やかさ、彩度は色みの違いを表す
  2. 色相は色みの違い、明度は明るさ、彩度は鮮やかさを表す
  3. 色相は光沢、明度は透明度、彩度は材質感を表す
  4. 色相は白黒の量、明度は暖かさ、彩度は面積の大きさを表す
正解と解説を見る

正解：色相は色みの違い、明度は明るさ、彩度は鮮やかさを表す

色の三属性は、色みを示す色相、明るさを示す明度、鮮やかさを示す彩度で構成される。

問2（色彩心理）

赤が一般に連想させる心理的印象として、カラーコーディネートで最も適切なものはどれか。

  1. 高貴、神秘、哀悼だけを感じさせる
  2. 自然、安定、休息を主に感じさせる
  3. 情熱、活力、危険や警告を感じさせる
  4. 静寂、沈着、清潔感を強く感じさせる
正解と解説を見る

正解：情熱、活力、危険や警告を感じさせる

赤は血や火を想起させ、情熱や活力とともに危険・警告の象徴にも用いられる。

問3（配色技法）

同一または近いトーンで色相だけを変えてまとめる配色について、最も適切な説明はどれか。

  1. 色相環で正反対の色だけを組み合わせる配色
  2. 明度差を極端に大きくして強いコントラストを作る配色
  3. 明度・彩度の印象をそろえ、統一感を出しやすい配色
  4. 無彩色だけを用いて素材感を強調する配色
正解と解説を見る

正解：明度・彩度の印象をそろえ、統一感を出しやすい配色

トーン配色は明度・彩度のまとまりを基準にするため、色相が違っても統一感を得やすい技法です。

問4（ビジネス色彩）

新しい飲料パッケージで、低糖質で軽やかな印象を伝えたい。商品色彩の観点から最も適切な配色方針はどれか。

  1. 淡い青緑や白を基調にし、清涼感と軽さを示す
  2. 濃い茶色と金色を中心にし、重厚な熟成感を強調する
  3. 紫と黒を多用し、神秘性と高価格感だけを訴求する
  4. 高彩度の赤と黒を大面積で使い、強い刺激感を出す
正解と解説を見る

正解：淡い青緑や白を基調にし、清涼感と軽さを示す

淡い青緑や白は清涼感、軽さ、低カロリー感を連想させやすく、商品特性の伝達に適する。

問5（色彩の基礎）

明度について述べた文として正しいものはどれか。無彩色と有彩色の両方に共通する属性である点に着目しなさい。

  1. 暖色と寒色を区別するためだけの属性である
  2. 色の鮮やかさの程度だけを示す属性である
  3. 赤や青などの色みの種類だけを示す属性である
  4. 色の明るい・暗いの程度を示す属性である
正解と解説を見る

正解：色の明るい・暗いの程度を示す属性である

明度は色の明るさの尺度であり、有彩色だけでなく白・灰・黒などの無彩色にも用いられる。

問6（色彩心理）

青を用いた室内配色の心理的効果として、一般的に最も期待しやすいものはどれか。

  1. 進出感を強め、壁面を近く感じさせる
  2. 冷静さや清涼感を与え、落ち着いた印象にする
  3. 食欲を高め、時間を短く感じさせる
  4. 熱気や興奮を強め、活動量を増やす
正解と解説を見る

正解：冷静さや清涼感を与え、落ち着いた印象にする

青は寒色系で、水や空を連想させるため、清涼感・冷静・沈静の印象を与えやすい。
