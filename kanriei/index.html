管理栄養士 予想問題の例

問1（基礎栄養学）

解糖系に関する記述として、最も適切なのはどれか。酸素供給が十分な条件での最終産物とエネルギー産生に着目して選べ。

  1. ミトコンドリア内膜で乳酸を生じ、ATPを消費する
  2. グリコーゲン合成を促進し、NADHを消費する
  3. 細胞質でピルビン酸を生じ、正味2分子のATPを産生する
  4. 脂肪酸を直接分解してアセチルCoAを生じる
正解と解説を見る

正解：細胞質でピルビン酸を生じ、正味2分子のATPを産生する

解糖系は細胞質でグルコースをピルビン酸へ分解し、正味2ATPとNADHを生じる。

問2（臨床栄養学）

栄養アセスメントで、浮腫を伴う患者の体重変化を評価する際に最も注意すべき点はどれか。

  1. 体液貯留により体重が過大評価される
  2. 血清ナトリウム値は評価に不要である
  3. 体重増加を筋肉量増加と判断する
  4. BMIのみで低栄養を判定する
正解と解説を見る

正解：体液貯留により体重が過大評価される

浮腫では体液貯留により体重が増え、栄養状態を過大評価しやすい。身体所見も併せて判断する。

問3（公衆栄養学）

国民健康・栄養調査について正しいのはどれか。健康増進法に基づき、身体状況、栄養摂取量、生活習慣の状況を把握する調査である。

  1. 対象は入院患者に限定される
  2. 介護保険法に基づき3年ごとに実施される
  3. 健康増進法に基づき毎年実施される
  4. 食品企業の販売量を主な資料とする
正解と解説を見る

正解：健康増進法に基づき毎年実施される

国民健康・栄養調査は健康増進法に基づき、国民の健康増進施策の基礎資料を得るため毎年行われる。

問4（給食経営管理論）

大量調理施設で加熱調理後の食品を冷却して提供する場合、細菌増殖を抑えるための温度管理として最も適切なのはどれか。

  1. 中心温度を75℃で1分以上保った後、室温で自然放冷する。
  2. 速やかに冷却し、危険温度帯に長時間置かないよう管理する。
  3. 冷却時は食品を深い容器に入れ、乾燥を防ぐため密閉する。
  4. 再加熱する食品は、冷却時間を記録しなくてもよい。
正解と解説を見る

正解：速やかに冷却し、危険温度帯に長時間置かないよう管理する。

加熱後食品は危険温度帯での滞留を短くし、冷却時間と温度を管理することが重要である。

問5（基礎栄養学）

血糖低下時に肝臓で促進される糖質代謝として、最も適切なのはどれか。空腹時の血糖維持に関わる反応を選べ。

  1. 糖新生
  2. ペントースリン酸経路の停止
  3. グリコーゲン合成
  4. 脂肪酸合成
正解と解説を見る

正解：糖新生

空腹時には肝臓で糖新生とグリコーゲン分解が促進され、血糖の維持に働く。

問6（臨床栄養学）

糖尿病食事療法において、食後高血糖の抑制に最も直接的に関係する指導はどれか。

  1. 炭水化物量を把握し、食事ごとの偏りを減らす
  2. たんぱく質を食事から完全に除く
  3. 夕食後の果物摂取量を無制限にする
  4. 水分摂取を1日500mL以下にする
正解と解説を見る

正解：炭水化物量を把握し、食事ごとの偏りを減らす

食後血糖は炭水化物量の影響を受けやすい。量と配分を整えることが食後高血糖対策となる。
