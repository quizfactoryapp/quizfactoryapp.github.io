パンシェルジュ検定 予想問題の例

問1（パンの歴史・文化）

古代エジプトで発酵パンが広まった背景として、最も関係が深いと考えられる条件はどれか。

  1. 砂糖を大量に輸入し、菓子パンを作っていたこと
  2. 米を主食とする湿田農業が発達していたこと
  3. 麦の栽培とビール醸造が盛んで、酵母を利用しやすかったこと
  4. じゃがいもを粉にしてパン生地へ混ぜていたこと
正解と解説を見る

正解：麦の栽培とビール醸造が盛んで、酵母を利用しやすかったこと

古代エジプトでは麦作とビール醸造が発達し、酵母による発酵パンの成立に結びついたとされます。

問2（製パン材料）

強力粉が食パンや山型パンに多く使われる主な理由として、最も適切なものはどれですか。

  1. 吸水しにくく、短時間で硬い生地に仕上がるから
  2. たんぱく質量が多く、弾力のある生地骨格を作りやすいから
  3. 灰分が少ないため、必ず白い焼き色になるから
  4. でんぷんが糖化しないため、発酵を遅らせられるから
正解と解説を見る

正解：たんぱく質量が多く、弾力のある生地骨格を作りやすいから

強力粉はたんぱく質が多く、グルテン形成により発酵ガスを保持する生地を作りやすい粉です。

問3（製パン工程）

ミキシングで生地が「つながる」段階を見極める際、グルテン形成の進み具合を確認する方法として最も適切なものはどれか。

  1. 生地の表面に粉が残っているかを見る
  2. 仕込み水の温度だけを測る
  3. 生地を薄く伸ばし、膜状に広がるかを見る
  4. 焼き色が均一かを確認する
正解と解説を見る

正解：生地を薄く伸ばし、膜状に広がるかを見る

薄い膜ができるかを見ることで、グルテンの伸展性と形成状態を判断しやすい。

問4（パンの種類）

バゲットの特徴として最も適切なものはどれか。細長い形状だけでなく、材料やクラストの性質にも注目して選びなさい。

  1. 小麦粉、水、塩、酵母を基本とし、薄く香ばしい皮と大きめの気泡が特徴のパン
  2. 砂糖と卵を多く使い、黄色い内相に焼き上げるパン
  3. バターを折り込み、層状に膨らませる発酵菓子パン
  4. 型に入れて焼き、しっとりした角形に仕上げるパン
正解と解説を見る

正解：小麦粉、水、塩、酵母を基本とし、薄く香ばしい皮と大きめの気泡が特徴のパン

バゲットはリーンな配合で、外皮の香ばしさと気泡のある軽い内相が持ち味です。

問5（パンの歴史・文化）

古代エジプトのパンについて、当時の生活や宗教文化との関係を説明したものとして適切なのはどれか。

  1. パン作りは寒冷地の保存食としてのみ発達した
  2. パンは日常食であるとともに、供物や副葬品としても重要だった
  3. パンは王族だけが食べ、庶民の食生活には無関係だった
  4. パンは食用ではなく、主に金属貨幣として使われた
正解と解説を見る

正解：パンは日常食であるとともに、供物や副葬品としても重要だった

エジプトではパンが日常の主食であり、神への供物や墓への副葬品にも用いられました。

問6（製パン材料）

グルテン形成に関わる小麦たんぱく質の組み合わせとして、最も適切なものはどれですか。

  1. アミロースとアミロペクチン
  2. カゼインとホエイたんぱく
  3. グリアジンとグルテニン
  4. アルブミンとグロブリン
正解と解説を見る

正解：グリアジンとグルテニン

小麦粉に水を加えてこねると、グリアジンとグルテニンが結びつきグルテンを形成します。
