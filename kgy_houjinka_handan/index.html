法人化の判断 練習問題の例

問1（メリット・デメリット）

法人化を検討する一般的な目安として、個人事業主の利益が大きくなった場合に比較検討される主な理由はどれか。

  1. 所得税の累進課税と法人税等の負担差を比較する余地が生じるため
  2. 個人事業では経費計上が一切認められないため
  3. 売上が少ないほど法人化の税務メリットが必ず大きいため
  4. 法人化するとすべての税金が免除されるため
正解と解説を見る

正解：所得税の累進課税と法人税等の負担差を比較する余地が生じるため

所得税は累進課税のため、利益水準が上がると法人税等との比較が法人化判断の基本になります。

問2（法人と個人の税負担）

個人事業主の所得税と法人の法人税について、税率構造の一般的な違いとして最も適切なものはどれか。

  1. 個人事業主には所得税がなく、住民税だけが課される
  2. 所得税は原則として累進税率、法人税は一定範囲で比例的な税率構造をとる
  3. 所得税も法人税も、所得が増えるほど必ず同じ段階で税率が上がる
  4. 法人税は利益が少ないほど税率が無制限に高くなる制度である
正解と解説を見る

正解：所得税は原則として累進税率、法人税は一定範囲で比例的な税率構造をとる

所得税は超過累進税率が基本で、法人税は法人所得に対する税として別体系で課される。

問3（設立手続き）

株式会社の設立手続きにおいて、原則として公証人による認証が必要となる書類はどれか。

  1. 定款
  2. 株主名簿
  3. 決算公告
  4. 就業規則
正解と解説を見る

正解：定款

株式会社では、作成した定款について公証人の認証を受けるのが原則です。

問4（社会保険・運営）

株式会社などの法人事業所における健康保険・厚生年金保険の適用について、制度上の一般的な扱いはどれか。

  1. 役員だけの会社は常に適用対象外となる
  2. 法人事業所は原則として強制適用事業所となる
  3. 従業員が10人以上になった月から任意加入となる
  4. 赤字決算の事業年度は加入義務が停止される
正解と解説を見る

正解：法人事業所は原則として強制適用事業所となる

法人の事業所は、健康保険・厚生年金保険の強制適用事業所とされるのが基本です。

問5（メリット・デメリット）

法人化による信用力の一般的なメリットとして、制度・実務上よく説明されるものはどれか。

  1. 法人は契約主体になれないため取引が制限される
  2. 法人名義の契約や口座により、対外的な継続性や組織性を示しやすい
  3. 法人化すると決算書の作成義務がなくなる
  4. 法人化すれば必ず銀行融資が無審査で受けられる
正解と解説を見る

正解：法人名義の契約や口座により、対外的な継続性や組織性を示しやすい

法人は独立した法主体であり、法人名義で取引できるため組織としての信用を示しやすくなります。

問6（法人と個人の税負担）

法人化後に社長へ支払う役員報酬について、法人税法上の損金算入に関する一般的な原則はどれか。

  1. 役員報酬は会社の支出であっても、一切損金算入できない
  2. 決算後に自由に増額しても、全額が自動的に損金算入される
  3. 定期同額給与など、一定の要件を満たすものが損金算入の対象となる
  4. 利益が出た月だけ支払えば、常に損金算入が認められる
正解と解説を見る

正解：定期同額給与など、一定の要件を満たすものが損金算入の対象となる

役員報酬は定期同額給与などの要件を満たす場合に損金算入が認められる。
