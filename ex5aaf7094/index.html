二級自動車整備士 予想問題の例

問1（エンジン整備）

電子制御式燃料噴射装置で、吸入空気量を検出するエアフロー・メータの信号が実際より小さく入力された場合の燃料噴射量として適切なものはどれか。

  1. 燃料噴射量は変化せず、点火時期だけ遅角する。
  2. 燃料噴射量は多くなり、混合気は濃くなる。
  3. 燃料噴射量は少なくなり、混合気は薄くなる。
  4. 燃料噴射は停止し、燃料ポンプも停止する。
正解と解説を見る

正解：燃料噴射量は少なくなり、混合気は薄くなる。

ECUは吸入空気量が少ないと判断するため、基本噴射量を減らし、混合気は薄くなる。

問2（シャシ整備）

クラッチの遊びが規定値より小さ過ぎる場合に起こりやすい不具合として、最も適切なものはどれか。

  1. クラッチ・ペダルが戻らなくなる
  2. デファレンシャル・ギヤのバックラッシュが減少する
  3. プロペラ・シャフトの振れが増大する
  4. クラッチの滑りが発生しやすくなる
正解と解説を見る

正解：クラッチの滑りが発生しやすくなる

遊びが小さいとレリーズ機構が常に押し気味となり、圧着力不足でクラッチが滑りやすい。

問3（電装整備）

スタータ・モータのマグネット・スイッチについて、プルイン・コイルの主な働きとして適切なものはどれか。

  1. 点火時期を進角させる
  2. ピニオンをリング・ギヤ側へ押し出す力を発生させる
  3. ヘッドランプの光軸を自動調整する
  4. 発電電圧を一定に制御する
正解と解説を見る

正解：ピニオンをリング・ギヤ側へ押し出す力を発生させる

プルイン・コイルは可動鉄心を吸引し、ピニオンをリング・ギヤへかみ合わせる初期動作を行う。

問4（点検・法令）

道路運送車両法における使用者の点検・整備義務として、最も適切なものはどれか。

  1. 検査に合格していれば、次回検査まで点検義務はない
  2. 整備管理者を置かない自家用車は点検整備記録簿を作成できない
  3. 販売店が常に保安基準適合状態を維持する義務を負う
  4. 使用者は点検し、必要に応じ整備して保安基準に適合させる
正解と解説を見る

正解：使用者は点検し、必要に応じ整備して保安基準に適合させる

道路運送車両法は、使用者に点検と必要な整備を行い、保安基準適合状態を維持する義務を課している。

問5（エンジン整備）

プレッシャ・レギュレータ付き燃料装置で、吸気管負圧が大きくなるアイドル時に燃圧を低下させる主な目的はどれか。

  1. 燃料温度を上げて霧化を促進するため。
  2. 燃料ポンプの吐出量を常に最大に保つため。
  3. インジェクタ前後の圧力差をほぼ一定に保つため。
  4. インジェクタの作動音を小さくするため。
正解と解説を見る

正解：インジェクタ前後の圧力差をほぼ一定に保つため。

吸気管圧力に応じて燃圧を調整し、噴射時間に対する実噴射量を安定させる。

問6（シャシ整備）

FR車のプロペラ・シャフトに用いられるユニバーサル・ジョイントの主な役割として、正しいものはどれか。

  1. 変速時のギヤ比を自動的に変更する
  2. 駆動輪の左右回転差を吸収する
  3. 制動時の液圧を均等に配分する
  4. 軸線角度の変化を許して動力を伝達する
正解と解説を見る

正解：軸線角度の変化を許して動力を伝達する

ユニバーサル・ジョイントは、変速機とデファレンシャル間の角度変化を吸収して回転を伝える。
