エンベデッドシステムスペシャリスト 予想問題の例

問1（午前I 共通基礎）

組込み機器メーカーが新製品を短期投入するため、基板実装工程を外部委託し、自社は制御アルゴリズム開発に集中する方針を立てた。経営戦略上、この判断の説明として最も適切なのはどれか。

  1. 垂直統合を強化し、全工程を内製化する戦略である
  2. コアコンピタンスへ資源集中し、非中核業務をアウトソースする戦略である
  3. 既存技術と無関係な事業へ進出する多角化戦略である
  4. 販売チャネルのみを共同化して規模の経済を狙う戦略である
正解と解説を見る

正解：コアコンピタンスへ資源集中し、非中核業務をアウトソースする戦略である

中核の制御技術に経営資源を集中し、非中核の基板実装を外部委託する考え方は、コアコンピタンス戦略とアウトソーシングの組合せである。

問2（午前II 組込ハードウェア）

5段パイプラインのRISC CPUで分岐命令が全体の20%を占め、分岐先決定がEX段で行われる。分岐ミス時の性能低下を最も抑える対策はどれか。

  1. 命令キャッシュ容量だけを2倍にする
  2. BTB付き動的分岐予測を導入する
  3. ALUの演算器を倍精度対応にする
  4. レジスタファイルのポート数を1つ増やす
正解と解説を見る

正解：BTB付き動的分岐予測を導入する

分岐ハザードの主因は分岐先未確定によるフラッシュであり、BTBと動的予測はミス率と分岐ペナルティを直接低減できる。

問3（午前II 組込ソフトウェア）

締切が各周期末で固定優先度プリエンプティブのRTOSを用いる。周期10ms/実行2msのT1、周期20ms/実行4msのT2、周期50ms/実行5msのT3に対する優先度割当として最も適切なのはどれか。

  1. 実行時間が最長のT3を最高優先度にする
  2. 全タスクを同一優先度でラウンドロビン実行する
  3. 周期が最短のT1を最高優先度にする
  4. 締切余裕が最大のT2を最高優先度にする
正解と解説を見る

正解：周期が最短のT1を最高優先度にする

Rate Monotonicでは締切=周期の固定優先度系で、周期が短いタスクほど高優先度にするのが可スケジュール性を高める基本則である。

問4（午前II ネットワーク・信頼性・安全性）

車載ECU間をEthernetで接続し、1ms周期の制御フレームを送る。送信時刻の揺らぎを抑えるため最も有効なIEEE 802.1機能はどれか。

  1. IEEE 802.1X（ポートベース認証）
  2. IEEE 802.3az（省電力Ethernet）
  3. IEEE 802.1D（スパニングツリー）
  4. IEEE 802.1Qbv（Time-Aware Shaper）
正解と解説を見る

正解：IEEE 802.1Qbv（Time-Aware Shaper）

802.1Qbvは送信キューのゲートを時刻表で開閉し、競合を制御するTSN機能である。周期通信の遅延ジッタ抑制に最も有効。

問5（午後I・午後II 設計・開発）

車載ECUの要求分析で、安全要求からソフト設計要素までの追跡可能性を担保したい。変更影響を最短で特定するため、最も有効な管理方法はどれか。

  1. 要求IDを議事録だけに記録し設計書は自由記述とする
  2. テスト項目のみ一意番号化し設計要素とは紐づけない
  3. 要求・設計・試験に共通IDを付与し双方向トレーサビリティ行列を維持する
  4. 変更時は担当者判断で関連文書を都度更新する
正解と解説を見る

正解：要求・設計・試験に共通IDを付与し双方向トレーサビリティ行列を維持する

共通IDで要求・設計・試験を双方向に結ぶと、変更時の影響範囲を漏れなく抽出でき、監査時の説明根拠も明確になる。

問6（午前I 共通基礎）

車載ECU更新基盤への投資案A～Dを比較する。初期投資額と将来キャッシュフローが異なる場合、貨幣の時間価値を考慮して投資可否を評価する指標として最も適切なのはどれか。

  1. 回収期間法
  2. 売上高成長率
  3. 損益分岐点売上高
  4. 正味現在価値（NPV）
正解と解説を見る

正解：正味現在価値（NPV）

NPVは将来キャッシュフローを割引現在価値に換算して初期投資と比較できる。時間価値を反映した投資評価として実務で広く用いられる。
