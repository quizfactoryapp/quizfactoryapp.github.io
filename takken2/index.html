土地家屋調査士 予想問題の例

問1（民法）

所有権に関して、他人の土地を自己のものとして支配し続け、一定期間経過した場合に認められる権利は何か。

  1. 使用貸借
  2. 占有権
  3. 抵当権
  4. 時効取得
正解と解説を見る

正解：時効取得

一定の要件を満たした占有により、法律上所有権が取得できるのが時効取得です。

問2（不動産登記法）

土地の分筆登記を申請する際、申請書に添付すべきものはどれか。

  1. 建物配置図
  2. 登記済証（権利証）
  3. 土地所有権移転契約書
  4. 地積測量図
正解と解説を見る

正解：地積測量図

分筆申請には新しい地積を示す地積測量図の添付が必要である。

問3（土地関連）

筆界とは何を示す境界線のことを指すか。土地の所有権の境界、土地の利用区分、行政区画、または測量基準点のうちどれか。

  1. 測量基準点
  2. 土地の所有権の境界
  3. 土地の利用区分
  4. 行政区画
正解と解説を見る

正解：土地の所有権の境界

筆界は土地の所有権の境界を指し、土地の管理や権利関係に重要な役割を果たします。

問4（建物関連）

建物の表示において、床面積の算出基準として一般的に用いられるのはどれか？

  1. 建物の建築面積に基づく面積
  2. 外壁の中心線で囲まれた部分の面積
  3. 内法（うちのり）による壁の内側の面積
  4. 軒先の先端までの面積
正解と解説を見る

正解：内法（うちのり）による壁の内側の面積

床面積は壁の内側の寸法（内法）で測定し、実際に使用できる面積を示します。

問5（民法）

抵当権設定登記について正しい記述はどれか。

  1. 抵当権は動産のみに設定可能である。
  2. 口頭での合意のみで効力が生じる。
  3. 登記がなければ第三者に対抗できない。
  4. 設定登記は不要である。
正解と解説を見る

正解：登記がなければ第三者に対抗できない。

抵当権は不動産に設定される物権で、登記により第三者に対抗力を持ちます。

問6（不動産登記法）

土地の合筆登記申請に関し、正しいものはどれか。

  1. 合筆は土地の所有者が異なっても可能である。
  2. 合筆後の土地は原則として元の地目を引き継ぐ。
  3. 合筆登記は法務大臣の許可が必要である。
  4. 合筆申請には必ず建物図面の添付が必要である。
正解と解説を見る

正解：合筆後の土地は原則として元の地目を引き継ぐ。

合筆後の土地は、原則としてもとの土地のうちの一つの地目を引き継ぐ。
