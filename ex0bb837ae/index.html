問1（国語）

評論文で「筆者は便利さを否定しているのではなく、それに伴う思考停止を問題にしている」とある。この主張の中心として最も適切なものはどれか。

  1. 便利な道具はすべて人間の能力を低下させる。
  2. 技術の発展は社会に何の影響も与えない。
  3. 便利さを使いながらも、自分で考える姿勢が必要である。
  4. 不便な生活に戻ることだけが望ましい。
正解と解説を見る

正解：便利さを使いながらも、自分で考える姿勢が必要である。

筆者は便利さ自体でなく、考えずに従う態度を批判しているため、自律的思考を述べる選択肢が適切です。

問2（数学）

式 3(x-2)-2(1-x) を展開して整理したとき、正しいものはどれか。

  1. x-4
  2. 5x-8
  3. 5x-4
  4. x-8
正解と解説を見る

正解：5x-8

3(x-2)=3x-6、-2(1-x)=-2+2xなので、合計は5x-8となる。

問3（理科）

植物の光合成では、光エネルギーを利用して無機物から有機物をつくる。このとき主に取り込まれる気体として最も適切なものはどれか。

  1. 二酸化炭素
  2. 窒素
  3. 水素
  4. 酸素
正解と解説を見る

正解：二酸化炭素

光合成では二酸化炭素と水からデンプンなどの有機物をつくり、酸素を放出する。

問4（地理歴史・公民）

第一次世界大戦後、国際協調を進めるために設立された国際機関として最も適切なものはどれか。

  1. 国際連盟
  2. 国際連合
  3. 世界貿易機関
  4. 欧州連合
正解と解説を見る

正解：国際連盟

国際連盟は第一次世界大戦後の1920年に発足し、集団安全保障をめざした国際機関である。

問5（国語）

次の一文「彼は黙って窓の外を見ていたが、その背中は多くを語っていた。」における表現効果として最も適切なものはどれか。

  1. 会話を中心にして人物関係を明らかにしている。
  2. 場面の時間経過を数字によって正確に示している。
  3. 人物の気持ちを直接説明して、読者の想像を制限している。
  4. 動作や姿から、人物の心情を間接的に示している。
正解と解説を見る

正解：動作や姿から、人物の心情を間接的に示している。

背中が語るという比喩的表現により、沈黙の中の心情を読者に想像させる間接描写になっています。

問6（数学）

x^2-7x+12 を因数分解した形として正しいものはどれか。

  1. (x-3)(x-4)
  2. (x-1)(x-12)
  3. (x+3)(x+4)
  4. (x-2)(x-6)
正解と解説を見る

正解：(x-3)(x-4)

積が12、和が-7になる2数は-3と-4であるため、(x-3)(x-4)となる。
