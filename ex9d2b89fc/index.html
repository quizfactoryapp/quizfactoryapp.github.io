問1（商業簿記）

商品を掛けで80,000円仕入れ、引取運賃3,000円を現金で支払った。三分法で仕訳する場合、借方に記入する科目と金額として正しいものはどれか。

  1. 商品 83,000円
  2. 仕入 80,000円、支払運賃 3,000円
  3. 仕入 80,000円、発送費 3,000円
  4. 仕入 83,000円
正解と解説を見る

正解：仕入 83,000円

仕入諸掛りである引取運賃は仕入原価に含めるため、仕入83,000円を借方に記入する。

問2（財務諸表）

貸借対照表において、正常営業循環基準により流動資産に分類されるものとして最も適切なものはどれか。

  1. 満期まで3年の定期預金
  2. 本社として使用する建物
  3. 営業目的で保有する商品
  4. 長期保有目的の投資有価証券
正解と解説を見る

正解：営業目的で保有する商品

商品は通常の営業過程で販売される資産であり、期間にかかわらず正常営業循環基準により流動資産となる。

問3（工業簿記）

材料を予定価格で記帳している。月末に実際購入価格が予定価格を上回った場合、材料消費価格差異として正しい処理はどれか。

  1. 不利差異として借方に処理する
  2. 有利差異として貸方に処理する
  3. 仕掛品勘定へ直接貸方記入する
  4. 材料勘定の借方残高を直接減額する
正解と解説を見る

正解：不利差異として借方に処理する

実際価格が予定価格を上回ると材料費が不足計上となるため、不利差異として借方処理する。

問4（原価計算）

標準原価計算で、実際生産量に対する標準消費量より実際消費量が多かった場合に発生する差異として最も適切なものはどれか。

  1. 数量差異の不利差異
  2. 予算差異の不利差異
  3. 価格差異の有利差異
  4. 操業度差異の有利差異
正解と解説を見る

正解：数量差異の不利差異

標準消費量を超えて実際消費量が多い場合、能率面の悪化として数量差異の不利差異となる。

問5（商業簿記）

得意先振出、当店宛ての約束手形50,000円を受け取り、売掛金の回収に充てた。この取引の貸方科目として正しいものはどれか。

  1. 売上
  2. 売掛金
  3. 受取手形
  4. 支払手形
正解と解説を見る

正解：売掛金

売掛金を手形で回収したため、借方は受取手形、貸方は減少する売掛金となる。

問6（財務諸表）

損益計算書において、売上総利益を計算する式として正しいものはどれか。

  1. 売上高－売上原価
  2. 売上高－販売費及び一般管理費
  3. 営業利益＋営業外費用
  4. 税引前当期純利益－法人税等
正解と解説を見る

正解：売上高－売上原価

売上総利益は、売上高から売上原価を差し引いて求める。販売費及び一般管理費は営業利益の計算で控除する。
