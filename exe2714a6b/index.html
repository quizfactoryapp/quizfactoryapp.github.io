調理師試験 予想問題の例

問1（食品衛生学）

カンピロバクター食中毒の予防として最も適切な対応はどれか。鶏肉の調理・取り扱いを想定して選びなさい。

  1. 野菜用まな板で生鶏肉を切る
  2. 鶏肉を中心部まで十分に加熱する
  3. 生食用でない鶏肉を刺身で提供する
  4. 調理前に室温で長時間なじませる
正解と解説を見る

正解：鶏肉を中心部まで十分に加熱する

カンピロバクターは鶏肉で問題となりやすく、中心部までの十分な加熱と二次汚染防止が重要である。

問2（栄養学）

炭水化物の栄養学的な主な役割として、最も適切なものはどれか。

  1. 骨や歯の主成分として沈着する
  2. 血液凝固因子を直接合成する
  3. 体内で主にエネルギー源として利用される
  4. 体内で消化酵素として働く
正解と解説を見る

正解：体内で主にエネルギー源として利用される

炭水化物は1g約4kcalを産生し、脳や筋肉などの主要なエネルギー源となる。

問3（調理理論）

野菜をゆでる際、ほうれん草など緑色野菜の色を鮮やかに保つ操作として最も適切なものはどれか。

  1. 酢を加えた湯でゆっくり加熱する
  2. 少量の水で蒸し煮にする
  3. ふたをして弱火で長時間加熱する
  4. 沸騰した多めの湯で短時間加熱し、すぐ冷水にとる
正解と解説を見る

正解：沸騰した多めの湯で短時間加熱し、すぐ冷水にとる

緑色野菜は短時間加熱と急冷でクロロフィルの変色を抑え、色と歯ざわりを保つ。

問4（公衆衛生・法規）

調理師法における「調理師」の説明として、最も適切なものはどれか。名称使用と免許の関係に着目して選べ。

  1. 都道府県知事の免許を受け、調理師の名称を用いて調理業務に従事できる者
  2. 料理学校を卒業すれば申請なしで調理師名簿に登録される
  3. 飲食店で3年以上働いた者は自動的に調理師を名乗れる
  4. 食品衛生責任者講習を修了した者は全員調理師である
正解と解説を見る

正解：都道府県知事の免許を受け、調理師の名称を用いて調理業務に従事できる者

調理師は都道府県知事の免許を受けた者であり、経験や講習修了だけでは名乗れない。

問5（食品衛生学）

ノロウイルスによる食中毒対策として、調理従事者の管理で最も適切なものはどれか。

  1. 下痢や嘔吐の症状がある者は調理作業を控える
  2. 手洗いは水洗いだけで済ませる
  3. 発症後も手袋をすれば盛り付けを行える
  4. 食品を冷凍すれば完全に不活化できる
正解と解説を見る

正解：下痢や嘔吐の症状がある者は調理作業を控える

ノロウイルスは少量でも感染し、調理従事者から食品へ移るため、有症状者の作業制限が重要である。

問6（栄養学）

たんぱく質を構成する基本単位として、正しいものはどれか。

  1. 単糖類
  2. アミノ酸
  3. 脂肪酸
  4. グリセロール
正解と解説を見る

正解：アミノ酸

たんぱく質は多数のアミノ酸が結合してでき、体組織や酵素、ホルモンの材料となる。
