マイナンバー実務検定 予想問題の例

問1（番号法）

番号法における「個人番号」の説明として最も適切なものはどれか。

  1. 住民票コードをそのまま民間利用のために公開した番号である。
  2. 希望者だけが申請により取得する任意の本人確認番号である。
  3. 住民票を有する者を識別するために指定される12桁の番号である。
  4. 法人の事業所ごとに税務署が付番する13桁の番号である。
正解と解説を見る

正解：住民票を有する者を識別するために指定される12桁の番号である。

個人番号は、住民票を有する個人に指定される12桁の番号で、社会保障・税・災害対策で使われます。

問2（実務運用）

従業員から扶養控除等申告書の提出を受ける際、会社が個人番号を取得する場合の本人確認として最も適切なものはどれか。

  1. 給与振込口座の通帳で番号確認を代替できる
  2. 入社時の履歴書で氏名を確認していれば不要である
  3. 本人の同意があれば番号確認だけで足りる
  4. 番号確認と身元確認を行い、利用目的に必要な範囲で取得する
正解と解説を見る

正解：番号確認と身元確認を行い、利用目的に必要な範囲で取得する

個人番号取得時は、番号の真正性と本人の身元を確認する措置が必要です。

問3（安全管理措置）

個人番号を取り扱う部署で、事務取扱担当者と責任者を明確に定めることは、どの安全管理措置に最も該当するか。

  1. 物理的安全管理措置
  2. 組織的安全管理措置
  3. 技術的安全管理措置
  4. 人的安全管理措置
正解と解説を見る

正解：組織的安全管理措置

担当者や責任者、取扱範囲を明確にする体制整備は、組織的安全管理措置の中心的内容である。

問4（個人情報保護）

個人情報取扱事業者が利用目的を本人に通知・公表せず、取得後に目的外利用を行う場合の原則的な対応として正しいものはどれか。

  1. あらかじめ本人の同意を得る必要がある
  2. 委託先の承認があれば利用できる
  3. 社内規程に記載すれば本人同意は不要である
  4. 匿名加工情報として扱えば直ちに利用できる
正解と解説を見る

正解：あらかじめ本人の同意を得る必要がある

個人情報は特定した利用目的の範囲内で扱うのが原則で、目的外利用には原則として本人同意が必要です。

問5（番号法）

番号法上の「特定個人情報」に該当するものとして正しいものはどれか。

  1. 匿名加工され個人を識別できない統計表
  2. 法人番号だけを記載した取引先一覧
  3. 個人番号をその内容に含む個人情報
  4. 氏名と住所のみを記載した社員名簿
正解と解説を見る

正解：個人番号をその内容に含む個人情報

特定個人情報とは、個人番号を内容に含む個人情報をいいます。番号を含まない通常の個人情報とは区別されます。

問6（実務運用）

個人番号カードの提示を受けて本人確認を行う場合、実務上の取扱いとして最も適切なものはどれか。

  1. 表面だけを確認すれば番号確認も完了する
  2. 確認後も本人確認書類の写しを永久保存する
  3. 裏面の番号だけを控え、顔写真は確認しない
  4. カードで番号確認と身元確認を行い、不要な写しは速やかに廃棄する
正解と解説を見る

正解：カードで番号確認と身元確認を行い、不要な写しは速やかに廃棄する

個人番号カードは番号確認と身元確認に使えますが、不要な写しの保管は避けます。
