色彩検定3級 予想問題の例

問1（色の基礎）

色の三属性のうち、赤・黄・緑・青のように『どんな色みか』の違いを表す要素を答えなさい。色相環の並び方にも関係する基本概念である。

  1. 色相
  2. 清濁
  3. 明度
  4. 彩度
正解と解説を見る

正解：色相

色相は赤み・黄み・青みなどの色みの違いを表す属性で、色相環では近い色ほど似た印象として扱われる。

問2（PCCSとトーン）

PCCSでは、有彩色を色相だけでなく、明るさ感と鮮やかさ感をまとめた概念でも整理します。この概念を何と呼ぶか、最も適切なものを選びなさい。

  1. 明度
  2. 残像
  3. トーン
  4. 面積比
正解と解説を見る

正解：トーン

PCCSは色相とトーンで色を把握する体系で、トーンは明るさ感と鮮やかさ感を合わせた印象のまとまりを表す。

問3（色彩心理と表示）

飲料の新商品パッケージで、清潔感や爽快感、冷たさを連想させたい。色彩心理を踏まえたとき、最も適した基調色はどれか。

  1. 黄系
  2. 茶系
  3. 黒系
  4. 青系
正解と解説を見る

正解：青系

青は冷たさ、清潔感、爽快感を連想させやすい色で、飲料や衛生分野のパッケージによく使われる。

問4（色の基礎）

同じ赤系でも、えんじ色よりピンクのほうが『明るく見える』とき、主に差がある属性として最も適切なものを選びなさい。

  1. 彩度
  2. 補色
  3. 色相
  4. 明度
正解と解説を見る

正解：明度

明度は色の明るさの程度を示す属性である。ピンクがえんじ色より明るく見えるなら、主な違いは明度にある。

問5（PCCSとトーン）

赤・青・緑など色相は異なるが、すべて同じトーンでそろえて配色したときに得やすい効果として、最も適切なものを選びなさい。

  1. すべて無彩色の配色になる
  2. 色相差が消えて同じ色に見える
  3. 必ず補色関係が生まれる
  4. 全体の印象に統一感が出やすい
正解と解説を見る

正解：全体の印象に統一感が出やすい

同一トーン配色は色相が異なってもトーンをそろえるため、印象がまとまりやすく、全体に統一感をつくりやすい。

問6（色彩心理と表示）

病院の待合室で、患者の緊張をやわらげて落ち着いた雰囲気をつくりたい。色彩心理の面から比較的適している色はどれか。

  1. 強い黒
  2. 鮮やかな赤
  3. やわらかい緑
  4. まぶしい黄
正解と解説を見る

正解：やわらかい緑

緑は自然や安らぎを感じさせ、緊張をやわらげる方向に働きやすい。待合室や休憩空間にも適した色である。
