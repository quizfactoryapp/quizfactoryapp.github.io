1級土木施工管理技術検定 予想問題の例

問1（土木一般）

粘性土の液性限界とは何を示す指標か？

  1. 土が固体状態を失い塑性状態になる水分量
  2. 土が塑性状態を失い液状になる水分量
  3. 土の最大乾燥密度
  4. 土の最小乾燥密度
正解と解説を見る

正解：土が塑性状態を失い液状になる水分量

液性限界は土が塑性状態から液状状態に変わる水分量を示す指標である。

問2（専門土木）

河川工事において、護岸工の主要な目的として最も適切なものはどれか。洪水時の浸食防止、河川の流速増加、地下水位の上昇、堆積物の堆積促進のいずれか。

  1. 地下水位の上昇
  2. 堆積物の堆積促進
  3. 河川の流速を増加させる
  4. 洪水時の浸食防止
正解と解説を見る

正解：洪水時の浸食防止

護岸工は河岸の浸食を防ぎ、河川の安定を図ることが主な目的であるため、洪水時の浸食防止が正解となる。

問3（土木施工管理法）

工程管理において、クリティカルパス法(CPM)の主な目的は何か？

  1. 安全管理基準の設定
  2. 環境影響評価の実施
  3. 工事全体の最短完了日を把握し遅延を防ぐこと
  4. 品質保証のための検査計画作成
正解と解説を見る

正解：工事全体の最短完了日を把握し遅延を防ぐこと

クリティカルパス法は、工程の中で最も遅延しやすい作業を特定し、全体の工期短縮や遅延防止を図る手法です。

問4（土木一般）

コンクリートの水セメント比に関する記述として、最も適切なものはどれか。

  1. 水セメント比は、単位水量を単位細骨材量で除した値である。
  2. 水セメント比を小さくすると、常に施工性は向上する。
  3. 水セメント比を小さくすると、一般に水密性や耐久性は向上する。
  4. 水セメント比を大きくすると、一般に圧縮強度は増加する。
正解と解説を見る

正解：水セメント比を小さくすると、一般に水密性や耐久性は向上する。

水セメント比は水量をセメント量で除した値で、小さいほど一般に強度・水密性・耐久性が向上するが、施工性は低下しやすい。

問5（専門土木）

道路工事における路盤の役割として最も適切なものはどれか。路面の排水、交通荷重の支持、舗装の摩耗防止、道路環境の美化。

  1. 交通荷重の支持
  2. 舗装の摩耗防止
  3. 路面の排水
  4. 道路環境の美化
正解と解説を見る

正解：交通荷重の支持

路盤は舗装の下層に位置し、交通荷重を基礎に分散し支持する役割を持つ。

問6（土木施工管理法）

品質管理において「管理図」を用いる主な目的は何か？

  1. 工程の進捗確認
  2. 施工計画の作成
  3. 施工現場の安全点検
  4. 製品や工程の安定性を監視し異常を早期発見すること
正解と解説を見る

正解：製品や工程の安定性を監視し異常を早期発見すること

管理図は品質のばらつきを視覚的に示し、工程の安定性や異常の検出に役立ちます。
