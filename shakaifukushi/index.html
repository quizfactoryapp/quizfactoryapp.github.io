社会福祉士 予想問題の例

問1（福祉基盤と制度）

日本の社会保障制度において、国民皆保険制度の目的として最も適切なものはどれか。

  1. 医療機関の自由競争を促進すること
  2. 全ての国民が必要な医療を受けられるようにすること
  3. 民間保険会社の利益拡大を支援すること
  4. 高齢者に限定した医療費の無料化
正解と解説を見る

正解：全ての国民が必要な医療を受けられるようにすること

国民皆保険制度は、全ての国民が必要な医療を公平に受けられることを目的としている。

問2（相談援助の理論と方法）

インテークにおいて最も重要な初期対応として適切なものはどれか。

  1. 信頼関係の形成を図る
  2. 具体的な支援計画を立案する
  3. 利用者の問題を詳細に分析する
  4. スーパービジョンを受ける
正解と解説を見る

正解：信頼関係の形成を図る

インテークの初期段階では、まず利用者との信頼関係を築くことが重要です。

問3（高齢者・障害・医療福祉）

高齢者虐待防止法において、介護者による身体的虐待の具体例として最も適切なものはどれか。

  1. 暴力を用いて身体に傷を負わせること
  2. 病状を過小評価すること
  3. 食事の提供を控えること
  4. 家族と会わせないこと
正解と解説を見る

正解：暴力を用いて身体に傷を負わせること

身体的虐待は暴力行為により身体に損傷を与えることを指します。暴力は明確な身体的虐待の一例です。

問4（福祉基盤と制度）

社会福祉法における「社会福祉法人」の主な役割として正しいものはどれか。

  1. 医療機関の管理運営
  2. 行政に代わって税金の徴収を行うこと
  3. 営利を目的とした福祉事業の運営
  4. 地域住民の生活支援や福祉サービスの提供
正解と解説を見る

正解：地域住民の生活支援や福祉サービスの提供

社会福祉法人は営利を目的とせず、地域住民の福祉向上を支援する役割を担う。

問5（相談援助の理論と方法）

アセスメントの目的として最も適切なのはどれか。

  1. サービス担当者会議を開催すること
  2. ケース記録を作成すること
  3. 支援計画を実施すること
  4. 利用者のニーズと資源を把握すること
正解と解説を見る

正解：利用者のニーズと資源を把握すること

アセスメントは利用者のニーズや状況、利用可能な資源を把握することが目的です。

問6（高齢者・障害・医療福祉）

障害者総合支援法に基づく「地域生活支援事業」の主な目的はどれか。

  1. 障害者の地域社会での自立支援
  2. 医療機関での専門治療提供
  3. 障害者の就労前訓練のみを行う
  4. 施設入所者の生活管理
正解と解説を見る

正解：障害者の地域社会での自立支援

地域生活支援事業は、障害者が地域で自立して生活できるようサポートすることを目的としています。
