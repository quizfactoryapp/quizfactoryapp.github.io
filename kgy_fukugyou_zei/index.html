副業の税金 予想問題の例

問1（副業所得の区分）

所得税の所得区分において、副業で継続的に物品販売を行う収入が「事業所得」とされるかは、一般に何を総合して判断するか。

  1. 営利性、継続性、規模、記帳状況などを総合して判断する
  2. 勤務先に届出をしているかだけで判断する
  3. 収入金額が毎月同じかだけで判断する
  4. 本人が副業と呼んでいるかだけで判断する
正解と解説を見る

正解：営利性、継続性、規模、記帳状況などを総合して判断する

事業所得か雑所得かは名称ではなく、社会通念上の事業性や記帳・帳簿保存などを総合して判定する。

問2（確定申告の要否）

給与所得者の多くが所得税の確定申告をしなくてよい理由として、制度上もっとも適切なものはどれか。

  1. 副業収入がある人もすべて会社が精算するため
  2. 給与について源泉徴収と年末調整により税額が精算されるため
  3. 住民税の申告をすれば所得税の申告も不要になるため
  4. 給与所得には所得税が課されないため
正解と解説を見る

正解：給与について源泉徴収と年末調整により税額が精算されるため

給与所得者は通常、源泉徴収と年末調整で所得税が精算されるため、申告不要となることが多いです。

問3（住民税と会社対策）

住民税の所得割について、一般的に課税対象となる所得の基準時点として正しいものはどれか。

  1. 前年1月から12月までの所得
  2. 給与支払月ごとの所得だけ
  3. 当年1月から12月までの見込み所得
  4. 前々年4月から翌年3月までの所得
正解と解説を見る

正解：前年1月から12月までの所得

住民税の所得割は、原則として前年中の所得を基に翌年度に課税されます。

問4（経費と控除）

副業の所得計算で必要経費として認められる支出の一般的な考え方として、最も適切なものはどれか。

  1. 副業に直接関係し、収入を得るために通常必要と認められる支出である
  2. 副業開始前の支出は、目的にかかわらず一切経費にならない
  3. 領収書があれば、生活費を含めてすべて経費にできる
  4. 売上より大きい支出は、制度上すべて経費から除外される
正解と解説を見る

正解：副業に直接関係し、収入を得るために通常必要と認められる支出である

必要経費は、業務との関連性と必要性が基本です。私的な生活費は原則として経費に含められません。

問5（副業所得の区分）

会社員が休日に単発で原稿料を得た場合、その収入が事業としての規模や継続性を欠くとき、一般に該当しやすい所得区分はどれか。

  1. 退職所得
  2. 不動産所得
  3. 雑所得
  4. 給与所得
正解と解説を見る

正解：雑所得

単発的・副次的な報酬で他の所得区分に当たらないものは、一般に雑所得として扱われやすい。

問6（確定申告の要否）

1か所から給与を受け年末調整済みの給与所得者について、給与・退職所得以外の所得が20万円以下の場合の所得税申告の原則はどれか。

  1. 所得税の確定申告は原則として不要
  2. 年末調整を受けていても必ず青色申告が必要
  3. 所得の種類に関係なく必ず確定申告が必要
  4. 20万円以下なら住民税の申告も常に不要
正解と解説を見る

正解：所得税の確定申告は原則として不要

一定の給与所得者は、給与・退職所得以外の所得が20万円以下なら所得税申告が原則不要です。
