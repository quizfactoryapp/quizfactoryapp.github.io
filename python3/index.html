Python 3 エンジニア認定基礎試験 予想問題の例

問1（Python文法）

Pythonのインデントに関する説明として正しいものはどれか。

  1. インデントは見た目だけで実行結果に影響しない
  2. 同じブロック内ではインデントをそろえる必要がある
  3. if文の次の行は必ずタブでインデントする
  4. 関数内の文は必ず8個の空白でインデントする
正解と解説を見る

正解：同じブロック内ではインデントをそろえる必要がある

Pythonではインデントがブロック構造を表す。同じブロック内では一貫した字下げが必要。

問2（組み込みデータ型）

タプルに関する説明として正しいものはどれか。Pythonの基本的な組み込みデータ型の性質に基づいて選べ。

  1. 丸括弧を使う場合もあるが、変更不能なシーケンスである
  2. 同じ値を複数含めることはできない
  3. 作成後に要素を追加できる
  4. キーと値の組でデータを管理する
正解と解説を見る

正解：丸括弧を使う場合もあるが、変更不能なシーケンスである

タプルはイミュータブルなシーケンスです。要素の追加や削除はできません。

問3（関数とモジュール）

Python の def 文について正しい説明はどれか。

  1. 関数名は予約語でなければ数字から始めてもよい
  2. return 文は関数の外側でも常に使用できる
  3. def 文を実行すると関数オブジェクトが作られ、名前に束縛される
  4. 関数本体は def 文を読み込んだ時点で必ず実行される
正解と解説を見る

正解：def 文を実行すると関数オブジェクトが作られ、名前に束縛される

def 文は関数オブジェクトを生成し、指定した名前に割り当てます。本体は呼び出し時に実行されます。

問4（例外と入出力）

try文で例外が発生しなかった場合だけ実行される節はどれか。ファイル処理の成功後に追加処理を行いたい。

  1. raise節
  2. finally節
  3. except節
  4. else節
正解と解説を見る

正解：else節

else節はtryブロックで例外が発生しなかった場合にだけ実行されます。

問5（Python文法）

Pythonのインデントに関する説明として、最も適切なものはどれですか。ブロック構造の判定方法に注意してください。

  1. 必ずタブ文字だけを使わなければならない
  2. if文の本体は中括弧で囲む必要がある
  3. 同じブロック内ではインデント幅をそろえる必要がある
  4. インデントは見た目だけで、実行には影響しない
正解と解説を見る

正解：同じブロック内ではインデント幅をそろえる必要がある

Pythonはインデントでブロックを表します。同じブロックではインデントの深さを一致させます。

問6（組み込みデータ型）

集合setの特徴として正しいものはどれか。リストやタプルとの違いを踏まえて選べ。

  1. 要素の重複を保持する
  2. インデックスで必ず順序通りに参照できる
  3. 重複しない要素の集まりを表す
  4. キーと値を対応づけて保存する
正解と解説を見る

正解：重複しない要素の集まりを表す

集合は重複を持たない要素の集まりです。通常、リストのような位置指定には使いません。
