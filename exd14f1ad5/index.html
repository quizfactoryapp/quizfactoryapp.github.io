統計検定 2級 予想問題の例

問1（記述統計）

5人の小テスト得点が 6, 7, 8, 9, 10 点であった。このデータの平均と不偏分散の組として正しいものはどれか。

  1. 平均8、不偏分散1.5
  2. 平均8、不偏分散2.5
  3. 平均7、不偏分散2.5
  4. 平均8、不偏分散2.0
正解と解説を見る

正解：平均8、不偏分散2.5

平均は40/5=8。偏差平方和は10なので、不偏分散は10/(5-1)=2.5である。

問2（確率分布）

ある製品の不良率が5%で一定とする。無作為に20個検査するとき、不良品がちょうど2個含まれる確率として正しい式はどれか。

  1. 20C2(0.05)^2(0.95)^18
  2. (0.05)^2(0.95)^18
  3. 20C2(0.95)^2(0.05)^18
  4. 2C20(0.05)^20(0.95)^2
正解と解説を見る

正解：20C2(0.05)^2(0.95)^18

二項分布B(20,0.05)で、ちょうど2個の確率は組合せを掛けた形になる。

問3（推定）

ある母集団から無作為抽出した標本平均は、母平均の点推定量として用いられる。この推定量の基本的な性質として最も適切なのはどれか。

  1. 常に母平均と完全に一致する
  2. 母分散が未知なら使用できない
  3. 標本の大きさに関係なく分散は0である
  4. 期待値が母平均に等しい不偏推定量である
正解と解説を見る

正解：期待値が母平均に等しい不偏推定量である

標本平均の期待値は母平均に等しいため、母平均の不偏推定量である。

問4（仮説検定）

ある検定でp値が0.032であった。有意水準5%の両側検定における結論として最も適切なものはどれか。

  1. 帰無仮説を棄却する
  2. 対立仮説が真である確率は3.2%である
  3. 帰無仮説が真であると断定する
  4. 帰無仮説を棄却しない
正解と解説を見る

正解：帰無仮説を棄却する

p値が有意水準0.05を下回るため、帰無仮説を棄却する。ただし仮説の真偽の確率ではない。

問5（記述統計）

データ 2, 4, 4, 6 の分散を、データ数 n で割る定義で求める。このとき標準偏差はいくらか。

  1. 2
  2. √2
  3. √5
  4. 1
正解と解説を見る

正解：√2

平均は4、偏差平方和は8。分散は8/4=2なので、標準偏差は√2である。

問6（確率分布）

Xが二項分布B(100,0.3)に従うとき、Xの期待値と分散の組合せとして正しいものはどれか。

  1. 期待値30、分散30
  2. 期待値30、分散21
  3. 期待値70、分散21
  4. 期待値21、分散30
正解と解説を見る

正解：期待値30、分散21

二項分布B(n,p)では期待値np、分散np(1-p)なので30と21である。
