日商簿記3級 予想問題の例

問1（簿記の基礎）

仕訳において、現金が増えた場合の借方貸方の正しい処理は？

  1. 貸方に売上、借方に仕入
  2. 借方に現金、貸方に売上
  3. 借方に売上、貸方に現金
  4. 貸方に現金、借方に売上
正解と解説を見る

正解：借方に現金、貸方に売上

現金が増える場合は資産の増加なので借方に記入します。売上は収益で貸方に記入。したがって、借方に現金、貸方に売上が正しい。

問2（商品売買）

商品5,000円を仕入れ、代金は後日支払うことにした。この取引の仕訳として正しいものはどれか。

  1. （借）仕入 5,000円　（貸）売掛金 5,000円
  2. （借）商品 5,000円　（貸）買掛金 5,000円
  3. （借）仕入 5,000円　（貸）買掛金 5,000円
  4. （借）買掛金 5,000円　（貸）仕入 5,000円
正解と解説を見る

正解：（借）仕入 5,000円　（貸）買掛金 5,000円

商品を掛けで仕入れた場合、費用である仕入を借方に記入し、後日支払う義務として買掛金を貸方に記入する。

問3（現金・預金）

当店は買掛金80,000円の支払いとして、自己振出しの小切手を仕入先に渡した。この取引の仕訳として正しいものはどれか。

  1. 借方：当座預金 80,000円　貸方：買掛金 80,000円
  2. 借方：仕入 80,000円　貸方：当座預金 80,000円
  3. 借方：買掛金 80,000円　貸方：当座預金 80,000円
  4. 借方：買掛金 80,000円　貸方：現金 80,000円
正解と解説を見る

正解：借方：買掛金 80,000円　貸方：当座預金 80,000円

自己振出しの小切手で支払うと当座預金が減少する。買掛金の支払いなので借方は買掛金、貸方は当座預金となる。

問4（固定資産・決算）

決算にあたり、当期首に取得した備品（取得原価120,000円、耐用年数4年、残存価額0円）について、定額法により減価償却を行う。なお、記帳方法は間接法である。このときの決算整理仕訳として正しいものはどれか。

  1. （借）減価償却費 30,000　（貸）備品減価償却累計額 30,000
  2. （借）減価償却費 120,000　（貸）備品減価償却累計額 120,000
  3. （借）備品減価償却累計額 30,000　（貸）減価償却費 30,000
  4. （借）減価償却費 30,000　（貸）備品 30,000
正解と解説を見る

正解：（借）減価償却費 30,000　（貸）備品減価償却累計額 30,000

定額法では120,000円÷4年＝30,000円を当期の費用とする。間接法では貸方を備品ではなく減価償却累計額で処理する。

問5（簿記の基礎）

勘定科目「備品」の説明として正しいものは？

  1. 現金同等物
  2. 短期間で消費される資産
  3. 長期間にわたり使用する資産で、形のあるもの
  4. 費用の発生を示す勘定科目
正解と解説を見る

正解：長期間にわたり使用する資産で、形のあるもの

備品は長期間使用する有形固定資産であり、消耗品などの短期消費資産とは異なる。

問6（商品売買）

商品売買における三分法の判定基準は何か？

  1. 商品の所有権移転の時点による売買の区分
  2. 売上の回収期日の長さ
  3. 仕入代金の支払条件
  4. 棚卸資産の期末評価方法
正解と解説を見る

正解：商品の所有権移転の時点による売買の区分

三分法とは、商品の売買において商品の所有権が移転したかどうかによって売買を判定し、仕訳を三つに分けて計上する方法です。
