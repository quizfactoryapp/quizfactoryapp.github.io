陸上特殊無線技士 予想問題の例

問1（無線工学）

電波の伝搬において、地表面に沿って伝わる波は何と呼ばれるか？

  1. 電離層波
  2. 自由空間波
  3. 地上波
  4. 空間波
正解と解説を見る

正解：地上波

地上波は地表面に沿って伝わる電波のことで、特に低周波帯で重要です。

問2（法規）

無線局の免許を受けた者が無線設備を変更する場合、事前に必要なのはどれか。

  1. 運用規則の改正申請を行う
  2. 変更届の提出のみでよい
  3. 免許の変更申請を行う
  4. 周波数の使用許可を更新する
正解と解説を見る

正解：免許の変更申請を行う

無線設備の変更は免許の変更申請が必要で、変更届だけでは認められません。

問3（無線工学）

振幅変調(AM)において、搬送波の振幅が変化する理由は何か？

  1. 搬送波の振幅を信号に応じて変えるため
  2. 搬送波の周波数を変えるため
  3. 搬送波をデジタルに変換するため
  4. 搬送波の位相を変えるため
正解と解説を見る

正解：搬送波の振幅を信号に応じて変えるため

AMは信号に応じて搬送波の振幅を変化させて情報を伝えます。

問4（法規）

電波法において、無線局の免許の有効期間は原則として何年間か。

  1. 10年
  2. 7年
  3. 3年
  4. 5年
正解と解説を見る

正解：5年

無線局の免許の有効期間は通常5年間と定められています。

問5（無線工学）

アンテナの利得を高めるために用いられるものはどれか？

  1. インピーダンス整合器
  2. バイアス抵抗
  3. ダイオード検波器
  4. 反射器
正解と解説を見る

正解：反射器

反射器はアンテナの指向性と利得を向上させるために使われます。

問6（法規）

無線局の無許可運用を行った場合に課される罰則として正しいのはどれか。

  1. 6ヶ月以下の懲役または30万円以下の罰金
  2. 罰金のみで刑事罰はない
  3. 行政指導のみで刑罰はない
  4. 1年以下の懲役のみ
正解と解説を見る

正解：6ヶ月以下の懲役または30万円以下の罰金

無許可運用は6ヶ月以下の懲役または30万円以下の罰金が科されます。
