応用情報技術者 予想問題の例

問1（基礎理論）

10進数の45を2進数で表したものはどれか。

  1. 101101
  2. 100101
  3. 110101
  4. 101011
正解と解説を見る

正解：101101

45は32+8+4+1なので、2進数では各桁を立てて101101となる。

問2（コンピュータ構成要素）

キャッシュメモリに関する説明として正しいものはどれか。

  1. 主記憶からデータを一度に大量に読み込むための装置である。
  2. データの永続保存に使われる。
  3. CPUと主記憶の間に配置される高速メモリである。
  4. 主記憶よりもアクセス速度が遅い。
正解と解説を見る

正解：CPUと主記憶の間に配置される高速メモリである。

キャッシュメモリはCPUと主記憶の間に配置され、主記憶より高速でアクセスできる小容量のメモリです。

問3（データベース）

関係モデルの主キーについての説明として正しいものはどれか。

  1. 各タプルを一意に識別するための属性または属性群
  2. 複数のテーブルを結合するためのキー
  3. 外部キーの別名
  4. テーブルの全ての属性を含むキー
正解と解説を見る

正解：各タプルを一意に識別するための属性または属性群

主キーはテーブル内の各レコード（タプル）を一意に識別するための属性または属性の集合である。

問4（ネットワーク）

TCP/IPのOSI参照モデルにおけるトランスポート層の主な役割は何か？

  1. IPアドレスの割り当てと管理
  2. データの誤り検出と再送制御
  3. エンドツーエンドの通信制御と信頼性の確保
  4. 物理的な接続の確立
正解と解説を見る

正解：エンドツーエンドの通信制御と信頼性の確保

トランスポート層はエンドツーエンドの通信管理を行い、TCPにより信頼性の高い通信を提供する。

問5（セキュリティ）

共通鍵暗号方式に関する説明として正しいものはどれか。

  1. 暗号化と復号に異なる鍵を使う。
  2. 公開鍵と秘密鍵のペアを使用する。
  3. 鍵の管理が不要である。
  4. 暗号化と復号に同じ鍵を使う。
正解と解説を見る

正解：暗号化と復号に同じ鍵を使う。

共通鍵暗号方式は、暗号化と復号に同じ鍵を使用し、高速に処理できるが鍵の配布と管理が課題となる方式です。

問6（マネジメント・ストラテジ）

プロジェクトマネジメントにおけるクリティカルパスの特徴はどれか。

  1. 遅延するとプロジェクト全体が遅れる経路である
  2. 最も短い期間で完了する経路である
  3. 全作業の中で最も総浮動時間が長い
  4. リスクが最も低い作業の集まりである
正解と解説を見る

正解：遅延するとプロジェクト全体が遅れる経路である

クリティカルパスとは、プロジェクト完了までの最長経路であり、この経路上の作業が遅延するとプロジェクト全体が遅延します。
