問1（契約）

契約が成立するために必要な要素として正しいものはどれか。

  1. 公証人の立会いが必須であること
  2. 契約の内容が書面でなければならない
  3. 第三者の承認が必要であること
  4. 当事者の合意があること
正解と解説を見る

正解：当事者の合意があること

契約成立には当事者間の合意が必要で、書面や公証は必ずしも要求されない。

問2（会社法）

株式会社における株主総会の説明として、正しいものはどれか。

  1. 株主総会は、取締役だけで構成される会社の業務執行機関である。
  2. 株主総会は、会社の従業員全員が参加して労働条件を決める機関である。
  3. 株主総会は、監査役が毎月必ず開催しなければならない機関である。
  4. 株主総会は、株主で構成され、会社の基本的事項などを決議する機関である。
正解と解説を見る

正解：株主総会は、株主で構成され、会社の基本的事項などを決議する機関である。

株主総会は株主で構成され、役員選任や定款変更など会社の重要事項を決議する株式会社の基本的な機関である。

問3（労働法・知財）

労働基準法上、使用者が労働者に年次有給休暇を与えるための基本的な要件として、正しいものはどれか。

  1. 正社員に限り、入社後6か月継続勤務すれば当然に発生すること
  2. 入社後3か月継続勤務し、全労働日の6割以上出勤したこと
  3. 入社後1年継続勤務すれば、出勤率にかかわらず当然に発生すること
  4. 入社後6か月継続勤務し、全労働日の8割以上出勤したこと
正解と解説を見る

正解：入社後6か月継続勤務し、全労働日の8割以上出勤したこと

年次有給休暇は、原則として6か月継続勤務し、全労働日の8割以上出勤した労働者に付与される。正社員に限られない。

問4（コンプライアンス）

個人情報保護法において、事業者が個人情報を第三者に提供する際に必要となるのはどれか。

  1. 利用目的の変更
  2. 弁護士の確認
  3. 国の許可
  4. 本人の同意
正解と解説を見る

正解：本人の同意

個人情報を第三者に提供する場合、原則として本人の同意が必要となります。

問5（契約）

契約自由の原則に関する説明として、最も適切なものはどれか。

  1. 一度契約を結ぶと、当事者が合意しても内容を変更することはできない。
  2. 当事者は、法令や公序良俗に反しない限り、契約内容を自由に決めることができる。
  3. 契約は必ず書面で作成しなければ有効に成立しない。
  4. 契約内容は、当事者の合意よりも常に一方当事者の希望が優先される。
正解と解説を見る

正解：当事者は、法令や公序良俗に反しない限り、契約内容を自由に決めることができる。

契約自由の原則により、契約の相手方・方式・内容は原則自由。ただし法令や公序良俗に反する内容は認められない。

問6（会社法）

株主総会に関して、特別決議を必要とするのは次のうちどれでしょうか。

  1. 剰余金の配当
  2. 定款の変更
  3. 取締役の解任
  4. 取締役の選任
正解と解説を見る

正解：定款の変更

定款の変更は株主総会の特別決議が必要で、議決権の3分の2以上の賛成が要件です。
