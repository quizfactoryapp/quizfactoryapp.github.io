ケアマネジャー 予想問題（無料・全問解説付き）

ケアマネ合格ドリルは、ケアマネジャーの出題分野に沿ったオリジナル予想問題226問を収録した学習ドリルです。すべての問題に解説が付いているので、間違えた問題もその場で理解できます。ページ上部のWeb版では20問を無料で体験でき、スマホアプリ版では全226問に取り組めます。

ケアマネジャー 予想問題の例

問1（介護保険制度）

介護保険の被保険者で、40歳から64歳までの者が支払う保険料はどのように位置づけられているか？

  1. 任意加入者のみが支払う
  2. 第2号被保険者の保険料として徴収される
  3. 自治体が負担し、被保険者は支払わない
  4. 第1号被保険者の保険料として徴収される
正解と解説を見る

正解：第2号被保険者の保険料として徴収される

40歳から64歳までの者は第2号被保険者に該当し、特定疾病に対する介護保険料を支払います。

問2（ケアマネジメント）

ケアマネジメントにおけるアセスメントの主な目的は何ですか？

  1. 施設職員の勤務表を作成すること
  2. 利用者のニーズと課題を把握すること
  3. 介護サービスの契約書を作成すること
  4. 介護保険料を計算すること
正解と解説を見る

正解：利用者のニーズと課題を把握すること

アセスメントは利用者のニーズや課題を正確に把握し、適切なケアプラン作成の基礎となります。

問3（福祉サービス）

訪問介護サービスにおいて、利用者の自立支援を促進するために最も重要とされる支援はどれか。

  1. 介護者が一方的にサービス内容を決めること
  2. 利用者の能力に応じた支援を行うこと
  3. すべての動作を介助すること
  4. 介護時間を最短にすることを優先すること
正解と解説を見る

正解：利用者の能力に応じた支援を行うこと

訪問介護は利用者の自立を支援することが目的であり、能力に応じた支援が重要です。

問4（医学的知識）

高齢者の認知症で最も多いタイプはどれか？

  1. レビー小体型認知症
  2. アルツハイマー型認知症
  3. 血管性認知症
  4. 前頭側頭型認知症
正解と解説を見る

正解：アルツハイマー型認知症

アルツハイマー型認知症は高齢者で最も頻度が高い認知症のタイプです。

問5（介護保険制度）

要介護認定の申請は誰が行うことができるか、最も適切なものはどれか？

  1. ケアマネジャーのみ
  2. 市町村のみ
  3. 本人または家族、代理人など
  4. 介護施設のスタッフのみ
正解と解説を見る

正解：本人または家族、代理人など

要介護認定の申請は本人や家族、代理人など誰でも行うことができます。

問6（ケアマネジメント）

ケアプラン作成時に最も重要視すべきことはどれですか？

  1. 全てのサービスを網羅的に入れること
  2. 法的な契約のみを重視すること
  3. サービス事業者の利益を最大化すること
  4. 利用者の希望と生活環境を反映すること
正解と解説を見る

正解：利用者の希望と生活環境を反映すること

利用者の意思や生活環境を尊重し、現実的で本人に適したプランを作成することが重要です。
