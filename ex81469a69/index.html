電気主任技術者試験 第三種 予想問題の例

問1（理論）

真空中で点電荷Qから距離rの点に生じる電界の大きさを表す式として正しいものはどれか。ただし真空の誘電率をε0とする。

  1. Q/(4πε0r)
  2. 4πε0Q/r^2
  3. Qr/(4πε0)
  4. Q/(4πε0r^2)
正解と解説を見る

正解：Q/(4πε0r^2)

点電荷の電界はクーロンの法則から距離の2乗に反比例し、E=Q/(4πε0r^2)となる。

問2（電力）

同期発電機の励磁を一定に保ったまま有効電力出力を増加させたとき、一般に増加する量として最も適切なものはどれか。

  1. 力率角のみが必ず減少する
  2. 端子電圧が必ず上昇する
  3. 周波数が定格値より大きく上昇する
  4. 負荷角が増加する
正解と解説を見る

正解：負荷角が増加する

同期発電機の有効電力は概ね負荷角の正弦に比例するため、励磁一定で出力を増すと負荷角が大きくなる。

問3（機械）

直流分巻電動機で端子電圧を一定とし、界磁抵抗を大きくして界磁電流を減少させたとき、無負荷に近い回転速度はどうなるか。

  1. 変化しない
  2. ほぼ同期速度になる
  3. 上昇する
  4. 低下する
正解と解説を見る

正解：上昇する

直流電動機の速度は概ね逆起電力を磁束で割った値に比例する。界磁を弱めると磁束が減り速度は上昇する。

問4（法規）

電気事業法における自家用電気工作物の説明として、最も適切なものはどれか。高圧受電の工場設備を念頭に判断せよ。

  1. 一般用電気工作物のうち、低圧で受電する住宅設備をいう
  2. 電気事業の用に供する電気工作物だけをいう
  3. 小出力発電設備を含むすべての低圧設備をいう
  4. 一般用電気工作物および電気事業の用に供する電気工作物以外の電気工作物をいう
正解と解説を見る

正解：一般用電気工作物および電気事業の用に供する電気工作物以外の電気工作物をいう

自家用電気工作物は、電気事業用と一般用を除く事業用電気工作物で、高圧受電設備などが該当する。

問5（理論）

抵抗6Ωと12Ωを並列に接続し、さらにその合成抵抗に8Ωを直列接続した回路の全抵抗として正しい値はどれか。

  1. 14Ω
  2. 26Ω
  3. 12Ω
  4. 10Ω
正解と解説を見る

正解：12Ω

6Ωと12Ωの並列合成は4Ωであり、これに8Ωを直列に加えるので全抵抗は12Ωである。

問6（電力）

変電所の母線保護に比率差動継電方式を用いる主な理由として、最も適切なものはどれか。

  1. 外部事故時のCT誤差による不要動作を抑えつつ内部事故を高速検出するため
  2. 遮断器の開閉サージを完全に消去するため
  3. 母線電圧を自動的に一定値へ調整するため
  4. 変圧器の鉄損を常時低減するため
正解と解説を見る

正解：外部事故時のCT誤差による不要動作を抑えつつ内部事故を高速検出するため

比率差動方式は流入出電流の差を監視し、外部事故時のCT飽和や誤差に対して安定性を高められる。
