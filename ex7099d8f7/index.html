きもの文化検定 予想問題の例

問1（きもの史）

平安時代の貴族女性の装束である十二単について、名称の「十二」が本来示すものとして最も適切なものはどれか。

  1. 宮中の十二の儀式に用いる装束
  2. 十二か月の季節を表す文様
  3. 多く重ねることを象徴する数
  4. 必ず十二枚の袿を重ねる決まり
正解と解説を見る

正解：多く重ねることを象徴する数

十二単の「十二」は厳密な枚数ではなく、女房装束の重ねの多さを表す通称として理解される。

問2（染織技法）

友禅染で、模様の輪郭に糊を置いて染料のにじみを防ぎ、色挿しの境界を明確にする工程を何というか。

  1. 地入れ
  2. 湯のし
  3. 糊伏せ
  4. 糸目糊置き
正解と解説を見る

正解：糸目糊置き

糸目糊置きは友禅染の特徴的工程で、細い糊線により染料のにじみを防ぎ輪郭を保ちます。

問3（着装・作法）

既婚女性が第一礼装の黒留袖を着る際、一般的に合わせる帯結びとして最もふさわしいものはどれですか。

  1. 文庫結び
  2. 二重太鼓
  3. 角出し
  4. 貝の口
正解と解説を見る

正解：二重太鼓

黒留袖には袋帯を用い、慶事が重なる意味をもつ二重太鼓が正式です。

問4（産地・素材）

大島紬の伝統的な絣模様を作る工程で、図案に従って経糸・緯糸を部分的に防染するために用いられる代表的な技法はどれか。

  1. 型紙を置いて刷毛で糊を置く型染め
  2. 筆で直接色を挿す手描き友禅
  3. 絞って括った布を藍甕に浸す絞り染め
  4. 絣筵を織り、泥染め前に糸へ締め跡をつける締機
正解と解説を見る

正解：絣筵を織り、泥染め前に糸へ締め跡をつける締機

大島紬では締機で絣筵を織り、糸に防染部を作って精密な絣を表すのが特徴です。

問5（きもの史）

小袖が室町時代から近世にかけて表着として発展した背景として、最も適切な説明はどれか。

  1. 絹の使用が完全に禁止され、麻だけで作られたため普及した
  2. 武家や町人の生活様式に合い、活動しやすい衣服として広まった
  3. 帯を使わず着られる衣服として女性だけに定着した
  4. 朝廷が庶民に唐衣の着用を義務づけたため広まった
正解と解説を見る

正解：武家や町人の生活様式に合い、活動しやすい衣服として広まった

小袖はもとは下着的な衣服だったが、武家・町人社会の実用性に合い、表着として発展した。

問6（染織技法）

京友禅と加賀友禅の特徴を比べた説明として、加賀友禅により当てはまるものはどれか。

  1. 草花を写実的に描き、外ぼかしなどを用いる
  2. 藍一色で型紙を使い小紋柄を染める
  3. 絣糸を用いて幾何学模様を織り出す
  4. 金箔や刺繍を多用し、華やかな装飾を重ねる
正解と解説を見る

正解：草花を写実的に描き、外ぼかしなどを用いる

加賀友禅は自然文様の写実性や外ぼかしが特徴で、金銀箔や刺繍を控える傾向があります。
