管理業務主任者 予想問題の例

問1（民法）

契約の成立に関し、申込みと承諾の意思表示が一致した時点で契約は成立する。これはどの原則によるか。

  1. 公序良俗の原則
  2. 合意の原則
  3. 信義則の原則
  4. 意思表示の錯誤の原則
正解と解説を見る

正解：合意の原則

契約成立は当事者の意思表示が合致した時点で成立する、これを合意の原則という。

問2（区分所有法）

区分所有法における共用部分の範囲に含まれないものはどれか。

  1. 共用廊下
  2. エレベーター
  3. 専有部分の内部壁
  4. 建物の外壁
正解と解説を見る

正解：専有部分の内部壁

専有部分の内部壁は専有部分に属し、共用部分には含まれません。

問3（適正化法）

適正化法において、管理業者が宅地建物取引業者に対して守るべき義務はどれか。

  1. 管理事務報告書の提出
  2. 宅地建物取引士の設置義務の免除
  3. 管理員の選任義務の免除
  4. 重要事項説明の省略
正解と解説を見る

正解：管理事務報告書の提出

管理業者は、区分所有者に対し管理事務報告書を作成し、適正に報告する義務があるため正しい。

問4（建築・設備）

建築基準法における防火地域内で建築する場合、特に求められる建築物の構造上の規制はどれか。

  1. 耐火建築物とすることが義務付けられる。
  2. 木造建築であっても制限はない。
  3. 高さ制限の緩和が認められる。
  4. 敷地内に消火用水槽の設置が免除される。
正解と解説を見る

正解：耐火建築物とすることが義務付けられる。

防火地域では火災の拡大を防ぐため、耐火建築物などの厳しい構造規制が義務付けられています。

問5（民法）

物権とは何か。次のうち正しい説明はどれか。

  1. 債権者が債務者に対して持つ請求権
  2. 不法行為によって生じる損害賠償請求権
  3. 当事者間の契約によってのみ効力を持つ権利
  4. 他人の物を一定の範囲で支配する直接的な権利
正解と解説を見る

正解：他人の物を一定の範囲で支配する直接的な権利

物権は物を直接支配し、その物に関する排他的な権利である。

問6（区分所有法）

管理組合の総会において、議決権を行使できる者は誰か。

  1. 管理者のみ
  2. 管理会社の社員
  3. 賃借人
  4. 区分所有者本人または代理人
正解と解説を見る

正解：区分所有者本人または代理人

議決権は区分所有者にあり、本人か代理人が行使できます。
