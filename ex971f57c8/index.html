問1（原付交通法規）

信号機で交通整理されている片側3車線の交差点で、一般原動機付自転車が右折するときの正しい方法はどれか。

  1. 右折車線に入り、自動車と同じように小回り右折する
  2. 左端に寄って交差点の向こう側まで直進し、停止して向きを変え、前方の青信号で進む
  3. 青の右折矢印が出たときだけ、交差点中央から右折する
  4. 横断歩道に乗り上げ、歩行者用信号に従って右折する
正解と解説を見る

正解：左端に寄って交差点の向こう側まで直進し、停止して向きを変え、前方の青信号で進む

片側3車線以上などの信号交差点では、原付は二段階右折を行い、青の右折矢印では進めません。

問2（標識・標示）

原動機付自転車で走行中、青地に白い矢印の一方通行標識がある道路に入った。この道路での正しい通行方法はどれか。

  1. 歩行者が少なければ、向きを問わず進める
  2. 矢印と反対方向へも、道路の左側を通れば進める
  3. 矢印の示す方向にだけ進行できる
  4. 原動機付自転車は標識の対象外なので自由に進める
正解と解説を見る

正解：矢印の示す方向にだけ進行できる

一方通行の標識がある道路では、原動機付自転車も矢印の方向にのみ進行でき、逆走はできません。

問3（原付安全運転）

原動機付自転車で走行するときのヘルメット着用について、頭部を守るために最も適切な方法はどれか。

  1. 短距離ならあごひもを締めなくてもよい
  2. 低速走行ではヘルメットを後ろにずらしてよい
  3. 暑い日は工事用ヘルメットで代用する
  4. 乗車前に正しくかぶり、あごひもを確実に締める
正解と解説を見る

正解：乗車前に正しくかぶり、あごひもを確実に締める

ヘルメットは正しい位置でかぶり、あごひもを締めて初めて転倒時の頭部保護に役立つ。

問4（原付車両知識）

原付をエンジン始動する前に行う確認として最も適切なものはどれか。周囲の安全と車両の状態を確かめてから操作する必要がある。

  1. スロットルを大きく開けてから始動する
  2. 後輪を浮かせて空転させてから始動する
  3. ライトを消してバッテリー消費だけを避ける
  4. スタンド、燃料、スイッチ類、周囲の安全を確認する
正解と解説を見る

正解：スタンド、燃料、スイッチ類、周囲の安全を確認する

始動前は車体が不意に動かないよう、スタンドやスイッチ、周囲の安全を確認することが基本である。

問5（原付交通法規）

最高速度50キロの標識がある道路を一般原動機付自転車で走行する場合、出してよい最高速度として正しいものはどれか。

  1. 40キロまでなら安全確認をすれば走行できる
  2. 50キロまでなら標識に従って走行できる
  3. 30キロを超えてはならない
  4. 交通の流れに合わせれば制限はない
正解と解説を見る

正解：30キロを超えてはならない

一般原動機付自転車の法定最高速度は30キロです。高い最高速度標識があっても30キロを超えられません。

問6（標識・標示）

「車両進入禁止」の標識がある道路の入口に、補助標識はない。原動機付自転車でその入口から入ろうとするとき、正しい判断はどれか。

  1. その入口から進入してはならない
  2. エンジンを切って乗ったままなら入ってよい
  3. 目的地がすぐ近くなら入ってよい
  4. 左端を徐行すれば入ってよい
正解と解説を見る

正解：その入口から進入してはならない

車両進入禁止は、その方向から車両が入ることを禁じる標識です。補助標識がなければ原付も進入できません。
