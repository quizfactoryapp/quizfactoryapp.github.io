環境計量士国家試験 予想問題の例

問1（濃度計量）

大気中の二酸化硫黄を吸収液に捕集し、パラロザニリン法で定量する場合、発色に直接関与する主な反応生成物として最も適切なものはどれか。

  1. ヨウ素デンプン錯体
  2. フェナントロリン錯体
  3. 硫酸バリウム沈殿
  4. ホルムアルデヒド付加体
正解と解説を見る

正解：ホルムアルデヒド付加体

パラロザニリン法では亜硫酸イオンがホルムアルデヒドと付加体を作り、パラロザニリンと反応して発色する。

問2（騒音・振動計量）

音圧実効値が20 μPaから200 μPaに増加した。基準音圧20 μPaに対する音圧レベルの増加量として正しいものはどれか。

  1. 20 dB
  2. 40 dB
  3. 10 dB
  4. 100 dB
正解と解説を見る

正解：20 dB

音圧レベルは20log10(p/p0)で表す。音圧が10倍なら20 dB増加する。

問3（計量法規）

計量法上の「特定計量器」に関する記述として、最も適切なものはどれか。取引又は証明に用いられる計量器の規制趣旨を踏まえて選べ。

  1. 輸出専用品として製造された計量器だけをいう。
  2. 研究室内だけで使うすべての計測器をいう。
  3. 環境計量士が校正した計量器だけをいう。
  4. 取引又は証明における適正計量確保のため、政令で定められた計量器をいう。
正解と解説を見る

正解：取引又は証明における適正計量確保のため、政令で定められた計量器をいう。

特定計量器は、取引・証明での信頼確保のため法令上特に規制される計量器で、対象は政令で定められる。

問4（分析化学）

0.1000 mol/L塩酸標準液を25.00 mL量り取り、炭酸ナトリウムで標定した。標定の主目的として最も適切なものはどれか。

  1. ビュレットの最小目盛を化学的に校正するため
  2. 滴定終点の指示薬変色域を酸性側へ移すため
  3. 調製濃度と実際の濃度のずれを補正し、正確な濃度を決めるため
  4. 塩酸中の水素イオンの活量係数を直接測定するため
正解と解説を見る

正解：調製濃度と実際の濃度のずれを補正し、正確な濃度を決めるため

塩酸は揮発性があり正確な秤量調製だけでは濃度が確定しにくいため、一次標準物質で標定する。

問5（濃度計量）

水質試料のCODMn測定で、過マンガン酸カリウムを過剰に加えて加熱後、残留酸化剤を定量する目的で用いられる標準液はどれか。

  1. しゅう酸ナトリウム標準液
  2. 塩化ナトリウム標準液
  3. 硝酸銀標準液
  4. チオ硫酸ナトリウム標準液
正解と解説を見る

正解：しゅう酸ナトリウム標準液

CODMnでは残留過マンガン酸をしゅう酸ナトリウムで還元し、酸化に消費された量から酸素当量を求める。

問6（騒音・振動計量）

同一の独立した騒音源2台が、それぞれ単独で70 dBの騒音レベルを示す。2台を同時に動かした場合の合成レベルに最も近い値はどれか。

  1. 73 dB
  2. 76 dB
  3. 140 dB
  4. 70 dB
正解と解説を見る

正解：73 dB

同じレベルの音源を2つ合成すると音のエネルギーが2倍となり、約3 dB増加する。
