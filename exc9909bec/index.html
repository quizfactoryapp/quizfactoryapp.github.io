珠算能力検定試験 予想問題の例

問1（見取算）

見取算で、365に482を加え、さらに157を加えた後、294を引く。最後に残る数として正しいものを選びなさい。

  1. 730
  2. 710
  3. 720
  4. 700
正解と解説を見る

正解：710

365+482+157=1004となり、そこから294を引くので答えは710です。

問2（乗算）

次の乗算を、位取りに注意して計算しなさい。 347×6 の答えとして正しいものはどれですか。

  1. 2,042
  2. 2,082
  3. 1,982
  4. 2,182
正解と解説を見る

正解：2,082

347×6は、300×6=1800、40×6=240、7×6=42。合計して2082となる。

問3（除算）

商立ての確認問題です。7384を46で割るとき、最初の商を立てて計算を進めた結果として正しいものはどれですか。

  1. 商161、余り-22
  2. 商159、余り70
  3. 商160、余り24
  4. 商160、余り46
正解と解説を見る

正解：商160、余り24

46×160=7360で、7384との差は24です。余りは除数46より小さいので正しい商です。

問4（暗算）

珠像記憶の練習です。頭の中のそろばんに 428 を置き、続けて 357 を加え、さらに 196 を引いたときの答えはどれですか。

  1. 589
  2. 681
  3. 599
  4. 579
正解と解説を見る

正解：589

428+357=785、そこから196を引くと589です。百の位と十の位の繰り下がりを確認します。

問5（見取算）

次の計算を、位をそろえて行いなさい。708+96+1345-429 の答えとして正しいものはどれですか。

  1. 1620
  2. 1820
  3. 1710
  4. 1720
正解と解説を見る

正解：1720

708+96=804、804+1345=2149、2149-429=1720となります。

問6（乗算）

両落としで48×36を計算する場合、被乗数と乗数の両方を消しながら進める利点として最も適切なものはどれか。

  1. 乗数の処理順を自由に変えても誤差が出ない
  2. 答えの桁数を必ず一桁少なくできる
  3. 盤面に残る数が少なくなり、処理済み桁を確認しやすい
  4. 九九を使わずに全て加減だけで求められる
正解と解説を見る

正解：盤面に残る数が少なくなり、処理済み桁を確認しやすい

両落としは処理した桁を消すため盤面が整理され、未処理桁と答えの位置を把握しやすい。
