第一種電気工事士 予想問題の例

問1（電気理論）

抵抗6Ωと12Ωを並列に接続し，これに抵抗4Ωを直列に接続した回路に，直流電圧40Vを加えた。この回路全体に流れる電流は何Aか。

  1. 5A
  2. 10A
  3. 6.7A
  4. 4A
正解と解説を見る

正解：5A

6Ωと12Ωの並列合成抵抗は4Ω。これに4Ωを直列接続するので全抵抗は8Ω，電流は40÷8=5A。

問2（高圧受電設備）

高圧受電設備において、地絡事故時に構内の地絡電流を検出し、波及事故を防ぐために用いられる機器はどれか。

  1. 地絡継電器（GR）
  2. 進相コンデンサ
  3. 計器用変圧器（VT）
  4. 避雷器（LA）
正解と解説を見る

正解：地絡継電器（GR）

地絡継電器は零相変流器などと組み合わせ、地絡電流を検出して遮断器や開閉器を動作させる。

問3（法規・施工）

低圧電路に施設する機械器具の金属製外箱にD種接地工事を施す場合、地絡時に0.5秒以内に自動的に電路を遮断する装置を設けないとき、接地抵抗値は何Ω以下としなければならないか。

  1. 100Ω以下
  2. 10Ω以下
  3. 1000Ω以下
  4. 500Ω以下
正解と解説を見る

正解：100Ω以下

D種接地工事の接地抵抗値は原則100Ω以下。0.5秒以内に動作する地絡遮断装置がある場合のみ500Ω以下に緩和される。

問4（電気理論）

三相交流回路の線間電圧が440V、相電圧は？

  1. 440V
  2. 760V
  3. 254V
  4. 127V
正解と解説を見る

正解：254V

相電圧は線間電圧を\sqrt{3}で割って求めます。

問5（高圧受電設備）

高圧受電設備において、主に負荷電流の開閉に用いられるが、短絡電流の遮断能力はなく、短絡事故時には限流ヒューズと組み合わせて保護を行う機器はどれか。

  1. 避雷器（LA）
  2. 断路器（DS）
  3. 計器用変圧器（VT）
  4. 高圧交流負荷開閉器（LBS）
正解と解説を見る

正解：高圧交流負荷開閉器（LBS）

LBSは負荷電流を開閉する機器で、短絡電流は遮断できないため、限流ヒューズなどと組み合わせて保護する。

問6（法規・施工）

第一種電気工事士が、免状の交付を受けた後に受講しなければならない定期講習の受講間隔として、正しいものはどれか。

  1. 5年ごとに受講する。
  2. 10年ごとに受講する。
  3. 3年ごとに受講する。
  4. 7年ごとに受講する。
正解と解説を見る

正解：5年ごとに受講する。

第一種電気工事士は、免状交付後および前回受講日から5年以内ごとに定期講習を受講する義務がある。
