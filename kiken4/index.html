危険物取扱者 乙種第4類 予想問題の例

問1（危険物に関する法令）

危険物施設の予防規程に関する記述として、正しいものはどれか。なお、予防規程を定めたときは、市町村長等の認可を受けなければならないものとする。

  1. 屋外タンク貯蔵所は、指定数量の倍数が10以上であれば必ず予防規程を定める必要がある。
  2. 給油取扱所は、取り扱う危険物の数量にかかわらず予防規程を定める必要がある。
  3. 一般取扱所は、指定数量の倍数が100以上の場合に限り予防規程を定める必要がある。
  4. 給油取扱所は、指定数量の倍数が10以上の場合に限り予防規程を定める必要がある。
正解と解説を見る

正解：給油取扱所は、取り扱う危険物の数量にかかわらず予防規程を定める必要がある。

給油取扱所と移送取扱所は数量にかかわらず予防規程が必要。一般取扱所は10倍以上が対象である。

問2（危険物の性質と消火）

ガソリンの性質について正しいものはどれか。

  1. 引火点は約-40℃で非常に低い。
  2. 水に容易に溶ける。
  3. 着火点は約100℃以上である。
  4. 比重は約1.2である。
正解と解説を見る

正解：引火点は約-40℃で非常に低い。

ガソリンは引火点が非常に低く、約-40℃のため、常温でも簡単に蒸気が発生し引火しやすい危険物です。比重は約0.7で水には溶けません。

問3（危険物に関する法令）

危険物の分類について、乙種第4類に該当する危険物はどれか。

  1. ガソリン
  2. リン
  3. 亜硝酸ナトリウム
  4. 硫黄
正解と解説を見る

正解：ガソリン

乙種第4類は揮発性の液体、特に可燃性液体を指し、ガソリンはその代表例です。硫黄は第1類、リンは第3類、亜硝酸ナトリウムは第5類に分類されます。

問4（危険物の性質と消火）

灯油の引火点に関する正しい記述はどれか。

  1. 引火点がない。
  2. 引火点は約100℃以上である。
  3. 引火点は約-20℃である。
  4. 引火点は約40℃である。
正解と解説を見る

正解：引火点は約40℃である。

灯油の引火点は通常38～45℃程度で、比較的安全性が高いですが、一定温度以上では引火します。

問5（危険物に関する法令）

指定数量に関する問題：ガソリンの指定数量は次のうちどれか。

  1. 5000 kg
  2. 200 kg
  3. 1000 kg
  4. 500 kg
正解と解説を見る

正解：200 kg

ガソリンの指定数量は200kgと定められており、これを超えて貯蔵・取扱う場合は法令の規制対象となります。

問6（危険物の性質と消火）

重油の特徴として正しいものはどれか。

  1. 引火点は約-30℃と非常に低い。
  2. 粘度が高く、比重は1以上である。
  3. 常温で気化しやすい。
  4. 水に容易に溶ける。
正解と解説を見る

正解：粘度が高く、比重は1以上である。

重油は粘度が高く比重が約0.9～1.0以上で、引火点は100℃以上と高いため、ガソリンなどに比べて扱いやすいが粘り気がある特徴があります。
