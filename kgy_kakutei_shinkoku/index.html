確定申告(個人事業主) 予想問題の例

問1（確定申告の基礎）

所得税の確定申告について、個人事業主が対象期間として計算する所得の期間は、制度上どの範囲とされているか。

  1. 事業を開始した日から任意に決めた1年間
  2. 毎年1月1日から12月31日まで
  3. 申告書を提出した日から過去12か月間
  4. 毎年4月1日から翌年3月31日まで
正解と解説を見る

正解：毎年1月1日から12月31日まで

所得税は暦年課税が原則で、1月1日から12月31日までの所得を翌年に申告する。

問2（所得と経費）

個人事業主の事業所得の計算における「必要経費」の一般的な考え方として、制度上もっとも適切なものはどれか。

  1. 必要経費は売上の一定割合で自動的に決まる
  2. 事業主が支払った支出は、領収書があればすべて必要経費になる
  3. 生活費も事業継続に必要なので原則として全額必要経費になる
  4. 売上に直接必要な費用や業務上生じた販売費・管理費などが必要経費になる
正解と解説を見る

正解：売上に直接必要な費用や業務上生じた販売費・管理費などが必要経費になる

必要経費は、収入を得るため直接必要な費用や業務上生じた費用が中心で、家事費は含まれません。

問3（各種控除）

所得税の基礎控除について、制度上の位置づけとして最も適切なものはどれか。個人事業主が確定申告で所得控除を整理する前提として問う。

  1. 医療費を支払った人だけが受けられる税額控除である
  2. 事業所得の必要経費として売上から差し引く控除である
  3. ふるさと納税をした年だけ自動的に増額される控除である
  4. 納税者本人の合計所得金額に応じて適用される所得控除である
正解と解説を見る

正解：納税者本人の合計所得金額に応じて適用される所得控除である

基礎控除は本人の合計所得金額に応じて適用される所得控除で、必要経費や税額控除ではありません。

問4（申告書の作成）

白色申告の個人事業主が事業所得の収入金額や必要経費の内訳を確定申告書に添えて示すため、一般に作成する書類はどれか。

  1. 収支内訳書
  2. 青色申告決算書
  3. 給与所得の源泉徴収票
  4. 消費税課税事業者届出書
正解と解説を見る

正解：収支内訳書

収支内訳書は、白色申告者などが総収入金額と必要経費の内訳を記載し、申告書と一緒に提出する書類です。

問5（確定申告の基礎）

所得税の確定申告の通常の申告期間として、一般的に正しいものはどれか。税務署閉庁日等の扱いは別として考える。

  1. その年の12月1日から12月31日まで
  2. 翌年1月1日から1月31日まで
  3. 翌年4月1日から5月31日まで
  4. 翌年2月16日から3月15日まで
正解と解説を見る

正解：翌年2月16日から3月15日まで

所得税の確定申告期間は、原則として対象年の翌年2月16日から3月15日までである。

問6（所得と経費）

個人事業主が自宅の一部を事務所として使う場合、家賃などの家事関連費についての一般的な取扱いはどれか。

  1. 自宅で仕事をしていれば、家賃は常に全額必要経費になる
  2. 家事関連費は制度上、どのような場合も必要経費にできない
  3. 業務に必要な部分を合理的に区分できる場合、その部分を必要経費にできる
  4. 居住用部分だけを必要経費に算入できる
正解と解説を見る

正解：業務に必要な部分を合理的に区分できる場合、その部分を必要経費にできる

家事関連費は、業務遂行上必要な部分を明らかに区分できる場合に限り、その部分が経費になります。
