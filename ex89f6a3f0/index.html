電気通信主任技術者試験 予想問題の例

問1（電気通信システム）

通信網を階層化して設計する主な目的として、最も適切なものはどれか。

  1. 伝送速度を物理的に常に一定に保つため
  2. IPアドレスを不要にして経路制御を省略するため
  3. 収容、集線、中継などの機能を分担し、拡張性と運用性を高めるため
  4. 全ノードを同一機能にして制御を単純化するため
正解と解説を見る

正解：収容、集線、中継などの機能を分担し、拡張性と運用性を高めるため

階層化によりアクセス、集線、コアなどの役割を分け、容量増設や障害切分けを容易にする。

問2（線路設備）

単一モード光ファイバの接続損失を低く抑えるための施工上の対策として、最も適切なものはどれか。

  1. コア軸のずれを小さくし、端面を清浄で平滑に保つ。
  2. 被覆を残したまま融着し、外力による変形を避ける。
  3. 曲げ半径を小さくして余長を短く収める。
  4. 接続部の反射を増やし、受光電力を高める。
正解と解説を見る

正解：コア軸のずれを小さくし、端面を清浄で平滑に保つ。

光ファイバ接続損失は軸ずれ、角度ずれ、端面汚れで増えるため、精密な位置合わせと清掃が重要である。

問3（伝送交換設備）

OSPFで同一エリア内のルータが経路計算に用いる情報として、最も適切なものはどれか。

  1. 各宛先までのホップ数だけを周期的に交換する。
  2. リンク状態広告を集めたリンク状態データベースを用いる。
  3. MACアドレス学習表から最短経路を決定する。
  4. 隣接ASから受信したASパス属性だけを用いる。
正解と解説を見る

正解：リンク状態広告を集めたリンク状態データベースを用いる。

OSPFはリンク状態型のIGPであり、LSAから作成したLSDBを基にSPF計算を行う。

問4（設備管理）

通信設備の品質管理において、月次の故障率が管理限界を超えた場合の初動として最も適切なものはどれか。

  1. 原因を層別し、異常要因の有無を調査する
  2. 直ちに全設備を同一型式へ更新する
  3. 測定項目を減らして管理工数を下げる
  4. 翌年度の保全計画まで対応を保留する
正解と解説を見る

正解：原因を層別し、異常要因の有無を調査する

管理限界超過時は偶然変動とみなさず、設備種別や地域などで層別し異常要因を確認する。

問5（電気通信法規）

電気通信事業法における「電気通信役務」に関する説明として、最も適切なものはどれか。

  1. 自己の社内連絡のために専用線を使用する行為のみをいう。
  2. 電気通信設備を用いて他人の通信を媒介し、その他電気通信設備を他人の通信の用に供することをいう。
  3. 電気通信設備を製造し、販売し、又は輸入する事業活動のみをいう。
  4. 放送番組を編集して公衆に直接受信させることのみをいう。
正解と解説を見る

正解：電気通信設備を用いて他人の通信を媒介し、その他電気通信設備を他人の通信の用に供することをいう。

電気通信役務は、他人の通信の媒介又は設備を他人の通信の用に供する役務である。

問6（電気通信システム）

回線交換方式と比較したパケット交換方式の特徴として、最も適切なものはどれか。

  1. 遅延ゆらぎが原理的に発生しないため音声専用に用いられる
  2. 各パケットに宛先情報を付加する必要がない
  3. バースト性のあるデータ通信で回線資源を統計多重により有効利用しやすい
  4. 通信開始時に必ず専用の物理回線を固定的に占有する
正解と解説を見る

正解：バースト性のあるデータ通信で回線資源を統計多重により有効利用しやすい

パケット交換は必要時だけ帯域を共有するため、間欠的なデータ通信の収容効率が高い。
