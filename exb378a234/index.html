危険物取扱者 丙種 予想問題の例

問1（第4類基礎）

第4類危険物に共通する燃焼の起点として最も適切な説明はどれか。液面付近で生じる可燃性蒸気と空気の混合気に着火する性質に着目して答えよ。

  1. 容器の金属部分だけが加熱で先に燃える
  2. 液体分子そのものが空気なしで自然に燃える
  3. 液面の下にある水分だけが先に燃焼する
  4. 液体から出た蒸気が空気と混ざった部分に着火する
正解と解説を見る

正解：液体から出た蒸気が空気と混ざった部分に着火する

引火性液体は液体自体が直接燃えるより、まず蒸発した可燃性蒸気が空気と混合し、その混合気へ着火して燃焼が進むのが基本である。

問2（貯蔵・取扱）

同一場所でガソリン120Lと灯油400Lを貯蔵する計画がある。指定数量の計算に基づく法令上の扱いとして、最も適切なものはどれか。

  1. 灯油は合算対象外なのでガソリン分のみで判定する
  2. 倍数は1.0となり、指定数量以上として扱う
  3. 異なる品名は合算できないため指定数量未満となる
  4. 倍数は0.8となり、指定数量未満である
正解と解説を見る

正解：倍数は1.0となり、指定数量以上として扱う

ガソリン120/200=0.6、灯油400/1000=0.4で合計1.0。異種危険物は同一場所なら倍数を合算し、1以上は指定数量以上として規制される。

問3（消火実務知識）

ガソリン火災で泡消火剤が有効とされる主な理由として、危険物取扱者の消火理論に照らして最も適切な説明はどれか。

  1. 危険物を完全に中和して可燃性を消失させるため
  2. 燃焼中の電流を増やして炎を分散させるため
  3. 泡で液面を覆って空気を遮断し、同時に含有水分で冷却できるため
  4. 油面温度を急上昇させて蒸発を終わらせるため
正解と解説を見る

正解：泡で液面を覆って空気を遮断し、同時に含有水分で冷却できるため

泡消火剤は液面を被覆して酸素供給を断つ窒息効果が中心で、泡中の水分による冷却効果も加わり油火災に有効である。

問4（第4類基礎）

ガソリンの法令上の分類として正しい組合せを選べ。第4類の品名区分と水溶性区分を同時に判断する典型問題である。

  1. 第3石油類・非水溶性液体
  2. 第2石油類・水溶性液体
  3. 第1石油類・非水溶性液体
  4. アルコール類・水溶性液体
正解と解説を見る

正解：第1石油類・非水溶性液体

ガソリンは引火点が低く第4類の中でも第1石油類に属し、水には溶けにくいため非水溶性液体として扱うのが正しい分類である。

問5（貯蔵・取扱）

軽油700Lのみを同一場所で貯蔵する場合、指定数量（軽油は第2石油類）との関係として正しい説明はどれか。

  1. 指定数量の1.7倍であり、直ちに超過している
  2. 指定数量1000Lに対し0.7倍で、指定数量未満である
  3. 軽油の指定数量は200Lなので3.5倍である
  4. 軽油は第1石油類なので指定数量400Lである
正解と解説を見る

正解：指定数量1000Lに対し0.7倍で、指定数量未満である

軽油は第2石油類で指定数量は1000L。700/1000=0.7なので指定数量未満である。品名ごとの指定数量を正確に使うのが基本。

問6（消火実務知識）

通電中の電気設備付近で火災が発生している場面で、一般的な泡消火剤の使用を避けるべき理由として最も適切なものはどれか。

  1. 泡の発泡により必ず有毒ガスが大量発生するため
  2. 泡が燃料の比重を下げて炎を拡大させるため
  3. 泡が金属を急速腐食させ設備を爆発させるため
  4. 水系成分により導電して感電リスクが生じるため
正解と解説を見る

正解：水系成分により導電して感電リスクが生じるため

泡消火剤は水系で導電性が問題となるため、通電中の電気火災では感電のおそれがある。まず通電遮断と適応消火剤選定が必要。
