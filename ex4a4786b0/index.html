建設業経理検定試験 2級 予想問題の例

問1（建設業簿記）

請負金額8,000,000円の工事が完成し、引渡しを行った。代金は後日入金予定である。このとき貸方に計上する勘定科目として正しいものはどれか。

  1. 未成工事受入金
  2. 完成工事原価
  3. 完成工事高
  4. 工事未払金
正解と解説を見る

正解：完成工事高

工事完成・引渡しにより収益が実現するため、貸方に完成工事高を計上する。

問2（原価計算）

工事現場で使用するセメントを購入し、うち一部が期末に未使用で残った。材料費として当期工事原価に算入すべき金額はどれか。

  1. 期末未使用材料の額
  2. 購入額から期末未使用材料を控除した額
  3. 購入額に期末未使用材料を加算した額
  4. 購入額の全額
正解と解説を見る

正解：購入額から期末未使用材料を控除した額

材料費は実際に工事で消費した分を原価算入し、未使用材料は棚卸資産として処理する。

問3（財務諸表）

建設業の貸借対照表において、未成工事に支出した材料費・労務費・外注費などで、まだ完成工事原価に振り替えられていないものの表示科目はどれか。

  1. 工事未払金
  2. 完成工事未収入金
  3. 未成工事支出金
  4. 未成工事受入金
正解と解説を見る

正解：未成工事支出金

未完成工事に係る原価は棚卸資産として未成工事支出金に計上し、完成時に完成工事原価へ振り替える。

問4（決算整理）

決算において、取得原価1,200,000円、残存価額ゼロ、耐用年数5年の機械を定額法で償却する。当期の減価償却費はいくらか。

  1. 120,000円
  2. 200,000円
  3. 240,000円
  4. 300,000円
正解と解説を見る

正解：240,000円

定額法では取得原価を耐用年数で均等配分する。1,200,000円÷5年＝240,000円である。

問5（建設業簿記）

未完成の工事について、材料費600,000円、労務費400,000円を支出した。これらを集計する資産勘定として正しいものはどれか。

  1. 材料貯蔵品
  2. 完成工事原価
  3. 未成工事支出金
  4. 完成工事未収入金
正解と解説を見る

正解：未成工事支出金

未完成工事に要した原価は、完成するまで未成工事支出金として資産計上する。

問6（原価計算）

作業員に支払った賃金のうち、特定工事に直接従事した時間に対応する部分の原価分類として最も適切なものはどれか。

  1. 一般管理費
  2. 直接労務費
  3. 間接労務費
  4. 現場管理費
正解と解説を見る

正解：直接労務費

特定工事への従事が明確な作業員賃金は、工事原価の直接労務費として処理する。
