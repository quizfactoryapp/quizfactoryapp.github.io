問1（権利関係）

借地借家法において、借地契約の存続期間が定められていない場合、法定更新後の存続期間は何年とされるか。

  1. 30年
  2. 50年
  3. 10年
  4. 20年
正解と解説を見る

正解：20年

借地借家法では、存続期間の定めがない場合、法定更新後の期間は20年とされます。

問2（法令上の制限）

都市計画法における「市街化調整区域」の主な目的は何か？

  1. 工業専用区域として指定すること
  2. 市街化を促進する区域に指定すること
  3. 市街化を抑制し、農地や自然を保全すること
  4. 住宅地専用の区域に指定すること
正解と解説を見る

正解：市街化を抑制し、農地や自然を保全すること

市街化調整区域は、市街化を抑制し農地や自然環境の保全を目的としています。

問3（宅建業法）

宅地建物取引業の免許について、営業所ごとに免許を受けなければならないのはどれか。

  1. 営業所の数にかかわらず、免許は1つだけでよい
  2. 同一都道府県内に複数の営業所を設ける場合
  3. 異なる都道府県に営業所を設ける場合も一つの免許でよい
  4. 営業所が1つであれば免許は不要である
正解と解説を見る

正解：同一都道府県内に複数の営業所を設ける場合

同一都道府県内の営業所ごとに免許が必要で、異なる都道府県では別個に免許が必要です。

問4（税・その他）

不動産取得税は、不動産の取得時に課税されますが、軽減措置が適用されるのはどのケースでしょうか？

  1. 住宅用家屋の新築取得
  2. 事務所用不動産の取得
  3. 投資用のマンション取得
  4. 農地の取得
正解と解説を見る

正解：住宅用家屋の新築取得

住宅用家屋の新築取得には不動産取得税の軽減措置が適用されることが多いです。

問5（権利関係）

民法における所有権の第三者対抗要件として必要なものはどれか。

  1. 登記
  2. 登録
  3. 引渡し
  4. 占有
正解と解説を見る

正解：登記

不動産の所有権を第三者に対抗するためには登記が必要です。

問6（法令上の制限）

建築基準法において、建築物の敷地は原則としてどのような道路に接しなければならないか？

  1. 幅員4m以上の道路
  2. 幅員1m以上の道路
  3. 幅員6m以上の道路
  4. 幅員2m以上の道路
正解と解説を見る

正解：幅員4m以上の道路

建築基準法では、建築物の敷地は幅員4メートル以上の道路に接することが原則とされています。
