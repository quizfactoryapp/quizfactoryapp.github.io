問1（商業簿記）

商品100,000円を掛けで仕入れ、引取運賃5,000円を現金で支払った。仕入原価に含める金額として正しいものはどれか。

  1. 105,000円
  2. 100,000円
  3. 95,000円
  4. 5,000円
正解と解説を見る

正解：105,000円

仕入諸掛りのうち当店負担の引取運賃は仕入原価に含めるため、100,000円に5,000円を加える。

問2（工業簿記）

個別原価計算において、特定の製造指図書に直接跡づけられる材料費と労務費を集計する目的として最も適切なものはどれか。

  1. 標準原価と実際原価の差異だけを求めるため
  2. 各製造指図書ごとの製造原価を算定するため
  3. 期間全体の販売費を製品別に配賦するため
  4. 完成品と月末仕掛品を平均法で按分するため
正解と解説を見る

正解：各製造指図書ごとの製造原価を算定するため

個別原価計算では、製造指図書ごとに直接費と配賦された間接費を集計し、製品別原価を計算する。

問3（財務諸表）

貸借対照表において、正常営業循環基準により流動資産に分類されるものとして最も適切なものはどれか。

  1. 長期貸付金
  2. 社債発行差金
  3. 投資有価証券
  4. 営業目的で保有する商品
正解と解説を見る

正解：営業目的で保有する商品

商品は営業活動の循環過程に含まれるため、回収期間にかかわらず流動資産に分類される。

問4（会計理論）

企業会計原則における真実性の原則に関する説明として、最も適切なものはどれか。

  1. 税法上の計算を常に企業会計より優先することを求める原則である。
  2. すべての資産を取得原価ではなく時価で評価することを求める原則である。
  3. 利益を多く見せるために、収益を早期に計上することを求める原則である。
  4. 財務諸表が企業の財政状態および経営成績を真実に表示することを求める原則である。
正解と解説を見る

正解：財務諸表が企業の財政状態および経営成績を真実に表示することを求める原則である。

真実性の原則は、財務諸表が企業の実態を適正に示すことを会計処理全体に求める基本原則である。

問5（商業簿記）

売上戻り20,000円が発生し、代金は掛け代金から差し引くことにした。この取引の貸方科目として正しいものはどれか。

  1. 売掛金
  2. 売上
  3. 買掛金
  4. 売上戻り
正解と解説を見る

正解：売掛金

売上戻りは売上の取消しであり、掛け代金を減額するため貸方に売掛金を記入する。

問6（工業簿記）

総合原価計算で、月末仕掛品の加工進捗度が60％である場合、加工費の完成品換算量を求める際の扱いとして正しいものはどれか。

  1. 月末仕掛品数量をすべて完成品換算量から除外する
  2. 月末仕掛品数量を材料費だけでなく加工費にも100％含める
  3. 月末仕掛品数量の60％を加工費の完成品換算量に含める
  4. 月末仕掛品数量の40％を加工費の完成品換算量に含める
正解と解説を見る

正解：月末仕掛品数量の60％を加工費の完成品換算量に含める

加工費は進捗度に応じて発生するため、月末仕掛品数量に加工進捗度を乗じて換算量を計算する。
