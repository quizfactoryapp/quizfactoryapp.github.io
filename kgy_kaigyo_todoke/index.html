開業届の基礎知識 練習問題の例

問1（開業届の基本）

個人が新たに事業を始めたときに提出する「開業届」は、制度上どのような書類と位置づけられているか。

  1. 従業員の社会保険加入を証明する書類
  2. 消費税の納税額を毎月確定させる申告書
  3. 個人事業の開始を税務署へ知らせるための届出書
  4. 法人を設立するために法務局へ提出する登記申請書
正解と解説を見る

正解：個人事業の開始を税務署へ知らせるための届出書

開業届は、個人が事業を開始した事実を所轄税務署へ届け出るための基本的な税務書類です。

問2（提出手続き）

個人事業の開業届に記載する事項として、一般に含まれるものはどれですか。提出手続き上の基本的な記載項目を問う問題です。

  1. 家族全員の勤務先、学歴、保有資格、住宅ローン残高のみ
  2. 確定申告で使う全経費の領収書番号と請求書番号のみ
  3. 毎月の売上見込み、全取引先名、預金残高、借入金の明細のみ
  4. 納税地、氏名、生年月日、個人番号、職業、屋号、開業日など
正解と解説を見る

正解：納税地、氏名、生年月日、個人番号、職業、屋号、開業日など

開業届は納税地や氏名、個人番号、職業、屋号、開業日など、事業開始の基本事項を記載します。

問3（開業時の税務）

青色申告承認申請書について、個人事業を新たに開始した年に青色申告を受けるための一般的な提出先はどこか。

  1. 事業所所在地の市区町村役場
  2. 納税地を所轄する税務署長
  3. 都道府県税事務所
  4. 年金事務所
正解と解説を見る

正解：納税地を所轄する税務署長

青色申告承認申請書は所得税の手続であり、納税地を所轄する税務署長に提出する書類である。

問4（屋号と事業形態）

個人事業主が開業届に屋号を記載する場合の一般的な扱いとして、制度上正しいものはどれですか。

  1. 屋号は税務署が業種ごとに指定する
  2. 屋号は法人名として登記されるため変更できない
  3. 屋号は必ず記載しなければ開業届を提出できない
  4. 屋号は任意記載で、未定なら空欄でも提出できる
正解と解説を見る

正解：屋号は任意記載で、未定なら空欄でも提出できる

屋号は個人事業の名称で、開業届では任意記載です。未定の場合は空欄でも提出できます。

問5（開業届の基本）

個人事業主の開業届について、一般的な提出期限として正しいものはどれか。

  1. 売上が発生してから1年以内
  2. 事業を始めた年の翌年3月15日まで
  3. 事業の開始等の事実があった日から1か月以内
  4. 最初の確定申告書を提出した後すぐ
正解と解説を見る

正解：事業の開始等の事実があった日から1か月以内

開業届は、事業の開始等の事実があった日から1か月以内に提出するものとされています。

問6（提出手続き）

開業届に記載する「納税地」について、制度上の一般的な考え方として正しいものはどれですか。

  1. 住所地など、所得税の納税地として扱われる場所を記載する
  2. 本人が好きな都道府県を自由に選び、理由なく記載できる
  3. 必ず事業用銀行口座を開設した金融機関の所在地を記載する
  4. 必ず最も売上が大きい取引先の所在地を記載する
正解と解説を見る

正解：住所地など、所得税の納税地として扱われる場所を記載する

納税地は所得税の手続きの基準となる場所で、通常は住所地などを記載します。任意の場所ではありません。
