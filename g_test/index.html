G検定 (JDLA) 予想問題の例

問1（AI基礎）

人工知能研究の黎明期において、1956年のダートマス会議で提唱された目標はどれか？

  1. 自己学習ロボットの実用化
  2. 人間の知能を完全に模倣するプログラムの開発
  3. ニューラルネットワークの大量普及
  4. 機械に知能を持たせることの研究開始
正解と解説を見る

正解：機械に知能を持たせることの研究開始

1956年のダートマス会議は、機械に知能を持たせる研究の出発点とされる。

問2（機械学習）

教師あり学習において、モデルの性能を評価する指標で、正例のうち正しく検出できた割合を示すものはどれか？

  1. F1スコア
  2. 適合率 (Precision)
  3. 正答率 (Accuracy)
  4. 再現率 (Recall)
正解と解説を見る

正解：再現率 (Recall)

再現率は、正例の中で正しく検出できた割合を表す指標です。

問3（深層学習）

畳み込みニューラルネットワーク（CNN）における「プーリング層」の主な役割は何ですか？

  1. 複数の入力データを結合して特徴を抽出する
  2. データの正規化を行い、過学習を防ぐ
  3. 特徴マップのサイズを縮小し、計算量を削減する
  4. 勾配消失問題を解決するために活性化関数を適用する
正解と解説を見る

正解：特徴マップのサイズを縮小し、計算量を削減する

プーリング層は特徴マップの空間的サイズを縮小し、計算コストの削減と特徴の抽象化を実現します。

問4（AIと社会）

AIの倫理的利用に関する原則として最も重要視されているのはどれか？

  1. 利益最大化の追求
  2. コスト削減
  3. 透明性と説明責任
  4. 技術的高速化
正解と解説を見る

正解：透明性と説明責任

AI倫理では、透明性と説明責任が重要視され、利用者に対する説明が求められる。

問5（AI基礎）

教師あり学習におけるモデルの学習に用いられるデータはどれか？

  1. 正解ラベルのみ
  2. 入力データのみ
  3. 入力データと正解ラベルのペア
  4. 入力データの分布のみ
正解と解説を見る

正解：入力データと正解ラベルのペア

教師あり学習では入力と正解ラベルのペアでモデルを学習する。

問6（機械学習）

クラスタリングに代表される教師なし学習の特徴はどれか？

  1. 報酬信号を基に学習する
  2. ラベル付きデータを用いる
  3. データの内在構造を発見する
  4. 損失関数が不要である
正解と解説を見る

正解：データの内在構造を発見する

教師なし学習はラベルなしデータの構造を見つける手法です。
