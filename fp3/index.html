FP3級 予想問題の例

問1（ライフプランニング）

FP倫理に関する問題。行動規範の内容について正しいものはどれか。

  1. FP資格取得者でなくてもFP業務を行ってよいこと
  2. 顧客の秘密を厳守し、信頼関係を保持すること
  3. 自己の利益のために誤解を招く説明を行うこと
  4. 顧客の利益よりも自社利益を優先すること
正解と解説を見る

正解：顧客の秘密を厳守し、信頼関係を保持すること

FPは顧客の利益を最優先し、秘密保持を徹底し信頼関係を保持することが求められている。

問2（リスク管理）

地震保険に関する次の記述のうち、最も適切なものはどれか。

  1. 地震保険の保険料率は、保険会社が自由に設定できるため、同じ条件でも保険会社によって異なる。
  2. 地震保険では、居住用建物に収容されている1個または1組の価額が50万円を超える貴金属等も自動的に補償される。
  3. 地震保険は、火災保険に付帯せず単独で契約することができる。
  4. 地震保険の保険金額は、主契約である火災保険の保険金額の30％以上50％以下の範囲で設定する。
正解と解説を見る

正解：地震保険の保険金額は、主契約である火災保険の保険金額の30％以上50％以下の範囲で設定する。

地震保険は火災保険に付帯して契約し、保険金額は火災保険金額の30～50％で設定する。

問3（金融資産運用）

表面利率年1.2％、額面100万円、残存期間5年の固定利付債券を98万円で購入し、償還まで保有する場合の単利最終利回りとして、最も近いものはどれか。なお、税金・手数料は考慮しない。

  1. 約1.20％
  2. 約1.63％
  3. 約3.27％
  4. 約2.04％
正解と解説を見る

正解：約1.63％

単利最終利回りは、年利息1.2万円と償還差益年0.4万円の合計1.6万円を購入価格98万円で割り、約1.63％となる。

問4（タックスプランニング）

給与所得控除の計算方法について正しいものはどれか。

  1. 144万円
  2. 126万円
  3. 162万円
  4. 108万円
正解と解説を見る

正解：126万円

給与収入が3,600,000円の場合、給与所得控除は「給与収入×30%＋18万円」で計算します。計算すると3,600,000×0.3＋180,000＝1,080,000＋180,000＝1,260,000円となります。

問5（ライフプランニング）

国民年金の被保険者区分に関する次の記述のうち、最も適切なものはどれか。

  1. 自営業者である30歳の者は、国民年金の第2号被保険者となる。
  2. 会社員である45歳の者は、国民年金の第1号被保険者となる。
  3. 20歳未満の学生は、収入の有無にかかわらず国民年金の第3号被保険者となる。
  4. 厚生年金保険の被保険者に扶養されている35歳の配偶者は、原則として国民年金の第3号被保険者となる。
正解と解説を見る

正解：厚生年金保険の被保険者に扶養されている35歳の配偶者は、原則として国民年金の第3号被保険者となる。

第3号被保険者は、第2号被保険者に扶養される20歳以上60歳未満の配偶者である。

問6（リスク管理）

火災保険に地震保険を付帯する場合の地震保険金額の設定として、正しいものはどれか。なお、建物の火災保険金額は2,400万円、家財の火災保険金額は800万円とする。

  1. 建物は720万円以上2,400万円以下、家財は240万円以上800万円以下で設定できる。
  2. 建物は720万円以上1,200万円以下、家財は240万円以上400万円以下で設定できる。
  3. 建物は480万円以上1,200万円以下、家財は160万円以上400万円以下で設定できる。
  4. 建物は1,200万円以上2,400万円以下、家財は400万円以上800万円以下で設定できる。
正解と解説を見る

正解：建物は720万円以上1,200万円以下、家財は240万円以上400万円以下で設定できる。

地震保険金額は火災保険金額の30％～50％の範囲内。建物2,400万円なら720万～1,200万円、家財800万円なら240万～400万円。
