運転免許学科試験 予想問題の例

問1（交通ルール）

赤信号で右折する場合、どのように進行すべきですか？

  1. 赤信号は絶対に停止し、進行してはいけない
  2. 右折は赤信号でも徐行しながら進んでよい
  3. 歩行者信号が青なら進行してよい
  4. 右折車専用信号が青なら進行してよい
正解と解説を見る

正解：右折車専用信号が青なら進行してよい

赤信号でも右折車専用信号が青の場合は進行可能です。それ以外は停止が必要です。

問2（安全運転）

車間距離を適切に保つ理由として正しいものはどれですか？

  1. 他車の進路を妨害するため
  2. 前方の車両の急停止に備えるため
  3. 渋滞を早く解消するため
  4. 燃費を良くするため
正解と解説を見る

正解：前方の車両の急停止に備えるため

適切な車間距離を保つことで、前方車両の急停止時に安全に停止できます。

問3（自動車の知識）

タイヤの空気圧が適切でない場合、どのような影響が最も考えられますか？

  1. 燃費が悪くなる
  2. ブレーキパッドの寿命が延びる
  3. エンジンオイルが劣化する
  4. ワイパーの効果が低下する
正解と解説を見る

正解：燃費が悪くなる

タイヤの空気圧が低いと転がり抵抗が増え、燃費が悪化します。

問4（交通ルール）

「徐行」の標識がある場所では、どのように運転しなければなりませんか？

  1. 標識が見えたらすぐに停止する
  2. 最低速度を守って走行する
  3. 安全のため必要に応じて一時停止しながら進む
  4. 時速30km以下で走行すればよい
正解と解説を見る

正解：安全のため必要に応じて一時停止しながら進む

徐行は安全確認のため必要に応じて停止しながら進むことを意味します。

問5（安全運転）

追い越し禁止場所に該当するのはどれですか？

  1. 見通しの良い直線道路
  2. 歩道橋のある場所
  3. 交差点付近
  4. 高速道路の追い越し車線
正解と解説を見る

正解：交差点付近

交差点付近は追い越し禁止で安全に走行する必要があります。

問6（自動車の知識）

ブレーキ液の点検で最も重要なのは何ですか？

  1. 粘度の柔らかさ
  2. 液の温度
  3. 匂いの強さ
  4. 色の変化と液量の確認
正解と解説を見る

正解：色の変化と液量の確認

ブレーキ液は液量不足や色の変化で交換時期を判断します。
