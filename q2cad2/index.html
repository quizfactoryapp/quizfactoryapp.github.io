問1（CADシステム）

CADで円弧や円を表すベクトルデータの特徴として最も適切なものはどれか。図形を拡大しても線の滑らかさを保ちやすい理由を問う。

  1. 画素の集合として保存され、拡大すると画素が目立つため
  2. 紙図面を読み取った濃淡情報をそのまま保持するため
  3. 表示時に必ず画像ファイルへ変換して線幅を固定するため
  4. 中心点、半径、角度などの幾何情報で図形を定義するため
正解と解説を見る

正解：中心点、半径、角度などの幾何情報で図形を定義するため

ベクトルデータは座標や寸法などの数値情報で図形を定義するため、拡大縮小しても形状精度を保ちやすい。

問2（製図規格）

第三角法で正面図を基準に三面図を配置する場合、上面図と右側面図の正しい位置関係として最も適切なものはどれか。

  1. 上面図は正面図の上、右側面図は正面図の右に置く
  2. 上面図は正面図の右、右側面図は正面図の上に置く
  3. 上面図は正面図の下、右側面図は正面図の左に置く
  4. 上面図と右側面図は、尺度が合えば任意の位置に置いてよい
正解と解説を見る

正解：上面図は正面図の上、右側面図は正面図の右に置く

第三角法では見た方向と同じ側に図を配置するため、上面図は上、右側面図は右に置く。

問3（CAD運用）

直線コマンドで水平・垂直方向の線分を正確に作図したい。マウス操作だけで角度のずれを抑えるために有効な機能はどれか。

  1. 画層ロック
  2. 直交モード
  3. グリップ編集
  4. 線種尺度
正解と解説を見る

正解：直交モード

直交モードはカーソル移動を水平・垂直方向に制限し、直線の角度ずれを防いで作図できる。

問4（CADシステム）

複数の部品図を一つのCAD図面で管理する際、寸法線だけを一時的に非表示にしたい。最も適切なレイヤ管理の方法はどれか。

  1. 寸法線を専用レイヤに分け、そのレイヤを非表示にする
  2. 寸法線をすべて削除し、必要時に手作業で描き直す
  3. 寸法線の色だけを白に変更し、印刷範囲外へ移動する
  4. 全レイヤを結合してから線種を変更する
正解と解説を見る

正解：寸法線を専用レイヤに分け、そのレイヤを非表示にする

要素の種類ごとにレイヤを分けると、表示、編集、印刷の制御を効率よく行える。削除や結合は管理性を損なう。

問5（製図規格）

第一角法と第三角法の説明として正しいものはどれか。投影図の配置は、正面図を基準にして判断するものとする。

  1. 第一角法では右側面図を正面図の右側に配置する
  2. 第三角法では上面図を正面図の下側に配置する
  3. 第一角法では上面図を正面図の下側に配置する
  4. 第一角法と第三角法で投影図の配置は同じである
正解と解説を見る

正解：第一角法では上面図を正面図の下側に配置する

第一角法では見た方向と反対側に図を配置するため、上面図は正面図の下側に置かれる。

問6（CAD運用）

既存の壁芯線から一定距離だけ離れた平行線を作図し、壁厚を表す線を効率よく作りたい。最も適切なコマンドはどれか。

  1. ストレッチ
  2. オフセット
  3. ミラー
  4. トリム
正解と解説を見る

正解：オフセット

オフセットは指定距離で平行な図形を作成するため、壁厚や中心線からの逃げ線作図に適する。
