生命保険専門課程試験 予想問題の例

問1（生命保険コンサルティング）

ライフプランニングに基づく生命保険コンサルティングで、最初に行う対応として最も適切なものはどれか。

  1. 家族構成、収支、資産・負債、将来の希望を確認する
  2. 現在加入中の保険をすべて解約するよう勧める
  3. 保険料を最小にすることだけを目標にする
  4. 予定利率が高い商品から順に提案する
正解と解説を見る

正解：家族構成、収支、資産・負債、将来の希望を確認する

ライフプランニングでは現状と将来の希望を把握し、課題を整理してから保障設計を行う。

問2（生命保険商品知識）

定期保険の基本的なしくみとして、最も適切なものはどれか。保険期間中の死亡保障と満期時の取扱いに着目して選びなさい。

  1. 一定期間の死亡保障を目的とし、一般に満期保険金はない。
  2. 保険期間の経過に応じて必ず保険金額が増加する。
  3. 年金受取を主目的とし、死亡保障は常に付加できない。
  4. 一生涯の死亡保障があり、満期保険金も必ず支払われる。
正解と解説を見る

正解：一定期間の死亡保障を目的とし、一般に満期保険金はない。

定期保険は一定期間の死亡保障を準備する商品で、満期保険金がない掛捨型が一般的です。

問3（税務・社会保障）

平成24年1月1日以後に締結した新契約について、所得税の生命保険料控除で設けられている3区分の組合せとして正しいものはどれか。

  1. 生命保険料、損害保険料、地震保険料
  2. 一般生命保険料、介護医療保険料、個人年金保険料
  3. 定期保険料、終身保険料、養老保険料
  4. 死亡保険料、満期保険料、年金保険料
正解と解説を見る

正解：一般生命保険料、介護医療保険料、個人年金保険料

新契約では、一般生命、介護医療、個人年金の3区分で控除額を計算し、合計限度額があります。

問4（生命保険コンサルティング）

一家の主たる生計維持者に万一のことがあった場合の必要保障額を考える際、基本的な算出方法はどれか。

  1. 貯蓄額と死亡退職金を合計する
  2. 遺族の支出見込額から公的保障や金融資産などを差し引く
  3. 現在の死亡保険金額をそのまま採用する
  4. 年間保険料に契約年数を掛ける
正解と解説を見る

正解：遺族の支出見込額から公的保障や金融資産などを差し引く

必要保障額は遺族の生活費等から、遺族年金・預貯金・死亡退職金などを控除して求める。

問5（生命保険商品知識）

逓減定期保険の活用例として最も適切なものはどれか。保障額の推移と必要保障額の変化を踏まえて選びなさい。

  1. 住宅ローン残高の減少に合わせた死亡保障の準備に適している。
  2. 老後資金を毎年一定額ずつ受け取る準備に適している。
  3. 一生涯同額の死亡保障を確保する目的に限られる。
  4. 満期時にまとまった資金を受け取る貯蓄目的に適している。
正解と解説を見る

正解：住宅ローン残高の減少に合わせた死亡保障の準備に適している。

逓減定期保険は保険金額が徐々に減るため、借入残高など減少する保障需要に合います。

問6（税務・社会保障）

新契約に係る介護医療保険料の年間支払額が90,000円で、剰余金等がない場合、所得税の介護医療保険料控除額はいくらか。

  1. 30,000円
  2. 35,000円
  3. 45,000円
  4. 40,000円
正解と解説を見る

正解：40,000円

新契約の各区分は年間支払額が80,000円超の場合、一律40,000円が控除限度額です。
