保育士 予想問題の例

問1（保育原理）

保育の意義として最も適切なものはどれか。子どもの健やかな成長を支援し、社会性や自立心を育むことを指す。

  1. 親の負担を軽減することのみを目的とする。
  2. 子どもの生活全般を支え、発達を促すこと。
  3. 子どもを集団から切り離して個別指導すること。
  4. 子どもの学力向上に特化すること。
正解と解説を見る

正解：子どもの生活全般を支え、発達を促すこと。

保育は子どもの生活全般を支え、心身の発達や社会性の形成を促すことが目的です。

問2（教育・発達心理学）

ピアジェの認知発達理論における感覚運動期の特徴として正しいものはどれか。

  1. 因果関係を言葉で説明できる
  2. 感覚や運動を通じて世界を理解する
  3. 抽象的な論理的思考ができる
  4. 他者の視点を考慮できる
正解と解説を見る

正解：感覚や運動を通じて世界を理解する

感覚運動期（0-2歳）は感覚と運動を通じて環境を理解する時期です。

問3（児童家庭福祉）

児童福祉法における児童の定義は何歳未満の者を指すか？

  1. 18歳未満
  2. 20歳未満
  3. 15歳未満
  4. 12歳未満
正解と解説を見る

正解：18歳未満

児童福祉法では、18歳未満の者を児童と定義しています。

問4（子どもの保健・栄養）

乳児の発育発達において、首がすわるのは通常何か月頃ですか？

  1. 1ヶ月
  2. 7ヶ月
  3. 10ヶ月
  4. 4ヶ月
正解と解説を見る

正解：4ヶ月

首がすわるのは生後約4ヶ月頃が目安で、この時期に頭を自分で支えられるようになります。

問5（保育原理）

「保育所保育指針」において、保育の基本的なねらいとして示されているものはどれか。

  1. 遊びを通じて心身の発達を促すこと。
  2. 大量の情報を教え込むこと。
  3. 学校教育の予備段階としての学習指導。
  4. 競争心を育てるための指導。
正解と解説を見る

正解：遊びを通じて心身の発達を促すこと。

保育指針では遊びを中心に、子どもの心身の発達を支えることが基本のねらいとされています。

問6（教育・発達心理学）

愛着理論で有名なボウルビィによれば、安全基地としての母親の役割が子どもの発達に与える影響は何か。

  1. 子どもの安心感と探索行動を促す
  2. 子どもの自立心を阻害する
  3. 社会性の発達に関係しない
  4. 子どもの攻撃性を高める
正解と解説を見る

正解：子どもの安心感と探索行動を促す

母親が安全基地となることで子どもは安心し、外の世界を探索しやすくなります。
