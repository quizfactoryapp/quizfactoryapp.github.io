問1（大型二輪操作）

大型二輪で極低速の直線走行をするとき、車体を安定させる操作として最も適切なものはどれか。

  1. 前輪ブレーキだけで速度を細かく調整する
  2. 視線を先へ向け、半クラッチと後輪ブレーキで微調整する
  3. 前輪のすぐ前を見て、ふらつきを早く見つける
  4. クラッチを完全に切り、惰性だけで進む
正解と解説を見る

正解：視線を先へ向け、半クラッチと後輪ブレーキで微調整する

低速では駆動力を残し、後輪ブレーキと半クラッチで速度を整えると車体が安定しやすい。

問2（課題走行）

大型自動二輪の一本橋で、進入直後に車体がふらついた。通過時間を確保しながら安定させる操作として最も適切なものはどれか。

  1. クラッチを完全につなぎ、アクセルを戻して惰性で進む
  2. 前輪を左右に大きく振り、ハンドルだけで時間を稼ぐ
  3. 視線を橋の先に置き、半クラッチと後輪ブレーキで速度を微調整する
  4. 前輪ブレーキを強く使い、停止寸前まで速度を落とす
正解と解説を見る

正解：視線を橋の先に置き、半クラッチと後輪ブレーキで速度を微調整する

一本橋は視線、ニーグリップ、半クラッチ、後輪ブレーキの調和で低速安定を保つことが重要である。

問3（大型二輪安全）

大型二輪車で下り坂を走行中、前方の信号が赤に変わった。重量による制動距離の伸びを考えた操作として最も適切なものはどれか。

  1. 早めに速度を落とし、前後ブレーキとエンジンブレーキを併用する
  2. 停止線直前まで速度を保ち、最後に強く制動する
  3. クラッチを切ったまま惰性で近づき、必要時だけ制動する
  4. 後輪ブレーキだけを強め、前輪は使わない
正解と解説を見る

正解：早めに速度を落とし、前後ブレーキとエンジンブレーキを併用する

大型二輪は車重があり下り坂では制動距離が伸びるため、早めの減速と前後ブレーキの安定した併用が必要である。

問4（大型二輪操作）

交差点を曲がり終えて加速する際、大型二輪のアクセル操作として最も安全なものはどれか。

  1. 車体が起き始めてから、なめらかに開けて加速する
  2. クラッチを切ったままアクセルだけを強くあおる
  3. 旋回中に一気に大きく開け、素早く立ち上がる
  4. 速度を保つため、曲がり始めから全開に近くする
正解と解説を見る

正解：車体が起き始めてから、なめらかに開けて加速する

旋回中の急な加速は姿勢を乱しやすい。車体が起きる動きに合わせて少しずつ開ける。

問5（課題走行）

波状路を通過する際、段差の衝撃を受け流しながら車体を安定させる基本姿勢として正しいものはどれか。

  1. シートに深く座り、上半身を後ろへ反らして通過する
  2. 両足を広げ、足先で地面に触れながら進む
  3. 腕を伸ばしてハンドルを固定し、体を動かさない
  4. 立ち姿勢で膝と肘を軽く曲げ、車体の動きに合わせる
正解と解説を見る

正解：立ち姿勢で膝と肘を軽く曲げ、車体の動きに合わせる

波状路では立ち姿勢で膝と肘を柔らかく使い、段差の衝撃を吸収しながら低速で通過する。

問6（大型二輪安全）

大型二輪車で交差点を右折中、路面に砂が浮いていることに気づいた。転倒を避けるための対応として最も適切なものはどれか。

  1. アクセルを急に戻し、エンジンブレーキを強める
  2. 前輪ブレーキを強くかけてすぐ止まる
  3. 急操作を避け、車体を起こし気味にしてゆるやかに通過する
  4. 車体をさらに傾けて小さく曲がる
正解と解説を見る

正解：急操作を避け、車体を起こし気味にしてゆるやかに通過する

砂や砂利はタイヤのグリップを低下させる。急制動や急旋回を避け、車体を起こして安定させることが大切である。
