情報セキュリティマネジメント 予想問題の例

問1（脅威と脆弱性）

脆弱性管理において、CVSS基本値が高い脆弱性Aと中程度の脆弱性Bが見つかった。Aは社内の検証用サーバだけに存在し、外部から到達できず、重要情報も扱っていない。Bはインターネット公開中のVPN装置に存在し、攻撃コードが公開され、認証なしで悪用可能である。優先対応として最も適切なものはどれか。

  1. AとBのどちらも情報漏えいが確認されるまで対応を保留する。
  2. 悪用可能性と公開範囲を考慮し、Bを優先して修正または緩和する。
  3. VPN装置は認証機能を持つため、Bは認証なしで悪用可能でも優先度を下げる。
  4. CVSS基本値が高いAを、利用状況に関係なく最優先で修正する。
正解と解説を見る

正解：悪用可能性と公開範囲を考慮し、Bを優先して修正または緩和する。

脆弱性対応はCVSSだけでなく、外部公開、攻撃コード、認証要否、資産重要度を含めて優先度を決める。

問2（情報セキュリティ管理）

ISMSの目的として最も適切なものはどれか。

  1. 情報システムの脆弱性を完全に排除すること
  2. 情報セキュリティに関する法規制をすべて遵守すること
  3. 組織の情報資産を適切に保護し、リスクを管理すること
  4. 全社員に情報セキュリティの研修を実施すること
正解と解説を見る

正解：組織の情報資産を適切に保護し、リスクを管理すること

ISMSの目的は、組織の情報資産に対して適切な管理策を実施し、情報セキュリティリスクを効果的に管理・低減することにあります。完全な排除や法規制遵守は重要ですが、ISMSの本質的な目的ではありません。

問3（セキュリティ技術）

共通鍵暗号方式の特徴について正しいものはどれか。

  1. 主に電子署名に使用される方式である。
  2. 公開鍵と秘密鍵のペアを用いる暗号方式である。
  3. 鍵管理が容易であるため、多数の通信相手に適している。
  4. 暗号化と復号に同じ鍵を使用する。
正解と解説を見る

正解：暗号化と復号に同じ鍵を使用する。

共通鍵暗号方式は暗号化と復号に同じ鍵を用いるため、鍵の管理に注意が必要であるが、計算コストが低い特徴がある。

問4（脅威と脆弱性）

Webアプリケーションの脆弱性診断で、利用者IDを指定するURLパラメータを変更すると、他人の注文履歴を閲覧できることが分かった。この脆弱性として最も適切なものはどれか。

  1. セッション固定攻撃
  2. SQLインジェクション
  3. 認可制御の不備
  4. クロスサイトスクリプティング
正解と解説を見る

正解：認可制御の不備

URLのID変更で他人の情報を閲覧できるのは、本人確認後のアクセス権確認が不足する認可制御の不備である。

問5（情報セキュリティ管理）

リスクアセスメントの定量的評価における計算式として正しいものはどれか。

  1. \text{リスク} = \text{影響度} - \text{脅威の発生頻度}
  2. \text{リスク} = \text{脅威の発生頻度} \times \text{影響度}
  3. \text{リスク} = \text{脅威の発生頻度} + \text{影響度}
  4. \text{リスク} = \frac{\text{影響度}}{\text{脅威の発生頻度}}
正解と解説を見る

正解：\text{リスク} = \text{脅威の発生頻度} \times \text{影響度}

リスクの定量的評価では、脅威がどの程度の頻度で発生するか（発生頻度）と、それによって生じる影響の大きさ（影響度）を掛け合わせてリスク値を算出します。

問6（セキュリティ技術）

認証方式における多要素認証の説明と効果。

  1. パスワードと指紋の組み合わせ
  2. スマートカードと指紋の組み合わせ
  3. パスワードとユーザ名の組み合わせ
  4. パスワードとワンタイムトークンの組み合わせ
正解と解説を見る

正解：パスワードとユーザ名の組み合わせ

多要素認証は異なるカテゴリーの認証要素を組み合わせることで安全性を高める。ユーザ名は認証要素ではなく識別情報である。
