世界遺産検定 予想問題の例

問1（世界遺産条約）

世界遺産条約でいう顕著な普遍的価値（OUV）についての説明として、国内での知名度や人気ではなく本質を最も正確に示しているものはどれか。

  1. 登録国の歴史教育で頻繁に扱われることによる価値
  2. 保存や修復に多額の費用を要することによる価値
  3. その国で最も有名な観光地であることを示す価値
  4. 人類全体にとって国境を超える卓越した重要性をもつ価値
正解と解説を見る

正解：人類全体にとって国境を超える卓越した重要性をもつ価値

OUVは一国や地域に限られず、人類全体に共有される卓越した重要性を指す。知名度や観光規模だけでは判断されない。

問2（文化遺産分野）

自然の景観そのものより、聖地・伝承・信仰対象としての精神的結び付きが価値の核となる文化的景観の類型として最も適切なものはどれか。

  1. 化石景観
  2. 意匠された文化的景観
  3. 進化し続ける景観
  4. 関連する文化的景観
正解と解説を見る

正解：関連する文化的景観

関連する文化的景観は、目に見える改変の量よりも、自然地形と信仰・芸術・伝承との強い結び付きが重視される類型である。

問3（自然遺産分野）

世界遺産の自然遺産で評価基準（x）が重視する内容として最も適切なのはどれか。景観美そのものではなく、生息地保全の観点から選べ。

  1. 絶滅危惧種を含む生物多様性の生息域を保つこと
  2. 伝統的祭礼が継承されていること
  3. 巡礼路として国際的に利用されてきたこと
  4. 大規模建造物が歴史的価値を示すこと
正解と解説を見る

正解：絶滅危惧種を含む生物多様性の生息域を保つこと

基準（x）は生物多様性保全、とくに絶滅危惧種の重要な生息地や生態学的過程を支える地域かどうかを重視する基準である。

問4（世界遺産条約）

登録基準に関する説明として正しいものを選べ。現在の世界遺産登録では、文化遺産と自然遺産の基準の扱いがどのように整理されているかが問われる。

  1. 登録基準の数は各締約国が毎年自由に定めている
  2. 文化6基準と自然4基準は現在も完全に別制度で運用される
  3. 文化・自然を通じた10の登録基準として一体的に整理されている
  4. 文化遺産だけに登録基準があり、自然遺産には基準がない
正解と解説を見る

正解：文化・自然を通じた10の登録基準として一体的に整理されている

現在は文化・自然を通じた10基準として整理されており、資産はそのうち少なくとも1基準を満たしてOUVを示す必要がある。

問5（文化遺産分野）

フィリピン・コルディリェーラの棚田群が文化的景観として高く評価される理由として、最も適切な説明はどれか。

  1. 単独の大聖堂が初期ゴシックの完成形を示す
  2. 宮殿庭園が王権の象徴として計画的に造営された
  3. 火山噴火で埋没した古代都市が良好に保存された
  4. 山岳地形に適応した棚田と共同体の水利・農耕システムが今も継承されている
正解と解説を見る

正解：山岳地形に適応した棚田と共同体の水利・農耕システムが今も継承されている

この遺産の価値は、急峻な山地に築いた棚田そのものだけでなく、共同体が維持する灌漑と農耕の継続的営みにある。

問6（自然遺産分野）

自然遺産のバッファゾーンについての説明として最も適切なのはどれか。登録資産の周囲に設ける目的と法的・管理的な役割に注目して答えよ。

  1. 登録資産と同一の範囲で、境界線を二重表示する区域
  2. 資産本体とは無関係で、景観上の目印としてのみ設定する区域
  3. 観光客向け施設だけを集中的に整備する開発優先区域
  4. 外部からの開発圧や景観改変の影響を和らげ、資産保護を補完する区域
正解と解説を見る

正解：外部からの開発圧や景観改変の影響を和らげ、資産保護を補完する区域

バッファゾーンは資産本体の顕著な普遍的価値を守るため、その周辺で土地利用や開発を調整し、悪影響を緩和する補完的区域である。
