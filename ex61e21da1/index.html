簿記実務検定試験 予想問題の例

問1（会計）

商品120,000円を仕入れ、代金は掛けとした。この取引を仕訳するとき、借方と貸方の組合せとして正しいものはどれか。

  1. 借方：仕入120,000円／貸方：支払手形120,000円
  2. 借方：買掛金120,000円／貸方：仕入120,000円
  3. 借方：商品120,000円／貸方：売掛金120,000円
  4. 借方：仕入120,000円／貸方：買掛金120,000円
正解と解説を見る

正解：借方：仕入120,000円／貸方：買掛金120,000円

商品を掛けで仕入れたため、費用である仕入を借方、後日支払う買掛金を貸方に記入する。

問2（財務諸表）

決算整理後の貸借対照表を作成する際、売掛金の期末残高から貸倒引当金を設定した場合、貸借対照表上の表示として最も適切なものはどれか。

  1. 貸倒引当金繰入を資産の部に表示する
  2. 貸倒引当金を売掛金から控除して表示する
  3. 売掛金を負債の部に表示する
  4. 売掛金と貸倒引当金を相殺せず収益に振り替える
正解と解説を見る

正解：貸倒引当金を売掛金から控除して表示する

貸倒引当金は売掛金など金銭債権の評価勘定であり、貸借対照表では対象債権から控除して表示する。

問3（原価計算）

材料を100kg、1kg当たり500円で掛購入し、引取運賃3,000円を現金で支払い、仕入値引1,000円を受けた。材料の取得原価はいくらか。

  1. 53,000円
  2. 52,000円
  3. 50,000円
  4. 54,000円
正解と解説を見る

正解：52,000円

材料の取得原価は購入代価に付随費用を加え、値引を控除する。50,000円＋3,000円－1,000円＝52,000円。

問4（2級商業簿記）

三分法で商品200,000円を掛けで仕入れ、引取運賃8,000円を現金で支払った。仕入時の正しい仕訳はどれか。

  1. 仕入208,000／買掛金200,000・現金8,000
  2. 仕入200,000／買掛金200,000、支払運賃8,000／現金8,000
  3. 商品208,000／買掛金200,000・現金8,000
  4. 仕入200,000・発送費8,000／買掛金208,000
正解と解説を見る

正解：仕入208,000／買掛金200,000・現金8,000

仕入諸掛である引取運賃は仕入原価に含め、三分法では仕入勘定に加算して処理する。

問5（会計）

得意先へ商品80,000円を販売し、代金は現金で受け取った。三分法で処理する場合の仕訳として正しいものはどれか。

  1. 借方：売上80,000円／貸方：現金80,000円
  2. 借方：現金80,000円／貸方：売上80,000円
  3. 借方：現金80,000円／貸方：仕入80,000円
  4. 借方：売掛金80,000円／貸方：売上80,000円
正解と解説を見る

正解：借方：現金80,000円／貸方：売上80,000円

現金販売では資産の現金が増加するため借方、収益の売上が発生するため貸方に記入する。

問6（財務諸表）

当期首に受け取った1年分の家賃収入のうち、翌期分が含まれている。決算整理仕訳で使用する勘定科目の組合せとして正しいものはどれか。

  1. 受取利息と未収収益
  2. 支払家賃と前払費用
  3. 雑益と仮受金
  4. 受取家賃と前受収益
正解と解説を見る

正解：受取家賃と前受収益

翌期分の収益を当期の収益から除くため、受取家賃を借方、前受収益を貸方に計上する。
