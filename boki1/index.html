問1（商業簿記）

当社は商品を割賦販売し、販売基準により収益を認識している。商品Aを現金販売価格600,000円、割賦販売価格660,000円（利息相当額60,000円を含む）で販売し、代金は12か月の均等払いとする。販売時の適切な処理として最も妥当なものはどれか。

  1. 売掛金600,000円を計上し、売上600,000円を計上する。利息相当額は入金時まで認識しない。
  2. 売掛金660,000円を計上し、売上660,000円を計上する。
  3. 売掛金660,000円を計上し、売上600,000円と受取利息60,000円を販売時に計上する。
  4. 売掛金660,000円を計上し、売上600,000円と前受利息60,000円を計上する。
正解と解説を見る

正解：売掛金660,000円を計上し、売上600,000円と前受利息60,000円を計上する。

割賦販売価格に含まれる利息相当額は販売時の売上に含めず、期間対応で利息収益化するため前受処理する。

問2（会計学）

資産除去債務に関する次の資料に基づき、当期末に貸借対照表へ計上される資産除去債務の金額として最も適切なものはどれか。期首に設備を取得し、5年後に原状回復費用1,000,000円を支払う義務が発生した。割引率は年3%であり、資産除去債務は取得時に割引現在価値で計上する。現在価値係数は、3%・5年が0.8626、3%・4年が0.8885とする。

  1. 888,478円
  2. 26,000円
  3. 862,600円
  4. 1,000,000円
正解と解説を見る

正解：888,478円

取得時は1,000,000円×0.8626＝862,600円。期末は利息費用25,878円を加算し888,478円となる。

問3（工業簿記）

標準原価計算を採用している。製品1個当たりの標準直接材料は4kg、標準単価は500円/kgである。当月の実際生産量は1,000個、実際材料消費量は4,200kg、実際購入単価は480円/kgであった。直接材料数量差異はいくらか。なお、有利差異を「有利」、不利差異を「不利」と表示する。

  1. 16,000円（有利）
  2. 100,000円（不利）
  3. 84,000円（不利）
  4. 80,000円（有利）
正解と解説を見る

正解：100,000円（不利）

数量差異は標準単価×（標準消費量－実際消費量）。500円×（4,000kg－4,200kg）＝100,000円不利。

問4（原価計算）

標準原価計算を採用している。製品1個当たりの標準直接材料は、標準価格500円/kg、標準消費量3kgである。当月の実際生産量は2,000個、実際材料消費量は6,300kg、実際材料購入・消費額は3,087,000円であった。直接材料費差異を価格差異と数量差異に分ける場合、数量差異はいくらか。なお、差異は不利差異を正の金額で示す。

  1. 237,000円（不利差異）
  2. 63,000円（有利差異）
  3. 87,000円（不利差異）
  4. 150,000円（不利差異）
正解と解説を見る

正解：150,000円（不利差異）

標準消費量は2,000個×3kg＝6,000kg。数量差異は(6,300－6,000)×500＝150,000円の不利差異。

問5（商業簿記）

決算日において、その他有価証券の帳簿価額は1,000,000円、時価は1,180,000円であった。法定実効税率は30%で、全部純資産直入法を適用する。この場合の決算整理仕訳として最も適切なものはどれか。

  1. その他有価証券 180,000／繰延税金負債 54,000、その他有価証券評価差額金 126,000
  2. その他有価証券評価差額金 126,000、法人税等調整額 54,000／その他有価証券 180,000
  3. その他有価証券 180,000／投資有価証券評価益 180,000
  4. その他有価証券 180,000／繰延税金資産 54,000、その他有価証券評価差額金 126,000
正解と解説を見る

正解：その他有価証券 180,000／繰延税金負債 54,000、その他有価証券評価差額金 126,000

その他有価証券の評価差額は純資産直入し、評価益180,000円の税効果30%を繰延税金負債とする。

問6（会計学）

満期保有目的債券として、額面1,000,000円、取得価額951,963円、クーポン利率年2%、実効利子率年3%、利払年1回の社債を期首に取得した。償却原価法は利息法による。取得後1年目の期末に認識する有価証券利息と、期末帳簿価額の組合せとして正しいものはどれか。なお、円未満は四捨五入する。

  1. 有価証券利息20,000円、期末帳簿価額951,963円
  2. 有価証券利息28,559円、期末帳簿価額971,963円
  3. 有価証券利息28,559円、期末帳簿価額960,522円
  4. 有価証券利息30,000円、期末帳簿価額961,963円
正解と解説を見る

正解：有価証券利息28,559円、期末帳簿価額960,522円

利息法では帳簿価額に実効利子率を乗じる。28,559円を収益計上し、現金利息20,000円との差額8,559円を帳簿価額に加算する。
