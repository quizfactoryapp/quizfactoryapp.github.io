問1（地震災害と津波防災）

津波の伝わる速さに関する説明として、最も適切なものはどれか。

  1. 津波は水深が深い外洋ほど速く進み、沿岸の浅い海域では速度が遅くなる。
  2. 津波は海底地形に関係なく、常に時速約50kmで進む。
  3. 津波は風で生じる波なので、台風時以外は速く進まない。
  4. 津波は沿岸に近づくほど必ず高さが低くなり、速度は速くなる。
正解と解説を見る

正解：津波は水深が深い外洋ほど速く進み、沿岸の浅い海域では速度が遅くなる。

津波の速さは水深に大きく左右され、外洋では速く、沿岸では遅くなる一方で波高が増すことがある。

問2（風水害と土砂災害）

線状降水帯に関する「顕著な大雨に関する気象情報」が発表された場合の対応として、最も適切なものはどれか。

  1. 災害の危険度が急激に高まっていると考え、安全確保を急ぐ
  2. 台風接近時だけ必要な情報なので通常の大雨では無視する
  3. 雨が弱まるまで屋外で河川の水位を直接確認する
  4. 発表後は必ず数時間の猶予があるため荷物整理を優先する
正解と解説を見る

正解：災害の危険度が急激に高まっていると考え、安全確保を急ぐ

線状降水帯による大雨は短時間で危険が高まるため、自治体情報も確認し直ちに安全確保する。

問3（避難所運営）

指定避難所の開設初期に行う対応として、最も適切なものはどれか。施設管理者と協力し、安全確認を行ったうえで受入れを始める。

  1. 自治会役員だけで運営し、行政職員の到着まで記録を取らない
  2. 避難者が集まり次第、建物内の全室を自由に使わせる
  3. 物資配布を優先し、避難者名簿の作成は数日後に行う
  4. 施設の安全確認、使用可能区域の設定、受付体制の準備を行う
正解と解説を見る

正解：施設の安全確認、使用可能区域の設定、受付体制の準備を行う

開設時は二次被害を防ぐため、施設の安全確認と使用区域、受付、名簿作成を早期に整えることが重要である。

問4（災害対応と地域防災）

大規模災害時の「自助・共助・公助」の関係について、最も適切な説明はどれか。

  1. 自助は個人の備え、共助は地域の助け合い、公助は行政などの支援を指す
  2. 自助は避難所運営、公助は家庭内備蓄を意味する
  3. 共助は企業だけが行う支援で、住民組織は含まれない
  4. 公助が最優先であり、住民は行政の指示があるまで行動しない
正解と解説を見る

正解：自助は個人の備え、共助は地域の助け合い、公助は行政などの支援を指す

災害直後は公助がすぐ届かないこともあり、自助と共助を組み合わせた備えが重要です。

問5（地震災害と津波防災）

長周期地震動に関する説明として、最も適切なものはどれか。

  1. 震度1未満の地震でしか観測されない特殊な揺れである
  2. 津波の高さを直接表す指標であり、陸上の揺れとは関係しない
  3. 周期の長い揺れが高層ビルなどを大きく長く揺らす現象である
  4. 震源近くの低層木造住宅だけに被害を起こす短い周期の揺れである
正解と解説を見る

正解：周期の長い揺れが高層ビルなどを大きく長く揺らす現象である

長周期地震動は周期の長い揺れで、高層建物や石油タンクなどを大きく長時間揺らすことがある。

問6（風水害と土砂災害）

洪水ハザードマップを平時に確認する目的として、最も適切なものはどれか。

  1. 堤防の強度を住民が判定し、補修の要否を決める
  2. 当日の降雨量を正確に予測し、警報の発表時刻を知る
  3. 自宅や職場の浸水深、避難先、避難経路のリスクを把握する
  4. 浸水区域外なら停電や断水も起こらないと確認する
正解と解説を見る

正解：自宅や職場の浸水深、避難先、避難経路のリスクを把握する

洪水ハザードマップは想定浸水区域や水深、避難場所などを事前に確認するために使う。
