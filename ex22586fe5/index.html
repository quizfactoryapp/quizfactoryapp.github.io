銀行業務検定試験 税務3級 予想問題の例

問1（所得税）

会社員Aが勤務先から受ける給与と、業務上必要な旅費の実費精算を受けた場合の所得税上の取扱いとして、最も適切なものはどれか。

  1. 給与は非課税、旅費精算のみ給与所得として課税する。
  2. 給与も旅費精算もすべて一時所得として総合課税する。
  3. 給与は給与所得、通常必要な実費弁償の旅費は原則非課税として扱う。
  4. 給与は事業所得、旅費精算は雑所得として申告する。
正解と解説を見る

正解：給与は給与所得、通常必要な実費弁償の旅費は原則非課税として扱う。

給与は給与所得に該当するが、通常必要と認められる旅費の実費弁償は原則として非課税である。

問2（法人税）

法人が商品を販売し、期末までに代金未収であっても引渡しが完了している場合、法人税上の売上収益の取扱いとして正しいものはどれか。

  1. 入金時まで益金に算入しない
  2. 請求書発行時まで益金に算入しない
  3. 翌事業年度の益金に任意に繰り延べる
  4. 引渡しのあった事業年度の益金に算入する
正解と解説を見る

正解：引渡しのあった事業年度の益金に算入する

法人税では収益の実現時期を基準とし、商品引渡しにより売上は当期の益金となる。

問3（相続税・贈与税）

相続税の基礎控除額を計算する式として、現行制度上もっとも適切なものはどれか。法定相続人の数をn人とする。

  1. 5,000万円＋1,000万円×n
  2. 2,000万円＋500万円×n
  3. 3,000万円＋600万円×n
  4. 1,100万円×n
正解と解説を見る

正解：3,000万円＋600万円×n

相続税の基礎控除額は、3,000万円に法定相続人1人当たり600万円を加算して計算する。

問4（消費税）

国内で事業者が対価を得て商品を販売した場合の消費税の取扱いとして、最も適切なものはどれか。

  1. 免税取引となる
  2. 不課税取引となる
  3. 課税取引となる
  4. 非課税取引となる
正解と解説を見る

正解：課税取引となる

国内における事業者の資産の譲渡等で、対価を得て行うものは原則として課税取引です。

問5（金融取引税務）

国内銀行の円預金利子について、個人が受け取る際の課税関係として最も適切なものはどれか。復興特別所得税を含めて考える。

  1. 配当控除の対象として税額控除を受けられる
  2. 総合課税として確定申告により税額を精算する
  3. 20.315％の源泉分離課税で課税関係が終了する
  4. 少額であれば常に非課税となり申告も不要である
正解と解説を見る

正解：20.315％の源泉分離課税で課税関係が終了する

国内預金利子は利子所得として20.315％が源泉徴収され、原則として源泉分離課税で完結する。

問6（所得税）

個人事業主がその年に商品を販売し、代金は翌年に入金された。発生主義による事業所得の収入計上時期として正しいものはどれか。

  1. 商品の引渡しなどにより収入すべき権利が確定した年に計上する。
  2. 請求書を発行した年ではなく、確定申告書を提出した年に計上する。
  3. 入金前であれば、売上として認識する必要は一切ない。
  4. 代金を実際に受け取った翌年に必ず計上する。
正解と解説を見る

正解：商品の引渡しなどにより収入すべき権利が確定した年に計上する。

事業所得の総収入金額は、原則として収入すべき権利が確定した年分に計上する。
