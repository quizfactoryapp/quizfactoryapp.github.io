基本情報技術者 予想問題の例

問1（基礎理論）

10進数の0.625を2進小数で表したものはどれか。

  1. 0.111₂
  2. 0.101₂
  3. 0.110₂
  4. 0.011₂
正解と解説を見る

正解：0.101₂

2進小数では0.101₂=1/2+0/4+1/8=0.5+0.125=0.625となる。

問2（コンピュータシステム）

主記憶へのアクセス時間が80ナノ秒，キャッシュメモリへのアクセス時間が10ナノ秒である。キャッシュヒット率が90%のとき，平均アクセス時間は何ナノ秒か。

  1. 17ナノ秒
  2. 18ナノ秒
  3. 72ナノ秒
  4. 90ナノ秒
正解と解説を見る

正解：17ナノ秒

平均アクセス時間は，10×0.9＋80×0.1＝17ナノ秒である。ヒット時とミス時の重み付き平均を求める。

問3（技術要素）

リレーショナルデータベースにおける正規形の目的は何か。

  1. 複雑なトリガーを多用すること
  2. データの整合性を保ち更新異常を防ぐこと
  3. SQLの実行速度を遅くすること
  4. データの重複を増やすこと
正解と解説を見る

正解：データの整合性を保ち更新異常を防ぐこと

正規化はデータの重複を削減し、データの整合性を保ち、更新異常を防止するために行われる。

問4（マネジメント）

システム監査の監査証拠に関する記述として正しいものはどれか

  1. 社外からの噂や憶測
  2. 監査人の主観的な意見のみ
  3. 監査対象者の口頭の説明だけ
  4. システムのログや記録、インタビュー記録など客観的な証拠
正解と解説を見る

正解：システムのログや記録、インタビュー記録など客観的な証拠

監査証拠は客観的かつ信頼できるものでなければなりません。口頭説明は補助的に扱われます。

問5（ストラテジ）

経営戦略の3C分析に含まれない要素はどれか。

  1. Competitor
  2. Customer
  3. Company
  4. Cost
正解と解説を見る

正解：Cost

3C分析は自社（Company）、顧客（Customer）、競合（Competitor）の3つの観点から戦略を検討する手法であり、Costは含まれない。

問6（基礎理論）

10進数の45を2進数で表したものはどれか。

  1. 101101
  2. 101011
  3. 110101
  4. 100101
正解と解説を見る

正解：101101

45は32+8+4+1なので、2進数では各桁が101101となる。
