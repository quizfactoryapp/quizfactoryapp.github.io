秘書技能検定試験 予想問題の例

問1（秘書理論）

上司が会議中に重要取引先から急ぎの折り返し依頼を受けた。秘書として最も適切な初動はどれか。

  1. 自分の判断で取引先に結論を伝え、上司への報告は後にする。
  2. 取引先には上司が忙しいとだけ伝え、会議終了まで何もしない。
  3. 会議室に入り、出席者全員の前で電話内容を詳しく伝える。
  4. 会議を中断せず、用件を確認して緊急度を判断し、必要ならメモで上司に知らせる。
正解と解説を見る

正解：会議を中断せず、用件を確認して緊急度を判断し、必要ならメモで上司に知らせる。

秘書は用件と緊急度を確かめ、上司の業務を妨げ過ぎない方法で必要情報を伝える。

問2（職場常識）

取引先の担当者が約束の時間より早く来社した。応接室の準備がまだ整っていない場合の対応として最も適切なものはどれか。

  1. 準備ができるまで受付で立って待つよう依頼する。
  2. 早く来た相手に理由を確認し、約束時刻まで外出を促す。
  3. 来社への謝意を述べ、座れる場所へ案内して担当者に到着を知らせる。
  4. 担当者の都合を優先し、準備中の応接室へそのまま通す。
正解と解説を見る

正解：来社への謝意を述べ、座れる場所へ案内して担当者に到着を知らせる。

早着でも来客を丁寧に迎え、待機場所を確保して担当者へ速やかに連絡するのが適切である。

問3（ビジネス文書）

社内文書である「稟議書」を作成する目的として、最も適切なものはどれか。

  1. 取引先へ契約条件を正式に通知するため
  2. 上司や関係部署の承認を得て、案件を実施するため
  3. 社員の慶事を社外に広く知らせるため
  4. 会議の発言内容を逐語的に記録するため
正解と解説を見る

正解：上司や関係部署の承認を得て、案件を実施するため

稟議書は、案件の内容や必要性を示し、決裁権者の承認を得るための社内文書である。

問4（事務管理）

上司の外出予定をスケジュール表に記入するとき、秘書として最も適切な記載方法はどれか。

  1. 予定変更が多いので、当日の朝まで記入しない
  2. 訪問先名、用件、出発・到着予定時刻、連絡先を確認して記入する
  3. 相手先に失礼にならないよう、社内では訪問先名を伏せる
  4. 上司が忙しい場合は、外出とだけ記入し詳細は省略する
正解と解説を見る

正解：訪問先名、用件、出発・到着予定時刻、連絡先を確認して記入する

予定管理では、行動把握と連絡対応のため必要事項を正確に記録することが重要である。

問5（秘書理論）

秘書が職務上知った新製品情報について、友人から何気なく尋ねられた場合の対応として最も適切なものはどれか。

  1. 社外秘の可能性があるため、知っていても話せないと丁寧に断る。
  2. 発売前であることを伏せ、概要だけなら話してもよい。
  3. すでに社内で話題になっているので、一般情報として共有する。
  4. 親しい友人なので、口外しない約束で詳しく説明する。
正解と解説を見る

正解：社外秘の可能性があるため、知っていても話せないと丁寧に断る。

職務上知った未公開情報は相手が親しい人でも漏らさず、機密保持を徹底する。

問6（職場常識）

上司宛てに電話があり、上司は会議中で電話に出られない。相手が急ぎだと言った場合の対応として最も適切なものはどれか。

  1. 会議中であることを詫び、用件と連絡先を確認して至急伝える。
  2. 会議中なので終わるまで待ってほしいとだけ伝える。
  3. 会議室へ電話をつなぎ、相手に直接話してもらう。
  4. 急ぎなら携帯番号を教えるので直接かけるよう案内する。
正解と解説を見る

正解：会議中であることを詫び、用件と連絡先を確認して至急伝える。

不在理由を簡潔に伝えて詫び、用件・連絡先・緊急度を確認し、上司へ速やかに取り次ぐ。
