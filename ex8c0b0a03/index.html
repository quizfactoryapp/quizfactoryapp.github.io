問1（石綿の健康障害）

石綿肺について、石綿作業主任者技能講習の健康障害分野で最も適切な説明はどれか。

  1. 石綿粉じんの吸入により肺に線維化が起こり、息切れなどが進行するじん肺である
  2. 喫煙だけが原因で発症し、石綿ばく露との関連は認められていない
  3. 胸膜の中皮細胞から発生する悪性腫瘍で、少量ばく露でも必ず発症する
  4. 石綿ばく露後、数日以内に高熱と発疹を起こす急性感染症である
正解と解説を見る

正解：石綿粉じんの吸入により肺に線維化が起こり、息切れなどが進行するじん肺である

石綿肺は石綿粉じんの長期吸入により肺が線維化するじん肺で、呼吸機能障害を生じます。

問2（石綿除去作業）

吹付け石綿を除去する作業場で負圧隔離を行う主な目的として、最も適切なものはどれか。

  1. 作業場内の温度を一定に保つため
  2. 石綿粉じんが隔離外へ漏えいすることを防ぐため
  3. 湿潤剤の使用量を減らすため
  4. 作業者の呼吸用保護具を省略するため
正解と解説を見る

正解：石綿粉じんが隔離外へ漏えいすることを防ぐため

負圧隔離は作業場内の気圧を外部より低くし、粉じんの外部流出を抑えるために行う。

問3（事前調査）

解体工事の事前調査で、書面調査と現地での目視調査を行っても建材の石綿含有の有無が判断できない場合の扱いとして適切なものはどれか。

  1. 施工者の経験で無含有と判断してよい
  2. 発注者が希望しなければ調査を省略できる
  3. 分析調査を行うか、石綿含有ありとみなして措置する
  4. レベル3建材だけを確認すれば足りる
正解と解説を見る

正解：分析調査を行うか、石綿含有ありとみなして措置する

不明な建材は分析で確認するか、石綿含有ありとみなして法令上の措置を講じる必要がある。

問4（石綿障害予防規則）

石綿等が使用されている建築物の解体作業を行う場合、作業計画について石綿障害予防規則上正しいものはどれか。

  1. 請負金額が一定額未満なら作業計画は不要である
  2. 作業開始後、実際の進み具合に合わせて作成すれば足りる
  3. 作業主任者を選任すれば作業計画の作成は省略できる
  4. あらかじめ作業計画を定め、その計画により作業を行う
正解と解説を見る

正解：あらかじめ作業計画を定め、その計画により作業を行う

石綿使用建築物等解体等作業では、事前に作業計画を定め、計画どおり作業する必要がある。

問5（石綿の健康障害）

石綿による中皮腫の発生部位として、最も代表的なものはどれか。

  1. 胸膜や腹膜などの中皮
  2. 胃粘膜と十二指腸粘膜
  3. 骨髄中の造血細胞
  4. 皮膚の表皮細胞
正解と解説を見る

正解：胸膜や腹膜などの中皮

中皮腫は胸膜や腹膜などの中皮細胞から発生する悪性腫瘍で、石綿ばく露との関連が強い疾患です。

問6（石綿除去作業）

負圧除じん装置に用いるHEPAフィルタの管理として、最も不適切なものはどれか。

  1. 交換時は粉じんの飛散を防ぐ手順で取り扱う
  2. 目詰まりや差圧の変化を確認し、必要に応じて交換する
  3. 装置の使用前に異常音や破損の有無を確認する
  4. 集じん効率を上げるため、破れた部分をテープで簡易補修して使う
正解と解説を見る

正解：集じん効率を上げるため、破れた部分をテープで簡易補修して使う

破損したHEPAフィルタは性能を確保できないため、補修使用せず適切に交換する必要がある。
