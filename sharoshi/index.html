問1（労働基準法・安全衛生法）

労働基準法において、法定労働時間は原則として１日何時間と定められているか。

  1. 7時間
  2. 8時間
  3. 9時間
  4. 6時間
正解と解説を見る

正解：8時間

法定労働時間は１日8時間、週40時間が原則とされています。

問2（労災保険・雇用保険）

労災保険の給付で、業務上の疾病と認定されるための要件として正しいものはどれか。

  1. 本人の故意による傷害であること
  2. 業務以外の原因で発生したこと
  3. 業務時間外の私用活動中であること
  4. 業務との関連性が明らかであること
正解と解説を見る

正解：業務との関連性が明らかであること

業務上の疾病として労災保険給付を受けるには、疾病と業務との因果関係が明確である必要があります。

問3（社会保険）

健康保険の被保険者が病気で療養を受けた場合、自己負担割合が原則として何割か？

  1. 3割
  2. 1割
  3. 5割
  4. 無料
正解と解説を見る

正解：3割

健康保険の自己負担は原則として医療費の3割です。一定の年齢や所得により異なります。

問4（一般常識）

労働基準法における法定労働時間は1日何時間と定められているか。

  1. 9時間
  2. 8時間
  3. 6時間
  4. 7時間
正解と解説を見る

正解：8時間

労働基準法では、1日の法定労働時間は8時間と定められています。

問5（労働基準法・安全衛生法）

安全衛生法に基づき、作業場における有害物質の濃度はどの基準に従って管理されるか。

  1. 労働者の自己判断
  2. 労働安全衛生規則の作業環境基準
  3. 賃金規定
  4. 労働契約書の記載
正解と解説を見る

正解：労働安全衛生規則の作業環境基準

安全衛生法では作業環境基準により、有害物質の濃度管理が義務付けられています。

問6（労災保険・雇用保険）

通勤災害に該当する事例として正しいものはどれか。

  1. 業務命令でない私用外出中に事故に遭った場合
  2. 勤務時間中に休憩室で転倒した場合
  3. 自宅から最寄り駅への通勤途中に転倒して負傷した場合
  4. 休日に趣味のスポーツで負傷した場合
正解と解説を見る

正解：自宅から最寄り駅への通勤途中に転倒して負傷した場合

通勤災害とは、通常の通勤経路における災害で発生した負傷等を指します。
