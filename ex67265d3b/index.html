日本語ワープロ検定試験 予想問題の例

問1（速度入力）

速度入力で「純字数」を数えるとき、一般的に入力した文章から除いて考えるものとして最も適切なものはどれですか。

  1. 句読点を含むすべての文字
  2. 正しく入力できた漢字だけ
  3. ひらがなで入力した文字
  4. 誤字・脱字・余分に入力した字
正解と解説を見る

正解：誤字・脱字・余分に入力した字

純字数は、入力した総字数から誤字や脱字などの誤りを差し引いた、正しく入力できた字数を表します。

問2（文書作成）

社外向けの案内文書を作成する際、一般的なビジネス文書の構成として最も適切なものはどれか。

  1. 時候のあいさつを省き、箇条書きだけで作成する
  2. 日付、宛名、発信者名、件名、前文、主文、末文、記書きの順に整える
  3. 発信者名を最初に置き、宛名を文末に配置する
  4. 件名、本文、結語、発信者名だけで作成する
正解と解説を見る

正解：日付、宛名、発信者名、件名、前文、主文、末文、記書きの順に整える

社外文書は日付、宛名、発信者、件名から始め、前文・主文・末文・記書きで整えるのが基本です。

問3（編集機能）

文書中の見出しだけを太字にして目立たせたい。本文の文字サイズや配置は変えずに行う操作として最も適切なものはどれか。

  1. 見出しの前にタブを複数回入力する
  2. 見出しの文字列を選択し、太字の文字装飾を設定する
  3. 見出しを含む段落全体に右揃えを設定する
  4. 文書全体の余白を広く設定する
正解と解説を見る

正解：見出しの文字列を選択し、太字の文字装飾を設定する

太字は選択した文字にだけ適用できる文字装飾で、本文の配置や余白には影響しません。

問4（校正処理）

案内文の体裁として、最も適切な記載はどれか。日時・場所・持ち物を箇条書きで示し、読みやすく整理する場合を考える。

  1. 日時だけを強調し、場所と持ち物は本文中に散らして書く。
  2. 「日時」「場所」「持ち物」の項目をそろえ、各内容を行ごとに記す。
  3. 日時場所持ち物を一文に続けて書く。
  4. 項目名を省略し、内容だけを行ごとに並べる。
正解と解説を見る

正解：「日時」「場所」「持ち物」の項目をそろえ、各内容を行ごとに記す。

案内文では項目名と内容をそろえて配置すると、必要な情報を短時間で確認しやすくなります。

問5（速度入力）

制限時間10分の速度入力で、開始直後に問題文の行を飛ばして入力してしまった。最も適切な対応はどれですか。

  1. 制限時間を止めて、試験監督に修正時間をもらう
  2. 気づいた時点で正しい位置に戻り、できるだけ早く修正する
  3. 行飛ばしは採点されないので、そのまま最後まで進める
  4. 飛ばした行を文末にまとめて入力すればよい
正解と解説を見る

正解：気づいた時点で正しい位置に戻り、できるだけ早く修正する

行飛ばしは大きな誤りにつながります。制限時間内で、気づいた時点から正しい順序に直すことが重要です。

問6（文書作成）

A4縦の文書で、1ページに入る文字数と行数を調整したい。最初に確認すべき設定項目として適切なものはどれか。

  1. ページ設定の用紙サイズ、余白、文字数と行数
  2. フォントの色と下線の種類
  3. 図形の塗りつぶしと影の設定
  4. 表のセル結合と罫線の太さ
正解と解説を見る

正解：ページ設定の用紙サイズ、余白、文字数と行数

ページ全体の収まりは、用紙サイズ、余白、文字数、行数などのページ設定で大きく変わります。
