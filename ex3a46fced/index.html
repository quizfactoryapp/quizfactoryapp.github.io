日本ビール検定 予想問題の例

問1（ビール史）

1516年にバイエルン公ヴィルヘルム4世が公布したビール純粋令で、当初ビールの原料として認められたものはどれか。

  1. 小麦・果実・水
  2. 米・麦芽・酵母
  3. 大麦・ホップ・水
  4. 大麦・香草・砂糖
正解と解説を見る

正解：大麦・ホップ・水

純粋令は当初、大麦、ホップ、水を原料と定めた。酵母は当時まだ微生物として認識されていなかった。

問2（醸造工程）

麦芽製造の工程で、発芽した大麦を乾燥・焙燥して発芽を止め、香味や色を整える工程はどれか。

  1. 糖化
  2. 焙燥
  3. 濾過
  4. 煮沸
正解と解説を見る

正解：焙燥

焙燥は発芽を止めるとともに、麦芽の色や香ばしさを決める重要な工程です。

問3（ビアスタイル）

チェコのプルゼニで誕生したピルスナーの特徴として、最も適切な組み合わせはどれですか。

  1. 濃色でロースト香が強く、上面発酵で造られる
  2. 淡色でホップの苦味があり、下面発酵で造られる
  3. 小麦麦芽主体で、バナナ様の香りが目立つ
  4. 酸味が強く、乳酸菌発酵を特徴とする
正解と解説を見る

正解：淡色でホップの苦味があり、下面発酵で造られる

ピルスナーは淡色ラガーの代表で、下面発酵によりすっきりした飲み口とホップの苦味を持ちます。

問4（ビール史）

ビール純粋令が定められた背景として、最も適切な説明はどれか。

  1. 修道院での醸造を全面的に禁止するため
  2. 輸出専用ビールの度数を統一するため
  3. ワイン産業から課税権を移すため
  4. 品質維持やパン用穀物の確保を図るため
正解と解説を見る

正解：品質維持やパン用穀物の確保を図るため

純粋令には品質安定のほか、小麦やライ麦をパン用に守る穀物政策としての意味もあった。

問5（醸造工程）

麦芽に含まれるデンプンを糖へ分解する酵素が主に働く、仕込工程中の操作として最も適切なものはどれか。

  1. 糖化
  2. 主発酵
  3. 麦汁煮沸
  4. 貯酒
正解と解説を見る

正解：糖化

糖化では麦芽由来の酵素がデンプンを麦芽糖などに分解し、酵母が利用できる糖を作ります。

問6（ビアスタイル）

IPAの名称に含まれる「India」が示す歴史的背景として、最も適切な説明はどれですか。

  1. インドの修道院で薬用酒として造られた
  2. 英国からインドへ輸送するビールとして発展した
  3. インドで初めて下面発酵ビールとして醸造された
  4. インド産小麦を必ず使用する規定に由来する
正解と解説を見る

正解：英国からインドへ輸送するビールとして発展した

IPAは英国からインドへの長距離輸送を意識し、ホップを多く使ったビールとして発展しました。
