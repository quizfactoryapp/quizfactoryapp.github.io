食品表示検定 予想問題の例

問1（食品表示法）

食品表示基準における一般用加工食品の名称表示として、最も適切な考え方はどれか。商品名ではなく、その食品の内容を一般に理解できる名称で表示する。

  1. 販売者が任意に決めたブランド名だけを名称として表示できる
  2. 消費者が食品の内容を理解できる一般的な名称を表示する
  3. 原材料のうち最も高価なものを必ず名称に用いる
  4. 包装の表面に写真があれば名称表示は省略できる
正解と解説を見る

正解：消費者が食品の内容を理解できる一般的な名称を表示する

名称は商品の愛称ではなく、食品の内容を的確に示す一般的名称で表示する必要がある。

問2（栄養成分表示）

一般用加工食品の栄養成分表示で、原則として必ず表示する5項目の組合せとして最も適切なものはどれか。

  1. 水分、灰分、たんぱく質、脂質、炭水化物
  2. 熱量、たんぱく質、脂質、炭水化物、食塩相当量
  3. 熱量、糖類、脂質、カルシウム、食塩相当量
  4. 熱量、たんぱく質、飽和脂肪酸、糖質、ナトリウム
正解と解説を見る

正解：熱量、たんぱく質、脂質、炭水化物、食塩相当量

義務表示の基本5項目は、熱量、たんぱく質、脂質、炭水化物、食塩相当量である。

問3（アレルゲン表示）

2026年4月1日改正後の食品表示基準で、加工食品に表示義務がある特定原材料の組合せとして正しいものはどれか。

  1. えび、かに、小麦、そば、卵、乳、落花生、大豆、ごま
  2. えび、かに、小麦、そば、卵、乳、落花生、くるみ、アーモンド
  3. えび、かに、小麦、そば、卵、乳、落花生、くるみ、カシューナッツ
  4. えび、かに、小麦、そば、卵、乳、落花生、いか、さけ
正解と解説を見る

正解：えび、かに、小麦、そば、卵、乳、落花生、くるみ、カシューナッツ

2026年4月からカシューナッツが特定原材料に追加され、表示義務品目は9品目となった。

問4（生鮮・加工食品表示）

国産の生鮮農産物を小売店で販売する場合、原産地表示として原則認められるものはどれか。

  1. 販売店の所在地を原産地として表示する
  2. 国産とだけ表示すれば、都道府県名等は不要である
  3. 製造所の所在地を都道府県名で表示する
  4. 収穫された都道府県名、市町村名その他一般に知られた地名を表示する
正解と解説を見る

正解：収穫された都道府県名、市町村名その他一般に知られた地名を表示する

国産農産物の原産地は、都道府県名等の一般に知られた地名で表示するのが原則です。

問5（食品表示法）

加工食品の原材料名表示で、原則として正しいものはどれか。使用した原材料は、添加物を除き、重量割合の高い順に表示する。

  1. 原材料は製造時の重量割合の高い順に表示する
  2. 原材料は使用量の少ない順に表示する
  3. 原材料は最終製品で目立つ順に表示する
  4. 原材料は五十音順に表示する
正解と解説を見る

正解：原材料は製造時の重量割合の高い順に表示する

原材料名は、原則として添加物以外の原材料を製造時の重量割合の高い順に表示する。

問6（栄養成分表示）

栄養成分表示の様式で、義務表示5項目を並べる場合の標準的な順序として正しいものはどれか。

  1. 熱量、炭水化物、脂質、たんぱく質、食塩相当量
  2. 熱量、たんぱく質、脂質、炭水化物、食塩相当量
  3. たんぱく質、脂質、炭水化物、熱量、食塩相当量
  4. 食塩相当量、熱量、たんぱく質、脂質、炭水化物
正解と解説を見る

正解：熱量、たんぱく質、脂質、炭水化物、食塩相当量

別記様式では、熱量から始まり、たんぱく質、脂質、炭水化物、食塩相当量の順に示す。
