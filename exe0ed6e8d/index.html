問1（二輪交通法規）

普通自動二輪車で車両通行帯のある片側二車線の道路を走るとき、追越しや右折などの必要がない場合の通行位置として最も適切なものはどれか。

  1. 二輪車は車線内なら左右どちらを通行してもよい
  2. 道路の左側端から数えて一番目の通行帯を通行する
  3. 大型車の後ろを避けるため常に右側通行帯を通行する
  4. 中央線に近い右側の通行帯を継続して通行する
正解と解説を見る

正解：道路の左側端から数えて一番目の通行帯を通行する

車両通行帯のある道路では原則として左側端から一番目の通行帯を通行し、追越しや右折など必要な場合だけ例外となります。

問2（二輪操作技能）

発進時にクラッチをつなぐ操作として適切なのはどれか。エンストを避け、急発進しないための基本操作を考える。

  1. 半クラッチで駆動力を確認しながら、少しずつつなぐ
  2. アクセルを戻したまま、クラッチだけで発進する
  3. 前ブレーキを強く握ったまま回転数を上げる
  4. 半クラッチを使わず、一気にレバーを離す
正解と解説を見る

正解：半クラッチで駆動力を確認しながら、少しずつつなぐ

半クラッチで駆動力を穏やかに伝えると、エンストや急発進を防ぎやすくなります。

問3（二輪危険回避）

乾いた直線路で急制動を行うとき、最も基本となる操作として適切なものはどれか。速度を落とす直前の姿勢とブレーキ操作に注意する。

  1. クラッチを早く切り、惰力だけで停止する
  2. 車体をまっすぐ保ち、前後ブレーキを適切に使う
  3. 後輪ブレーキだけを強くかけ、前輪は使わない
  4. 体を後ろへ大きく倒し、ハンドルを強く引く
正解と解説を見る

正解：車体をまっすぐ保ち、前後ブレーキを適切に使う

急制動では車体を直立に近い状態で安定させ、前後ブレーキを段階的に使うことが基本である。

問4（二輪交通法規）

道路標識や道路標示により二輪車の通行すべき通行帯が指定されている道路で、普通自動二輪車を運転する場合の正しい対応はどれか。

  1. 二輪車は標識の対象外なので任意の通行帯を選ぶ
  2. 混雑していなければ指定以外の通行帯を走れる
  3. 追越し目的なら指定通行帯を無視してよい
  4. 標識や標示で指定された通行区分に従って通行する
正解と解説を見る

正解：標識や標示で指定された通行区分に従って通行する

標識等で通行区分が指定されているときは、その指定に従う必要があります。二輪車も対象となる表示を確認します。

問5（二輪操作技能）

低速で直線を安定して走るときのニーグリップについて、最も適切な説明はどれか。

  1. ひざでタンクを軽く挟み、上体の余分な力を抜く
  2. ひざを強く締め続け、上体も硬くする
  3. 腕だけでハンドルを固定し、ひざは使わない
  4. 足を外側に開き、車体の傾きを足で止める
正解と解説を見る

正解：ひざでタンクを軽く挟み、上体の余分な力を抜く

ニーグリップは車体との一体感を高め、腕の力みを減らして低速でも安定しやすくします。

問6（二輪危険回避）

急制動で前輪がロックしそうになったと感じた場合の対応として、最も適切なものはどれか。転倒を避けるための操作を選ぶ。

  1. アクセルを開けて前輪の荷重を抜く
  2. ハンドルを左右に切って進路を保つ
  3. さらに強く前輪ブレーキを握り続ける
  4. 前輪ブレーキを少しゆるめ、すぐ握り直す
正解と解説を見る

正解：前輪ブレーキを少しゆるめ、すぐ握り直す

前輪ロックは転倒につながりやすい。いったん制動力をゆるめ、タイヤの回転を回復させる。
