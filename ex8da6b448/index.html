キャリアコンサルタント試験 予想問題の例

問1（キャリア理論）

スーパーのキャリア発達理論における「ライフ・キャリア・レインボー」が示す考え方として最も適切なものはどれか。

  1. 偶然の出来事を計画的に避けることで安定した職業生活が得られる
  2. 職業選択は主に無意識の欲求によって一度だけ決定される
  3. 職業満足は6つの興味領域の一致度だけで説明される
  4. 人は生涯を通じて複数の役割を担い、それらが相互に影響する
正解と解説を見る

正解：人は生涯を通じて複数の役割を担い、それらが相互に影響する

ライフ・キャリア・レインボーは、人生段階と生活上の役割の重なりからキャリアを捉える考え方である。

問2（カウンセリング技能）

初回面談で来談者が沈黙した。傾聴の基本姿勢として最も適切な対応はどれか。

  1. 沈黙の意味を決めつけず、待つ姿勢を保つ
  2. 面談が進まないため、話題を職務経歴に戻す
  3. 沈黙を避けるため、すぐに助言を始める
  4. 原因を特定するため、矢継ぎ早に質問する
正解と解説を見る

正解：沈黙の意味を決めつけず、待つ姿勢を保つ

沈黙も来談者の内的過程の表れであり、急がず受容的に待つことが傾聴に合う。

問3（労働市場・制度）

職業能力開発促進法における「職業能力」として最も適切なものはどれか。労働者が職業生活を営む上で必要となる能力の捉え方を問う。

  1. 企業内でのみ通用する作業手順を暗記する能力に限定される。
  2. 学校教育で修得した一般教養に限られ、実務経験は含まれない。
  3. 労働者が職業に必要な技能およびこれに関する知識を身につけ、発揮する能力をいう。
  4. 国家資格を取得した者だけに認められる法的な資格能力をいう。
正解と解説を見る

正解：労働者が職業に必要な技能およびこれに関する知識を身につけ、発揮する能力をいう。

職業能力は、職業に必要な技能と知識を含む広い概念であり、資格や企業内手順に限定されない。

問4（相談過程）

自己理解支援において、相談者が語った職務経験から価値観を明確化する際の支援として、最も適切なものはどれか。

  1. 相談者の希望に関係なく、求人倍率が高い職種を優先して勧める。
  2. 客観性を保つため、感情や意味づけには触れず職歴だけを確認する。
  3. 成功体験や葛藤場面を振り返り、何を大切にして行動したかを一緒に整理する。
  4. 価値観は変化しないため、初回面談で決めた内容を固定する。
正解と解説を見る

正解：成功体験や葛藤場面を振り返り、何を大切にして行動したかを一緒に整理する。

自己理解では経験の意味づけを通じて興味、価値観、強みを言語化する支援が重要である。

問5（キャリア理論）

ホランド理論において、RIASECの「S」に該当するタイプの特徴として最も適切なものはどれか。

  1. 数理的・観察的に物事を探究する活動を好む
  2. 人を援助し、教え、支える対人的活動を好む
  3. 機械や道具を用いた具体的・実践的活動を好む
  4. 秩序立った事務処理や定型的作業を好む
正解と解説を見る

正解：人を援助し、教え、支える対人的活動を好む

SはSocialの略で、教育、援助、相談など、人に関わり支援する活動への興味を表す。

問6（カウンセリング技能）

来談者が「転職したいが不安です」と語った。感情の反映として最も適切な応答はどれか。

  1. 転職市場は厳しいので資格取得が必要です
  2. なぜ不安なのか、三つ理由を挙げてください
  3. 不安なら転職はやめた方がよいでしょう
  4. 不安を感じながらも、転職を考えているのですね
正解と解説を見る

正解：不安を感じながらも、転職を考えているのですね

来談者の感情と内容を評価せずに返すことで、自己理解を促進する応答である。
