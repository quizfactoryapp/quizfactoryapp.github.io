マンション管理士 予想問題の例

問1（区分所有法）

区分所有法における共用部分とは、どの部分を指すか。次のうち最も適切なのはどれか。

  1. 建物の外壁や階段など、区分所有者全員が共同で使用する部分
  2. 個別の専用駐車場
  3. 各区分所有者の専用庭
  4. 専有部分の内部設備
正解と解説を見る

正解：建物の外壁や階段など、区分所有者全員が共同で使用する部分

共用部分は区分所有者全員が共同使用する建物の部分で、外壁や階段、エレベーターなどが該当します。

問2（標準管理規約）

標準管理規約（単棟型）において、共用部分の修繕費用は通常どのように負担されますか？

  1. 市区町村が負担する。
  2. 管理会社が負担する。
  3. 専有部分の所有者が全額負担する。
  4. 管理組合が全体で按分して負担する。
正解と解説を見る

正解：管理組合が全体で按分して負担する。

共用部分の修繕費用は管理組合の費用として、専有部分の割合に応じて負担します。

問3（適正化法）

マンション管理適正化法に基づく管理適正化計画の主な目的は何か？

  1. 入居者の居住環境の保証
  2. 建物の建築基準の強化
  3. 管理組合の管理運営の改善
  4. 管理会社の選定基準の統一
正解と解説を見る

正解：管理組合の管理運営の改善

管理適正化計画は管理組合の管理運営の改善を目的としているため、適切な管理の推進に役立つ。

問4（建築・その他）

マンションの共用部分の建築設備で、給水管の材質として最も適しているものはどれか。

  1. 銅管
  2. ステンレス鋼管
  3. 鉄管（亜鉛メッキ）
  4. 塩ビ管
正解と解説を見る

正解：ステンレス鋼管

給水管は耐食性が重要で、ステンレス鋼管が耐久性と衛生面で適しているため使用されることが多いです。

問5（区分所有法）

区分所有者が共用部分の変更を行う場合、原則として必要な決議は何か。

  1. 管理組合理事会の承認
  2. 管理者の単独決定
  3. 集会の特別決議
  4. 集会の普通決議
正解と解説を見る

正解：集会の特別決議

共用部分の変更は特別決議が必要で、出席区分所有者及び議決権の4分の3以上の賛成が求められます。

問6（標準管理規約）

団地型標準管理規約における「団地共用部分」とは何を指しますか？

  1. 各棟の専有部分。
  2. 複数棟に共通する管理用通路や公園等の区域。
  3. 各棟の屋上のみ。
  4. 各戸の玄関ポーチ。
正解と解説を見る

正解：複数棟に共通する管理用通路や公園等の区域。

団地共用部分は複数棟にまたがる共有区域や施設を指し、管理規約で明確に定められています。
