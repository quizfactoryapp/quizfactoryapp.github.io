毒物劇物取扱者試験 予想問題の例

問1（毒物劇物法規）

毒物及び劇物取締法の目的として、最も適切なものはどれか。対象物の指定趣旨と規制の観点から選べ。

  1. 危険物の火災予防だけを全国一律に規制すること
  2. 毒物及び劇物について保健衛生上の見地から必要な取締を行うこと
  3. すべての化学物質を医薬品として管理すること
  4. 産業振興のため毒物劇物の流通量を増やすこと
正解と解説を見る

正解：毒物及び劇物について保健衛生上の見地から必要な取締を行うこと

法第1条は、毒物及び劇物について保健衛生上必要な取締を行うことを目的とする。

問2（基礎化学）

酸性水溶液中で過マンガン酸イオン MnO4- が Mn2+ に還元されるとき、マンガン原子1個が受け取る電子数はいくつか。

  1. 7個
  2. 2個
  3. 3個
  4. 5個
正解と解説を見る

正解：5個

MnO4-中のMnは酸化数+7、Mn2+では+2である。5下がるため電子を5個受け取る。

問3（性質・取扱い）

シアン化ナトリウムを含む廃液の取扱いとして最も適切なものはどれか。酸性廃液との混合や密閉不十分な保管時の危険性を踏まえて選べ。

  1. 希釈すれば酸性廃液と混合しても安全である
  2. 金属容器なら種類を問わず長期保管できる
  3. 加熱して水分を除けば危険性は小さくなる
  4. 酸との接触を避け、アルカリ性を保って保管する
正解と解説を見る

正解：酸との接触を避け、アルカリ性を保って保管する

シアン化物は酸と接触すると猛毒のシアン化水素を発生するため、酸性化を避ける管理が重要である。

問4（毒物劇物法規）

毒物又は劇物を販売し、授与し、又は販売・授与の目的で店舗に貯蔵、陳列する場合に必要な登録はどれか。

  1. 危険物取扱者免状の交付
  2. 毒物又は劇物の販売業の登録
  3. 特定毒物研究者の許可
  4. 毒物劇物業務上取扱者の届出
正解と解説を見る

正解：毒物又は劇物の販売業の登録

販売、授与、販売目的の貯蔵・運搬・陳列には、毒物又は劇物の販売業登録が必要である。

問5（基礎化学）

0.100 mol/Lの塩酸25.0 mLを過不足なく中和するのに必要な0.200 mol/L水酸化ナトリウム水溶液は何mLか。

  1. 12.5 mL
  2. 6.25 mL
  3. 25.0 mL
  4. 50.0 mL
正解と解説を見る

正解：12.5 mL

塩酸の物質量は0.100×0.0250=0.00250 mol。NaOHも同量必要なので12.5 mL。

問6（性質・取扱い）

濃硫酸を水で希釈する作業について、発熱や飛散を防ぐための操作として正しいものはどれか。実験室や工場での基本操作として選べ。

  1. 発熱を利用するため、加温しながら水を加える
  2. 水を十分に冷やし、硫酸を少量ずつ水へ加える
  3. 撹拌を避け、容器内で自然に混ざるのを待つ
  4. 硫酸に水を一気に注ぎ、直ちにふたをする
正解と解説を見る

正解：水を十分に冷やし、硫酸を少量ずつ水へ加える

濃硫酸の希釈は大きく発熱するため、冷却しながら硫酸を水に少量ずつ加えて飛散を防ぐ。
