問1（社会の理解）

介護保険制度において、40歳以上の者が保険料を支払う目的は何ですか？

  1. 介護サービス利用の自己負担をなくすため
  2. 障害者福祉サービスを利用するため
  3. 介護サービスの財源を確保するため
  4. 医療費を全額補助するため
正解と解説を見る

正解：介護サービスの財源を確保するため

介護保険制度は40歳以上が保険料を納め、その財源で介護サービスを提供しています。

問2（介護の基本）

介護の基本原則の一つである「尊厳の保持」とは、どのような意味を持つか？

  1. 利用者の意思や感情を尊重し、人間としての価値を守ること
  2. 利用者の希望を無視して安全を最優先すること
  3. 経済的効率を最優先に考えること
  4. 介護者がすべての判断を行うこと
正解と解説を見る

正解：利用者の意思や感情を尊重し、人間としての価値を守ること

尊厳の保持は利用者の意思や感情を尊重し、人間としての価値を守ることを意味します。

問3（生活支援技術）

移動介助において、利用者が自立して歩行できる場合に最も適切な介助方法はどれか。

  1. 車椅子に座らせて移動させる
  2. 利用者の前に立ち、手を引いて歩かせる
  3. 利用者の後ろから両脇を支える
  4. 利用者の横で片腕を支え、歩行を補助する
正解と解説を見る

正解：利用者の横で片腕を支え、歩行を補助する

利用者の横で片腕を支えることで、歩行の補助と転倒防止が適切に行えます。

問4（医療的ケア）

喀痰吸引を行う際、感染予防のために最も重要な手順はどれか。

  1. 吸引後すぐに手を洗う
  2. 吸引カテーテルを共有して使用する
  3. 使い捨て手袋を着用する
  4. マスクを外して行う
正解と解説を見る

正解：使い捨て手袋を着用する

喀痰吸引時は使い捨て手袋を必ず着用し、交差感染を防止することが重要です。

問5（社会の理解）

地域包括支援センターに関する説明として、正しいものはどれか。

  1. 医療保険者が設置し、入院中の高齢者の退院許可を判断する機関である。
  2. 市町村が設置し、高齢者の総合相談、権利擁護、介護予防ケアマネジメントなどを担う機関である。
  3. 都道府県が設置し、要介護認定の一次判定を行う機関である。
  4. 社会福祉協議会が必ず設置し、生活保護の開始決定を行う機関である。
正解と解説を見る

正解：市町村が設置し、高齢者の総合相談、権利擁護、介護予防ケアマネジメントなどを担う機関である。

地域包括支援センターは市町村が設置主体となり、高齢者の総合相談支援、権利擁護、介護予防支援等を行う。

問6（介護の基本）

ICF（国際生活機能分類）における「活動」とは何を指すか？

  1. 個人が行う具体的な行動やタスク
  2. 社会的環境との相互作用
  3. 経済的背景や教育水準
  4. 身体構造の異常や欠損
正解と解説を見る

正解：個人が行う具体的な行動やタスク

ICFの「活動」は、個人が行う具体的な行動やタスクを指します。
