問1（商業簿記）

売買目的有価証券として取得した株式の期末時価が帳簿価額を下回った。決算整理仕訳として正しいものはどれか。

  1. 有価証券利息を借方、売買目的有価証券を貸方に記入する
  2. その他有価証券評価差額金を借方、投資有価証券を貸方に記入する
  3. 有価証券評価損を借方、売買目的有価証券を貸方に記入する
  4. 仕訳は不要で、翌期に売却した時点で損益を認識する
正解と解説を見る

正解：有価証券評価損を借方、売買目的有価証券を貸方に記入する

売買目的有価証券は期末に時価評価し、評価差額を当期の損益として処理する。

問2（工業簿記）

材料Aの月初有高は100kg・単価120円、当月仕入は400kg・単価150円、月末実地棚卸は80kgであった。先入先出法による材料消費額はいくらか。

  1. 72,000円
  2. 57,600円
  3. 50,400円
  4. 60,000円
正解と解説を見る

正解：60,000円

先入先出法では月末80kgは当月仕入分とみなし、残高は80kg×150円。消費額は72,000円－12,000円＝60,000円。

問3（原価計算）

個別原価計算において、製造指図書ごとに直接材料費・直接労務費・製造間接費を集計する主な目的として最も適切なものはどれか。

  1. 期間全体の平均単価を算定するため
  2. 完成品と仕掛品を常に同額にするため
  3. 各製品または注文別の製造原価を把握するため
  4. 部門別の販売費を配賦するため
正解と解説を見る

正解：各製品または注文別の製造原価を把握するため

個別原価計算は、注文や製造指図書ごとに原価を集計し、個別の製造原価を計算する方法である。

問4（財務諸表作成）

決算整理後、売上高3,200,000円、売上原価2,050,000円、販売費及び一般管理費780,000円、営業外収益40,000円、営業外費用65,000円である。当期純利益はいくらか。

  1. 345,000円
  2. 435,000円
  3. 370,000円
  4. 410,000円
正解と解説を見る

正解：345,000円

売上総利益1,150,000円から販管費を引き、営業外損益を加減して345,000円となる。

問5（商業簿記）

その他有価証券の期末時価が取得原価を上回った場合、全部純資産直入法で処理するときの貸方科目はどれか。

  1. 繰延税金負債
  2. 投資有価証券売却益
  3. その他有価証券評価差額金
  4. 有価証券評価益
正解と解説を見る

正解：その他有価証券評価差額金

その他有価証券の評価差額は損益にせず、純資産のその他有価証券評価差額金で処理する。

問6（工業簿記）

材料の予定消費単価を200円、実際消費数量を300kg、実際購入単価を210円とする。材料消費価格差異として正しいものはどれか。

  1. 6,000円不利差異
  2. 3,000円有利差異
  3. 6,000円有利差異
  4. 3,000円不利差異
正解と解説を見る

正解：3,000円不利差異

価格差異は（予定単価200円－実際単価210円）×実際消費量300kg＝3,000円の不利差異である。
