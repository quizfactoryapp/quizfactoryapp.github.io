FP2級 予想問題の例

問1（ライフプランニング）

一定の利率で運用しながら、今後10年間にわたり毎年末に50万円ずつ取り崩して受け取るため、現時点で必要な元本を求める際に用いる係数はどれか。

  1. 終価係数
  2. 資本回収係数
  3. 年金現価係数
  4. 減債基金係数
正解と解説を見る

正解：年金現価係数

年金現価係数は、一定期間に毎年一定額を受け取るために必要な現在の元本を求める係数である。

問2（リスク管理）

地震保険に関する次の記述のうち、最も適切なものはどれか。なお、居住用建物と家財を対象とする一般的な契約を前提とする。

  1. 地震による津波で建物が流失した場合、地震保険ではなく火災保険から保険金が支払われる。
  2. 地震保険は、火災保険に付帯せず単独で契約することができる。
  3. 地震保険の保険金額の限度額は、建物が1億円、家財が2,000万円である。
  4. 地震保険の保険金額は、原則として付帯する火災保険の保険金額の30％から50％の範囲内で設定する。
正解と解説を見る

正解：地震保険の保険金額は、原則として付帯する火災保険の保険金額の30％から50％の範囲内で設定する。

地震保険は火災保険に付帯して契約し、保険金額は火災保険の30～50％、限度額は建物5,000万円・家財1,000万円である。

問3（金融資産運用）

経済指標としてのGDP成長率が示す内容について正しいものはどれか。

  1. 企業の収益力を示す指標である。
  2. 失業率の変動を示す指標である。
  3. 国内で生産された財・サービスの総額の成長率を示す。
  4. 物価の上昇率を表す指標である。
正解と解説を見る

正解：国内で生産された財・サービスの総額の成長率を示す。

GDP成長率は一定期間内の国内総生産（財・サービスの総額）の増減を示し、経済の拡大や縮小を判断する指標です。

問4（タックスプランニング）

所得税の総合課税における損益通算の対象となる所得はどれか。

  1. 譲渡所得と退職所得
  2. 一時所得と山林所得
  3. 事業所得と不動産所得
  4. 給与所得と不動産所得
正解と解説を見る

正解：事業所得と不動産所得

損益通算は、事業所得、不動産所得、山林所得、譲渡所得などで認められますが、退職所得や一時所得は損益通算の対象外です。

問5（ライフプランニング）

老後資金として10年後に300万円を用意したい。年利率2％で複利運用できる場合、現在一括で預け入れるべき金額を求める際に用いる係数として、最も適切なものはどれか。

  1. 現価係数
  2. 終価係数
  3. 年金終価係数
  4. 資本回収係数
正解と解説を見る

正解：現価係数

将来必要な金額から現在必要な元本を逆算する場合は、複利で割り戻す現価係数を用いる。

問6（リスク管理）

地震保険に関する次の記述のうち、最も適切なものはどれか。

  1. 地震保険の保険金額は、主契約である火災保険の保険金額の30％から50％の範囲内で設定する。
  2. 地震保険は、火災保険に付帯せず単独で契約することができる。
  3. 地震保険では、居住用建物の保険金額に上限はなく、火災保険と同額まで設定できる。
  4. 地震による津波で家財が損害を受けた場合、地震保険では補償の対象とならない。
正解と解説を見る

正解：地震保険の保険金額は、主契約である火災保険の保険金額の30％から50％の範囲内で設定する。

地震保険は火災保険に付帯して契約し、保険金額は火災保険金額の30％～50％の範囲で設定する。
