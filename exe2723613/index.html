問1（全類危険物総論）

消防法上の危険物の類別で、空気中で自然発火するおそれや水と反応して可燃性ガスを発生する性状を持つ物質が該当するのはどれか。

  1. 第6類 酸化性液体
  2. 第3類 自然発火性物質及び禁水性物質
  3. 第2類 可燃性固体
  4. 第5類 自己反応性物質
正解と解説を見る

正解：第3類 自然発火性物質及び禁水性物質

自然発火性・禁水性の性状を持つ物質は第3類である。空気や水との接触で発火・可燃性ガス発生の危険があり、特に水分管理が重要となる。

問2（物理・化学）

標準状態でメタン1 m3を完全燃焼させるとき、反応式CH4+2O2→CO2+2H2Oを用いた理論空気量として最も適切な値を選べ。空気中酸素は21vol%とする。

  1. 19.0 m3
  2. 14.3 m3
  3. 4.76 m3
  4. 9.52 m3
正解と解説を見る

正解：9.52 m3

CH4 1 molにO2は2 mol必要。空気中O2を21%とすると必要空気は2/0.21=9.52で、体積比でも同値となる。

問3（法令・保安）

指定数量以上の危険物を製造所等以外で一時的に扱いたい。消防法上、所轄消防長または消防署長の承認で認められる仮貯蔵・仮取扱いの最長期間として正しいものはどれか。

  1. 10日以内
  2. 3日以内
  3. 期間制限はない
  4. 30日以内
正解と解説を見る

正解：10日以内

消防法第10条ただし書では、承認を受けた場合でも指定数量以上の危険物の仮貯蔵・仮取扱いは10日以内に限ると定められている。

問4（全類危険物総論）

同一場所で異なる危険物を同時に貯蔵するとき、指定数量以上かどうかを判断する方法として消防法令上正しいものはどれか。

  1. 最も数量が多い1品目だけで判定する
  2. 各危険物の数量を指定数量で割った値を合計し、1以上なら指定数量以上と判定する
  3. 危険等級IIIの危険物だけを合算対象にする
  4. 合計質量のみで判定し、類別ごとの指定数量は考慮しない
正解と解説を見る

正解：各危険物の数量を指定数量で割った値を合計し、1以上なら指定数量以上と判定する

混在貯蔵では数量の単純合計ではなく、各危険物の数量を指定数量で除した比を合算して判定する。合計が1以上であれば指定数量以上として扱う。

問5（物理・化学）

炭化水素蒸気の燃焼で、初期温度と圧力が同じ条件下において過剰空気率を大きくした場合の断熱火炎温度の変化として正しいものを選べ。

  1. 過剰空気率を上げると上昇する
  2. 過剰空気率を上げると低下する
  3. 過剰空気率に依存せず一定である
  4. 過剰空気率1未満で必ず完全燃焼する
正解と解説を見る

正解：過剰空気率を上げると低下する

過剰空気が増えると、反応熱が窒素や余剰酸素の加熱に多く使われるため、単位燃料あたりの断熱火炎温度は低下する。

問6（法令・保安）

消防本部と消防署を置く市町村の区域内に、移送取扱所を除く製造所等を新設する場合、消防法第11条に基づく設置許可権者として正しいものはどれか。

  1. 当該市町村長
  2. 都道府県知事
  3. 消防署長
  4. 総務大臣
正解と解説を見る

正解：当該市町村長

消防法第11条第1項では、消防本部等所在市町村内の移送取扱所以外の製造所等は、当該市町村長の許可を受ける区分となる。
