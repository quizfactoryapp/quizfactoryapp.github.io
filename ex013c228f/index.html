有機溶剤作業主任者技能講習 予想問題の例

問1（有機溶剤の有害性）

有機溶剤ばく露による急性影響として、中枢神経抑制作用が強く現れた場合に最も起こりやすい症状はどれか。

  1. 骨折しやすくなるだけ
  2. 視力が恒久的に向上する
  3. めまい、眠気、判断力低下
  4. 皮膚の黒色化のみ
正解と解説を見る

正解：めまい、眠気、判断力低下

有機溶剤は急性ばく露で中枢神経を抑制し、めまい、眠気、酩酊様症状、判断力低下を起こす。

問2（作業環境管理）

局所排気装置のフード開口面で制御風速が不足している場合に、最も直接的に生じやすい問題はどれか。

  1. 有機溶剤の管理濃度が自動的に低く設定される。
  2. 有機溶剤蒸気を十分に捕捉できず、作業者のばく露が増える。
  3. 作業場内の酸素濃度が直ちに過剰となる。
  4. 排気ダクト内の静圧が必ず大気圧と同じになる。
正解と解説を見る

正解：有機溶剤蒸気を十分に捕捉できず、作業者のばく露が増える。

制御風速は発散源から有害蒸気を捕捉するための風速で、不足すると外部へ漏れやすくなる。

問3（保護具管理）

有機ガス用防毒マスクの吸収缶を選定するとき、最も重視すべき事項として適切なものはどれか。

  1. 対象有機溶剤に適合した種類であることを確認する
  2. 価格が最も安いものを常に選ぶ
  3. 作業場の照明の明るさだけで決める
  4. 吸収缶の色が作業服と合うものを選ぶ
正解と解説を見る

正解：対象有機溶剤に適合した種類であることを確認する

吸収缶は対象物質に適合しなければ十分な防護性能を発揮できないため、種類確認が必要である。

問4（有機溶剤中毒予防規則）

有機溶剤中毒予防規則でいう「有機溶剤含有物」として扱われる混合物の要件として、正しいものはどれか。

  1. 有機溶剤を容量の10％以上含む混合物
  2. 有機溶剤を少量でも含むすべての混合物
  3. 有機溶剤を重量の1％以上含む混合物
  4. 有機溶剤を重量の5％を超えて含む混合物
正解と解説を見る

正解：有機溶剤を重量の5％を超えて含む混合物

有機溶剤含有物は、有機溶剤を混合物の重量の5％を超えて含有するものをいう。

問5（有機溶剤の有害性）

有機溶剤が皮膚から体内へ吸収される危険について、作業管理上の説明として最も適切なものはどれか。

  1. 皮膚に付着しても蒸発すれば吸収は全くない
  2. 呼吸用保護具を着ければ保護手袋は不要である
  3. 皮膚吸収を防ぐため、不浸透性手袋や保護衣を用いる
  4. 水で薄めた溶剤は皮膚から吸収されない
正解と解説を見る

正解：皮膚吸収を防ぐため、不浸透性手袋や保護衣を用いる

一部の有機溶剤は皮膚から吸収されるため、適切な材質の手袋や保護衣で接触を防ぐ必要がある。

問6（作業環境管理）

外付け式局所排気装置のフードを有機溶剤の発散源から離しすぎた場合の説明として、最も適切なものはどれか。

  1. 排風機の電源を切っても捕捉性能は維持される。
  2. 発散源での吸引効果が低下し、蒸気が作業場へ拡散しやすくなる。
  3. 発散源周囲の捕捉効果は距離に関係なく一定である。
  4. 作業環境測定を実施しなくてもよくなる。
正解と解説を見る

正解：発散源での吸引効果が低下し、蒸気が作業場へ拡散しやすくなる。

外付け式フードは発散源との距離が大きいほど捕捉力が弱まり、必要な制御風速を得にくい。
