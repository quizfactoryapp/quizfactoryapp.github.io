日本漢字能力検定 予想問題の例

問1（漢字の読み）

次の漢字の読みとして正しいものを1つ選びなさい。漢字は「凧」である。

  1. たこ
  2. かい
  3. いか
  4. とり
正解と解説を見る

正解：たこ

「凧」は訓読みで「たこ」と読み、空に揚げる玩具を指します。

問2（漢字の書き取り）

次の文のカタカナ部分を漢字で書くとき、正しいものを1つ選びなさい。会議で新しい企画をテイアンした。

  1. 提案
  2. 低案
  3. 題案
  4. 定案
正解と解説を見る

正解：提案

「テイアンする」は考えや計画を出すことなので「提案」と書く。「提」は差し出す意味を持つ漢字である。

問3（熟語・語法）

「温故知新」の意味として最も適切なものはどれか？

  1. 過去のことを学んで新しい知識を得ること
  2. 新しいことを試して成功を得ること
  3. 古い物を捨てて新しい物を作ること
  4. 温かい心で人に接すること
正解と解説を見る

正解：過去のことを学んで新しい知識を得ること

「温故知新」とは、昔のことをよく学び、それをもとに新しい知識や考えを得ることを意味します。

問4（漢字の読み）

漢字「匂い」の読みとして適切なものを選びなさい。音読みや訓読み、熟字訓も含む。

  1. におい
  2. しゅう
  3. こう
  4. こうばい
正解と解説を見る

正解：におい

「匂い」は訓読みで「におい」と読み、香りや臭いを意味します。

問5（漢字の書き取り）

「明日、友達と映画を○○する予定だ。」に入る正しい送り仮名を選びなさい。

  1. 見る
  2. 看る
  3. 視る
  4. 観る
正解と解説を見る

正解：観る

映画や芝居などを楽しむ場合は「観る」が適切。単なる視覚的な「見る」と区別するため使う。

問6（熟語・語法）

「以心伝心」の正しい読みと意味の組み合わせはどれか？

  1. いしんでんしん：心を失うこと
  2. いしんつうしん：心を伝える手紙
  3. いしんでんしん：心が通じ合うこと
  4. いしんつうしん：心が離れること
正解と解説を見る

正解：いしんでんしん：心が通じ合うこと

「以心伝心」は「いしんでんしん」と読み、言葉にしなくても心が通じ合うことを指します。
