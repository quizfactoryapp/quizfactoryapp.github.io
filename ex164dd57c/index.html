問1（労働法規）

労働基準法上の法定労働時間に関する説明として、原則として正しいものはどれか。休憩時間を除いて判断する。

  1. 1日7時間、1週35時間を超えてはならない
  2. 1日8時間、1週40時間を超えてはならない
  3. 1日9時間、1週45時間を超えてはならない
  4. 1日10時間、1週48時間を超えてはならない
正解と解説を見る

正解：1日8時間、1週40時間を超えてはならない

労働基準法の原則では、休憩時間を除き1日8時間、1週40時間が法定労働時間の上限です。

問2（社会保険）

標準報酬月額を決定する定時決定について、原則として算定の対象となる報酬支払基礎日数と対象月の組合せとして正しいものはどれか。

  1. 1月から3月の各月で、支払基礎日数が20日以上の月
  2. 7月から9月の各月で、支払基礎日数が11日以上の月のみ
  3. 4月から6月の各月で、支払基礎日数が17日以上の月
  4. 賞与支給月を含む任意の3か月で、支払基礎日数を問わない
正解と解説を見る

正解：4月から6月の各月で、支払基礎日数が17日以上の月

定時決定は原則4月から6月の報酬を基にし、各月の支払基礎日数が17日以上かを確認します。

問3（源泉所得税）

給与所得者が「給与所得者の扶養控除等申告書」を提出した場合、毎月の給与から控除する源泉所得税の税額表の適用区分として正しいものはどれか。

  1. 日額表のみを適用する
  2. 丙欄を適用する
  3. 甲欄を適用する
  4. 乙欄を適用する
正解と解説を見る

正解：甲欄を適用する

扶養控除等申告書の提出がある主たる給与は、月額表の甲欄を用いて源泉徴収税額を求める。

問4（給与計算）

月給制の従業員について、欠勤が1日あったため欠勤控除を行う。基本給を所定労働日数で割って控除額を求める考え方として最も適切なものはどれか。

  1. 就業規則等に定めた計算方法に従い、不就労分を控除する
  2. 欠勤日は残業時間から差し引いて処理する
  3. 欠勤控除は必ず時間単価ではなく日額で行う
  4. 月給は固定額なので欠勤控除は一切できない
正解と解説を見る

正解：就業規則等に定めた計算方法に従い、不就労分を控除する

月給者の欠勤控除は、賃金規程や就業規則の定めに基づき、不就労分を合理的に計算して控除します。

問5（労働法規）

使用者が労働者に法定労働時間を超える時間外労働をさせる場合、原則として必要となる手続はどれか。

  1. 時間外・休日労働に関する労使協定を締結し届け出る
  2. 給与計算時に割増賃金を支払えば協定は不要である
  3. 労働者本人の口頭同意があれば届出は不要である
  4. 就業規則に残業命令権を記載するだけで足りる
正解と解説を見る

正解：時間外・休日労働に関する労使協定を締結し届け出る

法定時間外労働には、いわゆる36協定の締結と労働基準監督署長への届出が必要です。

問6（社会保険）

健康保険料および厚生年金保険料の給与からの控除について、給与計算実務上の原則として正しいものはどれか。

  1. 前月分保険料を当月支給給与から控除する取扱いが一般的である
  2. 賞与からは健康保険料だけを控除する
  3. 資格取得月の保険料は日割りで控除する
  4. 当月分保険料は必ず当月支給給与から控除する
正解と解説を見る

正解：前月分保険料を当月支給給与から控除する取扱いが一般的である

社会保険料は月単位で発生し、給与計算では前月分を当月支給給与から控除する処理が一般的です。
