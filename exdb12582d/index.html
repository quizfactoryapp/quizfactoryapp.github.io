秘書技能検定 3級 予想問題の例

問1（秘書の基本職務）

上司が外出中に取引先から急ぎの確認電話が入った。秘書として最も適切な初期対応はどれか。

  1. 用件、期限、相手の連絡先を確認し、必要に応じて上司へ連絡する。
  2. 自分の判断で回答し、上司には戻ってからまとめて伝える。
  3. 上司の携帯番号を先方に伝え、直接連絡してもらう。
  4. 上司が戻るまで何もせず、再度電話をもらうよう伝える。
正解と解説を見る

正解：用件、期限、相手の連絡先を確認し、必要に応じて上司へ連絡する。

急ぎの用件は内容と期限を正確に把握し、必要性を判断して速やかに上司へ報告する。

問2（接遇マナー）

朝、廊下で上司とすれ違った。こちらから挨拶をする場合、秘書として最も適切な態度はどれか。

  1. 相手が声を掛けるまで待ち、会釈だけで済ませる。
  2. 立ち止まり、明るく聞こえる声で「おはようございます」と挨拶する。
  3. 親しみを込めて手を振りながら「おはよう」と言う。
  4. 忙しそうなら目を合わせず、小声で「どうも」と言う。
正解と解説を見る

正解：立ち止まり、明るく聞こえる声で「おはようございます」と挨拶する。

職場の挨拶は自分から、相手に届く声と丁寧な言葉で行う。上司にはくだけた表現を避ける。

問3（事務処理）

上司の外出予定を手帳に記入する際、訪問先名と時刻のほかに、まず確認しておくべき事項として最も適切なものはどれか。

  1. 訪問先の社長の趣味や家族構成
  2. 予定を入れた担当者の私用の予定
  3. 同行者、場所、移動時間など予定に必要な情報
  4. 当日の天気予報だけを詳しく調べること
正解と解説を見る

正解：同行者、場所、移動時間など予定に必要な情報

予定管理では、時刻だけでなく場所、相手、移動時間、同行者など実務に必要な情報を確認する。

問4（文書知識）

社内文書の作成で、件名の書き方として最も適切なものはどれか。読み手が内容をすぐ判断できるようにする。

  1. 本文の最後にだけ件名を書く
  2. 差出人名を件名として使う
  3. 「お願い」など短く抽象的に書く
  4. 内容が具体的に分かる表現にする
正解と解説を見る

正解：内容が具体的に分かる表現にする

件名は文書の内容を端的に示すものなので、用件が具体的に分かる表現が望ましい。

問5（秘書の基本職務）

上司から会議資料の準備を頼まれたが、必要部数が分からない。秘書として適切な行動はどれか。

  1. 多めに印刷しておけば問題ないと考える。
  2. 前回と同じ部数を自分で判断して印刷する。
  3. 部数が不明なので資料作成を後回しにする。
  4. 参加人数や予備の要否を確認してから準備する。
正解と解説を見る

正解：参加人数や予備の要否を確認してから準備する。

不明点は思い込みで進めず、必要事項を確認してから正確に準備するのが基本である。

問6（接遇マナー）

来客から「田中部長はいらっしゃいますか」と尋ねられた。社内の人を指して答える表現として適切なものはどれか。

  1. 「田中部長はただいま外出されています」
  2. 「田中部長様はただいまお出掛けです」
  3. 「田中部長はただいま外出しております」
  4. 「田中さんは今いらっしゃいません」
正解と解説を見る

正解：「田中部長はただいま外出しております」

来客に対して社内の人は身内として扱い、尊敬語ではなく謙譲・丁寧な表現で伝える。
