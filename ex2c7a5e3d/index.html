リテールマーケティング(販売士)検定試験 予想問題の例

問1（小売業の類型）

業態分類において、最寄品を中心に小商圏で長時間営業し、利便性を主な価値として提供する小売業態はどれか。

  1. ディスカウントストア
  2. コンビニエンスストア
  3. ホームセンター
  4. 百貨店
正解と解説を見る

正解：コンビニエンスストア

コンビニエンスストアは小商圏で最寄品を扱い、長時間営業や立地の便利さで需要に応える業態である。

問2（マーチャンダイジング）

小売業の商品計画において、対象顧客の購買目的や価格帯に合わせて、品種・品目・SKUの構成を決める活動として最も適切なものはどれか。

  1. 配送経路の計画
  2. 人員シフトの計画
  3. 売場清掃の計画
  4. 商品構成の計画
正解と解説を見る

正解：商品構成の計画

商品計画では顧客ニーズに合う品揃えの幅・奥行き・価格帯を設計し、売場の基本方針を決める。

問3（ストアオペレーション）

開店前の売場点検で最も優先して確認すべき項目として適切なものはどれか。

  1. 通路の安全確保、欠品、価格表示の誤り
  2. 競合店の広告デザインの好み
  3. 従業員休憩室の掲示物の色合い
  4. 閉店後に実施する日報の保存場所
正解と解説を見る

正解：通路の安全確保、欠品、価格表示の誤り

開店時は顧客の安全と購買判断に直結する通路、欠品、価格表示を優先して確認する。

問4（販売・経営管理）

販売促進計画を立てる際、まず確認すべき内容として最も適切なものはどれか。短期の売上増だけでなく、対象顧客や商品特性との整合が求められる。

  1. 競合店の広告をそのまま模倣すること
  2. 売場担当者だけで内容を決定すること
  3. 販促の目的、対象、実施時期、予算を明確にすること
  4. 値引き率を最大にして来店客数を増やすこと
正解と解説を見る

正解：販促の目的、対象、実施時期、予算を明確にすること

販促は目的、ターゲット、時期、予算を整理し、商品や顧客に合う手段を選ぶことが基本である。

問5（小売業の類型）

チェーンストア経営で、複数店舗の仕入れ・販売政策・店舗運営を本部が統一的に管理する主な狙いはどれか。

  1. 規模の利益と標準化による効率を高めるため
  2. 本部機能を廃止して人件費を削減するため
  3. 店舗ごとに商品構成を無制限に変えるため
  4. 各店の完全な独立採算を徹底するため
正解と解説を見る

正解：規模の利益と標準化による効率を高めるため

チェーンストアは本部統制により仕入れや運営を標準化し、大量仕入れなどの規模の利益を追求する。

問6（マーチャンダイジング）

仕入管理で用いる売上仕入計画において、期首在庫、仕入高、売上高、期末在庫の関係を確認する主な目的はどれか。

  1. 必要な仕入量と在庫水準を整合させるため
  2. 店舗設備の減価償却費を計算するため
  3. 広告媒体のデザインを統一するため
  4. 従業員の勤務評価を決めるため
正解と解説を見る

正解：必要な仕入量と在庫水準を整合させるため

売上予算と在庫目標から仕入高を算定し、過不足のない商品供給を図るのが目的である。
