問1（福祉・介護基礎）

介護保険制度における第1号被保険者について、もっとも適切なものはどれか。

  1. 障害者手帳を持つ者のみをいい、介護認定は不要である。
  2. 20歳以上のすべての住民をいい、保険料は全員同額である。
  3. 40歳以上65歳未満の医療保険加入者をいう。
  4. 65歳以上の者をいい、要介護状態等になった原因を問わず給付対象となる。
正解と解説を見る

正解：65歳以上の者をいい、要介護状態等になった原因を問わず給付対象となる。

第1号被保険者は65歳以上で、要介護・要支援認定を受ければ原因を問わず給付対象となる。

問2（住環境整備）

高齢者が夜間に寝室からトイレへ移動する動線計画として、転倒予防の観点から最も適切なものはどれか。

  1. 廊下に小さな敷物を複数置き、足元の冷えを防ぐ。
  2. まぶしさを避けるため、夜間は照明を設けない。
  3. 家具を廊下に配置し、つかまりながら歩けるようにする。
  4. 寝室からトイレまでを短くし、足元灯と連続した手すりを設ける。
正解と解説を見る

正解：寝室からトイレまでを短くし、足元灯と連続した手すりを設ける。

夜間の移動では距離短縮、足元の視認性、連続した支持が転倒予防に有効である。

問3（福祉用具）

標準型自走用車いすを選定する際、座幅の目安として最も適切なものはどれか。利用者が厚手の衣類を着る季節も考慮する。

  1. 介助者が押しやすいよう、できるだけ広い座幅にする
  2. 体幹保持を高めるため、臀部幅と同じ座幅にする
  3. 足こぎをしやすくするため、肩幅を基準に決める
  4. 臀部の最大幅に左右各2～3cm程度の余裕を加える
正解と解説を見る

正解：臀部の最大幅に左右各2～3cm程度の余裕を加える

座幅は狭すぎると圧迫、広すぎると姿勢不良を招くため、臀部幅に適度な余裕を加えて選ぶ。

問4（心身特性）

右片麻痺のある人が杖を使用して平地歩行する場合、基本的な杖の持ち方として最も適切なのはどれか。

  1. 杖は麻痺側と反対側に出さず体の後方で使う
  2. 右手に杖を持ち、左足だけを支える
  3. 左手に杖を持ち、右足を補助するように使う
  4. 右手に杖を持ち、右足と同時に出す
正解と解説を見る

正解：左手に杖を持ち、右足を補助するように使う

杖は原則として健側の手で持ち、麻痺側下肢の支持性不足を補うように使う。

問5（福祉・介護基礎）

地域包括支援センターの主な役割として、もっとも適切なものはどれか。

  1. 高齢者の総合相談、権利擁護、介護予防支援などを行うこと。
  2. 介護保険料を全国一律に決定すること。
  3. 障害者雇用率を企業ごとに認定すること。
  4. 急性期病院の入院治療を直接提供すること。
正解と解説を見る

正解：高齢者の総合相談、権利擁護、介護予防支援などを行うこと。

地域包括支援センターは高齢者の身近な相談窓口で、介護予防支援や権利擁護も担う。

問6（住環境整備）

住宅内の小さな段差を解消するためにすりつけ板を設置する場合の考え方として、最も適切なものはどれか。

  1. 通行方向、勾配、端部処理を確認し、安定して通過できる形にする。
  2. つまずきを防ぐため、端部の浮きやがたつきがあっても固定しない。
  3. 短い距離で急勾配にすると、歩行者も車いす使用者も通過しやすい。
  4. 段差が低ければ、色や材質の違いは安全性に影響しない。
正解と解説を見る

正解：通行方向、勾配、端部処理を確認し、安定して通過できる形にする。

すりつけ板は勾配や固定、端部処理が不適切だと転倒や車いすの不安定につながる。
