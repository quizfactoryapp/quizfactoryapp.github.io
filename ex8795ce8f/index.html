メンタルヘルス・マネジメント検定試験Ⅱ種 予想問題の例

問1（ラインケア）

新任課長が、自部署で欠勤者は少ない一方、残業増加と小さなミスの頻発に気づいた。ラインケアとして最初に優先すべき対応として最も適切なのはどれか。

  1. 部下の自己管理不足と判断し、注意喚起のメールを一斉送信する
  2. 問題が表面化するまで様子を見て、特に記録は残さない
  3. 不調者の有無だけを確認し、職場環境には触れない
  4. 業務量、役割分担、勤務実態などの客観的情報を把握する
正解と解説を見る

正解：業務量、役割分担、勤務実態などの客観的情報を把握する

ラインケアでは、個人責任に直結させず、まず業務量や勤務時間、役割分担など職場環境の実態を客観的に把握することが出発点となる。

問2（事業場内外資源）

長時間労働が続く部下に不眠や集中力低下がみられる。上司が産業医面談につなぐ場面で、産業医の役割として最も適切なのはどれか。

  1. 面談結果のみで懲戒の可否を決める
  2. 休職期間を人事権者として確定する
  3. 本人同意なしに家族へ病状を詳細説明する
  4. 医学的見地から就業上の配慮や面接指導後の意見を述べる
正解と解説を見る

正解：医学的見地から就業上の配慮や面接指導後の意見を述べる

産業医は医学的専門性に基づき健康確保のための意見を述べる。人事権の行使や懲戒判断そのものを行う立場ではない。

問3（法令・制度）

労働安全衛生規則に基づくストレスチェックの実施者として認められる者の組合せとして、最も適切なのはどれか。

  1. 弁護士・社会保険労務士・産業カウンセラー
  2. 上司・人事部長・衛生管理者
  3. 労働組合役員・総務課長・主治医
  4. 医師・保健師・所定研修を修了した公認心理師
正解と解説を見る

正解：医師・保健師・所定研修を修了した公認心理師

実施者は医師、保健師、または所定研修を修了した歯科医師・看護師・精神保健福祉士・公認心理師等に限られる。

問4（ラインケア）

部下から『最近眠れず集中できない。誰にも知られたくない』と相談された。上司の初期対応として最も適切なのはどれか。

  1. 気分転換を勧め、相談内容は記録せずその場で終える
  2. 詳細は聞かず、忙しい時期が過ぎるまで我慢するよう伝える
  3. 話を傾聴し、必要に応じて産業保健スタッフ等への相談につなぐ
  4. すぐに休職を命じ、本人の意向確認は後回しにする
正解と解説を見る

正解：話を傾聴し、必要に応じて産業保健スタッフ等への相談につなぐ

相談対応では、まず傾聴し、就業への影響や緊急性を見極めたうえで、必要時に社内外の専門資源へつなぐことが基本である。

問5（事業場内外資源）

メンタルヘルス不調による休業が増えている部署について、衛生委員会で扱う議題として最も適切なのはどれか。

  1. 特定社員の評価を下げるかどうかを決定する
  2. 個人の診療情報を委員全員に原本配布する
  3. 休業発生の傾向を踏まえた職場環境改善策や再発防止策を審議する
  4. 主治医の診断内容の真偽を委員会で判定する
正解と解説を見る

正解：休業発生の傾向を踏まえた職場環境改善策や再発防止策を審議する

衛生委員会は健康障害防止の観点から職場全体の改善を審議する場であり、個人の人事評価や診断の査定を行う場ではない。

問6（法令・制度）

ストレスチェックを受けた労働者の結果を事業者が把握する場面に関し、法令上の取扱いとして正しいものはどれか。

  1. 面接指導の対象者だけは口頭同意で提供できる
  2. 本人の書面または電磁的記録による同意が必要である
  3. 高ストレスと判定された場合は本人同意なしで提供できる
  4. 衛生委員会で了承されていれば個人結果を提供できる
正解と解説を見る

正解：本人の書面または電磁的記録による同意が必要である

結果は本人への通知が原則であり、事業者への提供には、本人の書面または電磁的記録による同意が必要である。
