マイクロソフト オフィス スペシャリスト 予想問題の例

問1（Word 文書作成）

Wordで新しいスタイルを作成する際、スタイルの書式設定を一括で管理できるのはどの機能ですか？

  1. セクション区切り
  2. スタイルウィンドウ
  3. 差し込み印刷ウィザード
  4. クイックパーツ
正解と解説を見る

正解：スタイルウィンドウ

スタイルウィンドウでは、文字のフォントや段落書式をまとめて管理し、新しいスタイルを作成できます。

問2（Excel データ活用）

Excelで、指定した範囲内の数値の平均値を求める関数はどれですか？

  1. AVERAGE
  2. COUNT
  3. SUM
  4. MAX
正解と解説を見る

正解：AVERAGE

AVERAGE関数は指定した範囲内の数値の平均を計算します。

問3（PowerPoint プレゼンテーション）

スライドマスターを使う目的として最も適切なものはどれですか？

  1. プレゼンテーション全体のデザインやレイアウトを一括で変更するため
  2. 画面切り替え効果を個別に設定するため
  3. スライド内のテキストを自動翻訳するため
  4. 特定のスライドのアニメーションを設定するため
正解と解説を見る

正解：プレゼンテーション全体のデザインやレイアウトを一括で変更するため

スライドマスターはプレゼン全体の共通デザインやレイアウトを一括管理できる機能です。

問4（Outlook メール管理）

Outlookで受信メールを特定の送信者から自動的に特定フォルダーに移動させるには、どの機能を使用すべきですか？

  1. クイックステップ
  2. 仕分けルール
  3. 連絡先グループ
  4. 予定表の共有
正解と解説を見る

正解：仕分けルール

仕分けルールは条件に基づいてメールを自動で振り分ける機能です。

問5（Access データベース）

Accessで2つのテーブル間に1対多のリレーションシップを作成する際、どのフィールドに「主キー」を設定するのが一般的ですか？

  1. 多側のテーブルの主キー
  2. 片方のテーブルの外部キー
  3. 片方のテーブルの主キー
  4. 多側のテーブルの外部キー
正解と解説を見る

正解：多側のテーブルの外部キー

1対多の関係では、一側のテーブルの主キーが多側のテーブルの外部キーとして設定されます。

問6（Word 文書作成）

Wordの差し込み印刷で、差し込みフィールドを文書に挿入する目的は何ですか？

  1. 文書のページ番号を追加するため
  2. データソースの情報を個別に表示するため
  3. 印刷の向きを設定するため
  4. ヘッダーやフッターを変更するため
正解と解説を見る

正解：データソースの情報を個別に表示するため

差し込みフィールドは外部データを文書内の指定位置に挿入し、個別情報を表示するために使います。
