問1（貸金業法）

貸金業の登録に関する次の記述のうち、正しいものはどれか。二以上の都道府県に営業所等を設ける場合の登録先に着目せよ。

  1. 主たる営業所所在地の都道府県知事の登録を受ければ足りる。
  2. 日本貸金業協会に加入すれば登録は不要となる。
  3. 内閣総理大臣の登録を受ける必要がある。
  4. 全営業所所在地の都道府県知事から個別に登録を受ける。
正解と解説を見る

正解：内閣総理大臣の登録を受ける必要がある。

二以上の都道府県に営業所等を置く貸金業者は内閣総理大臣登録となる。協会加入は登録の代替ではない。

問2（民事法・商事法）

口頭で金銭消費貸借の合意をしたが、貸主がまだ金銭を交付していない場合、民法上の契約成立に関する記述として正しいものはどれか。

  1. 返還約束があれば、交付前でも当然に成立する。
  2. 利息の約定があれば、交付前でも成立する。
  3. 原則として、金銭の受取りによって効力を生ずる。
  4. 公正証書でなければ、交付後も成立しない。
正解と解説を見る

正解：原則として、金銭の受取りによって効力を生ずる。

民法587条の消費貸借は、原則として目的物を受け取ることで効力を生ずる要物契約である。

問3（利息・契約規制）

元本80万円の金銭消費貸借契約で、利息制限法上、有効に約定できる利息の上限利率として正しいものはどれか。

  1. 年15％
  2. 年18％
  3. 年20％
  4. 年29.2％
正解と解説を見る

正解：年18％

元本が10万円以上100万円未満の場合、利息制限法の上限利率は年18％である。

問4（貸金業務実務）

貸金業者が個人顧客と金銭消費貸借契約を締結する際、犯罪収益移転防止法上の本人特定事項として確認すべき組合せはどれか。

  1. 氏名、電話番号、借入目的
  2. 氏名、住居、生年月日
  3. 氏名、本籍、家族構成
  4. 氏名、勤務先、年収
正解と解説を見る

正解：氏名、住居、生年月日

個人の本人特定事項は氏名、住居、生年月日であり、年収や勤務先は本人確認事項ではない。

問5（貸金業法）

貸金業者の登録更新について、正しいものはどれか。登録の有効期間と更新を受けない場合の効果を踏まえて選べ。

  1. 登録の有効期間は3年で、更新を受けなければ期間満了により効力を失う。
  2. 登録は一度受ければ取消処分がない限り無期限に有効である。
  3. 登録の有効期間は5年で、更新しなくても効力は存続する。
  4. 登録の有効期間は1年で、毎年更新を受けなければならない。
正解と解説を見る

正解：登録の有効期間は3年で、更新を受けなければ期間満了により効力を失う。

貸金業登録の有効期間は3年であり、期間満了後も営業するには更新登録が必要となる。

問6（民事法・商事法）

書面でする金銭消費貸借について、借主が貸主から金銭を受け取る前の法律関係として正しいものはどれか。

  1. 貸主は、受領前の解除による損害賠償を一切請求できない。
  2. 契約は金銭交付まで全く効力を生じない。
  3. 借主は、裁判所の許可がなければ解除できない。
  4. 借主は、受領前であれば契約を解除できる。
正解と解説を見る

正解：借主は、受領前であれば契約を解除できる。

書面でする消費貸借では合意で効力を生じるが、借主は受領前に解除でき、損害賠償問題が残り得る。
