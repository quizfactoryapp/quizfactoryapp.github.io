日本農業検定 予想問題の例

問1（作物栽培）

水稲の育苗箱に播種する際、覆土後の管理として発芽をそろえるために最も適切なものはどれか。

  1. 低温下で長く置き、徒長を防ぐ
  2. 適温と水分を保ち、過湿や乾燥を避ける
  3. 乾燥気味に管理し、灌水を控える
  4. 発芽前から強い直射日光に当て続ける
正解と解説を見る

正解：適温と水分を保ち、過湿や乾燥を避ける

水稲の発芽には適温と適度な水分が必要で、乾燥や過湿は発芽不良や苗立ち不良の原因になる。

問2（土壌・肥料）

土壌酸度を表すpHについて、一般的な野菜栽培で多くの作物に適するとされる弱酸性の範囲として最も適切なものはどれか。

  1. pH3.5〜4.5
  2. pH5.5〜6.5
  3. pH7.5〜8.5
  4. pH9.0〜10.0
正解と解説を見る

正解：pH5.5〜6.5

多くの野菜は弱酸性の土壌で養分を吸収しやすく、pH5.5〜6.5程度が目安となる。

問3（畜産・食料）

乳牛の飼養管理で、粗飼料を十分に与える主な目的として最も適切なものはどれか。

  1. 乳脂肪率を下げて飲みやすくするため
  2. 第一胃の働きを保ち、消化を安定させるため
  3. 搾乳回数を減らすため
  4. 子牛の出生数を増やすため
正解と解説を見る

正解：第一胃の働きを保ち、消化を安定させるため

牛は反すう動物で、粗飼料は第一胃の発酵を安定させ、健康な乳生産を支える。

問4（農業と環境）

スマート農業でドローンを用いてほ場を撮影する主な目的として、最も適切なものはどれか。

  1. 収穫後の米を乾燥機なしで乾かす
  2. 作物の生育むらや病害の兆候を広い範囲で把握する
  3. 土壌中の微生物をすべて除去する
  4. 農薬登録の内容を自動で変更する
正解と解説を見る

正解：作物の生育むらや病害の兆候を広い範囲で把握する

ドローン画像は生育状況や病害虫の兆候を面的に確認し、適期管理に役立てる技術です。

問5（作物栽培）

畑作物の施肥設計で、基肥を決めるときに最も基本となる考え方はどれか。

  1. 窒素だけを多く施せばよい
  2. 堆肥を入れる場合は化学肥料を全く使わない
  3. 前年と同じ量を必ず施す
  4. 土壌診断と作物の養分吸収量を参考にする
正解と解説を見る

正解：土壌診断と作物の養分吸収量を参考にする

施肥量は土壌中の養分状態と作物の必要量を見て決める。過不足を避けるため土壌診断が重要である。

問6（土壌・肥料）

酸性が強い畑で石灰資材を施用する主な目的として、最も適切なものはどれか。

  1. 窒素成分をすべて無効化するため
  2. 土壌中の水分を完全になくすため
  3. 土壌pHを上げ、酸性障害を和らげるため
  4. 作物の葉色を必ず濃くするため
正解と解説を見る

正解：土壌pHを上げ、酸性障害を和らげるため

石灰資材は酸性土壌のpHを矯正し、アルミニウム害や養分吸収不良を軽減する。
