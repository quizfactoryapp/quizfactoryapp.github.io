実用数学技能検定 予想問題の例

問1（計算・代数）

二次方程式 \(x^2-6x+8=0\) の2つの解の積を求めよ。

  1. 14
  2. 8
  3. 2
  4. -8
正解と解説を見る

正解：8

\(x^2-6x+8=(x-2)(x-4)\) より解は2と4。したがって2つの解の積は \(2\times4=8\) である。

問2（図形・関数）

三角比で、角30度の正弦の値を選びなさい。

  1. \(\frac{1}{2}\)
  2. \(1\)
  3. \(\frac{\sqrt{3}}{2}\)
  4. \(0\)
正解と解説を見る

正解：\(\frac{1}{2}\)

三角比で\(\sin 30^\circ = \frac{1}{2}\)です。

問3（確率・統計）

さいころを2個同時に投げたとき、和が7になる確率を求めよ。

  1. 5/36
  2. 1/6
  3. 1/12
  4. 1/36
正解と解説を見る

正解：1/6

さいころの和が7になる組み合わせは (1,6),(2,5),(3,4),(4,3),(5,2),(6,1)の6通り。全事象は36通りなので、確率は6/36 = 1/6。

問4（図形・関数）

座標平面上で、点A(2,1)を通り、直線 y = -2x + 5 に平行な直線の式として正しいものを選べ。

  1. y = -2x + 3
  2. y = -2x + 1
  3. y = -2x + 5
  4. y = 2x - 3
正解と解説を見る

正解：y = -2x + 1

平行な直線は傾きが同じなので y=-2x+b。点(2,1)を代入して1=-4+bよりb=5ではなく、b=5? 計算するとb=5となるため、正しくは元の直線と同じである。

問5（確率・統計）

二項分布の問題：成功確率0.3の試行を5回行ったとき成功回数が2回である確率。

  1. 0.2646
  2. 0.441
  3. 0.1323
  4. 0.3087
正解と解説を見る

正解：0.3087

二項分布の確率は \( \binom{n}{k} p^k (1-p)^{n-k} \)。よって \( \binom{5}{2} (0.3)^2 (0.7)^3 = 10 \times 0.09 \times 0.343 = 0.3087 \)。

問6（図形・関数）

直線 y=2x+1 と直線 y=-x+7 の交点を P とする。点 P の x 座標を求めよ。

  1. 2
  2. 4
  3. 1
  4. 3
正解と解説を見る

正解：2

交点では 2x+1=-x+7 が成り立つ。3x=6 より x=2 なので、正解は2。
