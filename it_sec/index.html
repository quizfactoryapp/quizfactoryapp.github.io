情報処理安全確保支援士 予想問題の例

問1（脅威と攻撃）

標的型攻撃において攻撃者が最も重視する情報はどれか。

  1. 公開された社員のSNS投稿
  2. 公開されている製品のマニュアル
  3. 一般的なインターネットトラフィック
  4. 内部の機密情報やアクセス権限
正解と解説を見る

正解：内部の機密情報やアクセス権限

標的型攻撃では攻撃者が内部の機密情報や高権限アカウントを狙い、システムへの侵入や情報漏えいを狙うため重要視される。

問2（暗号・認証）

共通鍵暗号方式の特徴として正しいものはどれか。

  1. 暗号化処理が常に遅い
  2. 公開鍵と秘密鍵のペアを使用する
  3. 鍵配布の手間がほとんどない
  4. 同じ鍵で暗号化と復号を行う
正解と解説を見る

正解：同じ鍵で暗号化と復号を行う

共通鍵暗号方式は、同じ鍵で暗号化と復号を行う方式であるため、鍵の配送管理が重要になる。

問3（ネットワークセキュリティ）

ファイアウォールの主な役割として適切なものはどれか。

  1. 内部ネットワークの帯域制御
  2. 不正アクセスの遮断
  3. ウイルス検出
  4. 通信内容の暗号化
正解と解説を見る

正解：不正アクセスの遮断

ファイアウォールは通信ルールに基づき、不正アクセスや不審な通信を遮断する役割を持ちます。

問4（セキュリティ管理）

ISMS（情報セキュリティマネジメントシステム）のPDCAサイクルで、リスク対応策の実施と運用に該当するフェーズはどれか。

  1. Plan（計画）
  2. Act（改善）
  3. Check（評価）
  4. Do（実行）
正解と解説を見る

正解：Do（実行）

リスク対応策の実施と運用はPDCAのDo（実行）フェーズに該当する。

問5（脅威と攻撃）

ランサムウェアに感染した場合、被害者に最も起こりうる影響はどれか。

  1. ファイルの暗号化による業務停止
  2. 不要な広告が表示される
  3. システムのパフォーマンスが向上する
  4. インターネット接続が高速化する
正解と解説を見る

正解：ファイルの暗号化による業務停止

ランサムウェアはファイルを暗号化し、復号のための身代金を要求するため、業務が停止し大きな被害をもたらす。

問6（暗号・認証）

公開鍵暗号方式における公開鍵の役割として最も適切なものはどれか。

  1. 秘密の情報を保存する
  2. 共通鍵の交換に使われない
  3. 電子署名を生成する
  4. 誰でも利用できる鍵で暗号化を行う
正解と解説を見る

正解：誰でも利用できる鍵で暗号化を行う

公開鍵は誰でも利用でき、メッセージの暗号化や電子署名の検証に使われる鍵である。
