ビジネス会計検定試験 予想問題の例

問1（財務諸表）

貸借対照表において、企業の一定時点における財政状態を把握するために表示される基本的な区分として正しいものはどれか。

  1. 売上高・売上原価・販売費
  2. 営業活動・投資活動・財務活動
  3. 資産・負債・純資産
  4. 収益・費用・利益
正解と解説を見る

正解：資産・負債・純資産

貸借対照表は一定時点の財政状態を示し、資産、負債、純資産に区分して表示する。

問2（会計基準）

企業会計原則における「正規の簿記の原則」が求める内容として、最も適切なものはどれか。

  1. 税法上認められた方法だけで会計処理を行うこと
  2. 利益が見込まれる場合のみ収益を認識すること
  3. 会計処理は常に時価を基礎として行うこと
  4. すべての取引を網羅的に記録し、検証可能な会計帳簿に基づき財務諸表を作成すること
正解と解説を見る

正解：すべての取引を網羅的に記録し、検証可能な会計帳簿に基づき財務諸表を作成すること

正規の簿記の原則は、網羅性・秩序性・検証可能性を備えた帳簿記録に基づく財務諸表作成を求める。

問3（財務分析）

流動資産が1,200万円、流動負債が800万円である会社の流動比率として正しいものはどれか。

  1. 100.0%
  2. 150.0%
  3. 66.7%
  4. 200.0%
正解と解説を見る

正解：150.0%

流動比率は流動資産÷流動負債×100で求める。1,200÷800×100＝150%である。

問4（開示制度）

有価証券報告書の主な目的として最も適切なものはどれか。投資者が企業の財政状態、経営成績、リスク等を継続的に判断できるよう開示する制度である。

  1. 法人税の申告税額を確定するための税務書類である
  2. 取引先への信用状況を非公開で説明する資料である
  3. 株主総会の議決権行使を電子化するための書類である
  4. 投資者の投資判断に必要な企業情報を提供する書類である
正解と解説を見る

正解：投資者の投資判断に必要な企業情報を提供する書類である

有価証券報告書は金融商品取引法に基づく継続開示書類で、投資判断に資する情報提供を目的とする。

問5（財務諸表）

損益計算書において、売上総利益を計算するために売上高から控除する項目として最も適切なものはどれか。

  1. 売上原価
  2. 販売費及び一般管理費
  3. 法人税等
  4. 営業外費用
正解と解説を見る

正解：売上原価

売上総利益は売上高から売上原価を差し引いて計算され、商品の採算性を示す。

問6（会計基準）

企業会計原則の保守主義の原則に関する説明として、最も適切なものはどれか。

  1. 予想される利益は早期に計上し、損失は確定時まで計上しない
  2. 不確実な状況では慎重な判断により、利益を過大に表示しないよう処理する
  3. 企業の財政状態を実際より良く見せる処理を優先する
  4. 将来の危険に備え、過度に悲観的な処理を常に行う
正解と解説を見る

正解：不確実な状況では慎重な判断により、利益を過大に表示しないよう処理する

保守主義は慎重な判断を求めるが、過度な保守処理により真実性を損なうことは認められない。
