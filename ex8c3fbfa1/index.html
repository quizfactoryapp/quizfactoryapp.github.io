健康管理能力検定 予想問題の例

問1（生体リズム）

概日リズムを調整する主な中枢はどこにあり、光の情報を受けて睡眠覚醒リズムを整えるか。

  1. 延髄の呼吸中枢
  2. 小脳の虫部
  3. 視床下部の視交叉上核
  4. 大脳皮質の運動野
正解と解説を見る

正解：視床下部の視交叉上核

視交叉上核は体内時計の中枢で、網膜からの光情報を受け概日リズムを同調させます。

問2（睡眠管理）

レム睡眠について正しい説明はどれか。脳の活動、筋緊張、夢の見やすさに着目して選びなさい。

  1. 脳活動は比較的活発で、筋緊張は低下し、鮮明な夢を見やすい
  2. 脳活動は低く、筋緊張は高まり、夢はほとんど見ない
  3. 成長ホルモン分泌の中心で、入眠直後だけに必ず出現する
  4. 睡眠中の呼吸と心拍が常に最も安定する段階である
正解と解説を見る

正解：脳活動は比較的活発で、筋緊張は低下し、鮮明な夢を見やすい

レム睡眠では脳は活動的になりやすく、筋肉は弛緩し、夢を体験しやすい状態です。

問3（栄養と代謝）

食後に血糖値が上がったとき、すい臓から分泌され、血液中のブドウ糖を細胞へ取り込ませる働きが最も強いホルモンはどれか。

  1. アドレナリン
  2. グルカゴン
  3. コルチゾール
  4. インスリン
正解と解説を見る

正解：インスリン

インスリンは食後の血糖上昇に応じて分泌され、筋肉や脂肪細胞への糖取り込みを促し血糖を下げる。

問4（ストレスケア）

強いストレスを受けたとき、副腎皮質から分泌が増え、血糖上昇や抗炎症作用に関わるホルモンとして正しいものはどれか。

  1. インスリン
  2. コルチゾール
  3. メラトニン
  4. セロトニン
正解と解説を見る

正解：コルチゾール

コルチゾールはストレス反応で分泌が増える副腎皮質ホルモンで、血糖維持などに関わります。

問5（生活習慣予防）

生活習慣病の予防に関する説明として、最も適切なものはどれか。日常の食事・運動・休養を総合的に整える視点で選びなさい。

  1. バランスのよい食事、適度な運動、十分な睡眠を継続する
  2. 症状が出てから生活を見直せば十分である
  3. 体重が標準なら喫煙や飲酒量は気にしなくてよい
  4. 短期間の極端な食事制限を続けることが基本である
正解と解説を見る

正解：バランスのよい食事、適度な運動、十分な睡眠を継続する

生活習慣病は複数の生活要因が関係するため、食事・運動・睡眠などを継続的に整えることが重要です。

問6（生体リズム）

夜間に分泌が高まり、眠気を促し体内時計の夜を知らせるホルモンとして最も適切なものはどれか。

  1. メラトニン
  2. インスリン
  3. 甲状腺ホルモン
  4. アドレナリン
正解と解説を見る

正解：メラトニン

メラトニンは暗くなると分泌が増え、眠気を促して睡眠覚醒リズムの調整に関わります。
