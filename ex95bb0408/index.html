問1（認知症の医学的理解）

アルツハイマー型認知症の初期に最も目立ちやすい中核症状として適切なのはどれか。

  1. 構音障害のみの出現
  2. 意識レベルの著明な低下
  3. 近時記憶の障害
  4. 四肢の麻痺
正解と解説を見る

正解：近時記憶の障害

アルツハイマー型認知症では海馬を含む記憶系が早期に障害され、近時記憶障害が目立つ。

問2（認知症ケアの理念）

パーソンセンタードケアの基本的な考え方として最も適切なのはどれか。

  1. 集団生活の秩序を保つため、生活リズムを施設の都合に合わせる
  2. 疾患名や症状だけでなく、その人の価値観や関係性を中心に支援する
  3. 本人の能力低下に注目し、できない行為を職員がすべて代行する
  4. 認知機能の低下を理由に本人の希望より安全管理を常に優先する
正解と解説を見る

正解：疾患名や症状だけでなく、その人の価値観や関係性を中心に支援する

パーソンセンタードケアは、認知症の人を一人の人として尊重し、価値観や生活背景に基づき支援する考え方である。

問3（ケア実践）

中等度認知症の人が食事中に箸を止め、皿を見つめたまま動かない。最も適切な食事支援はどれか。

  1. 一品ずつ見やすく置き、食べ始めの手がかりを示す
  2. 本人の手を強く誘導し、食具を握らせ続ける
  3. すぐに全介助へ切り替え、短時間で食べ終える
  4. 食欲がないと判断し、食事をすべて下膳する
正解と解説を見る

正解：一品ずつ見やすく置き、食べ始めの手がかりを示す

認知症では開始の手がかりが失われることがある。視覚情報を整理し、声かけや動作提示で自立を支える。

問4（家族・地域支援）

認知症の人を在宅で介護する家族への支援として、専門職の初期対応で最も適切なのはどれか。

  1. 本人の希望より家族の介護都合を優先して方針を決める
  2. 家族の負担感や生活状況を聴き、利用可能な支援を一緒に整理する
  3. 施設入所を前提に、在宅生活の継続可否を判定する
  4. 介護方法の不足を指摘し、家族に努力目標を示す
正解と解説を見る

正解：家族の負担感や生活状況を聴き、利用可能な支援を一緒に整理する

家族支援では、介護負担や心理状態を把握し、本人・家族の意思を尊重して支援を調整する。

問5（認知症の医学的理解）

レビー小体型認知症に特徴的で、診断を考える手がかりとなる症状の組合せはどれか。

  1. 多幸感と反社会的行動
  2. 失語と半側空間無視
  3. 急性発症と片麻痺
  4. 具体的な幻視と認知機能の変動
正解と解説を見る

正解：具体的な幻視と認知機能の変動

レビー小体型認知症では具体的な幻視、認知機能の変動、パーキンソン症状などが特徴である。

問6（認知症ケアの理念）

認知症の人の尊厳を保持する対応として、最も適切なのはどれか。

  1. 本人の呼び名や話し方の希望を確認し、敬意をもって接する
  2. 効率を上げるため、本人の訴えを短時間で遮る
  3. 失敗を防ぐため、本人の前で家族にだけ説明して決定する
  4. 混乱を避けるため、本人には予定変更を伝えない
正解と解説を見る

正解：本人の呼び名や話し方の希望を確認し、敬意をもって接する

尊厳保持には、本人の人格や好みを尊重し、子ども扱いや無視を避けて対等に関わる姿勢が重要である。
