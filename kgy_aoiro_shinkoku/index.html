青色申告と帳簿づけ 予想問題の例

問1（青色申告の制度）

青色申告と白色申告の制度上の大きな違いとして、最も適切なものはどれか。

  1. 青色申告は事前の承認申請と一定の記帳が前提となる
  2. 白色申告だけが損益計算書の作成を必須とする
  3. 青色申告では帳簿の保存が一切不要となる
  4. 白色申告は所得税の申告では使えない
正解と解説を見る

正解：青色申告は事前の承認申請と一定の記帳が前提となる

青色申告は、承認申請と一定水準の記帳・帳簿保存を前提に特典が認められる制度です。

問2（複式簿記の基礎）

複式簿記で、現金で商品を仕入れた取引を記録する場合、一般的に増加する費用または資産として借方に記入される勘定科目はどれですか。

  1. 仕入
  2. 買掛金
  3. 売上
  4. 資本金
正解と解説を見る

正解：仕入

商品を仕入れたときは、費用である仕入の増加を借方に記入し、現金の減少を貸方に記入します。

問3（帳簿の種類）

青色申告で正規の簿記の原則に従う場合、すべての取引を発生順に記録し、借方・貸方を示す主要簿として用いられる帳簿はどれか。

  1. 固定資産台帳
  2. 仕訳帳
  3. 棚卸表
  4. 現金出納帳
正解と解説を見る

正解：仕訳帳

仕訳帳は取引を発生順に仕訳として記録する主要簿で、総勘定元帳への転記の基礎となります。

問4（控除と特典）

青色申告特別控除65万円の適用を受けるための一般的な前提として、正しいものはどれか。

  1. 現金主義を選べば自動的に65万円控除となる
  2. 単式簿記で日々の収入だけを記録すれば足りる
  3. 白色申告でも電子申告をすれば適用される
  4. 複式簿記で記帳し、貸借対照表等を期限内に提出する
正解と解説を見る

正解：複式簿記で記帳し、貸借対照表等を期限内に提出する

65万円控除は、青色申告で正規の簿記により記帳し、決算書類を期限内に提出することが基本要件です。

問5（青色申告の制度）

所得税の青色申告承認申請書について、一般的な提出先として正しいものはどれか。

  1. 年金事務所
  2. 市区町村の住民税担当窓口
  3. 都道府県税事務所
  4. 納税地を所轄する税務署長
正解と解説を見る

正解：納税地を所轄する税務署長

所得税の青色申告承認申請書は、納税地の所轄税務署長に提出する書類です。

問6（複式簿記の基礎）

複式簿記における借方・貸方の基本原則として、1つの取引を仕訳したときに必ず一致するものはどれですか。

  1. 借方の金額合計と貸方の金額合計
  2. 資産の金額と費用の金額
  3. 現金残高と預金残高
  4. 売上の件数と仕入の件数
正解と解説を見る

正解：借方の金額合計と貸方の金額合計

複式簿記では取引を二面的に記録するため、仕訳ごとに借方合計と貸方合計は同額になります。
