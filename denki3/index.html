第三種電気主任技術者試験 予想問題の例

問1（理論）

真空中で、点電荷 Q=+2.0×10^{-6} C から 0.30 m 離れた点における電界の大きさとして、最も近いものはどれか。ただし、クーロンの比例定数を 9.0×10^{9} N・m^2/C^2 とする。

  1. 2.0×10^{4} V/m
  2. 6.0×10^{5} V/m
  3. 1.8×10^{7} V/m
  4. 2.0×10^{5} V/m
正解と解説を見る

正解：2.0×10^{5} V/m

点電荷による電界は E=kQ/r^2。9.0×10^9×2.0×10^{-6}/0.30^2=2.0×10^5 V/m。

問2（電力）

有効落差60m、使用水量8.0m^3/sの水力発電所がある。水車効率90%、発電機効率95%、水の密度1000kg/m^3、重力加速度9.8m/s^2とすると、発電機出力に最も近い値はどれか。

  1. 4.0MW
  2. 3.8MW
  3. 5.5MW
  4. 4.7MW
正解と解説を見る

正解：4.0MW

水力出力はρgQHηで求める。1000×9.8×8.0×60×0.90×0.95≒4.0MWとなる。

問3（理論）

直流回路で、抵抗 R1=2.0kΩ と R2=3.0kΩ を直列に接続し、全体に 10V の電圧を加えた。R2 の両端電圧として正しいものはどれか。

  1. 6.0V
  2. 5.0V
  3. 6.7V
  4. 4.0V
正解と解説を見る

正解：6.0V

直列回路では電圧は抵抗値に比例して分圧される。R2の電圧は10×3.0/(2.0+3.0)=6.0V。

問4（電力）

三相3線式送電線で、線間電圧66kV、力率0.90、送電電力18MWの負荷へ送電している。各線の抵抗が5.0Ωのとき、送電線全体の銅損に最も近い値はどれか。

  1. 0.41MW
  2. 0.83MW
  3. 1.38MW
  4. 0.46MW
正解と解説を見る

正解：0.46MW

線電流はP/(√3VIcosφ)ではなくP/(√3Vcosφ)で約175A。銅損は3I^2Rで約0.46MW。

問5（理論）

直流電源24Vに、抵抗R=6Ωと抵抗r=3Ωを並列に接続した。電源から流れ出す全電流として最も近いものはどれか。

  1. 8A
  2. 12A
  3. 2.7A
  4. 4A
正解と解説を見る

正解：12A

並列合成抵抗は1/(1/6+1/3)=2Ω。したがって全電流は24/2=12Aである。

問6（電力）

三相3線式の送電線で，受電端線間電圧が6.6 kV，負荷が1000 kW，力率0.80（遅れ）である。送電線1線当たりの抵抗を0.50 Ω，リアクタンスを1.0 Ωとし，電圧降下を ΔV=√3 I(Rcosφ+Xsinφ) で近似する。このとき，受電端電圧に対する電圧降下率として最も近いものはどれか。

  1. 3.8 %
  2. 1.4 %
  3. 2.9 %
  4. 5.7 %
正解と解説を見る

正解：2.9 %

電流は約109 A，sinφ=0.60。電圧降下は√3×109×(0.50×0.80+1.0×0.60)≈189 Vで，189/6600≈2.9%。
