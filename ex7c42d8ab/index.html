メンタルヘルス・マネジメント検定試験Ⅲ種 予想問題の例

問1（セルフケア）

ストレス反応に関する説明として最も適切なものはどれか。仕事上の負荷を受けた後に起こる心身や行動の変化に着目して選びなさい。

  1. ストレス反応は本人の性格だけで決まり、環境要因の影響は受けない
  2. ストレス反応は必ず病気であり、出た時点で就業できない状態を示す
  3. ストレス反応には不安、疲労感、睡眠の乱れ、飲酒量の増加などが含まれる
  4. ストレス反応は心理面だけに現れ、身体面や行動面には現れない
正解と解説を見る

正解：ストレス反応には不安、疲労感、睡眠の乱れ、飲酒量の増加などが含まれる

ストレス反応は心理面、身体面、行動面に現れる。早めに変化へ気づくことがセルフケアの第一歩である。

問2（メンタルヘルス不調）

職場でみられるうつ病のサインとして、早期の気づきにつながりやすいものはどれか。

  1. 一時的に食欲が増え、休日だけ活動的になる
  2. 遅刻や欠勤が増え、集中力や判断力の低下が続く
  3. 新しい趣味に熱中し、睡眠時間が短くても元気である
  4. 会議で発言が増え、業務量を自ら増やす
正解と解説を見る

正解：遅刻や欠勤が増え、集中力や判断力の低下が続く

うつ病では意欲低下、集中力低下、遅刻・欠勤の増加などが職場での重要なサインとなる。

問3（職場の健康管理）

労働安全衛生法に基づく健康管理について、事業者の基本的な責務として最も適切なものはどれか。

  1. 健康情報は職場全員で共有し、早期対応に役立てる。
  2. 健康診断は労働者本人が希望した場合だけ実施する。
  3. 労働者の健康確保のため、必要な健康診断や事後措置を行う。
  4. 健康管理は産業医だけが行い、事業者に責任はない。
正解と解説を見る

正解：労働者の健康確保のため、必要な健康診断や事後措置を行う。

労働安全衛生法では、事業者が労働者の健康確保のため健康診断や事後措置を行う責任を負う。

問4（相談資源）

従業員が強い不安や不眠を訴えているが、上司には詳しい事情を話したくないと言う。まず案内する相談資源として最も適切なものはどれか。

  1. 社内相談窓口や産業保健スタッフへの相談
  2. 人事評価面談で詳しく説明させる
  3. 休暇を取らせず業務量を増やす
  4. 同僚全員に状況を共有して助言を求める
正解と解説を見る

正解：社内相談窓口や産業保健スタッフへの相談

本人の同意とプライバシーに配慮し、社内の専門窓口へつなぐことが初期対応として適切です。

問5（セルフケア）

職場におけるストレス要因として最も適切なものはどれか。個人の反応ではなく、負荷や緊張を生じさせる原因に当たるものを選びなさい。

  1. 仕事量が多く、締切に追われ続けること
  2. 頭痛が続くこと
  3. 夜中に何度も目が覚めること
  4. 気分が落ち込みやすくなること
正解と解説を見る

正解：仕事量が多く、締切に追われ続けること

仕事量や時間的圧迫、人間関係などはストレス要因である。頭痛や不眠、落ち込みは反応に当たる。

問6（メンタルヘルス不調）

うつ病が疑われる同僚への職場での初期対応として、最も適切なものはどれか。

  1. 気合いで乗り切るよう強く励ます
  2. 話を落ち着いて聴き、産業保健スタッフ等への相談を勧める
  3. 本人の了解なく周囲に詳しい事情を共有する
  4. 仕事を増やして余計なことを考えないようにする
正解と解説を見る

正解：話を落ち着いて聴き、産業保健スタッフ等への相談を勧める

安易な励ましは負担になることがある。傾聴し、専門職や相談窓口につなぐ対応が望ましい。
