ホテルビジネス実務検定試験 予想問題の例

問1（宿泊実務）

フロントでウォークイン客を受け入れる際、満室に近い状況で最初に確認すべき事項として最も適切なものはどれか。

  1. 客室清掃員の翌日の出勤予定
  2. 館内レストランの予約台帳
  3. 過去の口コミ評価の平均点
  4. 当日の空室状況と販売可能な客室タイプ
正解と解説を見る

正解：当日の空室状況と販売可能な客室タイプ

ウォークイン対応では、まず販売可能な客室の有無と条件を確認し、誤販売を防ぐことが重要である。

問2（料飲実務）

レストランで席へ案内する際、予約客の氏名と人数を確認した後に行う対応として最も適切なものはどれか。

  1. 混雑時は予約席でも相席を依頼する
  2. 注文が決まるまで入口で待機してもらう
  3. 席まで先導し、着席しやすいよう椅子を引く
  4. 客に任せて自由に空席を選ばせる
正解と解説を見る

正解：席まで先導し、着席しやすいよう椅子を引く

予約確認後は係が席まで案内し、着席補助を行うことが基本的な接客手順である。

問3（ホテル経営）

ホテルのADR（平均客室単価）を算出する式として、最も適切なものはどれか。

  1. 客室売上高 ÷ 販売客室数
  2. 客室売上高 ÷ 総客室数
  3. 営業利益 ÷ 客室売上高
  4. 販売客室数 ÷ 総客室数
正解と解説を見る

正解：客室売上高 ÷ 販売客室数

ADRは販売した客室1室あたりの平均単価で、客室売上高を販売客室数で割って求める。

問4（宿泊実務）

予約記録における「ノーショー」とは、次のうちどの状態を指すか。

  1. 予定より早くチェックアウトした宿泊客
  2. 予約後すぐにキャンセルした利用客
  3. 団体予約から個人予約へ変更した客
  4. 到着予定日に連絡なく来館しない予約客
正解と解説を見る

正解：到着予定日に連絡なく来館しない予約客

ノーショーは、予約があるにもかかわらず到着日に連絡なく現れない状態をいう。

問5（料飲実務）

ワインサービスでホストテイスティングを行う主な目的として、最も適切なものはどれか。

  1. グラスの容量を調整するため
  2. ワインに劣化や異臭がないか確認してもらうため
  3. ボトルの価格が妥当か確認してもらうため
  4. 料理との相性を全員で比較するため
正解と解説を見る

正解：ワインに劣化や異臭がないか確認してもらうため

ホストテイスティングは味の好みではなく、品質に問題がないかを確認するために行う。

問6（ホテル経営）

RevPAR（販売可能客室1室あたり売上）を高める施策として、最も適切なものはどれか。

  1. 客室売上を料飲売上に振り替える
  2. 稼働率を下げて固定費を増やす
  3. 需要に応じた料金設定と販売管理を行う
  4. 全客室を常に同一料金で販売する
正解と解説を見る

正解：需要に応じた料金設定と販売管理を行う

RevPARは単価と稼働率の影響を受けるため、需要に応じた価格と在庫管理が重要である。
