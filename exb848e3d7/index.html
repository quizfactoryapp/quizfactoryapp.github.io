情報処理検定試験 予想問題の例

問1（ビジネス情報部門）

表計算ソフトで、売上表の「商品分類」が「文具」かつ「売上金額」が1万円以上の行だけを集計したい。最も適切な関数はどれか。

  1. SUMIFS関数
  2. ROUND関数
  3. SUMIF関数
  4. COUNT関数
正解と解説を見る

正解：SUMIFS関数

複数条件で数値を合計する場合はSUMIFS関数を使う。SUMIFは条件が1つの場合に適する。

問2（プログラミング部門）

変数xに1を代入し、「xを表示してからxに2を加える」をxが10以下の間くり返す流れ図で、最後に表示される値はどれか。

  1. 9
  2. 7
  3. 11
  4. 8
正解と解説を見る

正解：9

表示後に2を加えるため、表示値は1、3、5、7、9となり、次の11で条件を満たさず終了する。

問3（表計算実技）

セルC2に「=A2*B2」と入力し、C3へコピーした。C3で計算に使われるセルの組み合わせとして正しいものはどれか。

  1. B2とC2
  2. A3とB3
  3. A2とB2
  4. A1とB1
正解と解説を見る

正解：A3とB3

相対参照はコピー先に合わせて行や列が変化するため、1行下ではA3とB3を参照します。

問4（データベース）

社員表に社員番号、氏名、部門番号を持たせ、部門名は部門表で管理する設計にした。部門番号に設定する制約として最も適切なものはどれか。

  1. 部門番号を自動採番する制約
  2. 社員表の氏名を一意にする一意制約
  3. 部門名を空欄にしない制約
  4. 部門表の主キーを参照する外部キー制約
正解と解説を見る

正解：部門表の主キーを参照する外部キー制約

社員表の部門番号は部門表の存在する部門を示すため、参照整合性を守る外部キー制約が適切である。

問5（情報処理基礎）

CPUの性能を表す指標の一つであるクロック周波数について、基本的な意味として最も適切なものはどれか。

  1. 画面に表示できる色の種類を示す値
  2. ネットワークで同時接続できる端末数を示す値
  3. 主記憶装置に保存できるデータ量を示す値
  4. 1秒間に動作の基準となる信号が何回発生するかを示す値
正解と解説を見る

正解：1秒間に動作の基準となる信号が何回発生するかを示す値

クロック周波数はCPUが処理を進める基準信号の回数を表し、一般にHzで示されます。

問6（ビジネス情報部門）

表計算ソフトで、商品コードを入力すると別表の商品名を自動表示したい。参照表から一致する値を探す操作として適切なものはどれか。

  1. 絶対参照
  2. 並べ替え
  3. 条件付き書式
  4. VLOOKUP関数などの検索関数
正解と解説を見る

正解：VLOOKUP関数などの検索関数

商品コードをキーに別表から商品名を取り出すには、VLOOKUPやXLOOKUPなどの検索関数が適切である。
