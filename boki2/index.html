問1（商業簿記）

株式発行に関する会計処理として正しいものはどれか。

  1. その他資本剰余金に計上する
  2. 資本準備金に計上する
  3. 利益剰余金に計上する
  4. 資本金に計上する
正解と解説を見る

正解：資本準備金に計上する

株式の払込金額が額面を上回る超過額は、会社法により資本金の2分の1までを資本準備金に計上し、残りはその他資本剰余金に計上します。一般的に超過額は資本準備金に計上されます。

問2（工業簿記）

製品Aを1個製造するための標準直接材料消費量は4kg、標準価格は1kgあたり300円である。当月の実際生産量は500個、実際材料消費量は2,100kg、実際購入価格は1kgあたり280円であった。直接材料費の数量差異はいくらか。なお、差異は標準価格を用いて計算する。

  1. 42,000円の有利差異
  2. 12,000円の有利差異
  3. 30,000円の不利差異
  4. 18,000円の不利差異
正解と解説を見る

正解：30,000円の不利差異

標準消費量は4kg×500個＝2,000kg。実際は2,100kgなので超過100kg。100kg×300円＝30,000円の不利差異。

問3（原価管理）

ある製品の販売価格は1個あたり2,000円、変動費は1個あたり1,200円、月間固定費は480,000円である。目標営業利益を160,000円とする場合、必要な販売数量として正しいものはどれか。

  1. 900個
  2. 600個
  3. 800個
  4. 1,000個
正解と解説を見る

正解：800個

貢献利益は1個800円。目標利益達成数量は（固定費480,000円＋目標利益160,000円）÷800円＝800個。

問4（財務諸表）

次の資料に基づき、貸借対照表の流動資産に表示される金額として正しいものはどれか。現金預金120万円、売掛金300万円、貸倒引当金（売掛金に対するもの）6万円、商品180万円、前払保険料24万円のうち次期分は8万円、長期貸付金90万円のうち決算日の翌日から1年以内に回収予定の額は30万円である。

  1. 722万円
  2. 632万円
  3. 624万円
  4. 656万円
正解と解説を見る

正解：632万円

流動資産は現金預金、売掛金から貸倒引当金控除、商品、次期分前払費用、1年内回収予定貸付金を含める。

問5（商業簿記）

連結財務諸表作成における親会社株主持分の計算。

  1. 800万円
  2. 1,200万円
  3. 1,000万円
  4. 200万円
正解と解説を見る

正解：800万円

親会社株主持分は、子会社純資産の公正価値に持分比率を乗じて計算する。

問6（工業簿記）

当工場では月末仕掛品を平均法で評価している。材料は工程の始点で全量投入し、加工費は進捗に応じて発生する。当月投入数量は1,000個、月末仕掛品は200個（加工進捗度40%）、完成品は800個であった。当月製造費用は、直接材料費600,000円、加工費440,000円である。完成品総合原価はいくらか。

  1. 900,000円
  2. 800,000円
  3. 928,000円
  4. 1,040,000円
正解と解説を見る

正解：900,000円

材料の完成品負担は600,000円×800/1,000、加工費は440,000円×800/(800+200×40%)で計算する。
