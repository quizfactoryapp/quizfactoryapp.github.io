税理士 簿記論 予想問題の例

問1（仕訳・会計処理）

商品100,000円を掛けで仕入れ、引取運賃3,000円は現金で支払った。三分法による正しい仕訳はどれか。

  1. 借方：仕入 100,000円、支払手数料 3,000円／貸方：買掛金 100,000円、現金 3,000円
  2. 借方：仕入 100,000円／貸方：買掛金 103,000円
  3. 借方：仕入 103,000円／貸方：買掛金 100,000円、現金 3,000円
  4. 借方：仕入 100,000円、発送費 3,000円／貸方：買掛金 100,000円、現金 3,000円
正解と解説を見る

正解：借方：仕入 103,000円／貸方：買掛金 100,000円、現金 3,000円

仕入時の引取運賃は仕入原価に含めるため、仕入103,000円を借方に計上し、掛代金と現金支払を貸方に記入する。

問2（決算整理）

決算日において、当期首に1年分として支払った保険料120,000円のうち、翌期に属する分が30,000円あることが判明した。決算整理仕訳として正しいものはどれか。

  1. （借）保険料 30,000円　（貸）前払保険料 30,000円
  2. （借）前払保険料 30,000円　（貸）保険料 30,000円
  3. （借）未払保険料 30,000円　（貸）保険料 30,000円
  4. （借）保険料 90,000円　（貸）前払保険料 90,000円
正解と解説を見る

正解：（借）前払保険料 30,000円　（貸）保険料 30,000円

翌期分30,000円は当期費用から除き、資産の前払保険料に振り替えるため、前払保険料を借方、保険料を貸方に記入する。

問3（連結・組織再編）

P社は当期首にS社株式の80％を1,000,000円で取得し、支配を獲得した。取得日におけるS社の資本金は600,000円、利益剰余金は400,000円で、資産・負債の時価と簿価に差異はない。連結開始仕訳で計上されるのれんの金額はいくらか。

  1. 200,000円
  2. 250,000円
  3. 1,000,000円
  4. 0円
正解と解説を見る

正解：200,000円

S社純資産1,000,000円の80％は800,000円。取得原価1,000,000円との差額200,000円がのれんとなる。

問4（表示・開示）

財務諸表の表示に関する基本的な原則はどれか。

  1. 原則として、利益の過大表示を優先する。
  2. 財務諸表は税務申告書の内容と完全に一致させるべきである。
  3. 重要性の原則に従い、重要でない情報は省略してよい。
  4. 開示すべき情報はすべて脚注にまとめて記載すればよい。
正解と解説を見る

正解：重要性の原則に従い、重要でない情報は省略してよい。

財務諸表の表示では、重要性の原則に従い、利用者の意思決定に影響を与える重要な情報は表示・開示される。過大表示や税務目的との一致は求められない。

問5（仕訳・会計処理）

現金及び預金の入金時の仕訳について、正しいものはどれか。

  1. 売上 100,000 / 預金 100,000
  2. 現金 100,000 / 前受金 100,000
  3. 売上 100,000 / 現金 100,000
  4. 現金 100,000 / 売上 100,000
正解と解説を見る

正解：現金 100,000 / 売上 100,000

売上代金を現金で受け取った場合、現金（資産）が増加し、売上（収益）が発生するため、現金の借方、売上の貸方で仕訳を行う。

問6（決算整理）

決算にあたり、当期首に支払った1年分の保険料120,000円のうち、期末時点で翌期に属する期間が3か月分あることが判明した。支払時に全額を保険料として処理している場合、決算整理仕訳として正しいものはどれか。

  1. （借）前払保険料 90,000円 ／ （貸）保険料 90,000円
  2. （借）前払保険料 30,000円 ／ （貸）保険料 30,000円
  3. （借）未払保険料 30,000円 ／ （貸）保険料 30,000円
  4. （借）保険料 30,000円 ／ （貸）前払保険料 30,000円
正解と解説を見る

正解：（借）前払保険料 30,000円 ／ （貸）保険料 30,000円

翌期分3か月は120,000円×3/12＝30,000円。費用計上済みのため前払保険料へ振り替える。
