韓国語能力試験（TOPIK） 予想問題の例

問1（TOPIK I 聞取り）

[듣기 대본] 여자: 민수 씨, 지금 어디에 가요? 남자: 도서관에 가요. 한국어 책을 빌릴 거예요. 질문: 남자는 어디에 갑니까?

  1. 서점
  2. 학교
  3. 교실
  4. 도서관
正解と解説を見る

正解：도서관

남자는 한국어 책을 빌리러 도서관에 간다고 했습니다. 따라서 정답은 도서관입니다.

問2（TOPIK II 読解）

次の文を正しい順番に並べるとどのようになりますか？1. 彼は毎日韓国語を勉強しています。 2. 韓国語の実力が上がっています。 3. あきらめずに続けているからです。

  1. 1 → 2 → 3
  2. 1 → 3 → 2
  3. 2 → 1 → 3
  4. 3 → 1 → 2
正解と解説を見る

正解：1 → 3 → 2

勉強している(1)理由の説明(3)があり、その結果実力が上がる(2)という流れが自然です。

問3（TOPIK II 作文）

資料作文の例として最も適切なのはどれですか？

  1. 感想文のように自由に書く
  2. 新聞記事の内容を簡潔にまとめる
  3. 与えられた図表を基に説明文を書く
  4. 自分の意見を詳しく述べる
正解と解説を見る

正解：与えられた図表を基に説明文を書く

資料作文は資料を読み取り、それに基づいて説明する形式です。

問4（TOPIK I 聞取り）

[듣기 대본] 남자: 지금 뭐 해요? 여자: 방에서 한국어 책을 읽어요. 여자는 지금 무엇을 해요?

  1. 텔레비전을 봐요.
  2. 책을 읽어요.
  3. 음악을 들어요.
  4. 편지를 써요.
正解と解説を見る

正解：책을 읽어요.

女性は部屋で韓国語の本を読んでいると言っているため、正解は「책을 읽어요」です。

問5（TOPIK II 読解）

次の文の順序としてもっとも適切なものはどれですか？1. 韓国料理は辛味が特徴的です。 2. 多くの料理には唐辛子が使われています。 3. そのため、辛い味を好む人が多いです。

  1. 1 → 2 → 3
  2. 2 → 1 → 3
  3. 3 → 2 → 1
  4. 1 → 3 → 2
正解と解説を見る

正解：1 → 2 → 3

まず特徴(1)、具体例(2)、結論(3)の順に並べるのが自然です。

問6（TOPIK II 作文）

要約作文で重要なポイントはどれか？

  1. 主な内容を簡潔にまとめる
  2. 自分の意見を多く入れる
  3. 元の文章の意図を変える
  4. 文章を長くして詳しく書く
正解と解説を見る

正解：主な内容を簡潔にまとめる

要約作文は内容の核心を短くまとめることが大切です。
