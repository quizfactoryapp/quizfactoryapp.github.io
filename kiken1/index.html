危険物取扱者乙種第1類 予想問題の例

問1（第1類危険物）

塩素酸塩類の性質について正しいものはどれか。

  1. 水にほとんど溶けない。
  2. 強い酸化剤である。
  3. 引火性が高い。
  4. 強い還元剤である。
正解と解説を見る

正解：強い酸化剤である。

塩素酸塩類は強い酸化剤であり、特に有機物と接触すると発火の原因になるため注意が必要である。

問2（性質・火災予防）

硝酸カリウムの性質・火災予防に関する記述として、正しいものはどれか。

  1. 強い還元性を示すため、酸化剤と同じ場所に保管するのが適切である。
  2. 加熱により酸素を放出することがあり、可燃物との混合を避けて保存する。
  3. 水にほとんど溶けないため、消火時に注水しても冷却効果は期待できない。
  4. 常温で自然発火しやすいため、水中に沈めて保存する。
正解と解説を見る

正解：加熱により酸素を放出することがあり、可燃物との混合を避けて保存する。

硝酸カリウムは酸化性固体で、加熱時に酸素を供給し燃焼を助長する。可燃物や還元剤との接触を避ける。

問3（消火・保安）

第一類危険物の硝酸塩類を貯蔵する棚の近くで、木箱が燃え始めた。最も適切な初期消火・保安措置はどれか。

  1. 安全を確保し、危険物容器を移動または冷却しながら、大量の水で木箱を消火する。
  2. 発熱を避けるため注水せず、自然に燃え尽きるまで換気を止める。
  3. 二酸化炭素消火器で窒息消火を主とし、危険物はそのままにする。
  4. 乾燥砂で全面を覆い、酸素を遮断して硝酸塩類の分解を止める。
正解と解説を見る

正解：安全を確保し、危険物容器を移動または冷却しながら、大量の水で木箱を消火する。

硝酸塩類は酸化性固体で燃焼を助けるため、周囲の可燃物を大量の水で消火し、容器を冷却・隔離する。

問4（第1類危険物）

無機過酸化物の主な性質と危険性。

  1. 強い酸化力を持ち、衝撃や摩擦で爆発することがある。
  2. 水に溶けにくく、無害である。
  3. 酸素を放出せず、自己分解しない。
  4. 強い還元力を持ち、安定である。
正解と解説を見る

正解：強い酸化力を持ち、衝撃や摩擦で爆発することがある。

無機過酸化物は強い酸化剤であり、特に衝撃や摩擦により爆発や自己発火の危険があるため注意が必要である。

問5（性質・火災予防）

硝酸アンモニウムの性質・火災予防に関する記述として、正しいものはどれか。

  1. 水と激しく反応して酸素を発生するため、乾燥砂でのみ消火する。
  2. それ自体は不燃性だが酸化性をもち、可燃物や還元性物質との混合を避けて貯蔵する。
  3. 可燃性の白色固体であり、少量の水で窒息消火する。
  4. 加熱しても分解しにくく、火災時は密閉して空気を遮断すれば安全である。
正解と解説を見る

正解：それ自体は不燃性だが酸化性をもち、可燃物や還元性物質との混合を避けて貯蔵する。

硝酸アンモニウムは第1類の酸化性固体で不燃性だが、可燃物との混合や加熱で危険性が増す。大量の水で冷却する。

問6（消火・保安）

第1類危険物の過酸化ナトリウムを貯蔵する場所で小規模な漏えいが見つかった。保安上、最も適切な初期対応はどれか。

  1. 二酸化炭素消火器を噴射して酸化性を弱めてから回収する。
  2. 可燃物を遠ざけ、乾燥した砂などで覆って飛散を防ぎ、保護具を着けて回収する。
  3. 少量の水を散布して湿らせ、反応を抑えてから回収する。
  4. おがくずに吸着させて袋に密封し、空気との接触を断つ。
正解と解説を見る

正解：可燃物を遠ざけ、乾燥した砂などで覆って飛散を防ぎ、保護具を着けて回収する。

過酸化ナトリウムは水や可燃物と反応しやすい。乾燥状態で隔離し、可燃物を避けて処理する。
