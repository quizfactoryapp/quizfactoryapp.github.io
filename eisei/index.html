衛生管理者 予想問題の例

問1（関係法令）

労働安全衛生法において、50人以上の労働者を使用する事業場で選任が義務付けられている衛生管理者の役割はどれか。

  1. 労働者の代わりに労働契約を締結する
  2. 作業環境の維持管理及び従業員の健康管理を行う
  3. 労働基準監督署への報告業務のみを行う
  4. 災害時の緊急対応のみを担当する
正解と解説を見る

正解：作業環境の維持管理及び従業員の健康管理を行う

衛生管理者は作業環境の管理と従業員の健康保持を目的に選任され、健康障害防止のための措置を講じる役割があります。

問2（労働衛生）

作業環境管理における換気の主な目的として最も適切なのはどれか。

  1. 室温を一定に保つため
  2. 有害物質の濃度を低減するため
  3. 照明の明るさを調整するため
  4. 音響環境を改善するため
正解と解説を見る

正解：有害物質の濃度を低減するため

換気は作業環境中の有害物質やガスの濃度を下げ、労働者の健康を守るために行われる。

問3（労働生理）

呼吸の主な役割は何か。体内で酸素を取り込み二酸化炭素を排出することであるが、どの器官がこのガス交換の中心となるか。

  1. 胃
  2. 肺
  3. 腎臓
  4. 肝臓
正解と解説を見る

正解：肺

呼吸の中心は肺で、肺胞で酸素と二酸化炭素のガス交換が行われるため、呼吸機能の主要器官です。

問4（関係法令）

労働基準法に基づく労働時間の上限は、原則として1週間に何時間と定められているか。

  1. 40時間
  2. 36時間
  3. 48時間
  4. 44時間
正解と解説を見る

正解：40時間

労働基準法では、1週間の労働時間の上限を40時間と定めています（法定労働時間）。

問5（労働衛生）

有害物質のばく露により発生しやすい健康障害はどれか。

  1. 熱中症
  2. 振動障害
  3. 腰痛
  4. じん肺
正解と解説を見る

正解：じん肺

じん肺は粉じんばく露により肺に沈着し発症する職業病である。

問6（労働生理）

循環器系において、心臓から全身へ血液を送り出す血管はどれか。

  1. リンパ管
  2. 静脈
  3. 毛細血管
  4. 動脈
正解と解説を見る

正解：動脈

動脈は心臓から酸素を含む血液を全身に送り出す血管であるため、循環の主役です。
