運行管理者試験 旅客 予想問題の例

問1（旅客自動車運送事業法）

一般旅客自動車運送事業の区分に関する次の記述のうち、道路運送法上の分類として正しいものはどれか。

  1. 一般乗合、一般貸切、一般乗用の3種類に区分される。
  2. 一般貸切と一般乗用は同一の事業として扱われる。
  3. 路線、区域、特定、貨物の4種類に区分される。
  4. 一般乗合は旅客自動車運送事業に含まれない。
正解と解説を見る

正解：一般乗合、一般貸切、一般乗用の3種類に区分される。

一般旅客自動車運送事業は、乗合、貸切、乗用の3種類に区分され、許可制の対象となる。

問2（道路運送関係法令）

一般旅客自動車運送事業を新たに経営しようとする者が、道路運送法上、原則として事前に受けなければならない手続として正しいものはどれか。

  1. 営業所所在地の市町村長への届出
  2. 所轄警察署長への認可申請
  3. 国土交通大臣の許可
  4. 運行管理者試験センターへの登録
正解と解説を見る

正解：国土交通大臣の許可

一般旅客自動車運送事業の経営は、道路運送法により国土交通大臣の許可を受ける必要がある。

問3（運転者管理）

一般乗合旅客自動車運送事業者が、運転者ごとに業務記録を作成・保存する場合の保存期間として正しいものはどれか。

  1. 6か月間保存する。
  2. 5年間保存する。
  3. 1年間保存する。
  4. 3年間保存する。
正解と解説を見る

正解：1年間保存する。

一般乗合・特定旅客の業務記録は、運転者等ごとに記録させ、1年間保存する必要がある。

問4（安全運行管理）

一般貸切旅客自動車運送事業者が運行指示書を作成した場合の取扱いとして、法令上適切なものはどれか。

  1. 営業所に保存すればよく、運転者への携行指示は不要である
  2. 旅行業者が作成した行程表があれば運行指示書は不要である
  3. 運行終了後に実績だけを記録すれば作成したことになる
  4. 運転者に携行させ、指示内容に変更があれば適切に指示する
正解と解説を見る

正解：運転者に携行させ、指示内容に変更があれば適切に指示する

運行指示書は作成して運転者に携行させ、運行中の変更時も安全確保に必要な指示を行う。

問5（旅客自動車運送事業法）

一般貸切旅客自動車運送事業の説明として、最も適切なものは次のうちどれか。

  1. 特定の者の需要だけに応じ、国土交通大臣の許可を要しない事業である。
  2. 乗車定員11人以上の自動車を、一個の契約で貸し切って運送する事業である。
  3. 不特定多数の旅客を定期路線で運送する事業である。
  4. 乗車定員11人未満の自動車で個別契約により運送する事業である。
正解と解説を見る

正解：乗車定員11人以上の自動車を、一個の契約で貸し切って運送する事業である。

一般貸切は、乗車定員11人以上の自動車を一個の契約で貸し切って旅客を運送する事業である。

問6（道路運送関係法令）

旅客自動車運送事業者が、運行管理者を選任した場合の道路運送法上の取扱いとして、最も適切なものはどれか。

  1. 運転者全員の同意を得なければ効力を生じない
  2. 選任後、遅滞なく国土交通大臣へ届け出る必要がある
  3. 選任した日から5年ごとに再試験を受けさせる義務がある
  4. 選任は任意であり、届出も不要である
正解と解説を見る

正解：選任後、遅滞なく国土交通大臣へ届け出る必要がある

事業者は運行管理者を選任し、法令に従いその旨を届け出ることが求められる。
