家電製品アドバイザー試験 予想問題の例

問1（AV情報家電）

BS・110度CSによる新4K8K衛星放送を受信するために、テレビ側で特に必要となる機能として最も適切なものはどれか。

  1. 地上デジタル専用チューナー
  2. 新4K8K衛星放送対応チューナー
  3. VHS再生機能
  4. アナログRGB入力端子
正解と解説を見る

正解：新4K8K衛星放送対応チューナー

新4K8K衛星放送は従来の地デジチューナーだけでは受信できず、対応チューナーが必要です。

問2（生活家電）

冷蔵庫の年間消費電力量を比較するとき、同じ定格内容積で省エネ性能が高い機種を選ぶ目安として最も適切なものはどれか。

  1. 冷凍室の温度表示が低いものを選ぶ
  2. ドア数が多いものを選ぶ
  3. 本体重量が重いものを選ぶ
  4. 省エネ基準達成率が高いものを選ぶ
正解と解説を見る

正解：省エネ基準達成率が高いものを選ぶ

省エネ基準達成率は基準に対する効率の目安で、同容量帯の省エネ比較に使いやすい指標です。

問3（CS接客）

高齢の顧客が暖房器具を購入する際の説明として、商品説明義務の観点から最も適切なものはどれか。

  1. 本人が質問しない事項は説明せず、購入意思を優先する
  2. 他社品の欠点を強調し、自店商品の優位性を中心に説明する
  3. 価格と在庫だけを伝え、使い方は取扱説明書に任せる
  4. 安全装置や設置条件、誤使用時の危険を顧客の理解度に合わせて説明する
正解と解説を見る

正解：安全装置や設置条件、誤使用時の危険を顧客の理解度に合わせて説明する

事故防止に関わる機能や使用条件は、顧客属性に応じて分かりやすく説明する必要がある。

問4（家電関連法規）

電気用品安全法において、特定電気用品に表示されるPSEマークの形状として正しいものはどれか。

  1. ひし形のPSEマーク
  2. 星形のPSEマーク
  3. 丸形のPSEマーク
  4. 三角形のPSEマーク
正解と解説を見る

正解：ひし形のPSEマーク

特定電気用品は危険発生のおそれが高い品目で、ひし形PSEマークの表示が必要である。

問5（AV情報家電）

4K放送の映像信号で、従来のフルHD放送と比べた場合の主な特徴として正しいものはどれか。

  1. 録画時には必ず画質がSDに変換される
  2. 音声信号を送れないため外部アンプが必須である
  3. 画素数が約4倍となり、細部まで精細に表示できる
  4. 白黒映像専用で色信号を含まない
正解と解説を見る

正解：画素数が約4倍となり、細部まで精細に表示できる

4KはフルHDの縦横それぞれ約2倍、総画素数で約4倍の解像度を持ちます。

問6（生活家電）

冷蔵庫を設置するとき、省エネ性を保つための取り扱いとして最も適切なものはどれか。

  1. 背面と側面を壁に密着させて放熱を抑える
  2. 冷蔵室に食品を隙間なく詰めて冷気を逃がさない
  3. 直射日光が当たる場所に置いて庫内温度を安定させる
  4. 放熱スペースを確保し、熱源の近くを避ける
正解と解説を見る

正解：放熱スペースを確保し、熱源の近くを避ける

冷蔵庫は周囲へ放熱するため、隙間を確保し熱源を避けると余分な電力消費を抑えられます。
