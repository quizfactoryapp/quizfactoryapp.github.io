ICTプロフィシエンシー検定試験 予想問題の例

問1（タイピング技能）

タッチタイピングの特徴として正しいものはどれですか？

  1. 日本語入力専用のタイピング方法である
  2. キーボードを見ながら打つ方法である
  3. 音声入力の一種である
  4. 視線を画面からそらさずに入力できる技術である
正解と解説を見る

正解：視線を画面からそらさずに入力できる技術である

タッチタイピングとはキーボードを見ずに画面を見ながら入力する技術のことです。

問2（情報モラル・セキュリティ）

個人情報を第三者に提供する際に守るべき基本的なルールとして最も適切なものはどれか？

  1. 本人の同意を得ること
  2. 提供内容を暗号化すること
  3. 提供先を公に知らせること
  4. 提供を拒否できないこと
正解と解説を見る

正解：本人の同意を得ること

個人情報の提供には、事前に本人の同意を得ることが法律で義務付けられています。

問3（コンピュータ知識）

CPUのクロック周波数が高いほど、一般的にどのような影響がありますか？

  1. メモリ容量が増える
  2. ハードディスクの容量が増える
  3. 処理速度が速くなる
  4. 消費電力が減る
正解と解説を見る

正解：処理速度が速くなる

CPUのクロック周波数が高いと、1秒間に処理できる命令数が増え、処理速度が向上するためです。

問4（ネットワーク・Web）

LAN（ローカルエリアネットワーク）に関する説明として正しいものはどれか？

  1. 無線接続のみを利用するネットワークである
  2. 限られた範囲内で複数の機器を接続するネットワークである
  3. インターネットを指すネットワークの一種である
  4. 地理的に広範囲をカバーするネットワークである
正解と解説を見る

正解：限られた範囲内で複数の機器を接続するネットワークである

LANは家庭やオフィスなど狭い範囲内で機器を接続するネットワークです。

問5（タイピング技能）

ローマ字入力における「し」の正しい入力方法はどれですか？

  1. si
  2. sy
  3. ss
  4. sh
正解と解説を見る

正解：si

「し」はローマ字入力でsiと打つのが一般的です。shはしに続く文字と組み合わせる時に使います。

問6（情報モラル・セキュリティ）

著作権法で保護される著作物に該当しないものは次のうちどれか？

  1. 文学作品
  2. 映画作品
  3. 音楽作品の楽譜
  4. アイデアそのもの
正解と解説を見る

正解：アイデアそのもの

著作権法は具体的な表現を保護し、アイデアそのものは保護対象外です。
