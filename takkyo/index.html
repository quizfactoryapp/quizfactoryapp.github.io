賃貸不動産経営管理士 予想問題の例

問1（賃貸管理業法）

賃貸管理業法において、賃貸管理業を営むために必要な届出や許可の制度は何と呼ばれるか。

  1. 賃貸借契約届出制度
  2. 賃貸管理業登録制度
  3. 宅地建物取引業登録制度
  4. 建設業許可制度
正解と解説を見る

正解：賃貸管理業登録制度

賃貸管理業を営むには「賃貸管理業登録制度」に基づいて登録を受ける必要があるため、正しい制度名はこれです。

問2（契約）

賃貸借契約において、敷金の主な目的として正しいものはどれか。

  1. 管理会社への手数料として預ける金銭
  2. 家賃の前払いとしての保全
  3. 借主の契約違反や原状回復費用の担保
  4. 礼金の代わりに支払う費用
正解と解説を見る

正解：借主の契約違反や原状回復費用の担保

敷金は借主が契約違反した場合や原状回復費用を担保するための保証金であるため、敷金の主目的はこれにあたる。

問3（建物管理）

建物の外壁にひび割れが生じた場合、まず行うべき対応として最も適切なものはどれか。

  1. 建物全体の解体を検討する
  2. 表面の補修塗装を即座に実施する
  3. ひび割れの原因と進行状況を調査する
  4. 入居者に避難勧告を出す
正解と解説を見る

正解：ひび割れの原因と進行状況を調査する

ひび割れが見つかったら、まず原因と進行状況を調査し、適切な補修計画を立てることが重要です。

問4（税金・保険）

賃貸不動産の家賃収入に対して課される所得税の計算において、必要経費に含まれないものは次のうちどれか。

  1. 火災保険料
  2. 土地の購入代金
  3. 固定資産税
  4. 減価償却費
正解と解説を見る

正解：土地の購入代金

土地は減価償却資産ではなく、購入代金は必要経費に含まれません。

問5（賃貸管理業法）

賃貸管理業登録の申請を行う際、欠格事由に該当する者はどのように扱われるか。

  1. 仮登録が認められる
  2. 特別講習の受講が義務付けられる
  3. 登録が一時的に保留される
  4. 登録が拒否される
正解と解説を見る

正解：登録が拒否される

欠格事由に該当すると登録が拒否され、賃貸管理業を営むことはできません。

問6（契約）

サブリース契約において、サブリース業者が貸主に対して負う主な義務はどれか。

  1. 建物の大規模修繕を実施すること
  2. 借主の家賃支払いを保証すること
  3. 借主と直接契約を締結しないこと
  4. 固定資産税の納付を代行すること
正解と解説を見る

正解：借主の家賃支払いを保証すること

サブリース業者は貸主に対して家賃保証の義務を負い、借主からの家賃回収を行うことで貸主の収益の安定を図る。
