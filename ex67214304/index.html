歴史能力検定 予想問題の例

問1（日本古代史）

645年、中大兄皇子と中臣鎌足らが蘇我氏本宗家を倒した政変について、その後の政治改革と結びつけて一般に何と呼ばれるか。

  1. 保元の乱
  2. 大化改新
  3. 承平・天慶の乱
  4. 壬申の乱
正解と解説を見る

正解：大化改新

乙巳の変後、中大兄皇子らが進めた中央集権化の改革を、年号にちなみ大化改新という。

問2（日本中世史）

源頼朝が鎌倉に置いた侍所・公文所（のち政所）・問注所のうち、御家人の統制や軍事・警察を担当した機関はどれか。

  1. 侍所
  2. 公文所
  3. 問注所
  4. 六波羅探題
正解と解説を見る

正解：侍所

侍所は御家人の統制や軍事・警察を担った。公文所は政務、問注所は訴訟を扱った。

問3（日本近現代史）

五箇条の御誓文に示された新政府の基本方針として、もっとも適切なものはどれか。

  1. 公議世論の尊重と開国和親
  2. 武士身分の特権拡大
  3. 幕府による諸藩統制の強化
  4. 鎖国体制の復活と攘夷の徹底
正解と解説を見る

正解：公議世論の尊重と開国和親

五箇条の御誓文は公議世論の尊重や旧来の陋習打破、知識を世界に求める方針を掲げた。

問4（世界史）

メソポタミア文明について述べた文として最も適切なものはどれか。河川、文字、法典に関する特徴に注意して選べ。

  1. インダス川流域で発達し、モヘンジョ＝ダロなどの計画都市を築いた。
  2. 黄河流域で発達し、甲骨文字による占いが政治に用いられた。
  3. ティグリス・ユーフラテス川流域で発達し、楔形文字やハンムラビ法典を生んだ。
  4. ナイル川流域で発達し、象形文字とピラミッド建設を特徴とした。
正解と解説を見る

正解：ティグリス・ユーフラテス川流域で発達し、楔形文字やハンムラビ法典を生んだ。

メソポタミア文明は両河川流域に成立し、楔形文字やハンムラビ法典で知られる。

問5（日本古代史）

大化改新後に示された改新の詔の方針として、豪族の私有民・私有地を否定し、国家が土地と人民を支配する原則を何というか。

  1. 班田収授法
  2. 墾田永年私財法
  3. 寄進地系荘園
  4. 公地公民制
正解と解説を見る

正解：公地公民制

公地公民制は、土地と人民を天皇中心の国家が直接支配する律令国家の基本理念である。

問6（日本中世史）

承久の乱後、鎌倉幕府が朝廷の監視と西国御家人の統制を目的として京都に設置した機関はどれか。

  1. 評定衆
  2. 鎮西探題
  3. 引付衆
  4. 六波羅探題
正解と解説を見る

正解：六波羅探題

承久の乱後、幕府は京都に六波羅探題を置き、朝廷監視と西国支配を強化した。
