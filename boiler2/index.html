ボイラー技士二級 予想問題の例

問1（ボイラーの構造）

水管ボイラーの一般的な特徴として最も適切なものはどれか。伝熱面の配置、蒸気発生の速さ、使用圧力の傾向を踏まえて選べ。

  1. 水が管外、燃焼ガスが管内を流れるため低圧小容量に限られる。
  2. 水が管内、燃焼ガスが管外を流れるため高圧・大容量に適し、蒸気発生も比較的速い。
  3. 胴を必要としないので、安全弁を取り付ける必要がない。
  4. 保有水量が常に極めて多く、起動停止に長時間を要するのが特徴である。
正解と解説を見る

正解：水が管内、燃焼ガスが管外を流れるため高圧・大容量に適し、蒸気発生も比較的速い。

水管ボイラーは管内を水が流れ、外側から燃焼ガスで加熱されるため、伝熱性能が高く高圧・大容量運転に向く。

問2（ボイラーの取扱い）

油だきボイラーの点火操作で、点火前に炉内を十分にプレパージする主な目的として、最も適切なものはどれか。

  1. 蒸気圧を速く上昇させる
  2. 水位計の指示を上げる
  3. 給水温度を上げる
  4. 炉内の未燃ガスを排出し爆発を防ぐ
正解と解説を見る

正解：炉内の未燃ガスを排出し爆発を防ぐ

点火前のプレパージは、炉内や煙道内に残る可燃性ガスや油霧を排出し、着火時の炉内爆発を防止するために行う。

問3（燃料・燃焼及び関係法令）

重油だきボイラーで、負荷は一定のまま燃焼用空気だけが不足した。燃焼状態と排ガスの変化として最も適切なものはどれか。

  1. 二酸化炭素が消失し、水蒸気だけになる
  2. 窒素だけが増え、燃焼状態には影響しない
  3. 炉内温度が上がり、すすは著しく減少する
  4. 一酸化炭素やすすが増え、不完全燃焼になりやすい
正解と解説を見る

正解：一酸化炭素やすすが増え、不完全燃焼になりやすい

空気不足では炭素や水素が十分酸化されず、一酸化炭素やすすが増える。不完全燃焼は熱効率も悪化させる。

問4（ボイラーの構造）

自然循環式の水管ボイラーで、上昇管と下降管による水循環が生じる主な理由として最も適切なものはどれか。

  1. 給水ポンプの吐出圧が常に上昇管と下降管の循環を直接つくるから。
  2. 加熱された上昇管側と比較的低温の下降管側との密度差により、自然に循環が起こるから。
  3. 蒸気ドラム内の圧力変動が周期的に水を吸い上げるから。
  4. 下降管内で蒸気が多量に発生し、その浮力で水が押し上げられるから。
正解と解説を見る

正解：加熱された上昇管側と比較的低温の下降管側との密度差により、自然に循環が起こるから。

自然循環は、加熱で軽くなった上昇管内の混合流体と、比較的重い下降管内の水との密度差で生じる。

問5（ボイラーの取扱い）

手動で点火する炉筒煙管ボイラーにおいて、着火直後の火炎を監視するときの取扱いとして、最も適切なものはどれか。

  1. のぞき窓を開けたままその場を離れる
  2. 直ちに燃料弁を全開にする
  3. 火炎の安定を確認しながら燃料と空気を徐々に調整する
  4. 水面計のコックをすべて閉じる
正解と解説を見る

正解：火炎の安定を確認しながら燃料と空気を徐々に調整する

着火直後は失火や逆火が起こりやすいため、火炎の状態を見ながら燃料量と空気量を段階的に調整し安定燃焼へ導く。

問6（燃料・燃焼及び関係法令）

同じ負荷で燃焼を続ける油だきボイラーで、排ガス中の酸素濃度が必要以上に高い。最も起こりやすい影響はどれか。

  1. 火炎が短くなり、必ずすすが増える
  2. 給水温度が上がり、蒸発量が増す
  3. 過剰空気で排ガス損失が増え、ボイラー効率が下がる
  4. 煙突通風が不要になる
正解と解説を見る

正解：過剰空気で排ガス損失が増え、ボイラー効率が下がる

必要以上の空気は燃焼には寄与せず、余分な空気を加熱して煙突へ捨てるため、排ガス損失が増えて効率が下がる。
