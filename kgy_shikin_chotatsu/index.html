資金繰りの基礎 予想問題の例

問1（資金繰りの基礎）

資金繰りの基本的な目的として、最も適切なものはどれですか。利益の大きさだけでなく、日々の支払い能力に注目して考える必要があります。

  1. 売上高をできるだけ大きく見せること
  2. 法人税の申告書を作成すること
  3. 必要な時期に必要な現金を確保すること
  4. 固定資産を必ず増やすこと
正解と解説を見る

正解：必要な時期に必要な現金を確保すること

資金繰りは、入金と出金の時期を把握し、支払期限に現金不足を起こさないよう管理することです。

問2（資金調達の手段）

銀行融資における「プロパー融資」の一般的な説明として、最も適切なものはどれですか。

  1. 信用保証協会の保証を付けず、銀行が自らの判断とリスクで行う融資
  2. 国が返済を免除することを前提に行う給付型の資金提供
  3. 補助対象経費の支出前に全額が交付される制度
  4. 株式の発行により投資家から返済不要の資金を受ける方法
正解と解説を見る

正解：信用保証協会の保証を付けず、銀行が自らの判断とリスクで行う融資

プロパー融資は保証協会を利用せず、銀行が審査し貸倒リスクを負う融資です。

問3（ファクタリングの仕組み）

ファクタリングの基本的な仕組みとして、最も適切な説明はどれですか。売掛金の入金前に資金化する点に注目してください。

  1. 売掛債権をファクタリング会社へ売却し、手数料を差し引いた資金を受け取る仕組み
  2. 将来の売上予測を担保に株式を発行する仕組み
  3. 買掛金の支払期限を法律上自動的に延長する仕組み
  4. 銀行から売掛金と同額を必ず無利息で借り入れる仕組み
正解と解説を見る

正解：売掛債権をファクタリング会社へ売却し、手数料を差し引いた資金を受け取る仕組み

ファクタリングは売掛債権の売却による資金調達で、通常は手数料控除後の金額を受け取ります。

問4（リスクと注意点）

資金調達の契約書を確認する際、一般的に最も重視すべき基本項目として適切なものはどれか。

  1. 金利、返済期限、担保・保証、手数料などの条件
  2. 広告に掲載された最大融資額だけ
  3. 担当者の印象だけで判断すること
  4. 契約書の文字数が少ないこと
正解と解説を見る

正解：金利、返済期限、担保・保証、手数料などの条件

契約内容は返済負担を左右するため、金利・期限・担保保証・手数料などを確認するのが基本です。

問5（資金繰りの基礎）

キャッシュフローについての説明として、最も適切なものはどれですか。会計上の利益とは異なる視点で、会社のお金の動きを確認します。

  1. 会社の売上総利益率だけを示す指標
  2. 一定期間の現金および現金同等物の増減
  3. 株主総会で必ず決議する配当額
  4. 在庫商品の販売単価の一覧
正解と解説を見る

正解：一定期間の現金および現金同等物の増減

キャッシュフローは、一定期間における現金の流入と流出を表し、資金の実際の動きを見るための概念です。

問6（資金調達の手段）

日本政策金融公庫の主な役割として、一般的に正しいものはどれですか。

  1. 中小企業や創業者などへ政策目的に沿った融資を行う公的金融機関
  2. 上場企業だけを対象に株式投資を行う民間金融機関
  3. すべての補助金を審査なしで自動交付する機関
  4. 税務申告書を作成し、納税額を確定する行政機関
正解と解説を見る

正解：中小企業や創業者などへ政策目的に沿った融資を行う公的金融機関

日本政策金融公庫は、公的金融機関として創業者や中小企業等への融資を担います。
