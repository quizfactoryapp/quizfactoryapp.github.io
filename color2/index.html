色彩検定2級 予想問題の例

問1（色彩基礎）

光の三原色（RGB）による加法混色で、赤（R）と緑（G）の光を同じ強さで重ね、青（B）を加えない場合に生じる色はどれか。

  1. 青紫
  2. シアン
  3. 黄
  4. マゼンタ
正解と解説を見る

正解：黄

加法混色ではRとGの光を重ねると黄になる。シアンはG+B、マゼンタはR+Bで生じる。

問2（色彩心理）

同じ大きさ・同じ明度の赤と青の円を、灰色の背景上に並べて観察したときの見え方として最も適切なものはどれか。

  1. 赤は青より後退して見え、青は赤より進出して見えやすい。
  2. 赤と青は同じ明度なら、進出・後退の差はほとんど生じない。
  3. 赤は青より進出して見え、青は赤より後退して見えやすい。
  4. 青は赤より膨張して見え、赤は青より収縮して見えやすい。
正解と解説を見る

正解：赤は青より進出して見え、青は赤より後退して見えやすい。

暖色系の赤は進出色として手前に見えやすく、寒色系の青は後退色として奥に見えやすい。

問3（配色実務）

インテリアの配色計画で、床・壁・天井など広い面を落ち着いた色にし、クッションや小物で変化をつけたい。一般的な面積比の考え方として、アクセントカラーの比率に最も近いものはどれか。

  1. 約70％
  2. 約25％
  3. 約5％
  4. 約50％
正解と解説を見る

正解：約5％

インテリア配色では、ベースカラー約70％、アソートカラー約25％、アクセントカラー約5％が目安とされる。

問4（UC級領域）

次の色見本の中で、色覚多様性に配慮した判別しやすい配色はどれか。

  1. 配色D（ピンク系と赤系の組合せ）
  2. 配色B（赤と緑の組合せ）
  3. 配色C（黄と緑の組合せ）
  4. 配色A（青系と橙系の組合せ）
正解と解説を見る

正解：配色A（青系と橙系の組合せ）

青系と橙系は色覚異常でも判別しやすい代表的な配色です。赤と緑は判別が難しい場合があります。

問5（色彩基礎）

光の三原色（RGB）による加法混色について、赤（R）と緑（G）の光を同じ強さで重ねたときに生じる色として最も適切なものはどれか。

  1. マゼンタ
  2. シアン
  3. 黄
  4. 青紫
正解と解説を見る

正解：黄

加法混色では、赤と緑の光を重ねると黄になる。シアンは緑＋青、マゼンタは赤＋青で生じる。

問6（色彩心理）

色彩心理における進出色・後退色の説明として、最も適切なものを選べ。

  1. 一般に青や青緑などの寒色系は、実際より近く大きく感じられやすい。
  2. 進出・後退の感じ方は色相ではなく、主に形の複雑さだけで決まる。
  3. 一般に赤や黄などの暖色系は、実際より近くにあるように感じられやすい。
  4. 低彩度の無彩色は、常に高彩度の暖色より強く進出して見える。
正解と解説を見る

正解：一般に赤や黄などの暖色系は、実際より近くにあるように感じられやすい。

暖色系は進出色として近くに感じられやすく、寒色系は後退色として遠くに感じられやすい。
