問1（大気関係）

大気汚染防止法における「ばい煙」に通常含まれないものとして、最も適切なものはどれか。

  1. 有害物質として規制されるカドミウム及びその化合物
  2. 物の燃焼に伴い発生するばいじん
  3. 燃料の燃焼に伴い発生する硫黄酸化物
  4. 揮発性有機化合物として排出されるトルエン
正解と解説を見る

正解：揮発性有機化合物として排出されるトルエン

ばい煙は硫黄酸化物、ばいじん、有害物質を指す。VOCは別の規制区分で扱われる。

問2（水質関係）

水質汚濁防止法に基づく一律排水基準について、BODとCODの適用水域の組合せとして正しいものはどれか。

  1. BODは湖沼、CODは河川に限り適用される
  2. BODは海域、CODは河川への排出水に限り適用される
  3. BODは河川、CODは海域および湖沼への排出水に適用される
  4. BODとCODはいずれも地下浸透水だけに適用される
正解と解説を見る

正解：BODは河川、CODは海域および湖沼への排出水に適用される

有機汚濁指標の適用は水域特性で異なり、BODは河川、CODは海域・湖沼への排出水に用いられる。

問3（騒音・振動関係）

騒音規制法における「特定施設」の説明として最も適切なものはどれか。工場又は事業場に設置される施設に関する法令上の定義を問う。

  1. 著しい騒音を発生する施設で、政令で定めるものをいう。
  2. 敷地境界で環境基準を超えた施設だけをいう。
  3. すべての原動機付き機械を、出力にかかわらず一律にいう。
  4. 建設作業にだけ用いる移動式機械をいう。
正解と解説を見る

正解：著しい騒音を発生する施設で、政令で定めるものをいう。

特定施設は、著しい騒音を発生する工場・事業場内の施設で、施行令により種類や規模が定められる。

問4（粉じん・ダイオキシン類）

一般粉じん発生施設に係る大気汚染防止法上の規制として、事業者に求められる措置の説明で最も適切なものはどれか。

  1. すべての施設で煙突高さに応じたK値規制を受ける。
  2. 施設の構造、使用及び管理に関する基準を遵守し、飛散防止を図る。
  3. 排出口濃度を常時自動測定し、1時間値で基準適合を判定する。
  4. 年1回の敷地境界濃度測定だけで規制適合を確認する。
正解と解説を見る

正解：施設の構造、使用及び管理に関する基準を遵守し、飛散防止を図る。

一般粉じんは排出口濃度規制ではなく、施設の構造・使用・管理基準により飛散防止を図る点が基本である。

問5（大気関係）

燃料中の硫黄分が燃焼時にすべてSO2になると仮定した場合、SO2排出量の増減に最も直接影響する因子はどれか。

  1. 燃料中の窒素分
  2. 燃料中の硫黄分と燃料使用量
  3. 排ガス中の酸素濃度のみ
  4. 燃焼空気の相対湿度
正解と解説を見る

正解：燃料中の硫黄分と燃料使用量

SO2排出量は燃料に含まれる硫黄量にほぼ比例するため、硫黄分と使用量が支配的である。

問6（水質関係）

BOD測定で、試料を20℃で5日間培養する主な目的として最も適切なものはどれか。

  1. 微生物による有機物分解で消費される溶存酸素量を求めるため
  2. 懸濁物質を自然沈降させ、透明度を測定するため
  3. 水中の全窒素を硝酸態窒素へ完全酸化するため
  4. 重金属イオンを沈殿させ、その質量を求めるため
正解と解説を見る

正解：微生物による有機物分解で消費される溶存酸素量を求めるため

BODは好気性微生物が有機物を分解する際に消費する酸素量を表す指標で、5日間培養で評価する。
