日経TEST 予想問題（無料・全問解説付き）

日経TEST対策ドリルは、日経TESTの出題分野に沿ったオリジナル予想問題224問を収録した学習ドリルです。すべての問題に解説が付いているので、間違えた問題もその場で理解できます。ページ上部のWeb版では20問を無料で体験でき、スマホアプリ版では全224問に取り組めます。

日経TEST 予想問題の例

問1（経済）

GDP（国内総生産）に含まれないのは次のうちどれか？

  1. 政府の公共投資
  2. 民間企業の設備投資
  3. 個人の中古車売買
  4. 輸出による収入
正解と解説を見る

正解：個人の中古車売買

GDPは一定期間内に新たに生産された財・サービスのみ計上され、中古品の取引は含まれません。

問2（経営・ビジネス）

企業が持続的な競争優位を築くために重要とされるリソースや能力を統合・活用する戦略は何と呼ばれるか？

  1. ポートフォリオ戦略
  2. ブルーオーシャン戦略
  3. コストリーダーシップ戦略
  4. リソース・ベースト・ビュー
正解と解説を見る

正解：リソース・ベースト・ビュー

リソース・ベースト・ビューは企業が保有する独自の資源や能力に着目し、持続的な競争優位の獲得を目指す戦略論です。

問3（社会・国際）

世界の人口増加の主な要因として最も影響が大きいものはどれか。

  1. 移民の増加
  2. 死亡率の低下
  3. 平均寿命の減少
  4. 出生率の増加
正解と解説を見る

正解：死亡率の低下

世界人口増加は主に医療技術の発展などによる死亡率の低下が要因となっている。

問4（金融・会計）

貸借対照表における「流動資産」に該当しないものはどれか？

  1. 商品
  2. 売掛金
  3. 現金及び預金
  4. 土地
正解と解説を見る

正解：土地

土地は固定資産に分類され、流動資産には該当しません。

問5（経済）

日本銀行が金融政策で行う「公開市場操作」とは何か？

  1. 国債などの売買を通じて市場の資金量を調整すること
  2. 為替レートを固定すること
  3. 銀行に直接貸し付けを行うこと
  4. 財政支出の増減を決めること
正解と解説を見る

正解：国債などの売買を通じて市場の資金量を調整すること

公開市場操作は日銀が国債などを売買し、市中の資金量を調整する政策手段です。

問6（経営・ビジネス）

M&Aにおいて「デューデリジェンス」とは何を指すか？

  1. 買収後の統合プロセス
  2. 買収資金の調達方法
  3. 買収契約書の作成
  4. 買収対象企業の詳細な調査・分析
正解と解説を見る

正解：買収対象企業の詳細な調査・分析

デューデリジェンスは買収対象の財務・法務・事業状況などを詳細に調査し、リスクや価値を評価するプロセスです。
