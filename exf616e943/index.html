問1（高圧ガス保安法）

高圧ガスの販売事業を新たに営もうとする者の手続として、法令上もっとも適切なものはどれか。

  1. 販売数量が少量であれば、すべての高圧ガスについて届出は不要である。
  2. 会社単位で一度だけ、事業開始後30日以内に国へ報告すれば足りる。
  3. 販売所ごとに、事業開始の日の20日前までに都道府県知事へ届け出る。
  4. 販売先が法人に限られる場合は、貯蔵の有無にかかわらず許可だけで足りる。
正解と解説を見る

正解：販売所ごとに、事業開始の日の20日前までに都道府県知事へ届け出る。

販売事業は販売所ごとの届出が基本で、開始前の期限管理が重要である。

問2（液化石油ガス）

液化石油ガス容器内で、プロパンとブタンが混合している場合、低温時の供給圧力に最も大きく影響する性質はどれか。

  1. 混合比は供給圧力に影響せず、容器容量だけで決まる
  2. ブタンはプロパンより蒸気圧が低く、低温で気化しにくい
  3. プロパンとブタンの蒸気圧は温度に関係なく同じである
  4. ブタンはプロパンより蒸気圧が高く、低温でも気化しやすい
正解と解説を見る

正解：ブタンはプロパンより蒸気圧が低く、低温で気化しにくい

ブタンは低温で蒸気圧が下がりやすく、寒冷時の供給能力低下を招くため、混合比の理解が重要です。

問3（保安管理技術）

可燃性ガスを扱う販売事業所で、漏えいの初期確認として最も適切な方法はどれか。

  1. 臭気を頼りに発生箇所を直接吸い込んで確認する
  2. 火気を近づけて燃焼の有無を確認する
  3. 検知器や石けん水を用い、換気と火気管理を行いながら確認する
  4. 圧力を上げて漏えい音を大きくして確認する
正解と解説を見る

正解：検知器や石けん水を用い、換気と火気管理を行いながら確認する

漏えい確認は火気を避け、検知器や発泡液を用いる。換気と着火源管理を同時に行うことが重要である。

問4（供給設備）

バルク貯槽の設置管理について、腐食や沈下による事故を防ぐために最も適切な日常確認はどれか。

  1. 安全弁が付いていれば、外面腐食の確認は省略できる
  2. 塗装の色だけを確認し、支持部や基礎は定期検査時まで見ない
  3. 液面計の表示が読めれば、周囲の排水状態は確認しなくてよい
  4. 基礎、脚部、固定部、周囲の滞水や腐食の有無を目視で確認する
正解と解説を見る

正解：基礎、脚部、固定部、周囲の滞水や腐食の有無を目視で確認する

貯槽本体だけでなく、支持部や基礎、滞水環境を確認することで、転倒や漏えいの予防につながる。

問5（高圧ガス保安法）

販売業者が届出済みの販売所で、取り扱う高圧ガスの種類を追加又は変更した場合の対応として正しいものはどれか。

  1. 販売先から求められた場合に限り、変更届を提出する。
  2. 年末にまとめて帳簿へ記載すれば、行政庁への届出は不要である。
  3. 変更内容について、遅滞なく都道府県知事へ届け出る。
  4. 変更した日から5年間は試験販売として扱え、届出を猶予できる。
正解と解説を見る

正解：変更内容について、遅滞なく都道府県知事へ届け出る。

販売するガスの種類変更は保安管理に直結するため、遅滞ない変更届が必要となる。

問6（液化石油ガス）

プロパン容器を屋外に設置する際、容器交換作業の安全確保として最も適切な考え方はどれか。

  1. 容器弁を開けたまま接続部を外し、残ガスを抜きながら交換する
  2. 交換時間を短くするため、漏えい確認は異臭がある場合だけ行う
  3. 直射日光で温めてから交換すると残液が減り安全性が高まる
  4. 転倒防止を行い、火気を避け、接続後は漏えい確認を行う
正解と解説を見る

正解：転倒防止を行い、火気を避け、接続後は漏えい確認を行う

容器交換では転倒防止、火気管理、弁閉止、接続部の確実な締付けと漏えい確認が基本です。
