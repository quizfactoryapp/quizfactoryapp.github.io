ネットワークスペシャリスト 予想問題の例

問1（プロトコル）

TCPのコネクション確立に使われる3ウェイハンドシェイクの正しい順序は？

  1. SYN → ACK → SYN-ACK
  2. SYN-ACK → SYN → ACK
  3. ACK → SYN → SYN-ACK
  4. SYN → SYN-ACK → ACK
正解と解説を見る

正解：SYN → SYN-ACK → ACK

TCP接続確立時は、クライアントからSYNを送りサーバがSYN-ACKで応答し、クライアントがACKで応答する3ステップの通信が行われる。

問2（ルーティング・SW）

OSPFにおけるDR（Designated Router）の役割は何か？

  1. BGPピアの確立を担当する
  2. ネットワーク内のLSAを集約して配布する
  3. OSPFの認証情報を管理する
  4. 全てのルーターのルーティングテーブルを管理する
正解と解説を見る

正解：ネットワーク内のLSAを集約して配布する

DRはOSPFのマルチアクセスネットワーク（例：Ethernet）でLSAを効率的に配布するための代表ルーターである。

問3（セキュリティ）

ファイアウォールに関する説明として正しいものはどれか。

  1. データを暗号化し、通信の秘匿性を確保する装置である。
  2. ネットワーク間の通信を監視・制御し、不正アクセスを防止する装置である。
  3. ウェブアプリケーションの脆弱性を診断・修正する装置である。
  4. 内部ネットワークの全ての通信を許可する装置である。
正解と解説を見る

正解：ネットワーク間の通信を監視・制御し、不正アクセスを防止する装置である。

ファイアウォールはネットワーク間の通信を監視・制御し、不正アクセスや攻撃から内部ネットワークを保護する装置です。

問4（ネットワーク設計）

冗長化構成の目的として適切なものはどれか？

  1. コストを削減すること
  2. 通信遅延を完全にゼロにすること
  3. ネットワークのスループットを最大化すること
  4. 障害発生時もサービスを継続可能にすること
正解と解説を見る

正解：障害発生時もサービスを継続可能にすること

冗長化はネットワーク機器や経路を重複させ、故障発生時でもサービスを継続できるようにすることが目的である。

問5（プロトコル）

HTTPステータスコード200の意味は？

  1. リダイレクト
  2. リクエストエラー
  3. サーバエラー
  4. 成功
正解と解説を見る

正解：成功

HTTPステータスコード200はリクエストが正常に処理されレスポンスが返されたことを示す。

問6（ルーティング・SW）

BGPの経路選択基準で最も優先されるものは？

  1. ASパス長
  2. 最も低いMED値
  3. 最も遅いルート
  4. ローカルプリファレンスの値
正解と解説を見る

正解：ローカルプリファレンスの値

BGPの経路選択基準では、まずローカルプリファレンスの値が最も重要で、大きい値が優先される。
