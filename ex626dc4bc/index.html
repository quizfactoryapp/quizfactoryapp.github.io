危険物取扱者 乙種第5類 予想問題の例

問1（第5類危険物）

第5類危険物のうち有機過酸化物・ニトロ化合物・アゾ化合物に共通する危険性として、消防法上もっとも適切に説明しているものはどれか。

  1. 常温で必ず自然発火し続ける性質
  2. 自己反応により加熱や衝撃で急激に分解しうる性質
  3. 水と接触すると必ず水素を発生し爆発する性質
  4. 不燃性で酸素を遮断すれば危険性が消える性質
正解と解説を見る

正解：自己反応により加熱や衝撃で急激に分解しうる性質

3群はいずれも自己反応性物質で、熱・衝撃・摩擦で分解が加速し、発熱や爆発的燃焼に至る危険がある点が共通する。

問2（危険性評価）

自己反応性物質の危険性評価で、試料を連続昇温したときの発熱開始温度を把握する目的として、最も適切な説明はどれか。

  1. 比重を推定して容器材質を選ぶため
  2. 中和剤の濃度を決定するため
  3. 熱暴走が始まる温度帯を把握し、保管温度上限を設定するため
  4. 防毒マスクの吸収缶の交換時期だけを決めるため
正解と解説を見る

正解：熱暴走が始まる温度帯を把握し、保管温度上限を設定するため

発熱開始温度は熱暴走の入口を示す重要指標で、保管温度や工程温度の安全上限を決める根拠になる。

問3（保管・消火）

乙種第5類危険物を夏季に倉庫保管している。室温が上がりやすい環境で、自己反応による分解リスクを最も下げる管理として適切なのはどれか。

  1. 作業性向上のため保管前に温める
  2. 直射日光を避けた冷所で保管し、温度を継続監視する
  3. 保管庫内を40℃前後で一定化する
  4. 換気を止めて外気の流入を防ぐ
正解と解説を見る

正解：直射日光を避けた冷所で保管し、温度を継続監視する

第5類は加熱で分解反応が進みやすい。冷所保管と日射遮断、温度監視の併用が反応暴走予防の基本管理となる。

問4（第5類危険物）

有機過酸化物の危険性を理解するうえで重要な構造上の特徴として、最も適切なものを選べ。

  1. 分子内に-N=N-結合をもつこと
  2. 分子内に-O-O-（過酸化）結合をもつこと
  3. 分子内に-NO2基をもつこと
  4. 分子内に-S-S-結合をもつこと
正解と解説を見る

正解：分子内に-O-O-（過酸化）結合をもつこと

有機過酸化物は-O-O-結合をもつ化合物で、この結合が比較的不安定なため、加熱や衝撃で分解しやすく危険性が高い。

問5（危険性評価）

有機過酸化物の保管管理で用いられるSADT（自己促進分解温度）に関する説明として、最も適切なのはどれか。

  1. 反応熱量が最大となる温度だけを示す値
  2. 消火水の凍結温度を示す設備設計値
  3. 一定容器条件で自己加速的分解が起こり得る最低周囲温度の目安
  4. 引火点と同じ意味で、蒸気が点火する最低温度
正解と解説を見る

正解：一定容器条件で自己加速的分解が起こり得る最低周囲温度の目安

SADTは容器条件を含めた熱安定性指標で、自己加速分解の発生可能性を示し、温度管理要否の判断に使う。

問6（保管・消火）

第5類危険物の小分け作業で、容器口に固着物ができ除去が必要になった。摩擦・衝撃による発火危険を最も抑える方法はどれか。

  1. 非火花性工具を使い、衝撃を与えず静かに除去する
  2. 高速回転ブラシで短時間に除去する
  3. 乾いた布で強くこすって取り除く
  4. 金属ハンマーで軽くたたいて剥がす
正解と解説を見る

正解：非火花性工具を使い、衝撃を与えず静かに除去する

第5類は摩擦・衝撃・加熱が着火要因になる。打撃や強いこすり作業を避け、非火花性工具で低刺激に扱うのが正しい。
