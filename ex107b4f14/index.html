サービス接遇検定3級 予想問題の例

問1（サービススタッフの資質）

来店直後のお客様が少し不安そうに周囲を見回している。サービススタッフとして最も適切な対応はどれか。相手の気持ちに配慮したホスピタリティの観点から選びなさい。

  1. 他のお客様の対応が終わるまで入口で待ってもらう
  2. 笑顔で近づき、困りごとはないか短く声をかける
  3. お客様が声をかけるまで様子を見る
  4. 忙しくても目を合わせず作業を続ける
正解と解説を見る

正解：笑顔で近づき、困りごとはないか短く声をかける

相手の不安に気づき、先回りして安心感を与える声かけは、ホスピタリティの基本であり信頼づくりにつながる。

問2（接客応対）

開店直後、入口で立ち止まりながら店内を見回しているお客様が来店した。手が空いている場合、最初のお迎えとして最も適切な応対はどれか。

  1. 「いらっしゃいませ。何かお探しでしたらお声がけくださいませ」と明るく声をかける
  2. すぐに売れ筋商品を説明し始める
  3. お客様から話しかけられるまで完全に待つ
  4. 無言で会釈だけして様子を見る
正解と解説を見る

正解：「いらっしゃいませ。何かお探しでしたらお声がけくださいませ」と明るく声をかける

お迎えでは、来店への歓迎を伝えつつ、お客様が相談しやすい雰囲気をつくることが大切である。押しつけず、感じよく声をかけるのが基本である。

問3（言葉遣い）

お客様が会議室に到着し、担当者へ取り次ぐ場面です。「担当の者にそのように伝えておきます」と言い換える場合、最も適切な敬語表現を選びなさい。

  1. 担当の者にそのように申しておきます
  2. 担当の者にそのように申し伝えておきます
  3. 担当の者にそのようにお伝えされます
  4. 担当の者にそのように言われておきます
正解と解説を見る

正解：担当の者にそのように申し伝えておきます

「申し伝える」は、自分側の者に伝えるときの適切な謙譲表現です。社内の担当者に内容を伝える場面に合った言い方です。

問4（サービススタッフの資質）

身だしなみを整える目的として最も適切なものはどれか。サービススタッフとしての印象だけでなく、お客様に安心感と信頼感を与える視点から答えなさい。

  1. 清潔感を保ち、相手に不快感を与えないため
  2. 同僚より目立って評価されるため
  3. 自分の個性を強く印象づけるため
  4. 店舗のルールより流行を優先するため
正解と解説を見る

正解：清潔感を保ち、相手に不快感を与えないため

身だしなみはおしゃれの競争ではなく、清潔感と整った印象で相手に安心してもらうために整えるものだからである。

問5（接客応対）

館内で売り場の場所を尋ねられた。目的の場所は少し離れているが、今はすぐ対応できる。案内の仕方として最も適切なのはどれか。

  1. 「ご案内いたします」と伝え、歩調を合わせて目的地付近まで先導する
  2. 他の係が通るまでその場で待ってもらう
  3. 地図を渡して一人で行ってもらう
  4. 指で方向だけ示して説明する
正解と解説を見る

正解：「ご案内いたします」と伝え、歩調を合わせて目的地付近まで先導する

案内では、口頭説明だけで済ませず、可能なときは実際にお連れするのが丁寧である。歩く速さにも配慮し、不安なく移動できるようにする。

問6（言葉遣い）

受付で来客に着席を促すときの表現として、サービス接遇上もっとも自然で丁寧なものを選びなさい。相手は取引先の担当者です。

  1. どうぞお掛けになってお待ちください
  2. そこに座ってください
  3. どうぞお掛けくださいませ
  4. お座りしてください
正解と解説を見る

正解：どうぞお掛けになってお待ちください

来客応対では、着席を促す表現にも敬意が必要です。「お掛けになってお待ちください」は自然で丁寧な案内表現です。
