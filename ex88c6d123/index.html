二級小型船舶操縦士 予想問題の例

問1（基本航海）

海図上で2地点間の距離を測るとき、ディバイダーで取った長さは通常どの目盛に当てて海里を読むのが適切か。

  1. 図の上端または下端の経度目盛
  2. 最も近い緯度目盛
  3. 海図内の等深線の間隔
  4. コンパスローズの外周目盛
正解と解説を見る

正解：最も近い緯度目盛

緯度1分は1海里に相当するため、測った地点に近い緯度目盛で距離を読むのが基本です。

問2（船舶交通ルール）

夜間、航行中に常時適切な見張りを行う目的として、最も適切なものはどれか。

  1. 燃料消費を少なくするため
  2. 同乗者に操縦を任せやすくするため
  3. 衝突のおそれや周囲の危険を早期に判断するため
  4. 船位を海図上に正確に記入するためだけ
正解と解説を見る

正解：衝突のおそれや周囲の危険を早期に判断するため

見張りは視覚・聴覚などを用い、他船や障害物、衝突のおそれを早期に把握するために行う。

問3（安全運航）

出航前に同乗者へ救命胴衣を配るとき、船長として最も適切な確認はどれか。

  1. 操縦者だけが着用し、同乗者は座席下に保管する
  2. 体格に合うものを正しく着用させ、ベルト等の締まりを確認する
  3. 暑い日は着用を任意とし、落水時だけ着けるよう指示する
  4. 人数分を船内に積んでいれば、着用方法の説明は省略できる
正解と解説を見る

正解：体格に合うものを正しく着用させ、ベルト等の締まりを確認する

救命胴衣は備えるだけでなく、体格に合うものを正しく着用して初めて効果を発揮する。

問4（実技操船）

直進中、艇首が風下へ少し流され始めた。目標物に向けて安定して進むための舵と見張りの使い方として最も適切なのはどれか。

  1. 流される方向へ大きく舵を取り続ける
  2. 目標物と船首のずれを見ながら小舵で早めに修正する
  3. 機関を中立にして自然に向きが戻るのを待つ
  4. 船首方位だけを見て周囲の見張りは後回しにする
正解と解説を見る

正解：目標物と船首のずれを見ながら小舵で早めに修正する

直進では目標物とのずれを早めに確認し、小舵で修正する。大舵や見張り不足は不安定な操船につながる。

問5（基本航海）

真方位090度で航行中、付近の磁針偏差が西偏7度で自差が東偏2度のとき、操舵すべきコンパス方位はどれか。

  1. 081度
  2. 085度
  3. 099度
  4. 095度
正解と解説を見る

正解：095度

西偏は加え、東偏は差し引いて磁針方位を求めるため、090+7-2で095度となります。

問6（船舶交通ルール）

互いに視認できる動力船同士が正面から行き会い、衝突のおそれがある場合の基本動作はどれか。

  1. 速力を増して先に通過する船を決める
  2. 両船とも左に転針して右舷対右舷で通過する
  3. 両船とも右に転針して左舷対左舷で通過する
  4. 保持船と避航船を決め、保持船だけが進路を変える
正解と解説を見る

正解：両船とも右に転針して左舷対左舷で通過する

行会い船では、両船が避航動作をとり、原則として各船が右転して安全に通過する。
