第二種電気工事士 予想問題の例

問1（電気理論）

抵抗と誘導性リアクタンスをもつ交流回路のインピーダンス計算。

  1. 5Ω
  2. 1Ω
  3. 7Ω
  4. 12Ω
正解と解説を見る

正解：5Ω

インピーダンスは抵抗とリアクタンスのベクトルの和の大きさ。

問2（配電・機器）

理想変圧器の一次側電圧が200V、二次側電圧が100Vである。二次側に10Aの電流が流れているとき、一次側電流は何Aか。

  1. 2.5A
  2. 5A
  3. 20A
  4. 10A
正解と解説を見る

正解：5A

理想変圧器では一次側と二次側の電力が等しい。100V×10A=200V×一次電流より、一次電流は5A。

問3（施工方法）

低圧屋内配線のケーブル工事で、VVFケーブルを造営材に沿って露出して施設する場合、支持点間の距離として適切なものはどれか。

  1. 2.0m以下
  2. 1.0m以下
  3. 3.0m以下
  4. 4.0m以下
正解と解説を見る

正解：2.0m以下

ケーブルを造営材に沿って施設する場合、支持点間の距離は原則2m以下とする。

問4（法令・検査）

低圧屋内配線の絶縁抵抗測定を行った。使用電圧が単相2線式100Vの電路について、電気設備技術基準の解釈で定める絶縁抵抗値の最小限度として、正しいものはどれか。

  1. 0.4MΩ
  2. 0.05MΩ
  3. 0.1MΩ
  4. 0.2MΩ
正解と解説を見る

正解：0.1MΩ

使用電圧300V以下で対地電圧150V以下の低圧電路は、絶縁抵抗値が0.1MΩ以上必要である。

問5（電気理論）

三相交流回路の線間電圧と相電圧の関係。

  1. 380V
  2. 440V
  3. 220V
  4. 127V
正解と解説を見る

正解：380V

線間電圧は相電圧に√3倍する。

問6（配電・機器）

三相誘導電動機の回転方向を逆にしたい。電源側の配線で行う方法として、正しいものはどれか。

  1. 3本の電源線のうち任意の2本を入れ替える。
  2. 接地線と電源線の1本を入れ替える。
  3. 中性線を追加して接続する。
  4. 3本の電源線をすべて入れ替える。
正解と解説を見る

正解：3本の電源線のうち任意の2本を入れ替える。

三相誘導電動機は相順を変えると回転方向が逆になる。任意の2線を入れ替えると相順が反転する。
