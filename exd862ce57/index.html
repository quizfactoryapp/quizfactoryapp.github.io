一級建築士 予想問題の例

問1（学科I・II 計画・環境設備）

プロセニアム形式の劇場で、同じ客席面積を保ちながら後方席から舞台への視線の重なりを軽減する計画として、最も適切なのはどれか。

  1. 最前列の座面高さを高くする
  2. 通路幅を広くして座席列数を増やす
  3. 前方席ほど天井高を低くする
  4. 客席を千鳥配置とする
正解と解説を見る

正解：客席を千鳥配置とする

千鳥配置は前席の頭部による遮りを避けやすく、同じ床勾配条件でも視線の抜けを確保しやすい。劇場客席計画の基本的手法である。

問2（学科III・IV 法規・構造）

第一種住居地域で、指定容積率300%・前面道路幅員6mの敷地に住宅を計画する。特定行政庁の別指定がない場合、容積率の上限として正しいものはどれか。

  1. 180%
  2. 240%
  3. 200%
  4. 300%
正解と解説を見る

正解：240%

第一種住居地域では、前面道路幅員が12m未満なら道路幅員に0.4を乗じて容積率を求める。6m×0.4=2.4なので240%となる。

問3（学科V・設計製図）

市街地の狭小敷地で中層集合住宅を施工する。近隣歩行者の安全確保と搬入効率を両立する仮設計画として、最も適切なものはどれか。

  1. 敷地内通路を最短化するため、歩行者通路と搬入経路を共用する
  2. 仮囲い開口部を常時開放し、車両待機を道路上で処理する
  3. 作業半径を優先し、第三者通行部分の上空養生は省略する
  4. 工事車両と歩行者の動線を可能な限り分離し、搬入時間帯も調整する
正解と解説を見る

正解：工事車両と歩行者の動線を可能な限り分離し、搬入時間帯も調整する

市街地工事では第三者災害防止が最優先であり、歩車分離と時間調整を併用する計画が、安全性と搬入効率の両面で最も妥当である。

問4（学科I・II 計画・環境設備）

総合病院の外来部門を計画する際、複数診療科の患者が共通して利用する採血・画像診断などの部門配置として、最も適切なのはどれか。

  1. 診療科ごとに個別設置し共用を避ける
  2. 外来部門に近接させる
  3. 救急部門のさらに外側に分散配置する
  4. 病棟専用エリアの奥にまとめる
正解と解説を見る

正解：外来部門に近接させる

共用頻度の高い検査部門を外来部門に近接させると、患者移動が短くなり案内もしやすい。運営効率と利用者負担の両面で有利である。

問5（学科III・IV 法規・構造）

住居系用途地域の居室について採光計算を行ったところ、令の算式による採光補正係数が3.6となった。建築基準法令上、採用する数値として正しいものはどれか。

  1. 1.0
  2. 3.6
  3. 4.0
  4. 3.0
正解と解説を見る

正解：3.0

採光補正係数は用途地域ごとの式で算定するが、上限は3とされる。算出値が3を超えても、そのままではなく3を用いる。

問6（学科V・設計製図）

鉄筋コンクリート造の反復階施工で、各階の躯体工事を短いサイクルで安定して進めたい。工程計画上、最も有効な考え方はどれか。

  1. 各職種の作業量を平準化し、階ごとの作業順序をできるだけ固定する
  2. 揚重機の能力に関係なく、全資材を各階へ先行搬入する
  3. 型枠解体を早めるため、コンクリート強度確認を工程表から外す
  4. 職種間の手待ちを減らすため、全工区を同時着手とする
正解と解説を見る

正解：各職種の作業量を平準化し、階ごとの作業順序をできるだけ固定する

反復階ではタクト化と作業順序の固定が重要で、各職種の投入を平準化すると手待ちや干渉が減り、安定したサイクル工程を組みやすい。
