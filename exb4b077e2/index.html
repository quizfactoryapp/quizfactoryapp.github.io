ビジネス・キャリア検定試験 予想問題の例

問1（人事・労務管理）

採用面接における質問として、応募者の適性や能力の把握という目的に照らして最も適切なものはどれか。

  1. 本籍地や出生地を詳しく尋ねる。
  2. 業務に関連する経験や課題への対応方法を尋ねる。
  3. 支持政党や信条を確認する。
  4. 家族構成や親の職業を確認する。
正解と解説を見る

正解：業務に関連する経験や課題への対応方法を尋ねる。

採用では職務遂行能力に関係する事項を確認し、本人の責任でない事項や思想信条に踏み込まない。

問2（経理・財務管理）

貸借対照表において、企業の短期的な支払能力を判断するために最も直接的に用いられる比率はどれか。

  1. 自己資本比率
  2. 流動比率
  3. 売上高営業利益率
  4. 総資本回転率
正解と解説を見る

正解：流動比率

流動比率は流動資産を流動負債で割った比率で、短期債務への支払余力を示す。

問3（営業・マーケティング）

市場細分化を行う主な目的として最も適切なものはどれか。顧客の異質性を前提に、営業資源を有効配分する観点で選べ。

  1. 全顧客に同一の商品・価格・販促を適用し、管理を単純化するため
  2. 購買特性が似た顧客群を把握し、標的市場に適した施策を設計するため
  3. 市場調査を省略し、営業担当者の経験だけで販売方針を決めるため
  4. 競合企業の販売数量だけを基準に、自社の生産量を決定するため
正解と解説を見る

正解：購買特性が似た顧客群を把握し、標的市場に適した施策を設計するため

市場細分化は、顧客のニーズや行動の違いを整理し、狙う市場に合った製品・価格・販促を展開するために行う。

問4（生産管理）

工程管理において、各作業の前後関係と所要時間を図示し、納期遅延に直結する最長経路を把握する手法として最も適切なものはどれか。

  1. QC工程表
  2. PERT
  3. ABC分析
  4. 5S活動
正解と解説を見る

正解：PERT

PERTは作業の順序関係と所要時間からクリティカルパスを把握し、日程計画に用いる手法である。

問5（人事・労務管理）

配置転換を行う際の人事管理上の留意点として、最も適切なものはどれか。

  1. 本人への説明は不要で、辞令だけで十分である。
  2. 評価の低い社員だけを対象にすべきである。
  3. 本人の能力開発や組織上の必要性を踏まえて説明する。
  4. 異動後の職務内容は着任後まで知らせない。
正解と解説を見る

正解：本人の能力開発や組織上の必要性を踏まえて説明する。

配置転換は組織運営と人材育成の両面から行い、目的や職務内容を適切に説明することが重要である。

問6（経理・財務管理）

損益計算書で、売上高から売上原価を差し引いて算出される利益として正しいものはどれか。

  1. 営業利益
  2. 売上総利益
  3. 経常利益
  4. 税引前当期純利益
正解と解説を見る

正解：売上総利益

売上総利益は売上高から売上原価を控除した利益で、商品の基本的な採算性を表す。
