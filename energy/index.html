エネルギー管理士 予想問題の例

問1（エネルギー総合管理）

省エネ法における特定事業者の指定基準として、事業者全体の年度エネルギー使用量は原油換算でどの水準以上か。

  1. 500kL以上
  2. 1,500kL以上
  3. 3,000kL以上
  4. 1,000kL以上
正解と解説を見る

正解：1,500kL以上

事業者全体で年間のエネルギー使用量が原油換算1,500kL以上の場合、届出と指定の対象となる。

問2（熱分野基礎）

理想気体1 kgを可逆断熱圧縮した。比熱比をκとすると、圧力pと比体積vの関係として正しいものはどれか。

  1. pv^κ=一定
  2. pv^(1/κ)=一定
  3. p/v=一定
  4. pv=一定
正解と解説を見る

正解：pv^κ=一定

可逆断熱過程では熱の出入りがなく、理想気体ではポアソンの式pv^κ=一定が成り立つ。

問3（電気分野基礎）

平衡三相交流回路で、線間電圧200 V、線電流30 A、力率0.8のとき、有効電力として最も近い値はどれか。

  1. 8.3 kW
  2. 4.8 kW
  3. 12.0 kW
  4. 10.4 kW
正解と解説を見る

正解：8.3 kW

三相有効電力は√3VIcosφで求める。√3×200×30×0.8≒8.3 kWである。

問4（エネルギー設備）

ボイラの空気比を過大にした場合、一般に熱効率が低下する主な理由として最も適切なものはどれか。

  1. 燃焼ガス量が増え、排ガスとして持ち去られる顕熱損失が増加するため
  2. 炉内圧力が必ず上昇し、放散熱損失がなくなるため
  3. 燃料中の水分が増加し、潜熱損失が増えるため
  4. 給水温度が急激に上昇し、蒸発量が過大になるため
正解と解説を見る

正解：燃焼ガス量が増え、排ガスとして持ち去られる顕熱損失が増加するため

過剰空気が多いと加熱すべき空気量が増え、排ガス顕熱損失が増加して効率が低下する。

問5（計測・制御）

蒸気配管の熱量を評価するため、流量と入口・出口エンタルピー差から熱量を求める式として最も適切なものはどれか。

  1. 熱量＝流量×圧力差
  2. 熱量＝体積×密度差×時間
  3. 熱量＝質量流量×エンタルピー差
  4. 熱量＝流量×比熱×温度差のみ
正解と解説を見る

正解：熱量＝質量流量×エンタルピー差

蒸気や温水の熱量は、質量流量に入口と出口の比エンタルピー差を掛けて求める。

問6（エネルギー総合管理）

エネルギー消費原単位を用いた管理で、分母として最も適切に選定すべきものはどれか。

  1. エネルギー使用量と密接に関係する生産量や延床面積など
  2. 電力会社からの請求金額のみ
  3. 管理しやすい任意の暦日数
  4. 前年の原油換算使用量そのもの
正解と解説を見る

正解：エネルギー使用量と密接に関係する生産量や延床面積など

原単位はエネルギー使用量を活動量で割る指標であり、活動量は使用量変動を合理的に説明できるものを選ぶ。
