中小企業診断士 予想問題の例

問1（経済学）

需要曲線が右にシフトする要因として最も適切なものはどれか。

  1. 生産技術の進歩
  2. 消費者の所得の増加
  3. 商品の価格の上昇
  4. 代替財の価格の下落
正解と解説を見る

正解：消費者の所得の増加

消費者の所得が増加すると、通常の財の需要が増え、需要曲線は右にシフトする。

問2（財務・会計）

売上高が1,000万円、売上原価が600万円、販売費及び一般管理費が250万円の場合、営業利益はいくらか？

  1. 100万円
  2. 200万円
  3. 50万円
  4. 150万円
正解と解説を見る

正解：150万円

営業利益は売上高から売上原価と販売費及び一般管理費を差し引いた額で、1,000 - 600 - 250 = 150万円となる。

問3（企業経営理論）

SWOT分析における「T」は何を指すか？

  1. 技術（Technology）
  2. タスク（Task）
  3. 脅威（Threats）
  4. トレンド（Trend）
正解と解説を見る

正解：脅威（Threats）

Tは外部環境の脅威（Threats）を意味し、経営戦略策定に重要な要素です。

問4（運営管理）

生産管理における「ジャスト・イン・タイム（JIT）」の主な目的は何か？

  1. 生産ラインの自動化を進める
  2. 製品の多品種少量生産を避ける
  3. 必要なものを、必要な時に、必要な量だけ生産する
  4. 在庫を最大限に保持する
正解と解説を見る

正解：必要なものを、必要な時に、必要な量だけ生産する

JITは在庫削減と無駄の排除を目的に、必要なものを必要なタイミングで生産する方式です。

問5（経営法務）

会社法における取締役会設置会社で、取締役の解任決議が株主総会で可決された場合、解任後の取締役の権限はどうなるか？

  1. 解任決議後も任期満了まで権限を持つ
  2. 株主総会の特別決議でなければ解任できない
  3. 裁判所の許可があるまで権限を保持する
  4. 解任決議の効力発生日以降は権限を失う
正解と解説を見る

正解：解任決議の効力発生日以降は権限を失う

取締役は株主総会の決議によりいつでも解任でき、解任決議が効力を生じた時点で権限を失う。

問6（経営情報システム）

システム開発において、ウォーターフォールモデルの特徴として正しいものはどれか。

  1. 開発過程が反復的かつ逐次的に進む
  2. 小規模プロジェクトに最も適している
  3. ユーザーの要求変更に柔軟に対応しやすい
  4. 各工程が順序通りに一方向に進み戻らない
正解と解説を見る

正解：各工程が順序通りに一方向に進み戻らない

ウォーターフォールモデルは各工程を順序通りに進め、一度完了した工程には基本的に戻らない特徴がある。
