気象予報士 予想問題の例

問1（予報業務に関する一般知識）

乾燥空気塊を断熱的に上昇させたとき、飽和に達する前の気温変化について正しいものはどれか。

  1. 乾燥断熱減率にほぼ従って低下する
  2. 潜熱放出によりほとんど変化しない
  3. 周囲の気温減率と常に同じになる
  4. 高度1kmにつき約3℃上昇する
正解と解説を見る

正解：乾燥断熱減率にほぼ従って低下する

未飽和の空気塊では凝結が起こらず、気圧低下による膨張で乾燥断熱減率に従い冷却する。

問2（予報業務に関する専門知識）

全球モデルとメソモデルの予報結果が降水域の位置で異なるとき、短期予報で最初に確認すべき観点として最も適切なものはどれか。

  1. 降水量の最大値だけを比較し、多い方を採用する
  2. 前回予報から変化が小さい方を自動的に採用する
  3. 実況の気圧場・前線位置・水蒸気場との整合を確認する
  4. 解像度が高いモデルを常に優先する
正解と解説を見る

正解：実況の気圧場・前線位置・水蒸気場との整合を確認する

短期予報ではモデル間比較だけでなく、実況解析との整合性を基準に予測シナリオを評価する。

問3（気象業務法規）

気象業務法の目的として最も適切なものはどれか。気象業務の健全な発達を図り、災害予防や交通安全など公共の福祉に寄与する趣旨を問う。

  1. 気象観測の成果をすべて非公開にし、国家機関だけで利用すること
  2. 気象業務の健全な発達を図り、災害の予防、交通安全、産業の興隆など公共の福祉を増進すること
  3. 気象庁の収益事業を拡大し、民間予報を原則として禁止すること
  4. 天気予報の的中率に応じて、予報業務許可を自動的に更新すること
正解と解説を見る

正解：気象業務の健全な発達を図り、災害の予防、交通安全、産業の興隆など公共の福祉を増進すること

気象業務法は、気象業務の健全な発達を通じて災害予防や交通安全等に資することを目的とする。

問4（実技試験）

地上天気図で日本海に中心気圧996hPaの低気圧があり、東側で等圧線が南北に混んでいる。東日本で最も警戒すべき現象はどれか。

  1. 南寄りの強風と暖湿気流による大雨
  2. 移動性高気圧による広範囲の霧
  3. 乾いた北西風による放射冷却の強化
  4. 寒気移流の弱まりによる快晴の持続
正解と解説を見る

正解：南寄りの強風と暖湿気流による大雨

低気圧東側では気圧傾度が大きく南風が強まり、暖湿気流が流入して降水が強まる。

問5（予報業務に関する一般知識）

相当温位について述べた次の文のうち、最も適切なものはどれか。

  1. 飽和空気では必ず高度とともに減少する
  2. 放射冷却の強さだけを表す指数である
  3. 水蒸気量が多い空気ほど、同じ温位でも相当温位は高くなりやすい
  4. 乾燥空気では温位と無関係に一定値をとる
正解と解説を見る

正解：水蒸気量が多い空気ほど、同じ温位でも相当温位は高くなりやすい

相当温位は温位に水蒸気の潜熱効果を含めた量で、湿った暖気ほど大きくなる。

問6（予報業務に関する専門知識）

数値予報モデルの初期値に含まれる解析誤差が、時間とともに予報誤差を拡大させる主な理由として最も適切なものはどれか。

  1. 観測値が予報時間中に自動で削除されるため
  2. 大気が非線形な力学系で、小さな誤差が成長し得るため
  3. 地形データが毎時更新されるため
  4. 気圧の単位が時間とともに変化するため
正解と解説を見る

正解：大気が非線形な力学系で、小さな誤差が成長し得るため

大気は非線形性が強く、初期値の小さな誤差も流れ場の中で増幅し予報精度を低下させる。
