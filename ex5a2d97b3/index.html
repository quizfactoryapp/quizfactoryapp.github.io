問1（民法相続）

被相続人に配偶者と子2人がいる。遺言がなく、子はいずれも相続放棄していない場合、配偶者の法定相続分として正しいものはどれか。

  1. 2分の1
  2. 3分の1
  3. 4分の3
  4. 3分の2
正解と解説を見る

正解：2分の1

配偶者と子が相続人の場合、配偶者が2分の1、子全体が2分の1を取得します。子の人数で配偶者分は変わりません。

問2（相続税務）

相続税の基礎控除額を計算する式として、現行制度上正しいものはどれか。なお、法定相続人の数は民法上の相続人を基礎とする。

  1. 3,000万円＋1,000万円×受遺者の数
  2. 5,000万円＋1,000万円×法定相続人の数
  3. 1億6,000万円＋600万円×相続人の数
  4. 3,000万円＋600万円×法定相続人の数
正解と解説を見る

正解：3,000万円＋600万円×法定相続人の数

相続税の基礎控除は3,000万円に法定相続人1人当たり600万円を加算して計算する。

問3（相続手続）

遺言書がなく、共同相続人が預金の分け方を決めるため遺産分割協議を行う場合、原則として必要な参加者は誰か。

  1. 被相続人と同居していた親族だけ
  2. 相続人のうち過半数の者
  3. 法定相続人全員
  4. 預金を受け取る相続人だけ
正解と解説を見る

正解：法定相続人全員

遺産分割協議は共同相続人全員で行う必要があり、一部の相続人を除いた協議は原則無効となる。

問4（金融資産承継）

共同相続人の一人が、遺産分割前に被相続人名義の普通預金から単独で払戻しを受ける場合の上限額として正しいものはどれか。

  1. 同一金融機関で常に300万円まで払戻しできる
  2. 口座ごとに残高の3分の1に自己の法定相続分を乗じた額が基準となる
  3. 相続人全員の同意がなければ一切払戻しできない
  4. 預金残高の全額を法定相続分に応じて払戻しできる
正解と解説を見る

正解：口座ごとに残高の3分の1に自己の法定相続分を乗じた額が基準となる

遺産分割前の預貯金払戻しは、残高の3分の1に法定相続分を乗じ、金融機関ごとの上限もある。

問5（民法相続）

被相続人の相続人が配偶者と父母2人である場合、父母それぞれの法定相続分として正しいものはどれか。

  1. 各3分の1
  2. 各2分の1
  3. 各4分の1
  4. 各6分の1
正解と解説を見る

正解：各6分の1

配偶者と直系尊属が相続人の場合、配偶者が3分の2、直系尊属全体が3分の1です。父母2人なら各6分の1です。

問6（相続税務）

被相続人に配偶者と子2人がいる場合、相続税の基礎控除額として正しいものはどれか。相続放棄はないものとする。

  1. 5,400万円
  2. 4,800万円
  3. 4,200万円
  4. 3,600万円
正解と解説を見る

正解：4,800万円

法定相続人は配偶者と子2人の計3人で、3,000万円＋600万円×3人＝4,800万円となる。
