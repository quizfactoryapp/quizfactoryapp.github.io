問1（民法・商法）

売買目的物に契約不適合があったため買主が代金減額を求める場合の要件として、民法上の原則に最も適切な説明はどれか。

  1. 契約不適合の程度を問わず、催告なくいつでも全額減額できる。
  2. 買主は相当期間を定めて追完を催告し、その期間内に追完がないとき減額請求できる。
  3. 買主は損害賠償請求を先にしなければ代金減額請求できない。
  4. 買主は契約解除をした後でなければ代金減額請求できない。
正解と解説を見る

正解：買主は相当期間を定めて追完を催告し、その期間内に追完がないとき減額請求できる。

代金減額請求は、原則として買主が追完を催告し、相当期間内に追完されないことが要件である。催告不要の場合は例外的に限定される。

問2（企業法務実務）

株主総会で定款変更を行う場面を想定する。会社法上の原則として必要となる決議要件の組合せとして、最も適切なものはどれか。

  1. 総株主の議決権の過半数
  2. 出席株主の議決権の過半数
  3. 総株主の議決権の4分の3以上
  4. 出席株主の議決権の3分の2以上（定足数要件あり）
正解と解説を見る

正解：出席株主の議決権の3分の2以上（定足数要件あり）

定款変更は原則として特別決議事項であり、定足数を満たした上で出席株主の議決権の3分の2以上の賛成が必要となる。

問3（労務・知財・競争法）

業績不振を理由に、会社が特定社員を突然解雇した。就業規則上の手続も経ず、配置転換などの回避努力もない場合、労働契約法上の評価として最も適切なのはどれか。

  1. 30日前予告または解雇予告手当の支払いがあれば解雇は必ず有効である。
  2. 解雇は使用者の経営判断に属するため原則として常に有効である。
  3. 労働者が当日に抗議しなければ、後日争うことはできず有効となる。
  4. 客観的合理性と社会通念上の相当性を欠くとして、解雇が無効となり得る。
正解と解説を見る

正解：客観的合理性と社会通念上の相当性を欠くとして、解雇が無効となり得る。

労働契約法16条は、解雇に客観的合理的理由と社会的相当性を要求する。回避努力や手続不備は、権利濫用として無効判断を強める事情となる。

問4（民法・商法）

契約不適合を理由とする買主の救済手段のうち、売主の帰責事由（責めに帰すべき事由）が必要となるものとして正しいものはどれか。

  1. 代金減額請求
  2. 契約解除
  3. 損害賠償請求
  4. 履行の追完請求
正解と解説を見る

正解：損害賠償請求

追完請求・減額請求・解除は帰責事由がなくても可能だが、損害賠償請求は債務不履行責任の要件として売主の帰責事由が必要になる。

問5（企業法務実務）

取締役会設置会社が株主総会を招集する場合、会社法上の原則として招集通知を発すべき時期として正しいものはどれか。

  1. 株主総会日の2週間前まで
  2. 株主総会日の1週間前まで
  3. 株主総会日の前日まで
  4. 株主総会日の3日前まで
正解と解説を見る

正解：株主総会日の2週間前まで

取締役会設置会社では、株主が議案を検討する期間を確保するため、原則として総会日の2週間前までに招集通知を発する。

問6（労務・知財・競争法）

会社が賃金体系を不利益に変更する就業規則改定を実施した。労働者の個別同意がない場合でも、労働契約法10条により拘束力が認められ得る要件として正しいものはどれか。

  1. 変更後規則の内容に合理性があり、かつ労働者へ周知されていること。
  2. 過半数代表者の同意があれば、他の事情を問わず常に有効となる。
  3. 労基署への届出を行えば、合理性や周知がなくても足りる。
  4. 就業規則に「会社は自由に変更できる」とあれば直ちに有効となる。
正解と解説を見る

正解：変更後規則の内容に合理性があり、かつ労働者へ周知されていること。

不利益変更でも、就業規則変更の合理性と周知性が満たされれば拘束力が生じ得る。形式的な同意条項や届出のみでは足りない。
