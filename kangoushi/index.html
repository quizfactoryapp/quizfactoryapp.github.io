問1（基礎看護学）

看護師が患者の全身状態を把握するために最初に行うアセスメントの方法として最も適切なのはどれか。

  1. 画像検査の実施
  2. 血液検査の結果確認
  3. 家族からの聞き取り
  4. 問診と視診による情報収集
正解と解説を見る

正解：問診と視診による情報収集

初期アセスメントでは、まず問診と視診によって患者の状態を把握することが重要です。

問2（成人看護学）

2型糖尿病でインスリン自己注射を行っている成人患者が、発熱と食欲不振で食事量が普段の半分以下になった。自宅での対応として最も適切なのはどれか。

  1. 食事が摂れない間は、水分も控えて安静を優先する。
  2. 血糖測定を増やし、水分摂取を心がけて医療機関へ相談する。
  3. 発熱時は血糖が下がりやすいため、糖質摂取を完全に避ける。
  4. 低血糖を避けるため、自己判断でインスリンを中止する。
正解と解説を見る

正解：血糖測定を増やし、水分摂取を心がけて医療機関へ相談する。

シックデイでは血糖が変動しやすく脱水も起こりやすい。自己判断でインスリンを中止せず、測定と水分補給、早めの相談が重要である。

問3（母性・小児看護）

妊娠初期における葉酸の摂取が推奨される主な理由はどれか。

  1. 妊娠糖尿病の予防
  2. 早産の予防
  3. 神経管閉鎖障害の予防
  4. 妊娠高血圧症候群の予防
正解と解説を見る

正解：神経管閉鎖障害の予防

葉酸は神経管閉鎖障害のリスクを減らすため、妊娠初期からの摂取が推奨される。

問4（精神・在宅看護）

統合失調症で外来通院中のAさんは、訪問看護師に「近所の人が自分を監視している」と訴え、不安が強い。訪問看護師の対応として最も適切なのはどれか。

  1. 妄想の内容を詳しく聞き出し、矛盾点を指摘する。
  2. 不安な気持ちを受け止め、生活への影響を確認する。
  3. 近所の人に事情を確認し、Aさんへ結果を伝える。
  4. 「監視されている事実はありません」と強く否定する。
正解と解説を見る

正解：不安な気持ちを受け止め、生活への影響を確認する。

妄想内容を否定・訂正するより、不安を受け止め安全や生活への影響を把握し、支援につなげる対応が適切である。

問5（基礎看護学）

院内感染を防止するために、最も基本的かつ重要な感染予防策はどれか。

  1. 使い捨て手袋の装着
  2. 頻回の換気
  3. 空調設備の清掃
  4. 手指衛生の徹底
正解と解説を見る

正解：手指衛生の徹底

手指衛生は感染予防の基本であり、すべての医療従事者が徹底すべきです。

問6（成人看護学）

慢性閉塞性肺疾患＜COPD＞で在宅酸素療法中の患者が、労作時の息切れ増強を訴えて外来を受診した。SpO2 88％、呼吸数24/分、意識清明である。看護師の対応として最も適切なのはどれか。

  1. 息切れを軽減するため仰臥位で安静にする。
  2. 呼吸仕事量を減らすため深く速い呼吸を続けるよう促す。
  3. 低酸素を改善するため酸素流量を自己判断で大幅に増やすよう説明する。
  4. 口すぼめ呼吸を促し、前傾座位をとらせる。
正解と解説を見る

正解：口すぼめ呼吸を促し、前傾座位をとらせる。

COPDの息切れ時は前傾座位と口すぼめ呼吸で呼気を延長し、気道虚脱を防ぎ換気を助ける。酸素流量変更は医師の指示下で行う。
