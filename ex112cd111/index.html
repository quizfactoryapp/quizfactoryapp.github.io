損害保険募集人一般試験 予想問題の例

問1（基礎単位）

損害保険の基本的な仕組みに関する説明として、最も適切なものはどれか。偶然な事故による損害を、多数の契約者で分担する制度である。

  1. 事故が発生した契約者だけが、事故後に保険料を負担する制度である。
  2. 事故の有無にかかわらず、支払った保険料が全額返還される制度である。
  3. 契約者が必ず利益を得ることを目的とした投資制度である。
  4. 多数の契約者が保険料を出し合い、偶然な事故による損害を補償する制度である。
正解と解説を見る

正解：多数の契約者が保険料を出し合い、偶然な事故による損害を補償する制度である。

損害保険は、多数の契約者が保険料を負担し、偶然な事故による経済的損害を補償する仕組みである。

問2（自動車保険単位）

自賠責保険で補償される損害として、正しいものはどれか。自動車事故により他人を死傷させた場合を前提とする。

  1. 相手方の自動車の修理費
  2. 被害者のけがによる治療費
  3. 運転者本人の車両損害
  4. 契約車両の盗難損害
正解と解説を見る

正解：被害者のけがによる治療費

自賠責保険は対人事故の被害者救済を目的とし、物損や車両損害は補償対象外です。

問3（火災・傷害疾病保険単位）

住宅の火災保険で保険の目的を定める場合の説明として、最も適切なものはどれか。建物と家財の扱いに着目して選びなさい。

  1. 門や塀は、どの契約でも家財として取り扱われる。
  2. 建物と家財は別の保険の目的であり、補償するにはそれぞれ契約で明示する。
  3. 家財だけを保険の目的とする契約は、法律上認められていない。
  4. 建物を契約すれば、同じ敷地内の家財は常に自動的に補償される。
正解と解説を見る

正解：建物と家財は別の保険の目的であり、補償するにはそれぞれ契約で明示する。

火災保険では建物と家財を区分して保険の目的にします。補償対象は申込内容で確認する必要があります。

問4（基礎単位）

損害保険における利得禁止の原則に関する説明として、最も適切なものはどれか。

  1. 契約者は、事故がなくても一定額の保険金を受け取ることができる。
  2. 保険金は、実際の損害額を超えて支払われるのが原則である。
  3. 保険によって、被保険者が実際の損害を超える利益を得ることは認められない。
  4. 保険金額は、常に保険価額より高く設定しなければならない。
正解と解説を見る

正解：保険によって、被保険者が実際の損害を超える利益を得ることは認められない。

損害保険は損害の補てんを目的とするため、保険事故で損害額を超える利得を得ることは原則認められない。

問5（自動車保険単位）

対人賠償保険の説明として、最も適切なものはどれか。自賠責保険で支払われる金額がある事故を想定する。

  1. 運転者本人のけがを法律上当然に補償する
  2. 事故相手の所有物の損害だけを補償する
  3. 契約自動車の修理費だけを補償する
  4. 自賠責保険の支払額を超える対人賠償責任を補償する
正解と解説を見る

正解：自賠責保険の支払額を超える対人賠償責任を補償する

対人賠償保険は、他人を死傷させた場合の法律上の賠償責任を、自賠責超過部分中心に補償します。

問6（火災・傷害疾病保険単位）

火災保険の基本的な補償に関する次の記述のうち、一般に正しいものはどれか。偶然な事故による損害を前提に考えなさい。

  1. 経年劣化だけで屋根が傷んだ場合は、火災事故がないため必ず全額補償される。
  2. 火災、落雷、破裂・爆発など、約款で定める事故による損害が補償対象となる。
  3. 被保険者の故意による火災でも、近隣へ延焼していれば自己の損害は補償される。
  4. 地震による火災損害は、火災保険だけで常に全額補償される。
正解と解説を見る

正解：火災、落雷、破裂・爆発など、約款で定める事故による損害が補償対象となる。

火災保険は約款で定める偶然な事故を補償します。故意、自然消耗、地震火災などは扱いが異なります。
