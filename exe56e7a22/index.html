技術士第一次試験 予想問題の例

問1（基礎科目）

製品開発の初期段階でQFDを用いる主な目的として、最も適切なものはどれか。

  1. 作業者の勤務表を自動作成する
  2. 設備の減価償却費を計算する
  3. 顧客要求を設計特性へ体系的に展開する
  4. 完成品の市場価格だけを決定する
正解と解説を見る

正解：顧客要求を設計特性へ体系的に展開する

QFDは顧客の声を品質特性や設計仕様に変換し、設計計画へ反映する手法である。

問2（適性科目）

公共施設の設計で、発注者から安全率を下げれば工期と費用を削減できると強く求められた。技術者の対応として最も適切なものはどれか。

  1. 責任は発注者にあるとして、指示どおりに進める。
  2. 費用削減は公益にかなうため、安全率低下を受け入れる。
  3. 法令や基準、安全性への影響を説明し、必要なら変更を拒む。
  4. 発注者の意向を優先し、記録を残さず設計を変更する。
正解と解説を見る

正解：法令や基準、安全性への影響を説明し、必要なら変更を拒む。

技術者は発注者より公益と安全を優先し、根拠を示して不適切な要求を拒む責務がある。

問3（専門科目）

機械材料において、炭素鋼を焼入れした後に焼戻しを行う主な目的として最も適切なものはどれか。

  1. 結晶粒を粗大化し、硬さを最大化する
  2. 炭素含有量を増加させ、密度を高める
  3. 表面だけを溶融させ、耐食性を付与する
  4. 内部応力を低減し、靭性を改善する
正解と解説を見る

正解：内部応力を低減し、靭性を改善する

焼戻しは焼入れ後の脆さや内部応力を緩和し、必要な硬さを保ちながら靭性を高める処理である。

問4（技術基礎）

管理図において、工程が統計的管理状態にあると判断する根拠として最も適切なものはどれか。

  1. 平均値が目標値と完全に一致している
  2. 規格限界を一度も超えていない
  3. 点がすべて中心線上に並んでいる
  4. 点のばらつきに異常な傾向や管理限界外れがない
正解と解説を見る

正解：点のばらつきに異常な傾向や管理限界外れがない

管理状態は偶然原因による変動のみとみなせる状態で、管理限界外れや連などの異常がないことで判断する。

問5（基礎科目）

フェールセーフ設計の考え方として、最も適切なものはどれか。

  1. 通常運転時の効率だけを最大化する
  2. 故障時にも安全側の状態となるよう設計する
  3. 故障確率を計算せずに部品点数を増やす
  4. 保守作業をすべて利用者に任せる
正解と解説を見る

正解：故障時にも安全側の状態となるよう設計する

フェールセーフは故障や誤操作が起きても危険な状態に至らないようにする安全設計思想である。

問6（適性科目）

業務で知った顧客企業の未公表技術情報について、友人から投資判断の参考にしたいと相談された。適切な行動はどれか。

  1. 友人が秘密を守るなら、口頭で限定的に伝える。
  2. 個人的な相談で利益を得ないなら、情報提供してよい。
  3. 秘密保持義務を理由に情報提供を断り、必要に応じて社内規程に従う。
  4. 企業名を伏せれば問題ないので、技術の概要だけ伝える。
正解と解説を見る

正解：秘密保持義務を理由に情報提供を断り、必要に応じて社内規程に従う。

未公表情報は業務上の秘密であり、相手や目的にかかわらず無断開示してはならない。
