給水装置工事主任技術者 予想問題の例

問1（公衆衛生概論）

水道水を介して集団発生しやすい感染症として、病原体が細菌であり、激しい水様性下痢を主症状とするものはどれか。

  1. コレラ
  2. 麻しん
  3. 破傷風
  4. 日本脳炎
正解と解説を見る

正解：コレラ

コレラはコレラ菌による水系感染症で、汚染水を介して広がり、激しい水様性下痢を起こす。

問2（水道行政）

水道法の目的として最も適切なものはどれか。水道行政の基本理念に照らし、法第1条の趣旨に合うものを選べ。

  1. 水道事業の収益性を高め、民間投資を優先して配水区域を拡大すること
  2. 清浄で豊富低廉な水の供給を図り、公衆衛生の向上と生活環境の改善に寄与すること
  3. 水質検査を省略して料金を低減し、利用者負担を最小化すること
  4. すべての給水装置工事を国が直接施工し、地方公共団体の関与を排除すること
正解と解説を見る

正解：清浄で豊富低廉な水の供給を図り、公衆衛生の向上と生活環境の改善に寄与すること

水道法は清浄・豊富・低廉な水の供給により、公衆衛生と生活環境の向上を図る法律である。

問3（給水装置工事法）

給水管を宅地内に埋設する施工で、凍結や外力による破損を防ぐ観点から最も適切な措置はどれか。

  1. 浅く埋設して点検しやすくする
  2. 所定の土かぶりを確保し、必要に応じて防護する
  3. 管の上部に空洞を残して沈下を防ぐ
  4. 埋戻し土に大きな石を混入させる
正解と解説を見る

正解：所定の土かぶりを確保し、必要に応じて防護する

埋設管は所定の土かぶりと良質な埋戻しにより、凍結、荷重、衝撃から保護する必要がある。

問4（構造及び性能）

減圧式逆流防止器を給水装置に設置する場合の取扱いとして、最も適切なものはどれか。

  1. 常時水没するピット内に設置し、凍結防止を優先する。
  2. 点検・排水が可能な場所に水平に設置し、定期点検を行う。
  3. 排水口をふさぎ、漏水時の水量を抑える。
  4. 二次側圧力が一次側より高い場所では省略できる。
正解と解説を見る

正解：点検・排水が可能な場所に水平に設置し、定期点検を行う。

減圧式逆流防止器は逃し弁から排水するため、水没を避け、点検と排水が可能な場所に設置する。

問5（給水装置計画論）

集合住宅の給水装置計画で同時使用水量を算定する際、一般に最も適切な考え方はどれか。

  1. 水道メーター口径だけで使用水量を一律に決定する。
  2. 最上階の器具数だけを対象として使用水量を算定する。
  3. 全戸のすべての給水栓が常時同時に使用されるものとして算定する。
  4. 器具数や戸数に応じた同時使用率を考慮して算定する。
正解と解説を見る

正解：器具数や戸数に応じた同時使用率を考慮して算定する。

集合住宅では全器具同時使用は過大となるため、戸数や器具数に応じた同時使用率を用いる。

問6（公衆衛生概論）

水道法に基づく水質基準で、大腸菌の基準として正しいものはどれか。飲料水の安全性確認に関する基本事項である。

  1. 臭気がないこと
  2. 1mL中100個以下であること
  3. 100mL中10個以下であること
  4. 検出されないこと
正解と解説を見る

正解：検出されないこと

大腸菌はふん便汚染の重要な指標であり、水道水の水質基準では検出されないこととされる。
